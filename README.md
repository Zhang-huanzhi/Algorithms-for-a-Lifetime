## Learning plan

### Stage 1: Reach green

Practice ABC problems around contests 400–470, mainly A–D, to build problem-solving intuition. The target is a rating of 800+ (green).

### Stage 2: Aim for light blue

After building experience through contest problems, move to more systematic training:

- Main track: `tessoku-book` (The Essentials of Competitive Programming)
- Side tracks: EDPC, Typical 90, selected problem sets, and related topics
