# C - Chokudai Addiction / Chokutter 成瘾

**时间限制**: 2秒 / **内存限制**: 1024 MiB  
**分数**: 300分

## 问题描述

AtCoder 公司在时刻 0 开始上班，在时刻 T 下班。时刻 t 和时刻 t+1 之间的间隔是 1 秒。

高桥君在 AtCoder 公司的工作时间内按照以下规则查看 SNS"chokutter"：

- 上班的同时打开 chokutter。
- 如果青木君经过高桥君的桌子后面时，高桥君正在看 chokutter，则立即关闭 chokutter。
- 高桥君在时刻 t 关闭 chokutter 后，必定会在时刻 t+100 重新打开 chokutter。

从上班到下班期间，青木君共经过高桥君的桌子后面 N 次，其中第 i 次是在时刻 A_i。

从上班到下班，高桥君总共看了多少秒 chokutter？

注意：青木君不会在高桥君刚打开 chokutter 的瞬间经过桌子后面。

## 约束条件

- 所有输入都是整数
- 0 ≤ N ≤ 3×10^5
- 1 ≤ A_1 < A_2 < ⋯ < A_N ≤ T ≤ 10^9
- 青木君不会在高桥君打开 chokutter 的瞬间经过桌子后面

## 输入格式

```
N T
A_1 A_2 … A_N
```

## 输出格式

输出答案。

## 输入样例 1

```
5 700
100 150 300 350 700
```

## 输出样例 1

```
500
```

**说明**：

- 时刻 0：高桥君打开 chokutter。
- 时刻 100：青木君经过高桥君的桌子后面，高桥君立即关闭 chokutter。
- 时刻 150：青木君经过高桥君的桌子后面，但高桥君此时没有打开 chokutter。
- 时刻 200：高桥君重新打开 chokutter。
- 时刻 300：青木君经过高桥君的桌子后面，高桥君立即关闭 chokutter。
- 时刻 350：青木君经过高桥君的桌子后面，但高桥君此时没有打开 chokutter。
- 时刻 400：高桥君重新打开 chokutter。
- 时刻 700：青木君经过高桥君的桌子后面，高桥君立即关闭 chokutter。

高桥君总共看了 500 秒 chokutter。
