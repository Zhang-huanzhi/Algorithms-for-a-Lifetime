1. **CPython 是纯解释器**：像一个翻译官，看一句翻译一句，干活比较细但慢。
    
2. **PyPy 是带有“即时编译器”的解释器**：它会观察哪些活儿干得最频繁，然后把这部分活儿直接变成机器指令，干活极快。
    

### 竞赛建议：

- **默认选 PyPy 3**：能显著提升你的代码通过率，防止因为 Python 语言本身的性能问题而超时。
    
- **只有要用 NumPy 时选 CPython**：如果你这道题打算写 import numpy，那只能回过头来选 CPython。

### 1. Python (CPython 3.11.4 / 3.13.7)

- **身份**：这是最基础、最标准的 Python，也是你在电脑上从官网下载的那个版本。
    
- **原理**：它是**解释执行**的。它把你的代码转换成字节码，然后一行行解释运行。
    
- **特点**：
    
    - **库支持最全**：如果你想用 numpy, scipy, networkx 等第三方库，**必须选它**。
        
    - **启动快**：程序开始运行那一刻很快。
        
    - **运行慢**：如果你的代码里有巨大的 for 循环，它的执行效率比较低。
        
- **适用场景**：题目需要用到 NumPy 等高级数学库，或者题目对运行速度要求不严。
    

### 2. Python (PyPy 3.10 / 3.11)

- **身份**：这是 Python 的一个“加速版”实现。
    
- **原理**：它带有一个 **JIT (Just-In-Time) 编译器**。它会在程序运行时，实时把经常执行的代码（比如循环）翻译成机器码。
    
- **特点**：
    
    - **速度极快**：对于算法竞赛中最常见的 for 循环、递归，PyPy 通常比 CPython 快 **5 到 10 倍**。
        
    - **内存消耗大**：因为要缓存翻译好的机器码，它占用的内存比 CPython 多。
        
    - **库支持差**：在 AtCoder 环境下，PyPy 通常**不支持** NumPy。
        
- **适用场景**：**绝大多数算法题的默认选择**。只要你不打算用 NumPy，选 PyPy 准没错，它能帮你避免很多由于 Python 本身运行慢导致的 TLE（超时）。
