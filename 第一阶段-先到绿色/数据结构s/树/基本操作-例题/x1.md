题目：`树的基础操作练习`

给你一棵树，根节点固定为 `1`。请完成 3 个最基础操作：

1. 求每个点的父节点 `parent[i]`（根的父节点记为 `0`）
2. 求每个点的深度 `depth[i]`（根深度为 `0`）
3. 求每个点的子树大小 `size[i]`（包含自己）

输入格式：
```text
N
u1 v1
u2 v2
...
u(N-1) v(N-1)
```

输出格式：
```text
parent[1..N]
depth[1..N]
size[1..N]
```
每行输出一组，空格分隔。

样例输入：
```text
5
1 2
1 3
3 4
3 5
```

样例输出：
```text
0 1 1 3 3
0 1 1 2 2
5 1 3 1 1
```

解释：
- `parent`: 1 的父是 0，2 和 3 的父是 1，4 和 5 的父是 3
- `depth`: 根 1 深度 0，2/3 深度 1，4/5 深度 2
- `size`: 1 的子树有 5 个点，3 的子树有 3 个点，叶子都是 1

提示：
- 邻接表建树
- `dfs(u, p)` 时顺便维护 `parent/depth`
- 回溯时累加 `size[u] += size[v]`
