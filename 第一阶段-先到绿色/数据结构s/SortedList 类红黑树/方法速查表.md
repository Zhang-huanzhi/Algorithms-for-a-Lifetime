### 一、基础操作速查表

| 操作分类 | 方法 / 语法 | 说明 | 时间复杂度 |
| :--- | :--- | :--- | :--- |
| **导包** | `from sortedcontainers import SortedList` | 导入模块 | - |
| **初始化** | `sl = SortedList()` | 创建空有序列表 | $O(1)$ |
| | `sl = SortedList([3, 1, 2])` | 用可迭代对象初始化（自动排序为 `[1, 2, 3]`） | $O(N \log N)$ |
| **插入** | `sl.add(val)` | 插入一个元素 `val`，保持有序 | $O(\log N)$ |
| | `sl.update(iterable)` | 批量插入多个元素 | $O(K \log N)$ |
| **删除** | `sl.remove(val)` | 删除元素 `val`（**不存在会报 `ValueError`**） | $O(\log N)$ |
| | `sl.discard(val)` | 安全删除元素 `val`（**不存在也不会报错**） | $O(\log N)$ |
| | `sl.pop(index=-1)` | 删除并返回指定**索引**处的元素（默认删末尾） | $O(\log N)$ |
| | `del sl[i]` 或 `del sl[i:j]` | 按索引或切片删除 | $O(\log N)$ |
| | `sl.clear()` | 清空列表 | $O(1)$ |
| **查找/二分** | `sl.bisect_left(val)` | 找到 $\ge val$ 的第一个位置索引 | $O(\log N)$ |
| | `sl.bisect_right(val)` | 找到 $> val$ 的第一个位置索引 | $O(\log N)$ |
| | `val in sl` | 判断元素是否存在 | $O(\log N)$ |
| | `sl.count(val)` | 统计 `val` 出现的次数 | $O(\log N)$ |
| | `sl.index(val)` | 获取 `val` 首次出现的下标 | $O(\log N)$ |
| **访问/最值** | `sl[0]` / `sl[-1]` | 获取最小值 / 最大值 | $O(1)$ |
| | `sl[k]` | 按排名访问第 $k$ 小的元素（支持负索引） | $O(\log N)$ |
| | `len(sl)` | 获取元素总数 | $O(1)$ |

### 二、算法题常用套路代码

#### 1. 查找前驱（小于 $x$ 的最大数）与后继（大于 $x$ 的最小数）
```python
# 找后继（严格大于 x 的最小值）
idx = sl.bisect_right(x)
successor = sl[idx] if idx < len(sl) else None

# 找前驱（严格小于 x 的最大值）
idx = sl.bisect_left(x)
predecessor = sl[idx - 1] if idx > 0 else None
```

#### 2. 统计区间 $[L, R]$ 内的元素个数
```python
# 闭区间 [L, R] 内的元素个数
count = sl.bisect_right(R) - sl.bisect_left(L)
```

#### 3. 范围迭代（`irange`）—— 极高效的范围遍历
比切片 `sl[i:j]` 更快，因为它是**惰性生成器**，不需要复制创建新列表。
```python
# 遍历 [min_val, max_val] 之间的所有元素
for x in sl.irange(min_val=10, max_val=50, inclusive=(True, True)):
    print(x)
```

### 三、使用避坑指南 ⚠️

1. **不要直接修改元素的值**：
   * ❌ 错误：`sl[0] = 100`（`SortedList` 禁止通过下标直接赋值修改，会打破有序性）。
   * 正确做法：先 `sl.pop(0)` 或 `sl.remove(...)`，再 `sl.add(100)`。

2. **`remove()` vs `discard()`**：
   * 不确定元素在不在列表里时，优先用 `discard()`，避免抛异常中断程序。

3. **支持重复元素**：
   * `SortedList` 相当于 C++ 的 `std::multiset`，**允许存入重复值**。
   * 如果你需要去重（类似 `std::set`），可以使用同库中的 `SortedSet`：
     ```python
     from sortedcontainers import SortedSet
     ss = SortedSet([1, 2, 2, 3])  # 内部为 [1, 2, 3]
     ```
