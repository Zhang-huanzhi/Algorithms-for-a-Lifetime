### 两种解法的对比

| 维度 | 双指针法（拆分正负） | `SortedList`（平衡树） |
| :--- | :--- | :--- |
| **思维成本** | 需要观察出“已捡饼干必定从 0 向两边连续扩展” | **零思维成本**，直接按题意二分查找最近点 |
| **时间复杂度** | 排序 $O(N \log N)$ + 模拟 $O(N)$ | 查找与删除均为 $O(N \log N)$ |
| **常数与耗时** | 极快（纯列表与指针操作，~0.15s） | 稍慢一些（树结构操作，~0.6s，但 2.0s 限制下毫无压力） |
| **扩展性** | 适合静态数轴 | 如果后续**动态掉落新饼干**，这种写法可直接无缝支持 |
# 双指针Code
``` python
 import sys
from sortedcontainers import SortedList

def main():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    arr = list(map(int, input_data[1:]))

    # 初始化有序列表，底层为类似平衡树的高效数据结构
    sl = SortedList(arr)
    
    curr = 0
    total_dist = 0

    for _ in range(n):
        # 找到大于等于 curr 的第一个元素下标
        idx = sl.bisect_left(curr)
        
        # 左右两边的候选饼干
        cand_l = sl[idx - 1] if idx > 0 else None
        cand_r = sl[idx] if idx < len(sl) else None

        # 计算两边距离
        d_l = abs(curr - cand_l) if cand_l is not None else float('inf')
        d_r = abs(curr - cand_r) if cand_r is not None else float('inf')

        # 优先选距离近的；相等时优先选较小的坐标（左边）
        if d_l <= d_r:
            total_dist += d_l
            curr = cand_l
            sl.pop(idx - 1)  # 删除左侧饼干，复杂度 O(log N)
        else:
            total_dist += d_r
            curr = cand_r
            sl.pop(idx)      # 删除右侧饼干，复杂度 O(log N)

    print(total_dist)

if __name__ == "__main__":
    main()
```
