## C - 水洼 (Puddles)  
  
执行时间限制：2 秒 / 内存限制：1024 MiB    
分值：300 点  
  
### 题目描述  
  
给定一个 `H` 行 `W` 列的网格。  从上往下第 `i` 行、从左往右第 `j` 列的单元格记为 `(i, j)`。  如果 `S_{i,j}` 为 `#`，则该格为黑色；如果为 `.`，则该格为白色。  请计算：由白色单元格组成的、被黑色单元格完全包围的四连通区域的数量。  
  
更严密的定义如下：  
  
- 相邻：两个单元格 `(i, j)` 和 `(i', j')` 相邻，当且仅当它们共享一条边（即 `|i−i'|+|j−j'|=1`）。  
- 连通：一个白色单元格集合 `C` 是连通的，是指对于 `C` 中的任意两个单元格 `c` 和 `c'`，都可以通过只经过 `C` 中相邻单元格的方式从 `c` 到达 `c'`。  
- 白色连通块：一个非空的、极大的白色单元格连通集合（即不能再合并更多相邻白格的独立区域）。  
  
目标：计算满足以下条件的“白色连通块”的数量：该连通块不包含网格最外周（即第 `1` 行、第 `H` 行、第 `1` 列、第 `W` 列）的任何单元格。  
  
### 约束条件  
  
- `3 ≤ H, W ≤ 10^3`  
- `H, W` 是整数  
- `S_{i,j}` 是 `#` 或 `.`  
  
### 输入格式  
  
输入按以下格式从标准输入给出：  
  
```  
H W  
S_{1,1} S_{1,2} … S_{1,W}  
⋮  
S_{H,1} S_{H,2} … S_{H,W}  
```  
  
### 输出格式  
  
输出一个整数，表示符合条件的白色连通块的数量。  
  
### 样例说明  
  
样例 1 输入：  
```  
5 15  
##########..###  
#...#######.###  
####....###..##  
######.########  
########....###  
```  
输出：  
```  
2  
```  
解释：共有 2 个符合条件的区域：  
- 位于第 2 行，第 2,3,4 列的 3 个白色单元格组成的区域。  
- 位于第 3 行第 5,6,7,8 列以及第 4 行第 7 列，共 5 个白色单元格组成的区域。  
（注意：右上角和右下角的白格接触到了边缘，因此不计入答案。）  
  
样例 2 输入：  
```  
10 22  
######################  
####.#################  
###...################  
##.###.##.....########  
##.....##.####.#######  
.######.#......#.....#  
.######.#.####.#.#####  
#########.....##.#####  
################.#####  
################.....#  
```  
输出：  
```  
4  
```
