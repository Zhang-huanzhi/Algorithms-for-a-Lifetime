#### 用“全局变量 + 原生 list”模拟 Ring Buffer（最高效打法）
当题目既需要“头部操作/整体位移”，又需要“随机访问”时，**不要去写一个完整的 RingBuffer 类**，而是直接用一个原生 `list`，外加一个独立的整数变量 `offset`。

这就是为什么我当时给你写的代码是这样的：
```python
arr = list(range(1, n + 1))  # 原生 C 语言优化的 list
offset = 0                   # 独立变量模拟 head 指针

# 每次操作时，只做极简的数学运算
actual_index = (offset + p - 1) % n  
print(arr[actual_index])
```

这种写法**没有面向对象的开销，没有函数调用的开销**，把纯 Python 的执行负担降到了最低，是竞赛中应对这种题目的唯一正解。
