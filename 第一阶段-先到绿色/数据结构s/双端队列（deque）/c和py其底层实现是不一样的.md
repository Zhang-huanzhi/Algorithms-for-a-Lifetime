
### 1. Python 的 `deque` 底层：**双向链表 + 数组块**
* **结构**：由多个固定大小的“块（Block）”组成一个**双向链表**。在 CPython 中，每个块是一个可以容纳 **64 个元素** 的数组。
* **特点**：
  * **两端操作**：极快，均为 $O(1)$ 复杂度。
  * **随机访问**（如 `dq[i]`）：**较慢，为 $O(N)$**。因为需要沿着双向链表逐个块进行遍历查找。

---

### 2. C++ 的 `std::deque` 底层：**中控数组 + 连续块**
* **结构**：采用一个**中控图（Map，本质是一个指针数组）**，中控图中的每个指针指向一个固定大小的连续内存块（Buffer）。
* **特点**：
  * **两端操作**：极快，均为 $O(1)$ 复杂度。
  * **随机访问**（如 `dq[i]`）：**极快，为 $O(1)$**。通过双重指针计算（先算在第几个块，再算块内偏移），可以直接定位元素，不需要遍历。

---

### 对比总结

| 特性 | Python `deque` | C++ `std::deque` |
| :--- | :--- | :--- |
| **底层骨架** | 双向链表（连接各个块） | 中控指针数组（管理各个块） |
| **两端加减** | $O(1)$ | $O(1)$ |
| **随机访问 `dq[i]`** | **$O(N)$**（需要遍历链表） | **$O(1)$**（通过数学计算直接寻址） |
