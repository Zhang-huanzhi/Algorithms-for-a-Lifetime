``` python
	pre = [0] * (10**9 + 1)
```

不能这样初始化，因为这会直接超出系统的内存限制，导致 Python 抛出 `MemoryError` 异常而崩溃（在 OJ 上表现为 RE）。

---

以下是具体的物理原因和内存计算：

在 64 位的计算机系统（评测机）中，Python 的列表（`list`）在底层是一个**指针数组**（每个元素都是指向 Python 对象的指针）。

- 每个指针在 64 位系统下占用 **8 字节**（bytes）。
- 当你创建 `[0] * 10**9` 时，即使所有的位置都指向同一个数字 `0`，Python 也必须在内存中开辟一个能够容纳 $10^9$ 个指针的连续空间。

我们来计算一下这个列表本身的开销：
$$\text{内存开销} = 10^9 \times 8 \text{ 字节} = 8,000,000,000 \text{ 字节} \approx \mathbf{8\text{ GB}}$$
