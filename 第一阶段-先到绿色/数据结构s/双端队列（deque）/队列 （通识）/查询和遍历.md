Python中的`deque`（双端队列）来自`collections`模块，遍历和查询方式如下：

**遍历方法：**
```python
from collections import deque

d = deque([1, 2, 3, 4, 5])

# 1. for循环直接遍历
for item in d:
    print(item)

# 2. 索引遍历
for i in range(len(d)):
    print(d[i])

# 3. enumerate遍历
for idx, val in enumerate(d):
    print(idx, val)
```

**查询方法：**
```python
# 1. 索引访问（支持正负索引）
first = d[0]    # 第一个元素
last = d[-1]    # 最后一个元素

# 2. count() - 统计元素出现次数
count = d.count(3)

# 3. index() - 查找元素首次出现的索引
idx = d.index(3)  # 可选参数：start, stop

# 4. in 运算符 - 检查元素是否存在
if 3 in d:
    print("存在")
```

**注意：** deque的索引访问`O(n)`比list慢，但两端操作`O(1)`很快。如果需要频繁随机访问，用list更好；如果主要在两端操作，用deque更优。
