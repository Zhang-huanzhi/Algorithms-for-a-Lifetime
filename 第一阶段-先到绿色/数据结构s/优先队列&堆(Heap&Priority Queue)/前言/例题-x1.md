### 题目：折扣购买 (Discount)

**问题陈述**  
你有 NN 件商品，第 ii 件商品的价格为 AiAi​ 日元。  
你有 MM 张优惠券。每使用一张优惠券作用于价格为 XX 的商品，该商品的价格将变为 ⌊X/2⌋⌊X/2⌋（向下取整）。  
你可以对同一件商品使用多张优惠券。  
请计算购买所有 NN 件商品所需的最小总金额。

**约束条件**

- 1≤N,M≤1051≤N,M≤105
- 1≤Ai≤1091≤Ai​≤109

**输入**  
输入通过标准输入给出：  
NN MM  
A1A1​ A2A2​ …… ANAN​

### 样例 1
**输入**
```text
3 3
2 13 8
```
**输出**
```text
9
```
**解释**：
1. 对 13 使用：13 -> 6。价格变为 {2, 6, 8}。
2. 对 8 使用：8 -> 4。价格变为 {2, 6, 4}。
3. 对 6 使用：6 -> 3。价格变为 {2, 3, 4}。
总和：2 + 3 + 4 = 9。

### 样例 2
**输入**
```text
4 4
1 9 3 5
```
**输出**
```text
6
```

### Python 实现补充

由于 Python 的 `heapq` 默认是最小堆，我们需要通过取负数的方式来实现最大堆。

````python
import sys
import heapq
# ...existing code...
def main():
    n, m = map(int, sys.stdin.readline().split())
    a = list(map(int, sys.stdin.readline().split()))
    
    # Python heapq 是最小堆，通过取负数模拟最大堆
    hq = [-x for x in a]
    heapq.heapify(hq)
    
    for _ in range(m):
        # 取出当前最大值的负数
        max_val = -heapq.heappop(hq)
        # 折扣后重新放入
        heapq.heappush(hq, -(max_val // 2))
    
    # 结果取负数之和的相反数
    print(-sum(hq))

if __name__ == "__main__":
    main()
````

### 解题思路

为了使总金额最小，我们应该每次都将优惠券用在当前价格最高的商品上。这可以使用**优先队列（最大堆）**来高效实现。

1. 将所有价格 AiAi​ 放入一个最大堆中。
2. 重复 MM 次以下操作：
    - 取出堆顶元素（最大值）XX。
    - 将 ⌊X/2⌋⌊X/2⌋ 重新放回堆中。
3. 最后，累加堆中所有元素的和。
