**D - Chalkboard Median (黑板上的中位数)**  
**运行时间限制:** 2 sec / **内存限制:** 1024 MiB  
**分值:** 400 分

### 题目描述
黑板上写着 $1$ 个整数 $X$。

接下来会给出 $Q$ 个查询，请依次处理。
第 $i$ ($1 \leq i \leq Q$) 个查询如下：

- 给出 $2$ 个整数 $A_i, B_i$。在黑板上新写下这 $2$ 个整数 $A_i$ 和 $B_i$。
- 然后，输出黑板上写着的 $2i+1$ 个整数的中位数。

### 约束条件
- $1 \leq X \leq 10^9$
- $1 \leq Q \leq 2 \times 10^5$
- $1 \leq A_i, B_i \leq 10^9$
- 输入的值均为整数

### 输入格式
输入将由标准输入按以下格式给出：
> $X$
> $Q$
> $A_1$ $B_1$
> $A_2$ $B_2$
> $\vdots$
> $A_Q$ $B_Q$

### 输出格式
输出 $Q$ 行。
第 $i$ 行输出第 $i$ 个查询的答案。

---

### 样例输入 1
```text
5
3
2 3
1 2
8 9
```

### 样例输出 1
```text
3
2
3
```
**样例 1 说明：**
- 在第 $1$ 个查询中，黑板上的整数变为 $5, 2, 3$，这些整数的中位数是 $3$。
- 在第 $2$ 个查询中，黑板上的整数变为 $5, 2, 3, 1, 2$，这些整数的中位数是 $2$。
- 在第 $3$ 个查询中，黑板上的整数变为 $5, 2, 3, 1, 2, 8, 9$，这些整数的中位数是 $3$。
