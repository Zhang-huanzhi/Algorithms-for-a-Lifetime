
| 特征       | update (往上加) 📈             | query (往下减) 📉          |
| -------- | --------------------------- | ----------------------- |
| **操作目的** | **改变**树的值                   | **累加**树的值               |
| **核心语句** | tree[i] += delta            | res += tree[i]          |
| **指针走向** | i += lowbit(i) (**加号**)     | i -= lowbit(i) (**减号**) |
| **循环条件** | while i <= self.n (**找上限**) | while i > 0 (**找下限**)   |

**肌肉记忆口诀：**

- update 是**生长**：指针**加** lowbit，跑到 n 结束。
    
- query 是**收缩**：指针**减** lowbit，跑到 0 结束。
