## 版本二：函数式写法（适合快速刷题）

代码简洁，适合竞赛和快速实现。

python

```python
# 全局变量定义
n = 100005
tree = [0] * (n + 1)

def lowbit(x):
    """提取最低位的 1"""
    return x & -x

def add(i, val):
    """单点更新：在位置 i 增加 val"""
    while i <= n:
        tree[i] += val
        i += lowbit(i)

def ask(i):
    """前缀和查询：返回 [1, i] 的和"""
    res = 0
    while i > 0:
        res += tree[i]
        i -= lowbit(i)
    return res

def ask_range(l, r):
    """区间和查询：返回 [l, r] 的和"""
    return ask(r) - ask(l - 1)


# === 使用示例 ===
add(3, 5)               # 在下标 3 加 5
print(ask(3))           # 查询前 3 个数的和
print(ask_range(2, 5))  # 查询 [2, 5] 的区间和
```
