## 核心要点总结

|操作|时间复杂度|说明|
|---|---|---|
|`lowbit(x)`|O(1)|提取 x 二进制最低位的 1|
|`update(i, delta)`|O(log n)|单点更新|
|`query(i)`|O(log n)|前缀和查询|
|`query_range(l, r)`|O(log n)|区间和查询|

### 关键理解

1. **lowbit 操作**：`x & -x` 提取最低位的 1
    - 例如：`lowbit(6) = 2`（6 的二进制是 110）
2. **update 向上爬**：`i += lowbit(i)` 更新所有包含 i 的父节点
3. **query 向下走**：`i -= lowbit(i)` 累加所有子区间的和
4. **下标从 1 开始**：树状数组约定俗成从下标 1 开始使用

| 组成部分     | **类封装版本 (BIT)**        | **简单方法版本**        | 作用描述           |
| -------- | ---------------------- | ----------------- | -------------- |
| **初始化**  | __init__(self, n)      | 直接定义全局数组 tree     | 分配空间，准备好全 0 数组 |
| **核心逻辑** | self.lowbit(x)         | lowbit(x)         | 算出二进制最低位的 1    |
| **写数据**  | self.update(i, val)    | add(i, val)       | 把第 i 个数加上 val  |
| **读数据**  | self.query(i)          | ask(i)            | 算 1 到 i 的总和    |
| **读区间**  | self.query_range(l, r) | query_range(l, r) | 算 l 到 r 的总和    |
