**利用数字的“二进制拆分”来管理区间和，从而在“修改”和“查询”之间找到完美的平衡。**

### 为什么要用树状数组？（核心痛点）

假设我们要维护一个数组的区间和：

- **普通数组：** 修改一个值 $O(1)$，但查一次区间和要遍历，是 $O(N)$。
    
- **前缀和数组：** 查区间和是 $O(1)$，但如果修改一个值，后面的所有前缀和都要更新，是 $O(N)$。
    

**树状数组的价值：** 让“修改”和“查询”都变成 $O(\log N)$。


**“成批划分”**。i -= i & -i

它利用了**二进制**的数学特性。每一个整数都能唯一地拆成 2 的幂之和，这就保证了无论你查哪个区间，都能被拆成几个现成的“管理区”累加起来。

对于 50 万数据：

- $O(N)$ 需要走 500,000 步。
    
- $O(\log N)$ 只需要跳 $\approx 19$ 步。

``` 
# 查询：沿着管理链往下拿钱（拿走之前存好的大区间和）
while i > 0:
    sum += tree[i]
    i -= i & -i

# 更新：沿着管理链往上汇报（告诉上级我这一支多了个球）
while i <= max_size:
    tree[i] += val
    i += i & -i
```

### 一、 如何一眼识别“树状数组”？（信号识别）

当你在题目中看到以下关键词的组合时，就要高度怀疑需要用到树状数组：

- **关键词 1：动态求和 / 动态维护**
    
    - 题目要求你改一个数，马上查一次区间和；或者一边处理数组，一边查前面的某种统计值。
        
    - **信号：** 如果是静态（不改值），用前缀和；如果是动态（频繁改值），用树状数组。
        
- **关键词 2：统计“逆序对”或“顺序对”**
    
    - 凡是涉及“统计 $i < j$ 且 $A[i] < A[j]$（或 $A[i] > A[j]$）的对数”。
        
    - **信号：** 这类题 90% 的解法都是把数值作为“桶”的下标，用树状数组边走边统计。
        
- **关键词 3：值域统计**
    
    - 题目问：“在当前已知的数中，落在区间 $[L, R]$ 里的数有多少个？”
        
    - **信号：** 这本质上也是区间求和。
        
- **关键词 4：数据量级**
    
    - $N$ 在 $10^5$ 到 $10^6$ 之间，且需要 $O(N \log N)$ 的算法。
        

### 二、 树状数组 Python 万能模板

在比赛中，你可以直接套用下面这个类。我建议你把这个逻辑记在脑子里，或者写在自己的代码库里。

#### 1. 类封装版（推荐，逻辑清晰）

```
class FenwickTree:
    def __init__(self, n):
        self.size = n
        self.tree = [0] * (n + 1)

    def update(self, i, delta):
        """在第 i 个位置加上 delta (i 从 1 开始)"""
        while i <= self.size:
            self.tree[i] += delta
            i += i & (-i)

    def query(self, i):
        """查询前缀和 [1, i]"""
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & (-i)
        return s

    def query_range(self, l, r):
        """查询区间和 [l, r]"""
        return self.query(r) - self.query(l - 1)
```

#### 2. 极简函数版（如果你追求极致速度）

Python 中函数调用会有开销，有时直接写在 main 里的循环会更快：

```
# 初始化
bit = [0] * (max_val + 1)

# 更新
def update(i, val):
    while i <= max_val:
        bit[i] += val
        i += i & (-i)

# 查询
def query(i):
    res = 0
    while i > 0:
        res += bit[i]
        i -= i & (-i)
    return res
```

### 三、 使用模板时的 3 个“坑”

1. **下标必须从 1 开始：** 树状数组的二进制逻辑不支持下标 0。如果你的数据里有 0 或者负数，一定要加一个 offset（偏移量）或者进行离散化，确保传给 update 和 query 的 idx 至少是 1。
    
2. **值域过大怎么办？** 如果题目给的数值 $A[i]$ 特别大（比如 $10^9$），你不能开 $10^9$ 那么大的数组。解决方法：**离散化**。把所有出现的数排个序，用它们的“排名”（1, 2, 3...）作为树状数组的下标。
    
3. **Python 的运行速度：** 在 AtCoder 或 Codeforces 中，Python 处理 $5 \times 10^5$ 以上的数据时，尽量使用 `sys.stdin.read().split()` 快速读入，并把代码写在 `def solve():` 函数内部，这样局部变量的访问速度比全局变量快很多。
