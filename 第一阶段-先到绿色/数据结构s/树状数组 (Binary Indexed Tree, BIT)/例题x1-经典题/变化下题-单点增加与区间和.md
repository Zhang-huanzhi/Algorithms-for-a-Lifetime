### D - Point Add and Range Sum

时间限制: 2 秒 / 内存限制: 1024 MiB  
题目分值: 400 分

#### 题目描述
给你一个长度为 $N$ 的数列 $A=(A_1, A_2, \dots, A_N)$。

接下来给出 $Q$ 个操作，请按顺序进行处理。每个操作属于以下两种类型之一：

- `1 x v` : 将 $A_x$ 的值加上 $v$（即执行 $A_x \leftarrow A_x + v$）。
- `2 l r` : 计算 $\sum_{i=l}^r A_i$ 的值（即输出区间 $[l, r]$ 中所有元素之和）。

#### 制约条件
- $1 \le N \le 2 \times 10^5$
- $1 \le Q \le 2 \times 10^5$
- $0 \le A_i \le 10^9$
- 对于第 1 类操作：
  - $1 \le x \le N$
  - $0 \le v \le 10^9$
- 对于第 2 类操作：
  - $1 \le l \le r \le N$
- 输入的所有数值均为整数。

#### 输入格式
输入通过标准输入按以下格式给出：

$$
N \quad Q \\
A_1 \quad A_2 \quad \dots \quad A_N \\
\text{query}_1 \\
\text{query}_2 \\
\vdots \\
\text{query}_Q
$$

其中，$\text{query}_i$ 表示第 $i$ 个操作，格式为以下两种之一：

```text
1 x v
```
或
```text
2 l r
```

#### 输出格式
设第 2 类操作的个数为 $q$，请输出 $q$ 行。  
第 $i$ 行 $(1 \le i \le q)$ 应输出第 $i$ 个第 2 类操作的计算结果。

---

### 样例 1

#### 输入样例 1
```text
4 4
2 7 1 8
1 2 3
2 1 2
1 1 5
2 2 4
```

#### 输出样例 1
```text
12
19
```

**样例解释 1**：
- 初始数列为 $A = (2, 7, 1, 8)$。
- 第 1 个操作：将 $A_2$ 的值加上 $3$，数列变为 $A=(2, 10, 1, 8)$。
- 第 2 个操作：计算 $A_1 + A_2$，结果为 $2 + 10 = 12$。
- 第 3 个操作：将 $A_1$ 的值加上 $5$，数列变为 $A=(7, 10, 1, 8)$。
- 第 4 个操作：计算 $A_2 + A_3 + A_4$，结果为 $10 + 1 + 8 = 19$。

### 样例 2

#### 输入样例 2
```text
8 6
22 75 26 45 72 81 47 29
2 2 7
1 4 10
2 2 7
1 2 5
1 6 100
2 1 8
```

#### 输出样例 2
```text
346
356
512
```

**样例解释 2**：
- 查询 1：计算区间 $[2, 7]$ 的和为 $75+26+45+72+81+47 = 346$。
- 修改 1：$A_4$ 增加 $10$，变为 $55$。
- 查询 2：再次计算区间 $[2, 7]$ 的和，结果变为 $356$。
- 其余操作依此类推。注意最终输出结果可能较大，需使用 64 位整数类型保存结果。

# 树状数组-封装成类
``` python
import math  
import sys  
  
def main():  
  
    class BIT:  
        def __init__(self, n):  
            self.n = n  
            self.tree = [0] * (n + 1)  
  
        def lowbit(self, x):  
            return x & -x  
  
        def add(self, i, delta):  
            while i <= self.n:  
                self.tree[i] += delta  
                i += self.lowbit(i)  
  
        def query(self, i):  
            res = 0  
            while i > 0:  
                res += self.tree[i]  
                i -= self.lowbit(i)  
            return  res  
  
    n, q = map(int, sys.stdin.readline().strip().split())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    bit = BIT(n)  
    for i in range(1, n + 1):  
        bit.add(i, arr[i - 1])  
  
    outs = []  
    for _ in range(q):  
        line = sys.stdin.readline().strip().split()  
  
        op = line[0]  
  
        if op == '1':  
            x = int(line[1])  
            v = int(line[2])  
            bit.add(x, v)  
  
        if op == '2':  
            l = int(line[1])  
            r = int(line[2])  
            ans = bit.query(r) - bit.query(l - 1)  
            outs.append(ans)  
  
    print('\n'.join(map(str, outs)))  
  
if __name__ == "__main__":  
    main()
```
