在实际应用和算法面试中，判断括号是否匹配是一个非常经典的题目。根据**括号种类的多寡**，通用的标准算法写法主要分为以下两种。

---

### 情况一：只有一种括号（例如只有 `(` 和 `)`）

如果题目中只存在一种括号（就像我们这道题一样），**最通用的标准算法是不需要使用“栈”的**。
我们只需要维护一个计数器（即空间复杂度为 $O(1)$ 的变量）即可。

#### 核心逻辑
* 初始化计数器 `balance = 0`。
* 遍历字符串：
  * 遇到 `(`，计数器 `+1`。
  * 遇到 `)`，计数器 `-1`。
  * **关键点**：在遍历过程中的任何时候，如果 `balance < 0`，说明右括号多出来了，直接判定非法（返回 `False`）。
* 遍历结束后，如果 `balance == 0`，说明完全配对，返回 `True`；否则返回 `False`。

#### Python 标准写法
```python
def is_valid_single(s: str) -> bool:
    balance = 0
    for char in s:
        if char == '(':
            balance += 1
        elif char == ')':
            balance -= 1
        
        # 旅途中一旦低于海平面，说明右括号多出了，直接失败
        if balance < 0:
            return False
            
    # 终点必须正好回到平地
    return balance == 0
```

---

### 情况二：有多种括号（例如包含 `()`, `[]`, `{}`）

当存在多种括号时（如 LeetCode 第 20 题），仅仅靠计数器就不行了，因为**括号的顺序和嵌套关系**变得至关重要（例如 `([)]` 数量对得上，但顺序错乱，是非法的）。
这时，**必须使用“栈（Stack）”**来辅助判断。

#### 核心逻辑
* 建立一个栈，并使用一个**哈希表（字典）**存储右括号到左括号的映射关系，方便快速配对。
* 遍历字符串：
  * 遇到左括号，直接压入栈。
  * 遇到右括号，检查栈顶元素是否是与之配对的左括号：
    * 如果栈为空，或者栈顶元素不配对，说明非法，返回 `False`。
    * 如果配对成功，弹出栈顶左括号。
* 遍历结束后，如果栈为空，说明全部配对成功，返回 `True`；否则返回 `False`。

#### Python 标准写法
```python
def is_valid_multiple(s: str) -> bool:
    stack = []
    # 使用字典建立右括号与左括号的映射，使代码更简洁、易扩展
    mapping = {")": "(", "]": "[", "}": "{"}
    
    for char in s:
        if char in mapping:  # 如果是右括号
            # 取出栈顶元素（如果栈空则给一个占位符 '#'）
            top_element = stack.pop() if stack else '#'
            # 检查是否与当前右括号配对
            if mapping[char] != top_element:
                return False
        else:  # 如果是左括号
            stack.append(char)
            
    # 最后检查栈内是否还有残留的左括号
    return not stack
```

---

### 总结：通用写法的精髓

1. **单一种类用“计数器”**：空间复杂度只有 $O(1)$，效率极高。
2. **多种种类用“栈 + 字典（哈希表）”**：
   * 字典的妙处在于**消除繁琐的 `if-elif` 分支**。如果以后题目新增了其他符号（比如 `<>`），只需要在字典里多加一行，主逻辑完全不需要修改。
   * 这是在工业界写代码时非常提倡的一种具有**高扩展性（Scalability）**的优雅写法。
