其实更推荐这么写：

``` python
import sys  
  
  
def main():  
  
    n = int(sys.stdin.readline().strip())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    # 模拟stack  
    q = []  
    for v in arr:  
  
        if not q or q[-1][0] != v:  
            q.append([v, 1])  
  
        else:  
            q[-1][1] += 1  
  
            if q[-1][1] == 4:  
                q.pop()  
  
    ans  = sum(item[1] for item in q)  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```

使用“带频次标记的栈（Run-Length Encoding on Stack）”来实现这道题，代码会变得非常优雅，并且**具有极强的扩展性**（比如，如果题目改成“连续 $K$ 个相同的数就消除”，只需修改一个数字即可）。

在 Python 中，栈里面的每个元素可以是一个列表 `[数值, 出现次数]`。

---

### 这种写法好在哪里？（优势对比）

相比于官方题解直接把每个数字单独存入栈的做法，这种“带频次标记”的写法有两个巨大的优势：

#### 优势 1：对大参数的扩展性极强（高泛化性）
假设题目把条件从“连续 **$4$** 个消除”改为“连续 **$100$** 个消除”：
* **官方题解的写法**：你需要写 `len(q) >= 100` 以及 `q[-1] == q[-2] == ... == q[-100]`，这几乎是无法手工编写的；而且触发消除时需要循环调用 `pop()` 100次。
* **RLE 栈写法**：只需要将代码中的 `if q[-1][1] == 4:` 改为 `if q[-1][1] == 100:` 即可。而且消除时依然只需执行 **1 次** `q.pop()` 操作，非常高效。

#### 优势 2：节省空间和时间常数
如果输入中有很多连续重复的数字（例如 `100` 个连续的 `1`），官方写法会在列表中占用 `100` 个空间。而 RLE 栈只需要占用一个节点 `[1, 100]`，大大节省了内存空间和指针移动的开销。
