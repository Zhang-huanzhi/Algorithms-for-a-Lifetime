### D - (xx)  
**时间限制：** 2 秒 / **内存限制：** 1024 MiB  
  
**分值：** 425 分  
  
#### 问题描述  
给定一个由 `(`, `x`, `)` 组成的字符串 `A`。  
你可以对字符串 `A` 按任意顺序、任意次数执行以下两种操作：  
  
1.  选择 `A` 的一个子串 `(xx)`，并将其替换为 `xx`。  
2.  选择 `A` 的一个子串 `xx`，并将其替换为 `(xx)`。  
  
给定另一个由 `(`, `x`, `)` 组成的字符串 `B`。  
请判断是否能将字符串 `A` 变得与字符串 `B` 完全相同。  
  
你将会收到 `T` 个测试用例，请对每个测试用例求解。  
  
#### 约束条件  
*   1 ≤ T ≤ 3 × 10⁵  
*   `A`, `B` 是由 `(`, `x`, `)` 组成，长度在 1 到 2 × 10⁶ 之间的字符串。  
*   所有测试用例的 `|A| + |B|` 的总和不超过 2 × 10⁶ (这里 `|A|` 表示 `A` 的长度)。  
  
#### 输入  
输入格式如下：  
```  
T  
case_1  
case_2  
...  
case_T  
```  
每个测试用例的格式如下：  
```  
A  
B  
```  
  
#### 输出  
输出 `T` 行。  
第 `i` 行输出第 `i` 个测试用例的答案。  
对于每个测试用例，如果能将 `A` 变得与 `B` 相同，则输出 `Yes`，否则输出 `No`。  
  
#### 输入样例 1  
```  
6  
(xx)x  
x(xx)  
(x)x  
(xx)  
)x()x(  
)x()x(  
x  
(x)  
(((((xx)))))x  
x((((((((((xx))))))))))  
((xx)xx)xx  
(x((xx))x)(xx)  
```  
  
#### 输出样例 1  
```  
Yes  
No  
Yes  
No  
Yes  
Yes  
```  
  
例如，在第一个测试用例中，可以通过以下步骤将 `A` 变为 `B`：  
1.  将 `A` 中第 1 到第 4 个字符的 `(xx)` 替换为 `xx`。操作后 `A` 变为 `xxx`。  
2.  将 `A` 中第 2 到第 3 个字符的 `xx` 替换为 `(xx)`。操作后 `A` 变为 `x(xx)`。
