在竞赛中，我们通常将基本操作（如加减乘除、数组访问、简单判断）算作"一次运算"。

各语言2秒内的运算次数

| 语言                | 运算次数                               | 备注      |
| ----------------- | ---------------------------------- | ------- |
| C++               | $10^8 \sim 10^9$                   | 最快      |
| PyPy3             | $2 \times 10^7 \sim 2 \times 10^8$ | 非常接近C++ |
| Python3 (CPython) | $1 \times 10^7 \sim 3 \times 10^7$ | 较慢      |

# 根据题目数据范围推导最高时间复杂度

通常在看题时，先看输入数据 $N$ 的最大规模，然后通过以下表格来倒推你的解法是否会 TLE（超时）：

| 题目给定的最大 $N$ 范围          | 允许的最高时间复杂度            | 算法举例                           | 对应的运算量级                           |
| ----------------------- | --------------------- | ------------------------------ | --------------------------------- |
| $N \leq 10 \sim 11$     | $O(N!)$               | 全排列枚举 (itertools.permutations) | $\approx 3.6 \times 10^6$         |
| $N \leq 20 \sim 25$     | $O(2^N)$              | 状态压缩DP、子集枚举                    | $\approx 10^6 \sim 3 \times 10^7$ |
| $N \leq 100 \sim 500$   | $O(N^3)$              | Floyd多源最短路、区间DP                | $\approx 1.2 \times 10^7$         |
| $N \leq 3000 \sim 5000$ | $O(N^2)$              | 朴素的双层循环、树的直径                   | $\approx 2.5 \times 10^7$         |
| $N \leq 10^5$           | $O(N\sqrt{N})$        | 分块、莫队算法（在Python中较危险，需PyPy）     | $\approx 3.1 \times 10^7$         |
| $N \leq 2 \times 10^5$  | $O(N\log N)$          | 最常见！排序、二分、线段树、堆、字典             | $\approx 3.6 \times 10^6$         |
| $N \leq 10^6$           | $O(N)$ 或 $O(N\log N)$ | 线性扫描、双指针、前缀和（$N\log N$ 必须PyPy） | $\approx 10^6 \sim 2 \times 10^7$ |
| $N \geq 10^9$           | $O(\sqrt{N})$         | 判断素数、求所有因数                     | $\approx 3.1 \times 10^4$         |
| $N \geq 10^{18}$        | $O(\log N)$ 或 $O(1)$  | 数学公式、快速幂、最大公约数 (gcd)           | $\leq 100$                        |
