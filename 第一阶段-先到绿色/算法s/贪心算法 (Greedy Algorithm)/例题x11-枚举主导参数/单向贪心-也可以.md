``` python
import math  
import sys  
  
def main():  
    t = int(sys.stdin.readline().strip())  
    outs = []  
    for _ in range(t):  
        n = int(sys.stdin.readline().strip())  
  
        arr = []  
        diff = []  
        total = 0  
        cost = math.inf  
        for _ in range(n):  
            a, b = map(int, sys.stdin.readline().strip().split())  
            arr.append((a, b))  
            diff.append(a - b)  
            total += a  
            # 刷一个卷的最小成本  
            if a < cost:  
                cost = a  
  
        # 降序排序，省钱最多的在前面  
        diff.sort(reverse=True)  
  
        ans = total  # 初始值：一张券都不用时的总花费  
        y = 0  # 记录前 k 个商品用券累计节省的金额  
  
        # 枚举使用了 k 张优惠券 (k 从 1 到 n)        for k in range(1, n + 1):  
            y += diff[k - 1]  
            extra = max(0, 2 * k - n) * cost  # 刷券的额外成本  
            ans = min(ans, total - y + extra)  
  
        outs.append(ans)  
  
    print('\n'.join(map(str, outs)))  
  
if __name__ == "__main__":  
    main()
```

### 你的算法属于什么？
用算法术语来说，你的思路叫做：**「基于边际收益单调性的单向贪心（Marginal Greedy with Early Stopping）」**。

它的核心逻辑完全建立在**经济学中的“边际决策”**上：

#### 1. 边际决策（每一步看赚不赚）
你没有去全局尝试“如果用 1 张券会怎样、用 2 张券会怎样……”，而是把问题看成一个**连续的决策流**：
* 先拿满所有完全免费的券（`cnt = n // 2`）。
* 然后**一件一件商品往后看**：
  * 买下这件商品的**边际收益**是 `diff[i]`（它能省多少钱）。
  * 买下这件商品的**边际成本**是 `step_cost`（需要花多少钱补券）。
  * **净利润** $= \text{边际收益} - \text{边际成本}$。

#### 2. 利用单调性直接 `break`（纯贪心的标志）
为什么你不需要像官方题解那样把后面的情况都试一遍？
* **边际收益在递减**：因为 `diff` 从大到小排过序，越往后收益越低（$\downarrow$）。
* **边际成本在递增**：`step_cost` 从 $1\times \text{cost}$ 变成 $2\times \text{cost}$，成本越来越高（$\uparrow$）。
* **净利润严格递减**：当某一步 `diff[i] <= step_cost` 时，净利润首次 $\le 0$。由于后面的收益只会更低、成本只会更高，后面绝对不可能再赚到钱了！
* **所以直接 `break` 终止，一步到位拿到最优解。**

### 两种思路的本质区别对比

| 维度 | 官方题解（枚举贪心） | 你的思路（边际纯贪心） |
| :--- | :--- | :--- |
| **核心机制** | **全局试探**：把 $k=0 \sim N$ 所有情况全算一遍，取 `min()` | **导数/斜率找拐点**：只要每一步还能赚，就往前走，不赚了立马 `break` |
| **控制流** | 必须跑满 $N$ 次循环 | 遇到负收益立即 `break`，可能提前结束 |
| **思维层级** | 宏观固定参数，微观排序 | 深度利用了函数凸性（边际收益递减）的纯贪心 |
