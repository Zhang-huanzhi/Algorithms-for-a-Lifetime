### C - 偷看  
  
**时间限制：** 2 秒 / **内存限制：** 1024 MiB  
  
**分值：** 300 分  
  
#### 问题描述  
  
高桥君现在在数轴上的坐标 **0.5** 处。  
  
接下来，他要进行 **N** 次移动。在第 `i` 次移动中，他可以选择“正方向”或“负方向”中的一个，并朝着所选方向移动 **L<sub>i</sub>** 的距离。  
  
请问，高桥君最多可以经过坐标 **0** 几次？  
  
注意：根据本题的约束条件，移动不会恰好在坐标 0 处结束。  
  
#### 约束条件  
  
*   1 ≤ N ≤ 20  
*   1 ≤ L<sub>i</sub> ≤ 10<sup>9</sup>  
*   所有输入均为整数  
  
#### 输入  
  
输入将通过标准输入按以下格式给出：  
  
```  
N  
L_1 L_2 ... L_N  
```  
  
#### 输出  
  
请输出答案。  
  
---  
  
#### 输入样例 1  
  
```  
5  
2 5 2 2 1  
```  
  
#### 输出样例 1  
  
```  
4  
```  
  
例如，通过如下方式选择移动方向，可以经过坐标 0 四次，这是最大次数：  
  
1.  第一次移动选择负方向，移动 2。高桥君从坐标 0.5 移动到 -1.5，经过了坐标 0。  
2.  第二次移动选择正方向，移动 5。高桥君从坐标 -1.5 移动到 3.5，经过了坐标 0。  
3.  第三次移动选择负方向，移动 2。高桥君从坐标 3.5 移动到 1.5。  
4.  第四次移动选择负方向，移动 2。高桥君从坐标 1.5 移动到 -0.5，经过了坐标 0。  
5.  第五次移动选择正方向，移动 1。高桥君从坐标 -0.5 移动到 0.5，经过了坐标 0。  
  
---

```  
5

```  
  
#### 输出样例 2  
  
```  
1  
```
