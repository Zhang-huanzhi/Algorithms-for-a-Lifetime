
**D - Summer Vacation**  
执行时间限制：2 秒 / 内存限制：1024 MiB

**分值：**  
400 分

## 题目描述

有 `N` 份日结兼职工作。  
如果接受并完成第 `i` 份日结兼职工作，那么会在 `A_i` 天后获得报酬 `B_i`。

你可以从这些工作中选择去做，并且**每天最多只能选择 1 份**来接受并完成。

但是，**已经接受过的日结兼职工作不能再次选择**。

求从今天开始到 `M` 天后（**包含第 `M` 天后**）为止，能够获得的报酬总和的最大值。

另外，日结兼职工作从今天开始就可以接受并完成。

## 约束

输入中的所有值均为整数。

- `1 ≤ N ≤ 10^5`
- `1 ≤ M ≤ 10^5`
- `1 ≤ A_i ≤ 10^5`
- `1 ≤ B_i ≤ 10^4`

## 输入

输入从标准输入按如下格式给出：

```text
N M
A1 B1
A2 B2
⋮
AN BN
```

## 输出

输出到 `M` 天后为止能够获得的报酬总和的最大值。

## 输入样例 1

```text
3 4
4 3
4 1
2 2
```

## 输出样例 1

```text
5
```

如果像下面这样接受并完成日结兼职工作，则报酬总和为 `5`，且这是最大值。

- 今天，接受并完成第 `1` 份日结兼职工作，在今天起 `4` 天后获得报酬 `3`。
- 明天（即今天起 `1` 天后），接受并完成第 `3` 份日结兼职工作，在今天起 `1 + 2 = 3` 天后获得报酬 `2`。

## 输入样例 2

```text
5 3
1 2
1 3
1 4
2 1
2 3
```

## 输出样例 2

```text
10
```

## 输入样例 3

```text
1 1
2 1
```

## 输出样例 3

```text
0
```
