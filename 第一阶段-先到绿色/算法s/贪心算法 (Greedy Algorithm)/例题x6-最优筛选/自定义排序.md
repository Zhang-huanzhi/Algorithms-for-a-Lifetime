### 套路一：利用 tuple 进行多关键字排序（最常用、最推荐）

在算法题中，我们经常遇到需要“先按属性 A 升序，如果 A 相同则按属性 B 降序”这样的需求。Python 支持直接返回一个 tuple（元组）作为 key，Python 会默认**从左到右**比较元组中的每一个元素。

#### 1. 基础多关键字排序（升序）

``` python
# 假设每个元素是 (学号, 成绩)
students = [(1, 95), (2, 95), (3, 90)]

# 需求：先按成绩升序，成绩相同按学号升序
# key 返回的元组是 (成绩, 学号)
students.sort(key=lambda x: (x[1], x[0]))
# 结果: [(3, 90), (1, 95), (2, 95)]
```

#### 2. 升序与降序混搭（利用“负号” -）

如果我们希望**第一关键字升序，第二关键字降序**，对于数值类型的属性，最简单的技巧是**加负号** -。

``` python
# 需求：先按成绩降序（加负号），成绩相同按学号升序（正数）
students.sort(key=lambda x: (-x[1], x[0]))
# 结果: [(1, 95), (2, 95), (3, 90)]
```

> **注意**：加负号的方法只适用于**数值类型**（如整型、浮点型）。如果是字符串或无法直接变负的数据，需要使用套路二。
