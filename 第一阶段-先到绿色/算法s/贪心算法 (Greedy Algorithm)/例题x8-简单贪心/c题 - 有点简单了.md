### C - Domino
时间限制: 2 秒 / 内存限制: 1024 MiB

分值：300 分

#### 问题描述
数轴上排着 $N$ 个多米诺骨牌。
第 $i$ 个多米诺骨牌立在坐标 $i$ 的位置，高度为 $A_i$。

当第 $i$ 个多米诺骨牌向右倒下时，所有处于坐标范围 $[i, i + A_i)$（即坐标大于等于 $i$ 且严格小于 $i + A_i$）内的多米诺骨牌也都会向右倒下。

如果将第 $1$ 个多米诺骨牌向右推倒，总共会有多少个多米诺骨牌倒下？

#### 数据范围与约束
* $1 \le N \le 5 \times 10^5$
* $1 \le A_i \le N$
* 所有输入均为整数。

#### 输入
输入按以下格式从标准输入给出：
> $N$  
> $A_1$ $A_2$ $\dots$ $A_N$

#### 输出
输出一个整数，表示将第 $1$ 个多米诺骨牌向右推倒时，最终会倒下的多米诺骨牌的总数。

---

#### 输入样例 1
```text
4
3 1 4 1
```

#### 输出样例 1
```text
4
```
**样例说明 1**：
* 当第 $1$ 个多米诺骨牌向右倒下时，会波及坐标在 $[1, 1+3) = [1, 4)$ 内的骨牌，因此第 $2$ 和第 $3$ 个骨牌也会向右倒下。
* 当第 $3$ 个多米诺骨牌向右倒下时，会波及坐标在 $[3, 3+4) = [3, 7)$ 内的骨牌，因此第 $4$ 个骨牌也会随之倒下。

#### 输入样例 2
```text
9
1 4 1 4 2 1 3 5 6
```

#### 输出样例 2
```text
1
```
**样例说明 2**：
即使将第 $1$ 个多米诺骨牌向右推倒，其波及范围为 $[1, 1+1) = [1, 2)$，不会使第 $2$ 个及以后的任何多米诺骨牌倒下。

#### 输入样例 3
```text
10
5 4 3 2 1 1 2 3 4 5
```

#### 输出样例 3
```text
5
```

# 贪心Code AC
``` python
import sys  
  
import itertools  
  
  
def main():  
      
    n = int(sys.stdin.readline().strip())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    curr = arr[0]  
  
    for i in range(1, n):  
  
        if i + 1 > curr:  
            break  
  
        nex = i + arr[i]  
        curr = max(nex, curr)  
  
    print(min(curr, n))  
if __name__ == "__main__":  
    main()
```
