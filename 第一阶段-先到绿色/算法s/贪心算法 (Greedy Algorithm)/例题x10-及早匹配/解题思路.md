这道题的解题思路可以拆解为 **“看穿本质 $\to$ 建立模型 $\to$ 贪心推导”** 三个步骤：

---

### 第一步：看穿本质（跳出“删除”的陷阱）

题目描述是：“选出一组下标 $i < j < k$ 使得字符分别为 `A`, `B`, `C`，然后删掉它们并把剩下的字符拼起来”。

很多人的第一直觉是：
> “我是不是要用栈（Stack）或者链表去模拟删除？删完之后两边的字符拼在一起，会不会产生新的机会？”

**但只要仔细思考就会发现：**
* 题目要求的是 $i < j < k$ 的**子序列（Subsequence）**，而不是要求 `A`, `B`, `C` 必须连续紧挨着。
* 删除某些字符并把剩余字符向左靠齐，**完全不会改变剩余字符之间的前后相对顺序**。
* 只要在原字符串中原本就满足“A 在 B 前，B 在 C 前”，无论怎么删，这个前后关系永远成立。

#### 结论 1（问题等价转化）：
> **题目的本质是：在原字符串中，最多能选出多少组互不重叠的子序列 `"ABC"`？**

---

### 第二步：建立模型（工厂流水线组装）

要把一个完整的 `"ABC"` 生产出来，必须经历三个工序：
1. **工序 1**：收集到零件 `'A'`（获得状态：`[A]`）
2. **工序 2**：收集到零件 `'B'`，与 `[A]` 组装成半成品 `[AB]`
3. **工序 3**：收集到零件 `'C'`，与 `[AB]` 组装成最终成品 `[ABC]`

这就像一个**三级流转的库存系统**：

$$\text{字符串输入} \xrightarrow{遇到 A} \text{库存 } [A] \xrightarrow{遇到 B} \text{库存 } [AB] \xrightarrow{遇到 C} \text{最终成品 } [ABC]$$

---

### 第三步：贪心推导（为什么“及早匹配”一定最优？）

我们从左到右扫描字符串，每次遇到不同的字符时该怎么做？

1. **遇到 `'A'` 时**：
   * 零件多了一个，直接存入库存：`a_count += 1`。
2. **遇到 `'B'` 时**：
   * **思考**：如果此时有空闲的 `[A]`，我们应该立刻组装成 `[AB]`，还是把这个 `A` 留给后面的 `B`？
   * **贪心策略**：**立刻组装！** 
     * *直觉理由*：越早组装成 `[AB]`，这个 `[AB]` 出现的位置就越靠前，它就能“看到”后面更多的 `'C'`，从而更有机会变成最终的 `[ABC]`。留着没有任何额外收益。
     * 因此，只要 `a_count > 0`，就 `a_count -= 1`, `ab_count += 1`。
3. **遇到 `'C'` 时**：
   * **思考**：如果有现成的 `[AB]`，要不要立刻变成成品 `[ABC]`？
   * **贪心策略**：**立刻变成成品！**
     * 成品已经是最终目标了，落袋为安，操作数 `ans += 1`，消耗一个半成品 `ab_count -= 1`。

---

### 示例全程模拟演示

以样例 1 为例：$S = \text{"ABACBCC"}$

| 步数 | 当前字符 | 操作与理由 | 库存 `a` | 半成品 `ab` | 成品 `ans` |
| :---: | :---: | :--- | :---: | :---: | :---: |
| 初始 | - | 初始状态 | 0 | 0 | 0 |
| 1 | `'A'` | 获得 1 个 A | **1** | 0 | 0 |
| 2 | `'B'` | 有 A，组装成 AB（消耗 A） | **0** | **1** | 0 |
| 3 | `'A'` | 获得 1 个 A | **1** | 1 | 0 |
| 4 | `'C'` | 有 AB，组装成 ABC（消耗 AB） | 1 | **0** | **1** |
| 5 | `'B'` | 有 A，组装成 AB（消耗 A） | **0** | **1** | 1 |
| 6 | `'C'` | 有 AB，组装成 ABC（消耗 AB） | 0 | **0** | **2** |
| 7 | `'C'` | 没有可用的 AB，无法配对，舍弃 | 0 | 0 | 2 |

最终答案为 **2**。

---

### 总结提炼

这道题的破题要点非常纯粹：
1. **脱去外衣**：把“动态删除向左靠齐”识别为“静态不相交子序列选取”；
2. **状态流转**：维护 `[A]` 和 `[AB]` 两个半成品库存；
3. **贪心转移**：单次遍历，只要上游有货、下游立刻接收加工，即可在 $O(N)$ 时间与 $O(1)$ 空间内直接求出全局最优解。
