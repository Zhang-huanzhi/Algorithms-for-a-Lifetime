### D - Paid Walk

**时间限制**：2 秒 / **内存限制**：1024 MiB

**分值**：400 分

#### 题目描述

有一个包含 $N$ 个顶点和 $M$ 条边的有向图（可能包含重边和自环），顶点编号为 $1, 2, \dots, N$。
第 $i$ 条边（$1 \le i \le M$）是一条从顶点 $U_i$ 指向顶点 $V_i$ 的有向边，权重（花费）为 $C_i$。此外，**每个顶点的出度均不超过 4**。

请找出所有满足以下条件的顶点 $v$（$1 \le v \le N$）：

> 存在一条从顶点 $1$ 到顶点 $v$ 的路径，且同时满足以下两个条件：
> 1. 恰好经过 $L$ 条边。在路径中，同一条边可以被多次经过，每次经过都计入边数。
> 2. 经过的所有边的权重总和在 $[S, T]$ 之间（即 $\ge S$ 且 $\le T$）。同一条边多次经过时，每次经过的花费都会累加。

**关于出度**：
顶点 $u$ 的出度是指从顶点 $u$ 出发的边数。即使多条边指向同一个目标顶点，每条边也会被分别计数。

#### 制约条件

* $1 \le N \le 2 \times 10^5$
* $1 \le M \le 2 \times 10^5$
* $1 \le L \le 10$
* $1 \le S \le T \le 10^9$
* $1 \le U_i, V_i \le N$
* $1 \le C_i \le 10^8$
* 每个顶点的出度最多为 $4$。
* 所有输入均为整数。

---

#### 输入格式

输入通过标准输入按以下格式给出：

```text
N M L S T
U_1 V_1 C_1
U_2 V_2 C_2
⋮
U_M V_M C_M
```

#### 输出格式

按**升序**输出所有满足条件的顶点编号，顶点之间用空格分隔。
如果不存在满足条件的顶点，则输出一个空行。

---

#### 样例 1

**输入**
```text
5 8 3 80 100
1 2 20
1 3 70
2 1 30
2 5 10
3 2 10
3 4 30
3 5 20
5 1 70
```

**输出**
```text
1 5
```

**说明**
* 到顶点 $1$ 的路径：$1 \to 2 \to 5 \to 1$，恰好经过 $3$ 条边，总花费为 $20 + 10 + 70 = 100$，在 $[80, 100]$ 范围内，满足条件。
* 到顶点 $2$：路径 $1 \to 2 \to 1 \to 2$ 经过 $3$ 条边，总花费为 $20 + 30 + 20 = 70 < 80$，不满足条件；没有其他符合条件的路径。
* 到顶点 $3$：路径 $1 \to 2 \to 1 \to 3$ 经过 $3$ 条边，总花费为 $20 + 30 + 70 = 120 > 100$，不满足条件。
* 到顶点 $4$：不存在经过 $3$ 条边到达的路径。
* 到顶点 $5$ 的路径：$1 \to 3 \to 2 \to 5$，恰好经过 $3$ 条边，总花费为 $70 + 10 + 10 = 90$，在 $[80, 100]$ 范围内，满足条件。

因此，满足条件的顶点为 $1$ 和 $5$，按升序输出。

# 暴力搜索 AC Code
``` python
import math  
import sys  
from collections import deque  
  
def main():  
  
    n, m, l, s, t = map(int, sys.stdin.readline().strip().split())  
  
    adj = [ [] for _ in range(n + 1)]  
  
    for _ in range(m):  
        u, v, c = map(int, sys.stdin.readline().strip().split())  
        adj[u].append((v, c))  
  
    ans = [False] * (n + 1)  
    # 当前顶点u， 当前步数depth， 当前花费cost  
    q = deque()  
    q.append((1, 0, 0))  
  
    while q:  
  
        u, depth, cost =  q.pop()  
  
        if depth == l:  
            if s <= cost <= t:  
                ans[u] = True  
            continue  
        for v, c in adj[u]:  
            q.append((v, depth + 1, cost + c))  
  
    outs = [i for i in range(1, n + 1) if ans[i]]  
  
    print(*outs)  
  
if __name__ == "__main__":  
    main()
```
