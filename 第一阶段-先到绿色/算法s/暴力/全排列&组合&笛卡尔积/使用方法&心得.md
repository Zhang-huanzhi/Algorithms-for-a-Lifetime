## 1. 导入库 (Import)

要使用这个方法，你必须从 Python 的标准库 itertools 中导入它。

```python
import itertools
```

## 2. 方法/函数 (Function)

我们要使用的方法是 `itertools.permutations()`。

## 3. 参数 (Parameters)

这个函数主要接收 1 个必须参数和 1 个可选参数。

```python
itertools.permutations(iterable, r=None)
```

**iterable (必须参数):**

- 含义: 这是一个你想要进行全排列的"集合"。
- 类型: 任何可迭代的对象都可以,最常见的是列表 (list)、元组 (tuple) 或字符串 (string)。
- 示例: `[1, 2, 3]`, `'ABC'`

**r (可选参数):**

- 含义: 你希望生成的每个排列的长度。
- 类型: 整数。
- 默认值: 如果你不提供这个参数(`r=None`),它会默认等于你传入的 iterable 的总长度。在我们解决算法问题时,99% 的情况都是使用默认值。
- 示例: `itertools.permutations([1, 2, 3], r=2)` 会生成 `(1, 2), (1, 3), (2, 1), (2, 3), (3, 1), (3, 2)`。

## 4. 返回值 (Return Value)

这是最关键的部分:

**它返回什么?**

- 它返回一个迭代器 (iterator) 对象。

**"迭代器"是什么意思?**

1. 它不是列表: 它不会立刻把所有排列结果全部计算出来并存在内存里,非常节省空间。
2. 它是"一次性"的: 你只能完整地遍历它一遍。一旦 for 循环走完,这个迭代器就空了。

**遍历迭代器时得到什么?**

- 当你在 for 循环中遍历这个迭代器时,它会逐一产出 (yield) 多个元组 (tuple)。
- 每一个产出的元组,就代表一种排列组合。
