### D - Goin' to the Zoo

**运行时间限制:** 2 sec
**内存限制:** 1024 MiB
**分值:** 400 分

---

#### 问题描述

AtCoder 国有 N 个动物园，编号为 1 到 N。动物园 i 的入园费为 C_i 日元。

铃木先生喜欢 M 种动物，即动物 1, ..., M。 动物 i 可以在 K_i 个动物园中看到，分别是动物园 A_{i,1}, ..., A_{i,K_i}。

为了让这 M 种动物每种都至少看到 2 次，请计算所需的入园费总和的最小值。

另外，如果多次访问同一个动物园，该动物园里的动物被观看的次数等于访问该动物园的次数。

---

#### 约束条件

*   1 ≤ N ≤ 10
*   1 ≤ M ≤ 100
*   0 ≤ C_i ≤ 10^9
*   1 ≤ K_i ≤ N
*   1 ≤ A_{i,j} ≤ N
*   j ≠ j' ⟹ A_{i,j} ≠ A_{i,j'}
*   输入均为整数

---

#### 输入

输入通过标准输入按以下格式给出：

```
N M
C_1 ... C_N
K_1 A_{1,1} ... A_{1,K_1}
...
K_M A_{M,1} ... A_{M,K_M}
```

---

#### 输出

输出答案。

---

#### 输入样例 1

```
4 3
1000 300 700 200
3 1 3 4
3 1 2 4
2 1 3
```

#### 输出样例 1

```
1800
```

按照以下方式，可以花费 1800 日元让动物 1, 2, 3 每种都至少被看到 2 次：

*   去动物园 3。支付入园费 700 日元，看动物 1, 3。
*   去动物园 3。支付入园费 700 日元，看动物 1, 3。
*   去动物园 4。支付入园费 200 日元，看动物 1, 2。
*   去动物园 4。支付入园费 200 日元，看动物 1, 2。

---

#### 输入样例 2

```
7 6
500 500 500 500 500 500 1000
3 1 2 7
3 2 3 7
3 3 4 7
3 4 5 7
3 5 6 7
3 6 1 7
```

#### 输出样例 2

```
2000
```

去 2 次动物园 7，可以花费总计 2000 日元让动物 1, 2, 3, 4, 5, 6 每种都被看到 2 次。
