这道题的核心破局点在于一个极其关键的信息——**数据范围非常小**。

### 1. 核心突破口：观察数据范围
题目中给出的制约条件是：
$$1 \le M \le N \le 10$$

由于 $N$ 最大只有 $10$，这意味着：
* 我们能从网格中截取出的 $M \times M$ 子网格的总数量非常少。
* 在最极端的情况下（例如 $N=10, M=1$ 时），最多也只有 $(N-M+1)^2 = 10^2 = 100$ 个子网格。

因为总数量最大只有 100 个，我们**完全不需要使用任何高级算法**（例如二维哈希或高级树状结构），直接采用最朴素的**暴力模拟 + 集合去重**即可轻松通关。

---

### 2. 具体解题步骤

整个解题过程可以分为三步：

#### 第一步：枚举所有可能的子网格起点
一个 $M \times M$ 的子网格，其左上角顶点 $(r, c)$ 的可行范围是：
* 行索引 $r$：$0 \le r \le N - M$
* 列索引 $c$：$0 \le c \le N - M$

我们可以通过两重循环来枚举所有可能的左上角起点 $(r, c)$。

#### 第二步：截取并表示子网格
对于每一个起点 $(r, c)$，我们取出其往右下方延伸的 $M \times M$ 区域。
为了能够进行“去重”和“比较”，我们需要将这个二维区域转化为一个可以哈希（Hashable）的数据结构。在 Python 中，有几种很方便的转化方式：
1. **元组（Tuple）**：将这 $M$ 行、每行长度为 $M$ 的字符串存入一个元组中，如 `( "##", "#." )`。
2. **扁平化字符串**：将这 $M$ 行拼接成一整个一维字符串。例如把上面的图形拼接为 `"###."`。

#### 第三步：使用集合（Set）自动去重
将所有截取并转化后的子网格表示放入一个 `set`（集合）中。
由于集合具有**元素唯一性**的特点，重复的图案会自动被过滤掉。最后，集合中元素的个数（即 `len(set)`）就是最终的答案。

---

### 3. Python 参考代码

利用上述思路，我们可以写出非常简洁且高效的代码：

```python
import sys


def solve():
    # 读取输入
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    N = int(input_data[0])
    M = int(input_data[1])
    grid = input_data[2:]

    # 用于存储所有不同子网格图案的集合
    unique_subgrids = set()

    # 枚举子网格左上角的行 r 和列 c
    for r in range(N - M + 1):
        for c in range(N - M + 1):
            # 截取 M 行、M 列的子网格
            # 并将其转化为元组（tuple）以便放入 set 中
            subgrid = tuple(grid[i][c : c + M] for i in range(r, r + M))
            unique_subgrids.add(subgrid)

    # 输出不同图案的数量
    print(len(unique_subgrids))


if __name__ == "__main__":
    solve()
```

### 4. 复杂度分析
* **时间复杂度**：共有 $O(N^2)$ 个子网格，每个子网格截取和哈希的时间为 $O(M^2)$。因此总时间复杂度为 $O(N^2 \cdot M^2)$。在 $N \le 10$ 的情况下，最大计算量仅约 $100 \times 100 = 10^4$ 次操作，运行时间少于 0.01 秒。
* **空间复杂度**：存储集合需要 $O(N^2 \cdot M^2)$ 的空间，在当前数据范围下几乎不占用内存。
