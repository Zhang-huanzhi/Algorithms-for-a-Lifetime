Explicit is better than implicit.（明晰胜于隐晦）  
Readability counts.（可读性很重要）


``` python
for r in range(n - m + 1):  
    for c in range(n - m  + 1):  
        subgrid = tuple(tuple(grid[i][c : c + m]) for i in range(r, r + m))  
        se.add(subgrid)
```

``` python
for r in range(n - m + 1):
    for c in range(n - m + 1):
        # 1. 明确我们要构建的是一个子网格的行集合
        subgrid_rows = []

        # 2. 只关注纵向：循环提取 M 行
        for i in range(r, r + m):
            # 3. 只关注横向：切片提取 M 列
            row_slice = grid[i][c : c + m]

            # 4. 只关注类型转换：为了可哈希，转成元组
            subgrid_rows.append(tuple(row_slice))

        # 5. 最后整体打包
        subgrid = tuple(subgrid_rows)
        se.add(subgrid)
```
