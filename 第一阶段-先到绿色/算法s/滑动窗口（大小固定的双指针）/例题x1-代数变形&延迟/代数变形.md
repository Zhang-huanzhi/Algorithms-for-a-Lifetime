在这道题中，**“代数变形”**（Algebraic Transformation）确实是一个非常经典且高效的解题小技巧。

在算法竞赛中，很多涉及“双变量约束”的问题，往往可以通过简单的代数移项，化繁为简。

下面我们来拆解一下这个变形的妙处：

---

### 1. 变形的过程

题目给出的原始限制条件是：
$$L \le j - i \le R \quad (\text{其中 } i < j)$$

这个公式中，$i$ 和 $j$ 相互纠缠在一起。如果我们直接用这个公式去思考，脑海中浮现的画面是：**“寻找两个点，它们之间的距离要在 $[L, R]$ 之间”**。这需要我们同时考虑两个变量，容易陷入 $O(N^2)$ 的暴力思维。

此时，我们使用**代数变形**。假设我们已经固定了右端点 $j$，我们尝试将左端点 $i$ 孤立出来：

* 首先看左半边：$L \le j - i \implies i \le j - L$
* 再看右半边：$j - i \le R \implies i \ge j - R$

把两边合并，就得到了：
$$j - R \le i \le j - L$$

---

### 2. 这个变形妙在哪里？

看似只是简单的移项，但它在算法设计上带来了巨大的转变：

#### 妙处一：从“两点关系”变成了“区间搜索”
* **变形前**：我们需要判断任意两个位置 $i$ 和 $j$ 的**差值**是否满足条件（这是一个“关系”问题）。
* **变形后**：我们只需要判断 $i$ 是否落在区间 $[j - R, j - L]$ 内部（这是一个“空间”问题）。

这意味着，我们不需要再去管 $i$ 和 $j$ 的差值了，只要 $i$ 在这个特定的区间里，它就一定是合法的。

#### 妙处二：暴露了“固定大小窗口”的本质
当我们看到 $j - R \le i \le j - L$ 时，我们可以计算一下这个区间的长度：
$$\text{长度} = (j - L) - (j - R) + 1 = R - L + 1$$

这个长度是一个**常数**（不随 $j$ 的改变而改变）。
一旦发现区间长度是常数，脑海中就可以瞬间联想到**“固定大小的滑动窗口”**。代数变形直接指明了算法的实现方向。

#### 妙处三：解耦变量（降维）
在多变量问题中，最怕变量之间相互耦合。通过代数变形，我们将 $i$ 的范围完全用包含 $j$ 的表达式来表示。这样：
* 外层循环只需要老老实实地递增 $j$（一维遍历）。
* 内层通过滑动窗口 $O(1)$ 维护 $[j - R, j - L]$ 的状态。
从而成功将 $O(N^2)$ 的问题降维到了 $O(N)$。

### 总结

这种“代数变形”的技巧在处理**区间距离限制**、**差值限制**（如 $|A_i - A_j| \le K$）等题目时非常通用。

它的核心思想是：**“固定一端，通过代数移项，将另一端的范围孤立出来，从而将其转化为区间查询问题。”**
