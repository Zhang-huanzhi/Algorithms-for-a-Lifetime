### C - K-bonacci

时间限制: 2 秒 / 内存限制: 1024 MiB

分值：300 分

#### 问题描述

给定正整数 $N$ 和 $K$。定义一个长度为 $N+1$ 的数列 $A=(A_0, A_1, \dots, A_N)$，其每个元素的值定义如下：

* 当 $0 \le i < K$ 时：
  $$A_i = 1$$
* 当 $K \le i$ 时：
  $$A_i = A_{i-K} + A_{i-K+1} + \dots + A_{i-1}$$

求出 $A_N$ 除以 $10^9$ 的余数。

#### 限制条件

* $1 \le N, K \le 10^6$
* 输入的所有数值均为整数。

#### 输入

输入按以下格式从标准输入给出：

$$N \quad K$$

#### 输出

输出答案。

---

#### 输入样例 1
```text
4 2
```

#### 输出样例 1
```text
5
```

$A_0 = A_1 = 1$，且：
* $A_2 = A_0 + A_1 = 2$
* $A_3 = A_1 + A_2 = 3$
* $A_4 = A_2 + A_3 = 5$

#### 输入样例 2
```text
10 20
```

#### 输出样例 2
```text
1
```

#### 输入样例 3
```text
1000000 500000
```

#### 输出样例 3
```text
420890625
```

请注意，输出的是 $A_N$ 除以 $10^9$ 的余数。
