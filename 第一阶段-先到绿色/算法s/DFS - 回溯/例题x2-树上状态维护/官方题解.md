这篇官方题解的解题思路非常经典，是一道标准的 **“树上 DFS + 状态回溯（Backtracking）”** 问题。

下面为你详细拆解题解的核心逻辑与实现细节：

---

### 一、为什么暴力会超时？

- 如果我们对每一个节点 $k$（共 $N$ 个），都单独去寻找从根节点 $1$ 到 $k$ 的路径并判断是否有重复数字，那么每次单次查找最坏是 $O(N)$。
- 处理完所有 $N$ 个节点，总时间复杂度就是 $O(N^2) \approx (2 \times 10^5)^2 = 4 \times 10^{10}$，显然会超时（TLE）。

---

### 二、核心突破口：利用 DFS 调用栈天然对应「路径」

在以节点 $1$ 为根的树上做**深度优先搜索（DFS）**时，有一个极其优美的性质：

> **当 DFS 遍历到某个节点 $v$ 时，递归栈中经过的所有节点，恰好就是从根节点 $1$ 到节点 $v$ 的唯一简单路径！**

因此，我们**完全不需要重复寻找路径**。只要在 DFS 的“进入节点”和“离开节点（回溯）”时动态维护路径信息，就可以在 **$O(N)$ 遍历整棵树一次的过程中，把所有 $N$ 个节点的答案全部算出来**。

---

### 三、如何动态维护“是否有重复元素”？

题解设计了两个工具：
1. **一个集合 $S$**：记录当前路径上已经出现过的所有数值。
2. **一个计数器 $cnt$**：记录当前路径上**重复出现的数字对数**（只要 $cnt > 0$，就说明当前路径存在重复）。

> 💡 **为什么需要计数器 $cnt$，而不能只用一个布尔变量 `has_dup`？**  
> 因为一条路径上可能产生多次重复（比如先后出现了两个重复）。如果只用布尔变量，当回溯离开其中一个重复节点时，我们不知道“剩下的路径里是否还有其他重复”。用计数器 $cnt$，每发现一次重复 $cnt + 1$，回溯时 $cnt - 1$，只要 $cnt > 0$ 就代表有重复。

#### 具体维护逻辑：

#### 1. 进入节点 $v$ 时（Push 操作）：
- 判断 $A_v$ 是否已经在集合 $S$ 中：
  - **如果在**：说明 $v$ 的祖先节点中已经有相同的数字了，产生了重复，令 `cnt += 1`。
  - **如果不在**：说明这是该数字第一次出现，将 $A_v$ 加入集合 $S$（`S.insert(A_v)`）。
- **记录答案**：
  - 如果此时 $cnt > 0$，则节点 $v$ 的答案为 `Yes`；
  - 否则为 `No`。

#### 2. 遍历 $v$ 的所有子节点（递归深入）：
- 继续向下 DFS。

#### 3. 离开节点 $v$ 时（Pop 回溯操作）：
- **撤销**进入 $v$ 时对状态造成的修改（必须严格对称复原）：
  - 如果进入 $v$ 时把它加入了集合 $S$，则将 $A_v$ 从 $S$ 中删去；
  - 如果进入 $v$ 时触发了 `cnt += 1`，则令 `cnt -= 1`。

---

### 四、图解示例走读

以样例 1 为例：
树结构：`1(1) - 3(2) - 4(1)`
- 访问 `1`（数值 1）：$S=\{1\}, cnt=0 \implies \text{Ans}[1]=\text{No}$
- 访问 `3`（数值 2）：$S=\{1, 2\}, cnt=0 \implies \text{Ans}[3]=\text{No}$
- 访问 `4`（数值 1）：$1$ 已经在 $S$ 中！触发 `cnt += 1`（此时 $cnt=1$），$S=\{1, 2\} \implies \text{Ans}[4]=\text{Yes}$
- 回溯离开 `4`：撤销修改，`cnt -= 1`（$cnt$ 恢复为 0）。
- 回溯离开 `3`：撤销修改，从 $S$ 中删去 2。

### 五、代码实现

#### Python 实现
```python
import sys

# 提高递归深度限制，避免深树导致 RecursionError
sys.setrecursionlimit(300000)

def main():
    input = sys.stdin.read
    data = input().split()
    if not data:
        return

    n = int(data[0])
    
    # 读入每个顶点的权值 A_i (1-indexed)
    a = [0] + [int(x) for x in data[1 : 1 + n]]
    
    # 建邻接表
    adj = [[] for _ in range(n + 1)]
    idx = 1 + n
    for _ in range(n - 1):
        u = int(data[idx])
        v = int(data[idx + 1])
        adj[u].append(v)
        adj[v].append(u)
        idx += 2

    ans = [""] * (n + 1)
    seen_set = set()
    cnt = 0

    def dfs(u, parent):
        nonlocal cnt
        val = a[u]
        
        # 1. 进入节点 u
        is_new_element = False
        if val in seen_set:
            cnt += 1
        else:
            seen_set.add(val)
            is_new_element = True

        # 记录当前节点的答案
        ans[u] = "Yes" if cnt > 0 else "No"

        # 2. 递归访问子节点
        for v in adj[u]:
            if v != parent:
                dfs(v, u)

        # 3. 回溯（离开节点 u，复原状态）
        if is_new_element:
            seen_set.remove(val)
        else:
            cnt -= 1

    # 从根节点 1 开始 DFS
    dfs(1, 0)

    # 按照 1 到 N 输出答案
    sys.stdout.write('\n'.join(ans[1:]) + '\n')

if __name__ == '__main__':
    main()
```

#### C++ 实现
```cpp
#include <iostream>
#include <vector>
#include <unordered_set>
#include <string>

using namespace std;

int n;
vector<int> a;
vector<vector<int>> adj;
vector<string> ans;
unordered_set<int> seen;
int cnt = 0;

void dfs(int u, int p) {
    int val = a[u];
    bool is_new = false;

    // 1. 进入节点 u
    if (seen.count(val)) {
        cnt++;
    } else {
        seen.insert(val);
        is_new = true;
    }

    // 记录答案
    ans[u] = (cnt > 0) ? "Yes" : "No";

    // 2. 递归子节点
    for (int v : adj[u]) {
        if (v != p) {
            dfs(v, u);
        }
    }

    // 3. 回溯，离开节点 u
    if (is_new) {
        seen.erase(val);
    } else {
        cnt--;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    if (!(cin >> n)) return 0;

    a.resize(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }

    adj.resize(n + 1);
    for (int i = 0; i < n - 1; ++i) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    ans.resize(n + 1);
    dfs(1, 0);

    for (int i = 1; i <= n; ++i) {
        cout << ans[i] << "\n";
    }

    return 0;
}
```

### 六、复杂度分析

- **时间复杂度**：每个节点和每条边都只被访问常数次，哈希集合的插入/删除平均时间为 $O(1)$，总时间复杂度为 **$O(N)$**（若用 `std::set` 则为 $O(N \log N)$），在 2 秒内处理 $N = 2 \times 10^5$ 极其轻松。
- **空间复杂度**：邻接表和递归调用栈占用 **$O(N)$** 空间。
