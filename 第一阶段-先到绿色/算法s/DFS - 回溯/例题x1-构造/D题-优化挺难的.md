### D - Coefficient Stair

**时间限制**：2 秒 / **内存限制**：1024 MiB

**分值**：400 分

#### 题目描述

请按**字典序升序**输出所有满足以下条件的、由非负整数构成的长度为 $N$ 的序列 $A = (A_1, A_2, \dots, A_N)$：

$$\sum_{i=1}^{N} i \times A_i = K$$

保证输入的数据中，满足条件的序列总数不超过 $3 \times 10^5$ 个。

<details>
<summary>什么是数列的字典序？</summary>
若序列 $S = (S_1, S_2, \dots, S_{|S|})$ 满足以下条件 1 或 2 之一，则称 $S$ 的字典序小于 $T = (T_1, T_2, \dots, T_{|T|})$（其中 $|S|, |T|$ 分别表示序列 $S, T$ 的长度）：

1. $|S| < |T|$ 且 $(S_1, S_2, \dots, S_{|S|}) = (T_1, T_2, \dots, T_{|S|})$。
2. 存在一个整数 $1 \le i \le \min(|S|, |T|)$，使得：
   - $(S_1, S_2, \dots, S_{i-1}) = (T_1, T_2, \dots, T_{i-1})$
   - 且 $S_i < T_i$（数值大小）。
</details>

#### 制约条件

- $1 \le N \le 10$
- $1 \le K \le 2 \times 10^5$
- 满足条件的序列个数不超过 $3 \times 10^5$
- 所有输入均为整数

#### 输入格式

输入通过标准输入按以下格式给出：

```text
N K
```

#### 输出格式

设满足条件的非负整数序列共有 $q$ 个，请输出 $q$ 行。  
每行输出一个满足条件的序列，各元素之间用空格分隔。  
输出的所有序列必须严格按照字典序从小到大排列。

---

#### 样例 1

**输入**
```text
3 8
```

**输出**
```text
0 1 2 
0 4 0 
1 2 1 
2 0 2 
2 3 0 
3 1 1 
4 2 0 
5 0 1 
6 1 0 
8 0 0 
```

**说明**  
例如序列 $(0, 1, 2)$ 满足 $0 \times 1 + 1 \times 2 + 2 \times 3 = 0 + 2 + 6 = 8$。由于不存在比它字典序更小的满足条件的序列，因此第 1 行输出 `0 1 2`。  
包括 $(0, 1, 2)$ 在内共有 10 个序列满足条件，请按字典序升序输出它们。
