### C - ~ (波浪型)
**运行时间限制：2秒 / 内存限制：1024 MiB**

**分值：350 点**

#### 问题描述
对于一个整数序列 $A = (A_1, A_2, \dots, A_{|A|})$，如果它满足以下全部 4 个条件，则将其定义为 **“波浪型（Tilde 型）”**：

1.  $A$ 的长度 $|A|$ 为 4 以上。
2.  $A_1 < A_2$。
3.  满足 $A_{i-1} < A_i > A_{i+1}$ 的整数 $i$ ($2 \le i < |A|$) 恰好有 1 个（即序列中存在且仅存在一个局部极大值）。
4.  满足 $A_{i-1} > A_i < A_{i+1}$ 的整数 $i$ ($2 \le i < |A|$) 恰好有 1 个（即序列中存在且仅存在一个局部极小值）。

给定一个由 $(1, 2, \dots, N)$ 重排列得到的数列 $P = (P_1, P_2, \dots, P_N)$。
请计算 $P$ 的所有连续子序列中，是“波浪型”的子序列个数。

#### 约束条件
*   $4 \le N \le 3 \times 10^5$
*   $P = (P_1, P_2, \dots, P_N)$ 是 $(1, 2, \dots, N)$ 的一个排列
*   输入的所有值均为整数

#### 输入格式
输入通过标准输入按以下格式给出：

$N$
$P_1$ $P_2$ $\dots$ $P_N$

#### 输出格式
输出答案。

### 补充示例说明（输入/输出）

**输入例 1**
```
6
1 3 6 4 2 5
```
**输出例 1**
```
2
```
*解释：在 (1, 3, 6, 4, 2, 5) 中，符合条件的连续子序列是 (3, 6, 4, 2, 5) 和 (1, 3, 6, 4, 2, 5)。*

```
6
1 2 3 4 5 6
```
**输出例 2**
```
0
```

**输入例 3**
```
12
```

**输出例 3**

```
4
```
