# C - 1122 子串 2

**运行时间限制：** 2 sec / **内存限制：** 1024 MiB  
**配点：** 300 分

## 问题描述

给定一个由数字组成的字符串 `S`。

满足以下所有条件的字符串 `T` 被称为 **1122 字符串**（其定义与 F 题相同）：

1. `T` 是由数字组成的非空字符串。
2. `|T|` 是偶数。这里 `|T|` 表示字符串 `T` 的长度。
3. `T` 的前 `|T| / 2` 个字符（从第 1 到第 `|T| / 2` 个字符）全部由同一种数字组成。
4. `T` 的后 `|T| / 2` 个字符（从第 `|T| / 2 + 1` 到第 `|T|` 个字符）全部由同一种数字组成。
5. `T` 的第 1 个字符代表的数字加 1 等于 `T` 的最后一个字符代表的数字。

例如，`1122`、`01`、`444555` 都是 1122 字符串，但 `1222` 或 `90` 不是。

请计算 `S` 的子串中属于 1122 字符串的个数。

注意：即使两个子串作为字符串的内容相同，只要它们在 `S` 中的起始或结束位置不同，也应当分别计数。

## 制约条件

- `S` 是长度在 `1` 到 `10^6` 之间（包含边界）的由数字组成的字符串。

## 输入

输入按以下格式从标准输入给出：

```text
S
```

## 输出

输出 `S` 的非空子串中，属于 1122 字符串的个数。

## 输入例 1

```text
1122
```

## 输出例 1

```text
2
```

以下 2 个子串满足条件：

- 取出 `S` 的第 2 到第 3 个字符得到的 `12`。
- 取出 `S` 的第 1 到第 4 个字符得到的 `1122`。

因此输出 `2`。

## 输入例 2

```text
7788788
```

## 输出例 2

```text
3
```

请注意，即使字符串相同，只要位置不同就要分别计数。

## 输入例 3

```text
2025
```

## 输出例 3

```text
0
```

可能不存在任何满足条件的 1122 字符串子串。

## 输入例 4

```text
1112222334445556555
```

## 输出例 4

```text
11
```


# AC Code RLE
``` python
import sys  
  
def main():  
      
    arr = list(sys.stdin.readline().strip())  
    n = len(arr)  
  
    arr = [int(arr[i]) for i in range(n)]  
    ans = 0  
  
    # 直接行程压缩吧  
    brr = []  
    curr = arr[0]  
    cnt = 1  
    for i in range(1, n):  
        if arr[i] == curr:  
            cnt += 1  
        else:  
            brr.append( (curr, cnt) )  
            curr = arr[i]  
            cnt = 1  
    # 处理最后一个数字  
    brr.append( ( curr, cnt) )  
  
    for i in range(len(brr) - 1):  
        x, cnt = brr[i]  
        y, bnt = brr[i + 1]  
  
        if x + 1 == y:  
            ans += min(cnt, bnt)  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```
