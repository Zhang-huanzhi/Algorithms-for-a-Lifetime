游程编码的逻辑非常固定，通常使用一个变量记录**当前元素**，一个变量记录**连续出现的次数**。
你在之前的代码里写的非常标准。这里给出一个更通用、可以作为工具函数的 Python 模板：

```python
def run_length_encoding(arr):
    if not arr:
        return []
    
    encoded = []
    current_val = arr[0]
    count = 1
    
    for i in range(1, len(arr)):
        if arr[i] == current_val:
            count += 1
        else:
            # 遇到不同的元素了，把之前的打包存起来
            encoded.append((current_val, count))
            # 重置为新元素
            current_val = arr[i]
            count = 1
            
    # 别忘了收尾！把最后一组数据存进去
    encoded.append((current_val, count))
    
    return encoded
```
**注意：** 循环结束后的最后一次 `append` 是新手最容易漏掉的，但你在刚才的代码里完美地处理了它（`crr.append(...)`），非常赞！
