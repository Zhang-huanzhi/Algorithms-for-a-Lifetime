
| 查找需求                | 转换公式                             | 示例：在 `[1, 3, 3, 3, 5]` 中查找 `3` | 边界情况判定                            |
| :------------------ | :------------------------------- | :----------------------------- | :-------------------------------- |
| **第一个 $\ge X$ 的数**  | `idx = bisect_left(arr, X)`      | `idx = 1`（对应 `3`）              | 如果 `idx == len(arr)`，说明全部数都 $< X$ |
| **第一个 $> X$ 的数**    | `idx = bisect_right(arr, X)`     | `idx = 4`（对应 `5`）              | 如果 `idx == len(arr)`，说明没有数 $> X$  |
| **最后一个 $\le X$ 的数** | `idx = bisect_right(arr, X) - 1` | `idx = 3`（对应最后一个 `3`）          | 如果 `idx == -1`，说明全部数都 $> X$       |
| **最后一个 $< X$ 的数**   | `idx = bisect_left(arr, X) - 1`  | `idx = 0`（对应 `1`）              | 如果 `idx == -1`，说明没有数 $< X$        |
