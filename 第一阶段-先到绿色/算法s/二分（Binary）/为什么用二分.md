**二分的价值，在于把原本可能要做的线性扫描，从 $O(n)$ 优化到 $O(\log n)$。**

二分的核心不是“从中间找”，而是“利用有序性或单调性，每次排除一半搜索空间”，所以相比线性查找，效率从 $O(n)$ 优化到了 $O(\log n)$。



| 方法           | 优点         | 缺点       | 适用场景            |
| ------------ | ---------- | -------- | --------------- |
| **bisect 库** | 简洁、快速、不易出错 | 只能用于有序数组 | 有序数组查找/计数       |
| **手写二分**     | 灵活、适用范围广   | 容易出错、费时  | 二分答案、复杂逻辑       |
| **线性查找**     | 代码简单       | O(n) 太慢  | 小数据量 (n ≤ 1000) |
