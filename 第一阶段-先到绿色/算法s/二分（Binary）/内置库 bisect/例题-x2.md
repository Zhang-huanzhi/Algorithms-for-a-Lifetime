# 题目名称：四项礼品的组合方案

## 问题描述

你现在有四个礼品清单，分别是：零食 (A)、饮料 (B)、玩具 (C) 和 装饰品 (D)。每个清单中正好有 `N` 种物品。

- 第 `i` 种零食的价格为 `Aᵢ`
- 第 `j` 种饮料的价格为 `Bⱼ`
- 第 `k` 种玩具的价格为 `Cₖ`
- 第 `l` 种装饰品的价格为 `Dₗ`

你需要从每个清单中各选一种物品组成一个大礼包。你手中的总预算为 `K`。

**请问**：有多少种不同的组合方案，使得这四种物品的总价格之和不超过 `K`？

即：求满足 `Aᵢ + Bⱼ + Cₖ + Dₗ ≤ K` 的四元组 `(i, j, k, l)` 的总数。

---

## 输入格式

- 第一行包含两个整数 `N` 和 `K`
- 第二行包含 `N` 个整数 `A₁, A₂, …, Aₙ`
- 第三行包含 `N` 个整数 `B₁, B₂, …, Bₙ`
- 第四行包含 `N` 个整数 `C₁, C₂, …, Cₙ`
- 第五行包含 `N` 个整数 `D₁, D₂, …, Dₙ`

---

## 输出格式

输出一个整数，表示合法的方案总数。

---

## 约束条件

- `1 ≤ N ≤ 1000`（注意：这个规模下 `O(N⁴)` 必死，`O(N³)` 也很难过）
- `1 ≤ K ≤ 10⁹`
- 所有物品价格 `1 ≤ Aᵢ, Bⱼ, Cₖ, Dₗ ≤ 10⁹`
- 时间限制：2.0 秒

---

## 样例输入

```
2 10
1 2
3 4
1 5
2 3
```

## 样例输出

```
8
```

---

## 样例解释

`N=2, K=10`。

`A=[1,2], B=[3,4], C=[1,5], D=[2,3]`

可能的组合（部分）：

- `1+3+1+2=7≤10` (OK)
- `1+3+1+3=8≤10` (OK)
- `1+3+5+2=11>10` (不行)
- `2+4+1+3=10≤10` (OK)
- ...

经过计算，共有 8 种方案满足条件。

---

## 解题核心：折半搜索 (Meet-in-the-middle)

如果你直接用四层循环，复杂度是 `O(N⁴) = 1000⁴ = 10¹²`，没有任何计算机能在 2 秒内跑完。

### 优化思路：

#### 1. 两两组合

- 利用 `O(N²)` 的双层循环，计算出所有可能的 `Aᵢ + Bⱼ`。将这些和存入一个列表 `sum_AB`。
- 同样的，利用 `O(N²)` 的双层循环，计算出所有可能的 `Cₖ + Dₗ`。将这些和存入一个列表 `sum_CD`。
- 这两个列表的大小都是 `N² = 1,000,000`（一百万）。

#### 2. 排序

将 `sum_CD` 进行排序。复杂度为 `O(N² log N²)`。

#### 3. 二分查找

- 遍历 `sum_AB` 里的每一个数值 `s`。
- 我们要找的是有多少个 `sum_CD` 里的元素满足 `≤ K - s`。
- 这正是 `bisect.bisect_right(sum_CD, K - s)` 的用武之地！

### 总复杂度

`O(N² log N²)`。

计算量约为 `10⁶ × 20 = 2×10⁷`。这个量级在 PyPy3 中运行通常在 1 秒左右，非常安全。

### Python 性能小建议

#### 1. 生成 sum_AB 和 sum_CD 时，使用列表推导式

