**bisect** = Python 内置的**二分查找**库

- 全称：**bi**nary **sect**ion（二分分割）
- 作用：在**有序数组**中快速查找/插入
- 复杂度：O(log n)

底层是用 **C 语言** 实现的


---
## 1. 两个核心函数

### `bisect_left(arr, x)`

- 返回第一个**大于或等于** `x` 的索引
- 意为：如果要把 `x` 插入，且不破坏顺序，它应该放在哪里？
- 如果有重复的 `x`，它会放在最左边那个 `x` 的位置

### `bisect_right(arr, x)`

- 返回第一个**严格大于** `x` 的索引
- 意为：如果有重复的 `x`，它会放在最右边那个 `x` 的后面

---

## 2. 什么时候会用到？（竞赛常用场景）

### 场景 A：区间计数（最常用）

**问题**：给定一个有序数组 `A`，询问有多少个数在区间 `[L, R]` 之间？

- **解法**：`bisect_right(A, R) - bisect_left(A, L)`
- **复杂度**：`O(log N)`
- **例子**：ABC-C/D 经常让你数符合条件的数字个数，只要数组有序，这行代码就是绝杀

---

### 场景 B：查找前驱/后继

**问题**：在有序数组中，找到最接近 `X` 且小于 `X` 的数，或者大于 `X` 的数

- **大于 `X` 的第一个数**：`A[bisect_right(A, X)]`（注意判断索引是否越界）
- **小于 `X` 的最后一个数**：`A[bisect_left(A, X) - 1]`（注意判断索引是否小于 0）

---

### 场景 C：坐标离散化

**问题**：给你一堆很大的坐标（如 `10^9`），但总数只有 `10^5`，你需要知道某个坐标在所有坐标中排第几

- **解法**：先将所有坐标去重并排序存入 `sorted_coords`，然后对每个坐标用 `bisect_left` 查索引

---

### 场景 D：等级/档位判定

**问题**：90分以上A，80-90分B，70-80分C...

**解法**：

```python
grades = [70, 80, 90]
labels = ['D', 'C', 'B', 'A']
score = 85
idx = bisect.bisect_right(grades, score)
print(labels[idx])  # 输出 B
```

## 3. AtCoder 进阶技巧：key 参数

AtCoder 的 PyPy3 支持 `key` 参数（Python 3.10+ 特性）。如果你有一个元组列表，想根据其中一个元素二分，非常方便：

```python
# 假设每个元素是 (价值, 重量)，已按价值排序
items = [(10, 100), (20, 50), (30, 80)]

# 寻找第一个 价值 >= 25 的物品索引
idx = bisect.bisect_left(items, 25, key=lambda x: x[0])
# idx = 2
```

---

## 总结：什么时候不该用它？

### 1. 数组没排好序时

必须先 `sort()`。如果数组频繁变动（一会儿插入一会儿查），用 bisect 就不划算了，因为每次插入的时间复杂度是 `O(N)`（虽然查找快，但数组移动慢）。

### 2. 二分答案时

如果要二分一个"逻辑上的数值"（如射气球的高度），没有现成的数组，此时必须手写 `while l <= r`。

---

**简而言之**：只要你手里有一个排好序的 List，并且你想在里面"定位"，就用 bisect。
