# 题目：精明消费者的礼品选择

这道题是 ABC-D 级别中非常经典的一类问题：**组合计数问题**。它能帮你完美练习如何将 `O(N²)` 的暴力转化为 `O(N log N)` 的高效算法。

---

## 问题描述

你有两个礼品清单，分别是 `N` 种零食和 `M` 种饮料。

- 第 `i` 种零食的价格为 `Aᵢ`
- 第 `j` 种饮料的价格为 `Bⱼ`

你现在有 `Q` 个朋友。对于每个朋友，你都有一个不同的预算 `Kq`。你希望从零食清单里选一种，从饮料清单里选一种，作为礼品送给这个朋友。

**问题**：对于每一个朋友，有多少种不同的组合方案，使得"零食价格 + 饮料价格"不超过他的预算 `Kq`？

---

## 输入格式

- 第一行包含三个整数 `N, M, Q`
- 第二行包含 `N` 个整数 `Aᵢ`
- 第三行包含 `M` 个整数 `Bⱼ`
- 第四行包含 `Q` 个整数 `Kq`

---

## 输出格式

- 输出 `Q` 行，每行一个整数，表示对应预算下的方案总数

---

## 约束条件

- `1 ≤ N, M, Q ≤ 2 × 10⁵`
- `1 ≤ Aᵢ, Bⱼ ≤ 10⁹`
- `1 ≤ Kq ≤ 2 × 10⁹`
- 时间限制：2.0 秒（这对 `O(N²)` 绝对过不去，但 `O(N log N)` 没问题）

---

## 样例输入

```
3 3 2
3 1 4
6 2 8
10 5
```

## 样例输出

```
7
2
```

---

## 样例解释

### 朋友 1 的预算是 10：

- 选择 `A=3`：`3+B ≤ 10 ⟹ B ≤ 7`。饮料中 `B=2, 6` 符合（2 种）
- 选择 `A=1`：`1+B ≤ 10 ⟹ B ≤ 9`。饮料中 `B=2, 6, 8` 符合（3 种）
- 选择 `A=4`：`4+B ≤ 10 ⟹ B ≤ 6`。饮料中 `B=2, 6` 符合（2 种）
- 总共 `2+3+2=7` 种

### 朋友 2 的预算是 5：

- 选择 `A=3`：`B ≤ 2`（1 种）
- 选择 `A=1`：`B ≤ 4`（1 种）
- 选择 `A=4`：`B ≤ 1`（0 种）
- 总共 `1+1+0=2` 种

---

## 给你的练习提示（如果你想自己挑战，先别看）

### 1. 为什么暴力不行？

`N, M, Q` 都是 `2 × 10⁵`，如果三层循环，复杂度 `O(Q × N × M)` 是天文数字。

### 2. 固定一个，二分另一个

对于每一个预算 `K`，我们遍历每一个 `Aᵢ`。那么我们需要找的就是：有多少个 `Bⱼ` 满足 `Bⱼ ≤ K - Aᵢ`。

### 3. 准备工作

为了能快速数出有多少个 `Bⱼ` 小于某个值，你需要先把 `B` 数组排序。

### 4. 使用 bisect

在排序后的 `B` 数组里，找第一个大于 `K - Aᵢ` 的位置，那个位置的索引值不就是符合条件的个数吗？

### 5. 注意

这道题有 `Q` 个查询，你可以先只做 `Q=1` 的情况（也就是只针对一个预算算总数），然后再考虑多个朋友。
