不要试图找“正确的位置”，要试图“排除不可能的区间”

- **第一招：闭区间大法 (l <= r)**  
    始终让 l 指向区间的头，r 指向区间的尾（n-1）。只要 l <= r，区间就还有效。这样你永远不用担心 mid 会指向哪里，也不用纠结最后返回的是 l 还是 r。

- **第二招：ans 变量记录法**  
    这是最关键的一招。在 if 成立的代码块里，加上一句 ans = mid。  
    这样你就把“寻找问题”变成了“赋值问题”。循环结束后，ans 就是你最后一次心动（满足条件）的那个位置。
    
- **第三招：+1 / -1 永不回头**  
    只要进入了 if 或 else，就让 l = mid + 1 或 r = mid - 1。  
    为什么要加减1？因为当前的 mid 要么已经存进 ans 了，要么已经确定不是答案了，它已经没用了，必须跳过它。这样写**永远不会死循环**。
