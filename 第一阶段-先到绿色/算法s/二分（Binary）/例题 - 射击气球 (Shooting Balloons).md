# 题目名称：射击气球 (Shooting Balloons)

## 问题描述

有 `N` 个气球正在向上飞行。在时间 `t=0` 时，第 `i` 个气球的高度为 `Hi`，它的飞行速度是每秒 `Si`。也就是说，在时间 `t`（`t` 为非负整数），它的高度是 `Hi + Si × t`。

你是一个神射手，每秒钟可以射爆一个气球。

- 你可以在 `t=0, 1, 2, …, N−1` 这些时刻各射爆一个气球。
- 一旦气球被射爆，它就会消失，高度不再增加。

你的目标是：通过合理安排射击的顺序，使得所有被射爆的气球中，高度最高的那一个气球的高度尽可能小。

请输出这个"最小化的最大高度"。

---

## 输入格式

- 第一行包含一个整数 `N` (`1 ≤ N ≤ 10^5`)。
- 接下来的 `N` 行，每行包含两个整数 `Hi` 和 `Si` (`1 ≤ Hi, Si ≤ 10^9`)。

---

## 输出格式

- 输出一个整数，表示所有气球中最高高度的最小值。

---

## 样例输入

```
4
5 6
12 4
14 7
21 2
```

## 样例输出

```
23
```

---

## 样例解释

如果在 `t=0, 1, 2, 3` 分别射击气球 3, 2, 1, 4：

- `t=0` 射 3 号：高度 `14 + 7×0 = 14`
- `t=1` 射 2 号：高度 `12 + 4×1 = 16`
- `t=2` 射 1 号：高度 `5 + 6×2 = 17`
- `t=3` 射 4 号：高度 `21 + 2×3 = 27`

最大高度是 27。但这并不是最优的。

**最优策略**是 `t=0` 射 4 号，`t=1` 射 3 号，`t=2` 射 2 号，`t=3` 射 1 号。此时最大高度为 23。

---

## 解题思路与突破点

这道题如果直接想"怎么射"，会陷入复杂的贪心逻辑。我们要换个思路：

### 1. 为什么用二分？（判断单调性）

如果我问你："你能否在所有气球高度都不超过 `X` 的情况下，射爆所有气球？"

- 如果高度 `X` 是可以实现的，那么比 `X` 更大的高度（比如 `X+100`）肯定也能实现。
- 如果高度 `X` 无法实现，那么比 `X` 更小的高度肯定更无法实现。

这种**单调性**意味着我们可以通过**二分查找**来寻找那个临界点 `X`。
