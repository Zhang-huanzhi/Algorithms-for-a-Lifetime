你的第二个代码使用了优先队列（堆），虽然把复杂度从 $O(K \cdot N)$ 优化到了 $O(K \log N)$，但由于题目中 **$K$ 的范围最大达到 $10^{18}$**，即使是 $O(\log N)$ 的算法也会因为循环次数过多而**超时 (TLE)**。


---

``` python
import heapq
import sys

def solve():

    n, k = map(int, sys.stdin.readline().strip().split())

    arr = list(map(int, sys.stdin.readline().strip().split()))

    brr = []
    for i in range(n):
        brr.append((arr[i], i+1))

    heapq.heapify(brr)

    for _ in range(k):
        value, idx = heapq.heappop(brr)

        heapq.heappush(brr, (value + idx, idx))

    value, idx = heapq.heappop(brr)

    print(value)

if __name__ == '__main__':
    solve()
```
