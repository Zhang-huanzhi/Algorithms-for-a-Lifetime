## 二分查找 （浮点数）

### 方法一：基于精度的循环

python

```python
def binary_search_float(L, R, eps=1e-6):
    """
    L: 左边界
    R: 右边界
    eps: 精度要求
    """
    while R - L > eps:
        mid = (L + R) / 2
        if check(mid):
            R = mid  # 答案在 [L, mid]
        else:
            L = mid  # 答案在 [mid, R]
    return L  # 或 return R，或 return (L + R) / 2
```

### 方法二：固定迭代次数
```python
def binary_search_float_fixed(L, R, iterations=100):
    """
    L: 左边界
    R: 右边界
    iterations: 迭代次数（通常 100 次足够达到 1e-9 精度）
    """
    for _ in range(iterations):
        mid = (L + R) / 2
        if check(mid):
            R = mid
        else:
            L = mid
    return (L + R) / 2
```
