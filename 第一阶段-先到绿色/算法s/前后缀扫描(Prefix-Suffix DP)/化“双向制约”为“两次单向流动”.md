**前后缀扫描（Prefix-Suffix Scan / Two-Pass Scan）**是算法面试和竞赛中**最实用、性价比最高**的技巧之一。

它的核心威力在于：**把原本需要 $O(N^2)$ 的“全局互相影响问题”，拆解成两个 $O(N)$ 的“单向流动问题”。**

下面从 **核心思想、解题套路、经典应用、适用场景** 四个方面为你彻底讲透这个算法。

---

### 一、 核心思想：化“双向制约”为“两次单向流动”

在一维数组的问题中，一个位置 $i$ 的最终状态，往往同时受到两股力量的制约：
1. **来自它左边所有元素（$0 \sim i-1$）的累积影响（前缀力量）**
2. **来自它右边所有元素（$i+1 \sim n-1$）的累积影响（后缀力量）**

```text
              [来自左边的影响] --->  位置 i  <--- [来自右边的影响]
              (0, 1, ..., i-1)                 (i+1, ..., n-1)
```

如果我们在每个位置 $i$ 都把左边和右边全部看一遍，时间复杂度是 $O(N \times N) = O(N^2)$。

**前后缀扫描的破局点**：
因为左边的影响是一路向右传递的，右边的影响是一路向左传递的。我们不需要每次都回头看，只需要：
1. **Pass 1（正向遍历）**：自左向右扫一遍，**把左边的所有影响打包传递给右边**。
2. **Pass 2（反向遍历）**：自右向左扫一遍，**把右边的所有影响打包传递给左边**。
3. **Merge（合并得出结果）**：两个方向的信息碰撞，直接得出每个位置的全局最优解。

### 二、 前后缀扫描的经典通用模板

前后缀扫描通常有两种实现形态：

#### 形态 1：双辅助数组法（最直观、不易出错）
```python
# 1. 算前缀信息：只考虑左边对当前的影响
left = [0] * n
for i in range(1, n):
    left[i] = do_something(left[i - 1], arr[i - 1])

# 2. 算后缀信息：只考虑右边对当前的影响
right = [0] * n
for i in range(n - 2, -1, -1):
    right[i] = do_something(right[i + 1], arr[i + 1])

# 3. 汇总合并结果
ans = [0] * n
for i in range(n):
    ans[i] = merge(left[i], right[i])
```

#### 形态 2：原地滚动更新（极致省空间，也就是我们这道题的写法）
如果更新操作具有**单调性**（例如只取 $\min$ 或只取 $\max$），甚至连辅助数组都不需要，直接在原数组上改：
```python
# 1. 正向刷：把左边的限制推给右边
for i in range(1, n):
    arr[i] = min(arr[i], arr[i - 1] + 1)

# 2. 反向刷：把右边的限制推给左边
for i in range(n - 2, -1, -1):
    arr[i] = min(arr[i], arr[i + 1] + 1)
```

### 三、 经典真题串讲（举一反三）

掌握了这个思维模型，你会发现 LeetCode 和各大竞赛中的一大批中等/困难题本质上都是同一道题：

#### 1. LeetCode 135. 分发糖果 (Candy)
* **题目**：每个孩子有评分。相邻孩子中，评分高的必须比评分低的多拿糖果。求最少糖果数。
* **前后缀解法**：
  1. 初始每个人发 1 颗糖。
  2. **从左往右扫**：如果右边评分比左边高，右边糖果 = 左边糖果 + 1。
  3. **从右往左扫**：如果左边评分比右边高，左边糖果 = $\max(\text{左边糖果}, \text{右边糖果} + 1)$。
  4. 两趟扫完，求和即为答案！

#### 2. LeetCode 42. 接雨水 (Trapping Rain Water)
* **题目**：给一组柱子的高度，求下雨能接多少水。
* **物理规律**：位置 $i$ 能接的水高度 = $\min(\text{左边最高柱子}, \text{右边最高柱子}) - \text{当前柱子高度}$。
* **前后缀解法**：
  1. 从左往右扫出 `left_max` 数组（记录 $i$ 左边的最高峰）。
  2. 从右往左扫出 `right_max` 数组（记录 $i$ 右边的最高峰）。
  3. 遍历每个位置，水深就是 $\min(left\_max[i], right\_max[i]) - height[i]$。

#### 3. LeetCode 238. 除自身以外数组的乘积 (Product of Array Except Self)
* **题目**：求除了当前元素外，其他所有元素的乘积（要求不能用除法且 $O(N)$）。
* **前后缀解法**：
  - 位置 $i$ 的答案 = **（$i$ 左边所有数的乘积）$\times$（$i$ 右边所有数的乘积）**。
  - 从左往右算前缀积，从右往左算后缀积，两者相乘。

### 四、 什么情况下该想到“前后缀扫描”？

只要在做题时发现以下 **3 个信号**，就要立刻联想到前后缀扫描：

1. **一维线性数据**（数组、字符串、一排棋子/柱子/人）。
2. **约束/状态依赖于全局左右两侧**（例如：题目要求同时和左边比、和右边比，或者取决于左侧极值与右侧极值）。
3. **不能直接排序**（一旦排序就会破坏原有的左右相对位置顺序）。

只要满足这三点，不用怀疑，**“正向扫一遍记录前缀，反向扫一遍记录后缀”** 几乎就是唯一且最优的解法！
