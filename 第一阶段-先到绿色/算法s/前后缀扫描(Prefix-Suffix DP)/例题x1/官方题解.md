这篇官方题解的思路非常经典，属于**双向传递约束（前后缀扫一遍 / 动态规划传播）**。

下面将题解的思考过程拆解为直观的三个部分进行讲解：

---

### 一、 核心观察：操作的方向与约束的传递

1. **棋子只能往上移（行号只能变小）**：
   - 设棋子最终所在的行数为 $R'_i$。
   - 既然只能往上走，那么最终位置必须满足：$R'_i \le R_i$。
   - 要让操作次数最少，也就是要让每个 $R'_i$ **尽可能大**（尽量少往上移）。
   - 每次操作让行号减少 $1$，因此第 $i$ 列的操作次数为 $R_i - R'_i$。总操作次数就是 $\sum (R_i - R'_i)$。

2. **相邻高度差不超过 1 的连锁反应**：
   - 题目要求 $|R'_i - R'_{i+1}| \le 1$。
   - 这意味着：第 $i$ 列的棋子每向左或向右走 1 列，高度最多只能增加 1。
   - 推广到任意两列 $i$ 和 $j$：$|R'_j - R'_i| \le |j - i|$，即 **$R'_j \le R'_i + |j - i|$**。
   - 结合 $R'_i \le R_i$，我们可以推导出：**每一个棋子 $R_i$，都会对其他所有位置 $j$ 施加一个上限约束**：
     $$R'_j \le R_i + |j - i|$$
   - 因此，第 $j$ 列棋子能处于的**最大行号**（最少移动位置），就是所有棋子对它施加约束的**最小值**：
     $$R'_j = \min_{1 \le i \le N} (R_i + |j - i|)$$

---

### 二、 算法实现：如何快速求出所有 $R'_j$？

如果对每个 $j$ 都去遍历所有的 $i$，时间复杂度是 $O(N^2)$，总复杂度会高达 $O(N^2)$ 导致超时。

观察公式 $R_i + |j - i|$，它可以拆解为两部分：
1. **来自左侧的约束**（$i \le j$）：$R_i + (j - i) = (R_i - i) + j$
2. **来自右侧的约束**（$i \ge j$）：$R_i + (i - j) = (R_i + i) - j$

这种左右相邻传递的性质，可以通过 **两次线性扫描（从左到右 + 从右到左）** 在 $O(N)$ 内完成传播：

#### 步骤 1：从左向右扫描（传播左侧的约束）
对于 $i = 2, 3, \dots, N$：
$$R_i = \min(R_i, R_{i-1} + 1)$$
*含义：第 $i$ 列的行号不能超过第 $i-1$ 列的行号加 1。*

#### 步骤 2：从右向左扫描（传播右侧的约束）
对于 $i = N-1, N-2, \dots, 1$：
$$R_i = \min(R_i, R_{i+1} + 1)$$
*含义：第 $i$ 列的行号不能超过第 $i+1$ 列的行号加 1。*

#### 步骤 3：统计答案
两次扫描结束后，得到的数组 $R$ 就是最优的最终高度配置 $R'$。
答案即为：
$$\text{总操作次数} = \sum_{i=1}^N (\text{初始 } R_i - \text{更新后的 } R_i)$$

---

### 三、 题解中的严谨性证明简析

为什么只需要 **从左往右扫一次 + 从右往左扫一次**，就能保证所有相邻差都 $\le 1$？会不会第二次扫描破坏了第一次扫描的结果？

题解给出的证明如下：
1. **第一轮扫描后**，必然满足：$R_i \le R_{i-1} + 1 \iff R_{i-1} \ge R_i - 1$。
2. **第二轮扫描时**（从右往左）：
   - 操作是 $R_i = \min(R_i, R_{i+1} + 1)$。
   - 如果 $R_i$ 被更新为 $R_{i+1} + 1$，那么 $R_i - R_{i+1} = 1 \le 1$。
   - 如果 $R_i$ 没被更新，说明更新前就有 $R_i \le R_{i+1} + 1$。
   - **关键点**：在第二轮中，右边的项只会**变小**（或不变），由于第一轮保证了 $R_i \ge R_{i+1} - 1$，即便 $R_{i+1}$ 变小了，不等式 $R_i \ge R_{i+1} - 1$ 依然恒成立。
3. 综合两边可知：$R_{i+1} - 1 \le R_i \le R_{i+1} + 1$，即 $|R_i - R_{i+1}| \le 1$ 得到严格保证。

### 四、 代码实现 (Python / C++)

#### Python 3 实现：
```python
import sys


def solve():
    input = sys.stdin.read
    data = input().split()
    if not data:
        return

    it = iter(data)
    num_test_cases = int(next(it))
    out = []

    for _ in range(num_test_cases):
        n = int(next(it))
        # 0-indexed
        r = [int(next(it)) for _ in range(n)]

        initial_sum = sum(r)

        # 1. 从左往右扫
        for i in range(1, n):
            if r[i] > r[i - 1] + 1:
                r[i] = r[i - 1] + 1

        # 2. 从右往左扫
        for i in range(n - 2, -1, -1):
            if r[i] > r[i + 1] + 1:
                r[i] = r[i + 1] + 1

        final_sum = sum(r)
        out.append(str(initial_sum - final_sum))

    print("\n".join(out))


if __name__ == "__main__":
    solve()
```

#### 复杂度分析：
- **时间复杂度**：每个测试用例只需对长度为 $N$ 的数组遍历 2 次，总时间复杂度为 $O(\sum N) \le 3 \times 10^5$，在 2 秒内可瞬间跑完。
- **空间复杂度**：$O(N)$，存储数组。
