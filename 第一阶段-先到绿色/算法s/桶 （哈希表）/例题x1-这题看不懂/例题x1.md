# D - 183183  
  
**运行时间限制：** 2 sec / **内存限制：** 1024 MiB  **配点：** 400 分  
  
## 问题描述  
  
对于正整数 `x, y`，定义函数 `f(x, y)` 如下：  
  
1. 将 `x` 和 `y` 分别视为不含前导零的十进制表示的字符串。  
2. 将这两个字符串按此顺序连接得到一个新的字符串 `S`。  
3. `f(x, y)` 即为将 `S` 视为十进制整数时的值。  
  
例如，`f(12, 3) = 123`，`f(100, 40) = 10040`。  
  
现在给定正整数 `N, M` 以及一个长度为 `N` 的正整数序列    
`A = (A1, A2, …, AN)`。  
  
请计算满足以下所有条件的整数对 `(i, j)` 的个数：  
  
4. `1 ≤ i, j ≤ N`  
5. `f(Ai, Aj)` 是 `M` 的倍数  
  
## 制约条件  
  
- `1 ≤ N ≤ 2 × 10^5`  
- `1 ≤ M ≤ 10^9`  
- `1 ≤ Ai ≤ 10^9`  
- 所有输入均为整数  
  
## 输入  
  
输入按以下格式从标准输入给出：  
  
```text  
N M  
A1 A2 … AN  
```  
  
## 输出  
  
输出满足条件的整数对 `(i, j)` 的总数。  
  
## 输入例 1  
```text  
2 11  
2 42  
```  
  
## 输出例 1  
```text  
2  
```  
  
当 `(i, j) = (1, 1)` 时：    
`f(A1, A1) = 22` 是 11 的倍数。  
  
当 `(i, j) = (1, 2)` 时：    
`f(A1, A2) = 242` 是 11 的倍数。  
  
当 `(i, j) = (2, 1)` 时：    
`f(A2, A1) = 422` 不是 11 的倍数。  
  
当 `(i, j) = (2, 2)` 时：    
`f(A2, A2) = 4242` 不是 11 的倍数。  
  
满足条件的整数对共有 `(1, 1)` 和 `(1, 2)` 这 2 个。  
  
## 输入例 2  
```text  
4 7  
2 8 16 183  
```  
  
## 输出例 2  
```text  
4  
```  
  
## 输入例 3  
```text  
5 5  
1000000000 1000000000 1000000000 1000000000 1000000000  
```  
  
## 输出例 3  
```text  
25  
```  
  
## 输入例 4  
```text  
12 13  
80 68 862370 82217 8 56 5 168 672624 6 286057 11864  
```  
  
## 输出例 4  
```text  
10  
```  
  
## 解题思路提示（非翻译部分）  
  
**数学转换：**  
  
`f(Ai, Aj) = Ai × 10^{digit_len(Aj)} + Aj`。  
  
**取模条件：**  
  
`(Ai × 10^{digit_len(Aj)} + Aj) ≡ 0 (mod M)`  
  
即：  
  
`(Ai × 10^{digit_len(Aj)}) ≡ -Aj (mod M)`。  
  
**算法优化：**  
  
由于 `N` 很大，不能用 `O(N^2)`。注意到 `Aj` 的位数最多只有 10 位（`10^9` 是 10 位），可以按位数对 `A` 进行分类，使用频率表（Hash Map 或数组）记录每种余数的出现次数，从而实现 `O(N × 10)` 的复杂度。
