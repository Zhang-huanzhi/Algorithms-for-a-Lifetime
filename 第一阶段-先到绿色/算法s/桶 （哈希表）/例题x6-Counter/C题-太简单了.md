### C - Change Schools

时间限制: 2 秒 / 内存限制: 1024 MiB  
分值: 300 分

#### 题目描述

目前 AtCoder 高中有 $K$ 个班级和 $N$ 名学生，第 $i$ 名学生（$1 \le i \le N$）属于第 $A_i$ 个班级。

高桥同学决定从 9 月起转入 AtCoder 高中。在转入时，高桥可以从 $K$ 个班级中任意选择 **1** 个加入。

加入某个班级后，如果**存在其他班级的人数严格多于自己所在的班级**，高桥就会感到**悲伤**；否则（即自己所在班级的人数并列第一或独自最多），他就会感到**高兴**。

请计算：有多少个班级，高桥在加入后会感到**高兴**？

#### 数据范围

- $1 \le N \le 2 \times 10^5$
- $1 \le K \le N$
- $1 \le A_i \le K$ （$1 \le i \le N$）
- 所有输入均为整数

---

#### 输入格式

输入从标准输入给出，格式如下：

$N$ $K$  
$A_1$ $A_2$ $\dots$ $A_N$  

#### 输出格式

输出满足条件的班级数量。

---

#### 样例 1

**输入：**
```text
8 5
3 3 5 5 4 4 3 2
```

**输出：**
```text
3
```

**解释：**  
初始时各班人数如下：
- 班级 1：0 人
- 班级 2：1 人
- 班级 3：3 人
- 班级 4：2 人
- 班级 5：2 人

- 如果高桥选择加入第 5 个班级，第 5 班的人数变为 3 人。此时人数最多的班级（第 3、5 班）都是 3 人，不存在人数超过 3 人的班级，因此高桥会感到高兴。
- 如果高桥选择加入第 1 个班级，第 1 班的人数变为 1 人。此时第 3 班有 3 人，人数严格多于第 1 班，高桥会感到悲伤。

当且仅当高桥选择第 3、4、5 班时他会感到高兴，因此输出 `3`。

---

#### 样例 2

**输入：**
```text
6 1
1 1 1 1 1 1
```

**输出：**
```text
1
```

**解释：**  
学校可能只有 1 个班级。

---

#### 样例 3

**输入：**
```text
14 8
6 1 5 3 8 4 3 4 3 5 1 2 5 1
```

**输出：**
```text
4
```

# AC Code
``` python
import sys  
  
def main():  
  
    n, k = map(int, sys.stdin.readline().strip().split())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    # 什么乱七八糟的，这道题，直接贪心呀  
    ans = 0  
    memo = set()  
    memo.add(0)  
  
    pre = [0] * (n + 1)  
    for i in range(1, n + 1):  
        pre[i] = (pre[i - 1] + arr[i - 1]) % k  
  
    for i in range(1, n + 1):  
        if pre[i] in memo:  
            ans += 1  
  
            memo = set()  
            memo.add(pre[i])  
        else:  
            memo.add(pre[i])  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```
