### C - 等边三角形 (Equilateral Triangle)
**时间限制：** 2 秒 / **内存限制：** 1024 MiB / **分值：** 300 点

---

### 题目描述
有一个周长为 $L$ 的圆，圆周上分布着点 $1, 2, \dots, N$。
对于 $i=1, 2, \dots, N-1$，点 $i+1$ 位于从点 $i$ 开始沿顺时针方向移动 $d_i$ 距离的位置。

请计算满足以下两个条件的整数三元组 $(a, b, c)$ ($1 \le a < b < c \le N$) 的个数：

1. 三个点 $a, b, c$ 位于圆周上互不相同的位置。
2. 以这三个点为顶点构成的三角形是等边三角形。

### 约束条件
*   $3 \le L, N \le 3 \times 10^5$
*   $0 \le d_i < L$
*   输入均为整数

### 输入格式
输入通过标准输入按以下格式给出：
> $N \ L$
> $d_1 \ d_2 \ \dots \ d_{N-1}$

### 输出格式
输出满足条件的个数。
