这份官方题解介绍了一种非常经典且高效的图论技巧：**建反图 + 增量式广度/深度优先搜索（Incremental BFS/DFS）**。

下面将该题解的思路拆解并详细说明：

---

### 一、 核心转换：建反图（Reversing Edges）

原图为 $G$。
* **原问题（查询 2）**：在 $G$ 中，能否从顶点 $v$ 出发到达**任意一个黑色顶点**？
* **逆向思考**：如果我们把图 $G$ 中的所有有向边全部反向，得到反图 $G'$。那么原问题就等价于：**在反图 $G'$ 中，能否从任意一个黑色顶点出发到达 $v$？**

通过这个转换，问题从“单起点、多终点”变为了“多起点（黑色顶点）、单终点”。我们可以转而在 $G'$ 上维护“从黑色顶点出发的可达性”。

---

### 二、 状态维护与查询

我们在反图 $G'$ 上为每个顶点 $v$ 维护一个布尔值 $A_v$：
* $A_v = \text{True}$：表示在 $G'$ 中，可以从某个黑色顶点到达 $v$。
* $A_v = \text{False}$：表示目前无法从任何黑色顶点到达 $v$。
* 起初所有顶点都是白色，因此所有 $A_v$ 均初始化为 $\text{False}$。

对于**第二类查询（`2 v`）**：
我们只需要直接输出 $A_v$ 的值即可。由于只需一次数组查值，时间复杂度为 $\mathcal{O}(1)$。

---

### 三、 增量式更新（第一类查询 `1 v`）

当收到第一类查询（将 $v$ 染成黑色）时，我们需要更新 $A$ 数组。

1. **如果 $A_v$ 已经是 $\text{True}$**：
   说明在 $G'$ 中，已经有其他黑色顶点可以到达 $v$ 了。这意味着从 $v$ 出发能到达的所有顶点，在之前的更新中就已经被标记为 $\text{True}$ 了。此时我们**什么都不需要做**，直接跳过。

2. **如果 $A_v$ 为 $\text{False}$**：
   说明 $v$ 是一个新拓展出的“黑色源头”。我们将其设为 $A_v = \text{True}$，并以 $v$ 为起点在反图 $G'$ 上进行一次 **BFS 或 DFS**。
   * 在搜索过程中，当我们从当前点 $u$ 走到邻居点 $w$ 时：
     * 如果 $A_w == \text{True}$：说明 $w$ 及其能到达的后继节点之前已经处理过了，我们**不需要**继续往 $w$ 的深处搜索，直接剪枝。
     * 如果 $A_w == \text{False}$：我们将其更新为 $A_w = \text{True}$，并继续将 $w$ 放入队列/递归栈，去拓展它的邻居。

---

### 四、 复杂度分析：为什么是 $\mathcal{O}(Q + N + M)$？

这个算法最精妙的地方在于，看似在每次染黑时都在做 BFS/DFS，但整体的复杂度极低。

* **每个顶点的状态变化**：每个顶点 $v$ 的 $A_v$ 只会经历一次从 $\text{False}$ 到 $\text{True}$ 的转变（布尔值的单调性：白色 $\to$ 黑色，不可达 $\to$ 可达，状态不可逆）。
* **边的遍历次数**：只有当一个顶点 $v$ 的状态**首次**从 $\text{False}$ 变为 $\text{True}$ 时，我们才会去遍历从 $v$ 出发的有向边（在 $G'$ 中）。因为每个顶点最多经历一次这个过程，所以反图 $G'$ 中的每条边在整个运行过程中**最多只会被遍历一次**。

因此：
* 所有第一类查询带来的 BFS/DFS 累计时间复杂度上限为 $\mathcal{O}(N + M)$。
* 第二类查询单次为 $\mathcal{O}(1)$，总共为 $\mathcal{O}(Q)$。

最终，整体时间复杂度为 **$\mathcal{O}(Q + N + M)$**，可以在 3 秒的限制内非常轻松地通过。


---

为您提供基于上述官方题解思路的 Python 代码实现。

这里使用**迭代式 DFS（利用栈）**来进行增量更新，以避免 Python 默认递归深度限制的问题，同时保证了执行效率。此外，代码采用了**快速 I/O** 来处理多达 $3 \times 10^5$ 级别的数据输入。

### Python 代码实现

```python
import sys

def main():
    # 快速一次性读取所有标准输入
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    N = int(input_data[0])
    M = int(input_data[1])
    
    # 构建反图 G' (邻接表表示)
    # 原图中的 u -> v，在反图中表示为 v -> u
    adj_rev = [[] for _ in range(N + 1)]
    
    idx = 2
    for _ in range(M):
        u = int(input_data[idx])
        v = int(input_data[idx+1])
        adj_rev[v].append(u)
        idx += 2
        
    Q = int(input_data[idx])
    idx += 1
    
    # A[v] 记录在反图 G' 中，顶点 v 是否可由某个黑色顶点到达
    A = [False] * (N + 1)
    
    output = []
    # 用于 DFS 的辅助栈
    stack = []
    
    for _ in range(Q):
        type_q = int(input_data[idx])
        v = int(input_data[idx+1])
        idx += 2
        
        if type_q == 1:
            # 第一类查询：将顶点 v 染黑
            if not A[v]:
                A[v] = True
                stack.append(v)
                # 增量式向外传播可达状态
                while stack:
                    curr = stack.pop()
                    for nxt in adj_rev[curr]:
                        if not A[nxt]:
                            A[nxt] = True
                            stack.append(nxt)
        else:
            # 第二类查询：判断 v 能否到达黑色顶点
            if A[v]:
                output.append("Yes")
            else:
                output.append("No")
                
    # 批量输出结果，提高 I/O 效率
    print('\n'.join(output))

if __name__ == "__main__":
    main()
```

### 代码要点说明

1. **反图构建**：在读取边 `u v` 时，执行 `adj_rev[v].append(u)`，即将边的方向反转。
2. **状态单向变化**：`if not A[nxt]` 保证了每个节点只会被染成 `True` 一次，一旦染成 `True`，其后续邻居也只会被遍历拓展一次。
3. **高效 I/O 技巧**：
   * `sys.stdin.read().split()` 将所有输入一次性读入内存并按空格/换行切分，比循环调用 `readline()` 快得多。
   * 使用 `output.append()` 收集答案，最后通过 `'\n'.join(output)` 一次性输出。
