这是一份专为 **AtCoder ABC (C/D 题)** 准备的**基础组合数学速查表**：

| 常见题型 / 场景             | 题目特征                          | 数学公式                                   | Python 3 一行代码                                   |
| :-------------------- | :---------------------------- | :------------------------------------- | :---------------------------------------------- |
| **选数对 (Pair)**        | 统计满足条件的 2 个数 / 连线             | $\binom{n}{2} = \frac{n(n-1)}{2}$      | `math.comb(n, 2)` 或 `n * (n - 1) // 2`          |
| **选三元组 (Triplet)**    | 选 3 个人（如本题审稿人）/ 选 3 个点        | $\binom{n}{3} = \frac{n(n-1)(n-2)}{6}$ | `math.comb(n, 3)`                               |
| **选 $k$ 个（无序）**       | 从 $n$ 个不同物品中任选 $k$ 个          | $\binom{n}{k} = \frac{n!}{k!(n-k)!}$   | `math.comb(n, k)`                               |
| **挑 $k$ 个排队（有序）**     | 从 $n$ 个人里挑 $k$ 个人排顺序          | $P(n, k) = \frac{n!}{(n-k)!}$          | `math.perm(n, k)`                               |
| **全排列**               | $n$ 个人全部排成一排                  | $n!$                                   | `math.factorial(n)`                             |
| **网格图路径**             | 从 $(0,0)$ 走到 $(H,W)$（只能向下/向右） | $\binom{H+W}{H}$                       | `math.comb(H + W, H)`                           |
| **分苹果（每人 $\ge 1$ 个）** | $n$ 个相同物品分给 $m$ 个人，**非空**     | $\binom{n-1}{m-1}$                     | `math.comb(n - 1, m - 1)`                       |
| **分苹果（允许有人为 0）**      | $n$ 个相同物品分给 $m$ 个人，**可为空**    | $\binom{n+m-1}{m-1}$                   | `math.comb(n + m - 1, m - 1)`                   |
| **相邻排队（捆绑法）**         | $n$ 个人排队，其中 $k$ 个人**必须相邻**    | $(n-k+1)! \times k!$                   | `math.factorial(n - k + 1) * math.factorial(k)` |
| **不相邻排队（插空法）**        | $n$ 个男生排好，$m$ 个女生**互不相邻**插入   | $n! \times P(n+1, m)$                  | `math.factorial(n) * math.perm(n + 1, m)`       |

---

### 💡 刷题口诀
1. **不讲顺序（选出来就行）** $\to$ 用 `comb`
2. **要讲顺序（排成一排/分职位）** $\to$ 用 `perm` 或 `factorial`
3. **分相同物品（求分配方案）** $\to$ 用隔板法（查表第 7、8 行）
4. **遇大数取模** $\to$ 算完加个 `% 998244353`（或题目指定的 `MOD`）
