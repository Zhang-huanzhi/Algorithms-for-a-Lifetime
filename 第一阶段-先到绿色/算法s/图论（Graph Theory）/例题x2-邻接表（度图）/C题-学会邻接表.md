### C - 同行评审 (Peer Review)

**时间限制**：2 秒 / **内存限制**：1024 MiB  
**分值**：300 分

#### 题目描述
有 $N$ 位研究人员，编号为 $1, 2, \dots, N$。

研究人员之间存在 $M$ 对利益冲突关系。对于每个 $i = 1, 2, \dots, M$，研究人员 $A_i$ 和研究人员 $B_i$ 之间存在利益冲突。

一篇论文的审稿人必须由 $3$ 位**互不相同**的研究人员组成，且这 $3$ 位审稿人**不能是该论文的作者本人**，也**不能与作者存在利益冲突**。

请对于每个 $i = 1, 2, \dots, N$ 分别解决以下问题：
- 求以研究人员 $i$ 为作者的论文，可能的 $3$ 人审稿人组合共有多少种？
- 注意：假设所有论文均为单人独立作者。

#### 制约条件
- $1 \le N \le 2 \times 10^5$
- $0 \le M \le 2 \times 10^5$
- $1 \le A_i, B_i \le N$
- $A_i \neq B_i$
- 当 $i \neq j$ 时，$(A_i, B_i) \neq (A_j, B_j)$
- 当 $i \neq j$ 时，$(A_i, B_i) \neq (B_j, A_j)$
- 输入的所有数值均为整数

#### 输入格式
输入从标准输入中按以下格式给出：

$$N \quad M$$
$$A_1 \quad B_1$$
$$A_2 \quad B_2$$
$$\vdots$$
$$A_M \quad B_M$$

#### 输出格式
按顺序输出针对 $i = 1, 2, \dots, N$ 的答案，各数值之间用空格分隔。

### 输入输出样例

#### 样例 1
**输入**
```text
6 5
1 2
1 4
2 3
5 3
3 1
```

**输出**
```text
0 1 0 4 4 10
```

**说明**  
下文用研究人员编号的集合表示研究人员的组合：
- 以研究人员 $1$ 为作者的论文，没有符合条件的 $3$ 人审稿人组合（方案数为 $0$）。
- 以研究人员 $2$ 为作者的论文，符合条件的组合只有 $\{4, 5, 6\}$ 这 $1$ 种。
- 以研究人员 $3$ 为作者的论文，方案数为 $0$。
- 以研究人员 $4$ 为作者的论文，符合条件的组合有 $\{2, 3, 5\}, \{2, 3, 6\}, \{2, 5, 6\}, \{3, 5, 6\}$ 这 $4$ 种。
- 以研究人员 $5$ 为作者的论文，符合条件的组合有 $\{1, 2, 4\}, \{1, 2, 6\}, \{1, 4, 6\}, \{2, 4, 6\}$ 这 $4$ 种。
- 以研究人员 $6$ 为作者的论文，符合条件的组合有 $\{1, 2, 3\}, \{1, 2, 4\}, \{1, 2, 5\}, \{1, 3, 4\}, \{1, 3, 5\}, \{1, 4, 5\}, \{2, 3, 4\}, \{2, 3, 5\}, \{2, 4, 5\}, \{3, 4, 5\}$ 这 $10$ 种。

``` python
import math  
import sys  
  
def main():  
  
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    arr = [ [] for _ in range(n + 1)]  
  
    for _ in range(m):  
        a, b = map(int, sys.stdin.readline().strip().split())  
  
        arr[a].append(b)  
        arr[b].append(a)  
  
    outs = []  
    for i in range(n):  
        x = n - len(arr[i + 1]) - 1  
  
        ans = math.comb(x, 3)  
        outs.append(ans)  
  
    print(*outs)  
  
if __name__ == "__main__":  
    main()
```
