**只要想找“最短、最少”或者要“按层办事”，就请出 BFS。**

---

### 💡 记忆口诀（BFS 五部曲）

1. **建一对儿**：建立**队列** (Queue) 和 **访问集合** (Visited)。
    
2. **进起点**：将起点放入队列，并标记已访问。
    
3. **大循环**：只要队列不空，就一直 popleft。
    
4. **找邻居**：对弹出的节点，寻找它四周能走的邻居。
    
5. **判断入**：如果邻居**没越界**、**没墙**、**没去过**，就**标记访问**并**入队**。
    

### ⚠️ 避坑指南（必看）

1. **入队即标记**：
    
    - **错误做法**：出队时才标记 visited。
        
    - **后果**：会导致同一个点被多次重复加入队列，造成内存爆炸（MLE）或超时。
        
    - **正确做法**：一旦决定要把这个点 append 进队列，**立刻**把它 add 进 visited。
        
2. **使用 deque 而不是 list**：
    
    - Python 的 list.pop(0) 是 
        
        ```
        O(n)O(n)
        ```
        
        ，deque.popleft() 是 
        
        ```
        O(1)O(1)
        ```
        
        。节点一多，list 会慢得像蜗牛。
        
3. **图中有环怎么办？**：
    
    - 只要有 visited 集合，BFS 就能自动处理有环图，不会陷入死循环。
