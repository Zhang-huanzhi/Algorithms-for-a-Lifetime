### **题目：逃离迷宫**

**问题描述：**

你被困在一个 R x C 的迷宫中，迷宫由以下几种符号组成：

- 'S'：你的起始位置。
    
- 'E'：迷宫的出口。
    
- '.'：可以通行的空地。
    
- '#'：无法通行的墙壁。
    

你每次只能向**上、下、左、右**四个方向移动一格，且不能移动到墙壁上或迷宫外。

请你判断，是否存在一条从起点 'S' 到出口 'E' 的路径。

**输入格式：**

第一行包含两个整数 R 和 C，分别表示迷宫的行数和列数 (1 <= R, C <= 50)。  
接下来的 R 行，每行包含 C 个字符，描述了整个迷宫的布局。

**输出格式：**

如果可以从起点到达出口，输出 "Yes"。  
否则，输出 "No"。

**样例输入 1：**
```
3 4
S.##
..#.
#.E.
```

**样例输出 1：**
```
Yes
```

**路径解释：** S -> (1,0) -> (1,1) -> (2,1) -> (2,2) -> E

**样例输入 2：**
```
4 4
S.#.
.#.#
##.E
....
```

**样例输出 2：**

```
No
```

**解释：** 起点被墙壁完全包围，无法移动到任何其他位置。

---

**解题提示：**

你可以把这个迷宫看作一个**图**。每个 .、S 或 E 都是图中的一个节点，如果两个节点在迷宫中相邻（上下左右），那么它们之间就有一条边。

这个问题就转化为了：**判断图中是否存在一条从 'S' 节点到 'E' 节点的路径。**

这正是深度优先搜索（DFS）和广度优先搜索（BFS）的经典应用场景。

- **用DFS**：就像一个人在迷宫里探索，一条路走到黑，碰到墙就退回上一个路口换个方向。
    
- **用BFS**：就像水波一样，从起点开始，一圈一圈地向外探索所有能到达的地方，看最终能不能“淹没”出口。
    

你可以任选一种方法来尝试解决它。祝你成功！
