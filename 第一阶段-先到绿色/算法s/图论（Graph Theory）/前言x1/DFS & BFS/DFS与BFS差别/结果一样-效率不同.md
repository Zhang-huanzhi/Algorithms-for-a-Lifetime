在这道题中，**BFS 和 DFS 的结果是一样的，但效率不同**。

---

|           | BFS          | DFS         |
| --------- | ------------ | ----------- |
| **正确性**   | ✓ 能得到答案      | ✓ 能得到答案     |
| **时间复杂度** | O(N²)        | O(N)        |
| **实现方式**  | 分两步：先找路径，再检查 | 一步到位：边遍历边检查 |

**如果题目问的是"从根到某节点的整条路径信息"**  
（比如路径权值和、路径上有无重复、路径上的最大值等）  
⟹ **首选 DFS + 回溯**

**如果题目问的是"树的层次、最短距离、最小步数"**  
⟹ **首选 BFS**
