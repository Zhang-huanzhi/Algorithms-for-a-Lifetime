# D - 整数重复路径  
  
**执行时间限制**：2 秒  **内存限制**：1024 MB    
**配点**：400 分  
  
## 问题描述  
  
给定一棵有 N 个顶点（顶点编号为 1, 2, …, N）的树。树的第 i 条边连接顶点 $U_i$ 和顶点 $V_i$。  
  
顶点 i 上写有整数 $A_i$。  
  
对于所有的 $k = 1, 2, \ldots, N$，回答以下问题：  
  
**问题**：在从顶点 1 到顶点 k 的简单路径（不重复经过同一顶点的路径）上的顶点中，是否存在两个不同的顶点上写有相同的整数？若存在，答 Yes；否则答 No。  
  
注：树上任意两个顶点之间的简单路径是唯一的。  
  
## 约束条件  
  
- 输入的所有值都是整数  
- $2 \leq N \leq 2 \times 10^5$  
- $1 \leq A_i \leq 10^9$  
- $1 \leq U_i, V_i \leq N$  
- 给定的图是一棵树  
  
## 输入格式  
  
```  
N  
A_1 A_2 ... A_N  
U_1 V_1  
U_2 V_2  
⋮  
U_{N-1} V_{N-1}  
```  
  
## 输出格式  
  
输出 N 行。第 i 行输出当 $k = i$ 时的答案。  
  
## 示例 1  
  
**输入**  
```  
5  
1 3 2 1 2  
1 2  
1 3  
3 4  
3 5  
```  
  
**输出**  
```  
No  
No  
No  
Yes  
Yes  
```  
  
### 说明  
  
- **k=1**：从顶点 1 到顶点 1 的路径包含顶点 1。路径仅由 1 个顶点组成，无重复，答案为 No。  
  
- **k=2**：从顶点 1 到顶点 2 的路径包含顶点 1, 2，其值分别为 1, 3。无重复，答案为 No。  
  
- **k=3**：从顶点 1 到顶点 3 的路径包含顶点 1, 3，其值分别为 1, 2。无重复，答案为 No。  
  
- **k=4**：从顶点 1 到顶点 4 的路径包含顶点 1, 3, 4，其值分别为 1, 2, 1。顶点 1 和顶点 4 都写有整数 1，答案为 Yes。  
  
- **k=5**：从顶点 1 到顶点 5 的路径包含顶点 1, 3, 5，其值分别为 1, 2, 2。顶点 3 和顶点 5 都写有整数 2，答案为 Yes。  
  
## 示例 2  
  
**输入**  
```  
2  
1000000000 1000000000  
2 1  
```  
  
**输出**  
```  
No  
Yes  
```
