### 3. 形象对比

| 特性         | 显式图 (Explicit)          | 隐式图 (Implicit)                |
| ---------- | ----------------------- | ----------------------------- |
| **比喻**     | **通讯录**：你想找谁，直接翻开看名字就行。 | **解密规则**：你想知道下一步，得根据当前的密码算出来。 |
| **内存消耗**   | 较高（需要存储所有的点和边）。         | 极低（只需要存储当前状态和规则）。             |
| **灵活性**    | 适合不规则的、随机的连接关系。         | 适合有固定规律、规模庞大的状态空间。            |
| **常见数据结构** | 邻接表、邻接矩阵。               | 状态转移方程、方向数组。                  |
### 4. 为什么这个区分很重要？

在学习算法时，你会发现：

1. **入门时**，你遇到的多是**隐式图**（如迷宫、跳马问题、单词接龙）。这些题考察的是你如何把“实际问题”抽象成“搜索问题”。
    
2. **进阶后**，你遇到的多是**显式图**（如最短路径 Dijkstra 算法、网络流、拓扑排序）。这些题考察的是你对复杂拓扑结构的处理能力。
