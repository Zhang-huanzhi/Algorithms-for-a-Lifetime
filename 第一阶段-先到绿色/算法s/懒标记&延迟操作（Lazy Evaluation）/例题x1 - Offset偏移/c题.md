### 题目：C - Rotatable Array

**执行时间限制：** 2 秒  
**内存限制：** 1024 MiB  
**分数：** 300 点

#### 问题描述
有一个长度为 $N$ 的整数序列 $A$，初始状态下 $A_i = i$（即 $A = (1, 2, \dots, N)$）。请处理总共 $Q$ 个查询，查询类型如下：

* **类型 1**：将 $A_p$ 修改为 $x$。
* **类型 2**：输出 $A_p$ 的值。
* **类型 3**：重复执行 $k$ 次“将序列 $A$ 的首个元素移到末尾”的操作。
  严格来说，即将 $A$ 替换为 $(A_2, A_3, \dots, A_N, A_1)$ 的操作重复 $k$ 次。

#### 限制条件
* 输入均为整数
* $1 \le N \le 10^6$
* $1 \le Q \le 3 \times 10^5$
* 所有查询满足以下限制：
    * $1 \le p \le N$
    * $1 \le x \le 10^6$
    * $1 \le k \le 10^9$

#### 输入格式
输入通过标准输入按以下格式给出：

$N$ $Q$
$Query_1$
$Query_2$
$\vdots$
$Query_Q$

其中 $Query_i$ 表示第 $i$ 个查询。

* **类型 1** 查询格式：`1 p x`
* **类型 2** 查询格式：`2 p`
* **类型 3** 查询格式：`3 k`

#### 输出格式
对于每一个类型 2 的查询，请在一行中输出结果。

---

#### 输入示例 1
```
5 5
2 3
1 2 1000000
3 4
2 2
2 3
```

#### 输出示例 1
```
3
1
1000000
```
*解释：*
初始序列 $A=(1, 2, 3, 4, 5)$。
1. `2 3`：查询 $A_3$，输出 3。
2. `1 2 1000000`：将 $A_2$ 修改为 $1,000,000$。序列变为 $(1, 1000000, 3, 4, 5)$。
3. `3 4`：重复 4 次左移操作。序列变为 $(5, 1, 1000000, 3, 4)$。
4. `2 2`：查询 $A_2$，输出 1。
5. `2 3`：查询 $A_3$，输出 $1,000,000$。
