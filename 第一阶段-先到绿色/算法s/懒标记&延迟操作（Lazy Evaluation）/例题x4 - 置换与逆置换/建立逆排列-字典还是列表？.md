强烈推荐使用 **列表（`list`）**，而不是字典（`dict`）！

---

### 一、为什么用列表（`list`）比字典（`dict`）更好？

1. **键（Key）是连续的整数**：
   在这道题中，数值和位置都是 $0 \sim N-1$（或 $1 \sim N$）的连续整数。列表的下标天然就是连续整数，**列表就是最完美的高效映射表**。
2. **执行速度极快（常数小）**：
   * **列表**：在 Python 底层是连续内存数组，根据下标查找/修改元素（如 `B[i]`）是真正的 $O(1)$ **直接内存偏移**。
   * **字典**：涉及哈希计算（Hash）、冲突处理、动态扩容等，虽然理论也是 $O(1)$，但在 $5 \times 10^5$ 的数据量下，字典比列表**慢 3 ~ 5 倍**。
3. **内存占用极小**：
   列表的内存开销远小于字典，能更好地利用 CPU 缓存（Cache）。

---

### 二、如何用列表建立“逆排列”？

假设原排列为 $A$（0-indexed），逆排列为 $B$（0-indexed）：
* **定义**：如果 $A[i] = v$（表示位置 $i$ 上的数值是 $v$），那么逆排列中 $B[v] = i$（表示数值 $v$ 所在的位置是 $i$）。

#### 正确建立代码：

```python
# 假设 N 是元素个数，A 是原排列 (0-indexed)
n = len(A)

# 1. 先开辟一个长度为 n 的空列表
B = [0] * n

# 2. 遍历 A，填充 B
for i in range(n):
    value = A[i]
    B[value] = i  # 数值 value 所在的位置是 i
```

简单写成一行也可以：
```python
B = [0] * n
for i in range(n):
    B[A[i]] = i
```

### 三、完整的建立与更新对比示例

#### 1. 初始化过程演示：
假设输入排列 $P = [2, 1, 3, 5, 4]$（1-based）：

```python
# 转换为 0-based
A = [1, 0, 2, 4, 3]
n = len(A)

# 建立逆排列 B
B = [0] * n
for i in range(n):
    B[A[i]] = i

# 执行完后：
# B = [1, 0, 2, 4, 3]
# 验证：数值 0 在位置 1，数值 1 在位置 0，数值 4 在位置 3……完全正确！
```

#### 2. 在操作 1 中如何用列表更新？
```python
# 假设要在 A 中交换位置 x 和位置 y 的元素
vx, vy = A[x], A[y]  # 1. 取出旧值

A[x], A[y] = vy, vx  # 2. 交换 A 的元素

B[vx], B[vy] = y, x  # 3. 列表 B 极其简洁地更新位置！
```

### 总结

在算法竞赛中，只要**键（Key）是范围确定的整数（$0 \sim N-1$）**，一律**优先使用列表（`list`）**，性能和简洁度都远超字典！
