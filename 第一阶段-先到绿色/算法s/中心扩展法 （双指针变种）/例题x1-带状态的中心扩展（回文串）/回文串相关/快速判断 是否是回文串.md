在算法中，快速判断一个字符串是否为回文串，最常用的有以下两种方式。

### 方法一：切片逆序法（Python 特色，最快最简短）

利用 Python 的切片操作 `[::-1]` 将字符串逆序，然后与原字符串进行比较。

**Python 代码：**
```python
def is_palindrome(s: str) -> bool:
    return s == s[::-1]
```

*   **优点**：代码极简，且由于切片操作在 Python 底层由 C 语言实现，实际运行速度通常非常快。
*   **缺点**：需要 $O(N)$ 的额外空间来存储逆序后的新字符串。

---

### 方法二：双指针法（经典算法，省内存）

在字符串的首尾各设一个指针，向中间靠拢并逐个比较对应字符。一旦发现不相等，立刻返回 `False`。

**Python 代码：**
```python
def is_palindrome(s: str) -> bool:
    left, right = 0, len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False  # 提前终止，效率高
        left += 1
        right -= 1
    return True
```

*   **优点**：不需要额外空间，空间复杂度为 $O(1)$；遇到非回文串时可以提前结束，不需完全遍历。
*   **适用场景**：面试中面试官明确要求不能使用额外空间，或者需要处理超长字符串时。
