### 1. 贪心算法 (Greedy) 的思维路径

**核心思想：** 每次都做**当前看起来最好**的选择，不考虑对未来的影响。

|           |      |                         |                       |                 |             |
| --------- | ---- | ----------------------- | --------------------- | --------------- | ----------- |
| 步骤        | 昨天选择 | 今天可选的活动 (幸福度)           | 贪心选择 (今日增量)           | 总幸福度            | 最终路径        |
| **第 1 天** | (起点) | A(10), **B(90)**, C(80) | **选 B (90)**          | **90**          | B           |
| **第 2 天** | B    | A(1), C(1)              | **选 A (1)** (或 C，值相同) | 90 + 1 = **91** | B -> A      |
| **第 3 天** | A    | B(1), C(1)              | **选 B (1)** (或 C，值相同) | 91 + 1 = **92** | B -> A -> B |

#### 贪心算法总结：

- **结果：** 总幸福度 **92**。
    
- **错误原因：** 它在第 1 天选择了**局部最优**的 **B (90)**，却因此**“锁死”**了第 3 天的超高价值 **A (100)**，导致总和落败。
    
- **教训：** **贪心算法无法解决需要“牺牲眼前小利，以换取未来大利”的问题。**

### 2. 动态规划 (DP) 的思维路径

**核心思想：** 同时维护所有可能的路径，让它们之间互相竞争，从而确保找到全局最优解。

#### 状态表：dp[i][j] (到第 i 天，且当天做 j 活动的最大幸福度)

|   |   |   |   |   |
|---|---|---|---|---|
|天数|dp[i][A] (昨天B或C)|dp[i][B] (昨天A或C)|dp[i][C] (昨天A或B)|最终最大值|
|**第 1 天**|**10**|**90**|**80**|90|
|**第 2 天**|```<br>1+max⁡(90,80)=911+max(90,80)=91<br>```|```<br>10+max⁡(10,80)=9010+max(10,80)=90<br>```|```<br>1+max⁡(10,90)=911+max(10,90)=91<br>```|91|
|**第 3 天**|```<br>100+max⁡(90,91)=191100+max(90,91)=191<br>```|```<br>1+max⁡(91,91)=921+max(91,91)=92<br>```|```<br>1+max⁡(91,90)=921+max(91,90)=92<br>```|**191**|

#### 动态规划总结：

- **结果：** 总幸福度 **191**。
    
- **最优路径：** 191 是由 **dp[3][A]** 得到的。追溯路径为：
    
    - 第 3 天选 A (100)，它由第 2 天的最大值 dp[2][C] (91) 转移而来。
        
    - 第 2 天选 C (1)，它由第 1 天的最大值 dp[1][B] (90) 转移而来。
        
    - **最优路径：** **B (90) -> C (1) -> A (100)**。
        
- **教训：** DP 在第 1 天**没有丢弃** A (10) 和 C (80) 这两条信息。正是因为保留了 **C (80)** 这条次优路径，它才得以在第 2 天转移到 C (1)，并成功**“避开”**了B的惩罚，从而在第 3 天抓住了那个**100**的巨大奖励。
    

### 最终结论

动态规划解决了这个问题，因为它没有被第 1 天的 **90** 所迷惑。它在每一步都保留了所有可能的“最优结局”信息，并选择了一个**虽然开始并不完美，但最终总和最高**的长期最优解。
