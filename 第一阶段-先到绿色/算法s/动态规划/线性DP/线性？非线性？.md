如果你处理的问题，**“下一个状态”完全由“上一个状态”决定**，那就是**线性 DP**。  
如果你处理的问题，**“大状态”是由“两个或多个碎片状态”组合而成的**，那就是**非线性 DP**。

| 特征       | 线性 DP                                               | 非线性 DP (以区间 DP 为例)       |
| -------- | --------------------------------------------------- | ------------------------ |
| **状态依赖** | 依赖前项 (<br><br>```<br>i−1,i−2i−1,i−2<br>```<br><br>) | 依赖子区间 ([i, k], [k+1, j]) |
| **推进方向** | 从左向右（1D）                                            | 从小区间向大区间（2D）             |
| **思考难度** | 找递推公式                                               | 找分割点 (Split Point)       |
| **形象比喻** | **多米诺骨牌**：推倒一张，后面顺着倒                                | **拼积木**：把小块拼成大块，再拼成整体    |
