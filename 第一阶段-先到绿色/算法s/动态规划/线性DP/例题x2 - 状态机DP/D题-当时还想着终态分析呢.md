### D - Celester

**时间限制**: 2 秒 / **内存限制**: 1024 MiB

**分值**: 400 分

#### 问题描述

接下来的 $N$ 天天气将以字符串 $S$ 的形式给出。
当 $S$ 的第 $i$ 个字符为 `S` 时，表示第 $i$ 天的天气为晴天（Sunny）；为 `R` 时，表示第 $i$ 天的天气为雨天（Rainy）。
初始状态下，你的“喜悦值”为 $0$。

你可以执行以下操作任意次数（也可以不执行）：

* 选择一个介于 $1$ 到 $N$ 之间的整数 $i$。如果第 $i$ 天的天气为晴天则改为雨天，为雨天则改为晴天。但是，每修改一次第 $i$ 天的天气，喜悦值就会减少 $X_i$。

在执行完全部操作后，你的最终喜悦值将根据最终的天气状况，按照以下规则增加：

* 对于满足 $1 \le i \le N-1$ 的每个整数 $i$，如果修改后的**第 $i$ 天天气为雨天且第 $i+1$ 天天气为晴天**，则喜悦值增加 $Y_i$。

请计算在合理执行操作后，能够达到的最大可能喜悦值。

共有 $T$ 组测试数据，请对每组测试数据分别求解。

#### 限制条件

* $1 \le T \le 10^4$
* $N$ 是介于 $2$ 到 $2 \times 10^5$ 之间的整数
* $S$ 是一个长度为 $N$ 且仅由 `S` 和 `R` 组成的字符串
* $X_i$ 是介于 $1$ 到 $10^9$ 之间的整数
* $Y_i$ 是介于 $1$ 到 $10^9$ 之间的整数
* 在一个输入文件中，所有测试数据的 $N$ 之和不超过 $2 \times 10^5$

#### 输入格式

输入按以下格式从标准输入给出。其中 $\text{case}_i$ 代表第 $i$ 组测试数据。

$$T$$
$$\text{case}_1$$
$$\text{case}_2$$
$$\vdots$$
$$\text{case}_T$$

每组测试数据按以下格式给出：

$$N$$
$$S$$
$$X_1 \quad X_2 \quad \dots \quad X_N$$
$$Y_1 \quad Y_2 \quad \dots \quad Y_{N-1}$$

#### 输出格式

输出共 $T$ 行。
第 $i$ 行应当输出第 $i$ 组测试数据的答案。

#### 输出样例 1

该输入包含 $5$ 组测试数据。

* 对于**第 1 组**测试数据，可以通过以下操作使喜悦值最大化：
  * 将第 $3$ 天的天气由雨天改为晴天。喜悦值减少 $X_3 = 4$，此时每天的天气序列变为：晴天、雨天、晴天、雨天、晴天、雨天。
  * 操作后：第 $2$ 天为雨天且第 $3$ 天为晴天，喜悦值增加 $Y_2 = 6$；第 $4$ 天为雨天且第 $5$ 天为晴天，喜悦值增加 $Y_4 = 3$。
  * 总喜悦值为 $(-4) + 6 + 3 = 5$，这是可以达到的最大值。
* 对于**第 2、3 组**测试数据，不进行任何操作（即操作 $0$ 次）可能是最优解。
* 对于**第 5 组**测试数据，请注意答案可能会超出 32 位有符号整数型（int）的表示范围。

# Code
``` python
import sys


def main():
    t = int(sys.stdin.readline().strip())

    for _ in range(t):
        n = int(sys.stdin.readline().strip())
        s = sys.stdin.readline().strip()

        xrr = list(map(int, sys.stdin.readline().strip().split()))
        yrr = list(map(int, sys.stdin.readline().strip().split()))

        # ==================== 动态规划核心逻辑 ====================

        # dp0 维护当前天为“雨天(R)”时的最大喜悦值
        # dp1 维护当前天为“晴天(S)”时的最大喜悦值

        # 初始化第 1 天（索引 0）
        if s[0] == "S":
            dp0 = -xrr[0]  # 晴改雨，需要扣除 X_1
            dp1 = 0  # 保持晴，不扣除
        else:  # s[0] == 'R'
            dp0 = 0  # 保持雨，不扣除
            dp1 = -xrr[0]  # 雨改晴，需要扣除 X_1

        # 从第 2 天开始递推到第 N 天
        for i in range(1, n):
            # 计算今天不改变天气的成本
            if s[i] == "S":
                cost_r = xrr[i]  # 改变为雨天的花费
                cost_s = 0  # 保持晴天的花费
            else:  # s[i] == 'R'
                cost_r = 0  # 保持雨天的花费
                cost_s = xrr[i]  # 改变为晴天的花费

            # 状态转移
            # 1. 今天选雨天：前一天是雨是晴都可以，但没有转移奖励
            new_dp0 = max(dp0, dp1) - cost_r

            # 2. 今天选晴天：前一天如果是雨天（dp0），可以获得转移奖励 yrr[i-1]
            new_dp1 = max(dp0 + yrr[i - 1], dp1) - cost_s

            # 更新滚动变量
            dp0 = new_dp0
            dp1 = new_dp1

        # 输出当前测试案例的最大可能喜悦值
        print(max(dp0, dp1))


if __name__ == "__main__":
    main()
```
