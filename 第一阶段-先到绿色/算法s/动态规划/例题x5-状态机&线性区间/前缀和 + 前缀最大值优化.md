这道题除了用动态规划（DP）之外，还有一个**数学上更简洁、更直观**的方法，那就是：**前缀和 + 前缀最大值优化**。

这个方法甚至不需要你去思考任何复杂的“状态”和“转移”，只需要做一些简单的**数学公式变形**。

---

### 解法思路：公式变形法

我们先写出题目要求最大化的目标公式：
$$ \text{Total} = \sum_{i=1}^{x} A_i + \sum_{i=x+1}^{y} B_i + \sum_{i=y+1}^{N} C_i $$

我们定义 $S_A, S_B, S_C$ 分别为序列 $A, B, C$ 的**前缀和**（即 $S[i]$ 表示前 $i$ 个元素的和）。那么上面的公式可以写成：
$$ \text{Total} = S_A[x] + (S_B[y] - S_B[x]) + (S_C[N] - S_C[y]) $$

我们把这个公式重新拆开并组合一下：
$$ \text{Total} = \underbrace{(S_A[x] - S_B[x])}_{\text{只跟 } x \text{ 有关}} + \underbrace{(S_B[y] - S_C[y])}_{\text{只跟 } y \text{ 有关}} + \underbrace{S_C[N]}_{\text{常数}} $$

#### 巧妙的发现：
1.  $S_C[N]$ 是一个**固定的常数**（整个 $C$ 序列的总和），它跟切刀位置 $x, y$ 毫无关系。
2.  为了让整个公式最大，我们只需要让前两部分最大。
3.  我们令：
    *   $f(x) = S_A[x] - S_B[x]$
    *   $g(y) = S_B[y] - S_C[y]$
4.  问题变成了：在满足 $1 \le x < y < N$ 的条件下，求 **$f(x) + g(y)$ 的最大值**。

---

### 线性扫描算法（不用 DP）

既然我们要找 $f(x) + g(y)$ 的最大值，且要求 $x < y$：
我们可以**从左到右枚举 $y$ 的位置**（$y$ 的范围是 $2$ 到 $N-1$）。

当我们在看某一个确定的 $y$ 时，我们需要在它的左边（即 $1$ 到 $y-1$ 的范围内）找一个 $x$，使得 $f(x)$ 最大。
*   因为我们是顺着往右走的，所以我们可以用一个变量 `max_f` 来**实时记录在当前 $y$ 左边出现过的 $f(x)$ 的最大值**。
*   每走到一个新的 $y$，我们就用 `max_f + g(y)` 去更新全局的最大答案。

这个过程完全不需要定义 DP 数组，只需要一边遍历，一边维护一个“前缀最大值”即可。

---

### 代码实现

这个方法写起来比 DP 还要短，而且非常容易理解：

```python
import sys


def main():
    n = int(sys.stdin.readline().strip())

    arr = list(map(int, sys.stdin.readline().strip().split()))
    brr = list(map(int, sys.stdin.readline().strip().split()))
    crr = list(map(int, sys.stdin.readline().strip().split()))

    # 1. 计算前缀和
    sa = [0] * (n + 1)
    sb = [0] * (n + 1)
    sc = [0] * (n + 1)
    for i in range(n):
        sa[i + 1] = sa[i] + arr[i]
        sb[i + 1] = sb[i] + brr[i]
        sc[i + 1] = sc[i] + crr[i]

    # 定义 f(i) 和 g(i) 函数
    # f(i) = sa[i] - sb[i]
    # g(i) = sb[i] - sc[i]

    # 2. 线性扫描，维护前缀最大值
    max_f = sa[1] - sb[1]  # 初始时，x 只能选 1，所以 max_f 是 f(1)
    max_total = -float("inf")

    # 枚举 y，范围是 2 到 n-1 (对应 1-based 索引就是 2 到 n-1)
    for y in range(2, n):
        # 此时左边的 x 范围是 1 到 y-1。
        # 此时先算 g(y) 并更新答案
        gy = sb[y] - sc[y]
        max_total = max(max_total, max_f + gy)

        # 准备走向下一个 y，将当前的 y 作为下一个循环的候选 x，更新 max_f
        fy = sa[y] - sb[y]
        max_f = max(max_f, fy)

    # 3. 加上常数项 S_C[N]
    ans = max_total + sc[n]
    print(ans)


if __name__ == "__main__":
    main()
```

### 两种解法的对比

| 比较维度 | 动态规划（DP）解法 | 公式变形（前缀最大值）解法 |
| :--- | :--- | :--- |
| **思维方向** | 状态机，模拟一步步走的过程 | 数学推导，消除变量之间的耦合 |
| **扩展性** | **极高**。如果要切 $K$ 刀（分成 10 段），DP 只需增加状态数，依然是 $O(N)$。 | **较低**。如果段数变多，公式拆解会变得极其复杂，难以用单变量维护。 |
| **代码量** | 适中 | 极少 |
| **直观程度** | 稍微抽象 | 非常直观（只要懂前缀和就能懂） |

**总结：** 
如果段数只有 3 段（切两刀），**公式变形法**是最快、最不容易出错的选择。但如果未来题目升级为“切 $K$ 刀”，那么**动态规划**就是唯一的解法。
