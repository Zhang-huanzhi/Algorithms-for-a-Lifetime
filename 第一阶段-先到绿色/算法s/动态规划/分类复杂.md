动态规划（DP）的分类确实非常多，很多初学者觉得乱，是因为**不同的分类标准混杂在了一起**。

有些分类是按**“问题结构”**划分的（如树形 DP、区间 DP），有些是按**“状态存储方式”**划分的（如状压 DP），还有些是按**“应用场景”**划分的（如背包 DP）。

为了帮您理清笔记，我们可以将 DP 分为 **三大核心维度**：

1. **按“拓扑结构/状态转移方向”分类**（最基础的分类方式）
2. **按“状态表示技巧”分类**（如何用巧妙的方法表示状态）
3. **按“经典业务模型”分类**（特定场景的套路）

---

### 维度一：按“拓扑结构与状态转移方向”分类

这是最本质的分类，决定了你外层循环的编写方式（如何从小规模问题推导到大规模问题）。

#### 1. 线性 DP (Linear DP)
*   **核心思想**：状态沿着一条线（单向、无环）向前推进。
*   **状态表示**：通常为 $dp[i]$（前 $i$ 个元素的状态）或 $dp[i][j]$（两个序列的比对）。
*   **子类型**：
    *   **单序列/双序列 DP**：如最长上升子序列（LIS）、最长公共子序列（LCS）。
    *   **字符串/子串 DP**：处理字符串的前缀、子串匹配。
    *   **划分型 DP**（如本题）：把一根线切成 $K$ 段，求最值。
*   **经典例题**：最长公共子序列、最大子数组和。

#### 2. 区间 DP (Interval DP)
*   **核心思想**：状态定义在“区间”上，通常从短区间转移到长区间（合并）。
*   **状态表示**：$dp[l][r]$ 表示区间 $[l, r]$ 的最优解。
*   **转移特点**：通常需要枚举分割点 $k$ ($l \le k < r$)，由 $dp[l][k]$ 和 $dp[k+1][r]$ 转移而来。
*   **经典例题**：石子合并、括号匹配、矩阵链乘法。

#### 3. 树形 DP (Tree DP)
*   **核心思想**：在树形结构上做 DP，一般利用 DFS（后序遍历），子节点的信息计算完后汇报给父节点。
*   **状态表示**：$dp[u]$ 表示以节点 $u$ 为根的子树的最优解。
*   **子类型**：
    *   **树上背包（有依赖的背包）**。
    *   **换根 DP（二次扫描与换根）**：第一次 DFS 计算以某个点为根的答案，第二次 DFS 快速推导其他点为根的答案。
*   **经典例题**：没有上司的舞会、树的直径。

#### 4. DAG 上的 DP (Directed Acyclic Graph DP)
*   **核心思想**：在有向无环图上做 DP，通常需要先进行**拓扑排序**，然后按照拓扑序进行状态转移。
*   **经典例题**：DAG 上的最长路、旅行商问题（小规模）。

### 维度二：按“状态表示技巧”分类

这种分类不关心图的结构，而是关心**如何用数学/计算机语言高效、巧妙地表达一个复杂的“状态”**。

#### 5. 状态压缩 DP (Bitmask DP)
*   **核心思想**：当状态包含多个“是/否”的决策（且规模较小，一般 $N \le 20$）时，利用一个整数的**二进制位**（0 和 1）来表示这组状态。
*   **状态表示**：$dp[i][state]$，$state$ 是一个二进制掩码（mask）。
*   **经典例题**：旅行商问题（TSP）、蒙德里安的梦想（网格图铺砖）。

#### 6. 数位 DP (Digit DP)
*   **核心思想**：解决“在区间 $[L, R]$ 中，满足某种特定条件的数字有多少个”的问题。它将数字按“位”（个位、十位、百位等）拆开，从高位到低位进行记忆化搜索。
*   **状态表示**：$dp[pos][state][limit]$（当前在第几位、之前的约束状态、是否贴着上限）。
*   **经典例题**：求 $[L, R]$ 中不含数字 4 的个数、Windy 数。

#### 7. 状态机 DP (State Machine DP)
*   **核心思想**：每个阶段，不仅有“位置”的变化，还有“角色/行为状态”的变化。状态之间通过特定的规则（转移图）进行转换。
*   **状态表示**：$dp[i][state]$，其中 $state$ 是一个有限的状态（如 0: 持股, 1: 不持股且在冷冻期, 2: 不持股且不在冷冻期）。
*   **经典例题**：买卖股票的最佳时机系列、打家劫舍。

### 维度三：按“经典业务模型”分类

这些是算法竞赛或面试中极为常见的**固定应用场景**，有着非常成熟的模板。

#### 8. 背包 DP (Knapsack DP)
*   **核心思想**：给定一组物品（有体积和价值）和一个容量有限的背包，求如何选择物品使价值最大。
*   **常见模型**：
    *   **0-1 背包**：每种物品仅一件。
    *   **完全背包**：每种物品无限件。
    *   **多重背包**：每种物品有固定件数。
    *   **分组背包**：物品分租，每组至多选一件。

#### 9. 概率与期望 DP (Probability/Expectation DP)
*   **核心思想**：求解达到某个状态的概率，或者完成任务的期望步数。由于期望具有“倒推”性质，通常从终点向起点逆向转移。
*   **经典例题**：飞行棋概率问题、抽卡期望。

#### 10. 博弈 DP (Game Theory DP)
*   **核心思想**：用于解决两人轮流行动、且信息完全公开的博弈游戏（如取石子、棋类）。
*   **核心逻辑**：采用 **Minimax 策略**（我方极大化收益，敌方极小化我方收益）。
*   **经典例题**：预测赢家、Nim 游戏的变种。
