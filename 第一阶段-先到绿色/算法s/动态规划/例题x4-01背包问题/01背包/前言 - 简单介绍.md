**0-1 背包问题（0-1 Knapsack Problem）** 是算法与组合优化中最经典的课题之一，也是动态规划（Dynamic Programming, DP）的入门级问题。

简单来说，它解决的是如何在**有限的承重限制下，选择物品以获得最大价值**的问题。

---

### 1. 问题场景

假设你是一个探险家，发现了一个宝藏库，里面有 $N$ 件宝物。你只有一个背包，这个背包最多只能承重 $C$（Capacity）。

每件宝物 $i$ 都有两个属性：
*   **重量（Weight）**：$W_i$
*   **价值（Value）**：$V_i$

你的目标是：选择若干件宝物装入背包，在**总重量不超过背包承重 $C$** 的前提下，让背包里**宝物的总价值最大**。

---

### 2. 为什么叫 “0-1”？

“0-1” 代表的是一种**二选一的决策**：
*   **0**：表示**不放入**该物品。
*   **1**：表示**放入**该物品。

在 0-1 背包问题中，有以下两个关键限制：
1.  **物品不可分割**：你不能把一个金像砍成两半只带走一半，要么整件带走（1），要么留在原地（0）。
2.  **每件物品只有一个**：你不能同一件东西拿多次。

*注：如果物品可以任意分割（例如金沙），则称为“部分背包问题”，可以用贪心算法求解；如果每种物品有无限多个，则称为“完全背包问题”。*

---

### 3. 如何求解？（动态规划法）

由于每个物品都有“装”与“不装”两种选择，如果用暴力枚举，一共有 $2^N$ 种组合，当 $N$ 较大时计算会非常慢。因此，通常使用**动态规划**来求解。

#### 核心思想：状态转移
我们用一个二维数组 `dp[i][j]` 来表示状态：
*   **状态定义**：`dp[i][j]` 表示在前 $i$ 个物品中进行选择，在背包容量为 $j$ 时的**最大价值**。

对于第 $i$ 个物品（重量为 $W_i$，价值为 $V_i$），我们面临两种选择：
1.  **不装它**：背包的最大价值就等于只在前 $i-1$ 个物品里选、容量同样为 $j$ 时的价值：
    $$\text{价值} = dp[i-1][j]$$
2.  **装它**（前提是当前背包容量 $j \ge W_i$）：背包要腾出 $W_i$ 的空间来放它，此时的最大价值等于前 $i-1$ 个物品在剩余容量 $j - W_i$ 下的价值，加上当前物品的价值 $V_i$：
    $$\text{价值} = dp[i-1][j - W_i] + V_i$$

为了求最大价值，我们在这两种选择中取较大值，得到**状态转移方程**：
$$dp[i][j] = \max(dp[i-1][j], dp[i-1][j - W_i] + V_i)$$

---

### 4. 空间复杂度优化（一维数组）

在实际写代码时，我们会发现 `dp[i][j]` 的值只与上一行 `dp[i-1][...]` 的数据有关。因此，我们可以将二维数组压缩为一维数组 `dp[j]`。

在一维数组写法中，为了保证更新 `dp[j]` 时用到的 `dp[j - W_i]` 依然是“上一行”的数据（即该物品还没被放入时的状态），**背包容量 $j$ 必须从大到小（逆序）进行遍历**。

**标准一维 0-1 背包模板（Python）**：
```python
# N: 物品数量, C: 背包容量
# W: 物品重量列表, V: 物品价值列表


def knapsack_01(N, C, W, V):
    # 初始化 dp 数组，dp[j] 表示容量为 j 时的最大价值
    dp = [0] * (C + 1)

    for i in range(N):
        wi = W[i]
        vi = V[i]
        # 逆序遍历容量，确保每个物品只被使用一次
        for j in range(C, wi - 1, -1):
            dp[j] = max(dp[j], dp[j - wi] + vi)

    return dp[C]
```

### 总结
0-1 背包问题是许多复杂算法问题的原型。例如您上一轮询问的“机器人定制”问题，就是通过巧妙的数学转化，将“头重”与“体重”的平衡约束，转化为了一个标准的 0-1 背包模型来求解。
