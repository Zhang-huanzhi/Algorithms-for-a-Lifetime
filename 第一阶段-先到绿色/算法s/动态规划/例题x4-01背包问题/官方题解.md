

### 官方题解翻

#### **D - Robot Customize 题解 by MMNMM**

设所有零件的重量总和为 $S$。

起初，我们设想**把所有零件都安装在身体上**，然后考虑**将其中一部分零件移动到头部**。

这样一来，问题就可以转化为求解以下子问题：
> **第 $i$ 个物品的重量为 $W_i$，价值为 $V_i = H_i - B_i$。在所选物品的重量总和不超过 $\lfloor \frac{S}{2} \rfloor$ 的前提下，求选择部分物品所能达到的最大价值总和。**

这是一个典型的背包问题，可以使用动态规划（DP）在时间复杂度为 $O(NS)$ 内求解。

---

### 详细讲解：为什么要这样转化？

官方题解的转化思路非常巧妙，它通过“设想初始状态”和“数学不等式变形”，将一个看似复杂的双变量决策问题（既要考虑头部、又要考虑身体）简化为了标准的**01背包问题**。

#### 1. 为什么限制条件是“重量总和不超过 $\lfloor \frac{S}{2} \rfloor$”？
* 设所有零件的总重量为 $S$（即 $S = \sum W_i$）。这是一个固定值。
* 设最后安装在头部的零件总重量为 $W_H$，安装在身体的零件总重量为 $W_B$。
* 显然有：$W_H + W_B = S \implies W_B = S - W_H$。
* 题目的要求是机器人不能倒下，即：
  $$W_H \le W_B$$
* 我们把 $W_B = S - W_H$ 代入上式：
  $$W_H \le S - W_H \implies 2W_H \le S \implies W_H \le \frac{S}{2}$$
* 因为重量都是整数，所以头部的重量 $W_H$ 必须满足：
  $$W_H \le \lfloor \frac{S}{2} \rfloor$$
* **结论**：我们不需要同时记录头部和身体的重量，**只需要确保放进头部的零件总重量不超过总重的一半 $\lfloor \frac{S}{2} \rfloor$ 即可**。这个限制就是背包的“最大容量”。

#### 2. 为什么物品的价值变成了 $V_i = H_i - B_i$？
* 题解假设：**最开始所有零件都在身体上**。
  此时，初始的喜悦值总和为：
  $$\text{初始总和} = \sum_{i=1}^{N} B_i$$
* 现在，我们决定把第 $i$ 个零件从身体**移动到头部**：
  * 我们**失去了**把它放在身体上的喜悦值 $B_i$。
  * 我们**获得了**把它放在头部上的喜悦值 $H_i$。
  * 这一步操作带来的**喜悦值净变化（净收益）**为：
    $$\Delta = H_i - B_i$$
* **结论**：选择把第 $i$ 个零件放进头部，就相当于在背包中放入了一个“重为 $W_i$，价值为 $H_i - B_i$”的物品。我们的目标是让这个净收益最大化。

#### 3. 为什么是 $O(NS)$ 的复杂度？
在背包问题中，物品数量为 $N$，背包容量为 $V = \lfloor \frac{S}{2} \rfloor$。
* 动态规划的表格大小为 $N \times V$。
* 因为 $V \le S / 2$，所以状态数不超过 $N \times \frac{S}{2}$。
* 状态转移时间为 $O(1)$，因此总时间复杂度为 $O(NS)$。
* 题目中 $N \le 500, W_i \le 500$，所以 $S \le 250,000$，背包容量 $V \le 125,000$。
* 计算量约为 $500 \times 125,000 = 6.25 \times 10^7$ 次，在 2 秒的时间限制内，使用动态规划完全可以轻松通过。


### Code
``` python
import sys


def main() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    n = data[0]

    # dp[body_weight] = 最大喜悦值
    dp = [0]
    index = 1

    for _ in range(n):
        w = data[index]
        h = data[index + 1]
        b = data[index + 2]
        index += 3

        prev = dp
        # 新数组长度为：此前总重量 + 当前零件重量 + 1
        dp = [-10**30] * (len(prev) + w)

        for body_weight, value in enumerate(prev):
            # 安装到头部：身体重量不变
            if value + h > dp[body_weight]:
                dp[body_weight] = value + h

            # 安装到身体：身体重量增加 w
            next_weight = body_weight + w
            if value + b > dp[next_weight]:
                dp[next_weight] = value + b

    # 设全部零件总重量为 S。
    # 不倒下要求：身体重量 >= ceil(S / 2)。
    print(max(dp[len(dp) // 2:]))


if __name__ == "__main__":
    main()
```
