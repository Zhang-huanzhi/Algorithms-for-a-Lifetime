这道题的核心算法由 **DP 状态转移** 和 **查询转移** 两部分组成。以下是完整的数学状态转移方程：

---

### 一、 动态规划（DP）部分

#### 1. 状态定义
设 $dp[i][x]$ 表示从第 $i$ 个礼物开始，当前情绪值为 $x$ 时，收完剩下所有礼物后的最终情绪值。
* 状态范围：$0 \le i \le N$，$0 \le x \le 1000$。

#### 2. 初始状态（边界条件）
当所有礼物都收完时（第 $N$ 步），最终情绪值就是当前值本身：
$$dp[N][x] = x \quad (\text{对于 } 0 \le x \le 1000)$$

#### 3. 状态转移方程（逆推，$i$ 从 $N-1$ 降至 $0$）
对于第 $i$ 个礼物（其属性为 $P_i, A_i, B_i$），情绪值的转移方程为：

$$dp[i][x] = \begin{cases} 
dp[i+1][x + A_i] & \text{if } x \le P_i \\ 
dp[i+1][\max(0, x - B_i)] & \text{if } x > P_i 
\end{cases}$$

*(注：根据数学性质，只要 $x \le 1000$，转移后的新状态 $x + A_i$ 和 $\max(0, x - B_i)$ 均保证在 $[0, 1000]$ 范围内，状态空间是封闭的)*。

---

### 二、 查询（Query）处理部分

对于每个初始情绪值 $X$ 的查询，其结果计算方程如下：

#### 1. 前缀和定义
设 $pref[k]$ 表示前 $k$ 个礼物的降低度 $B$ 的总和：
$$pref[k] = \sum_{j=0}^{k-1} B_j \quad (pref[0] = 0)$$

#### 2. 查询转移方程

* **情况一：$X \le 1000$**
  直接查表：
  $$\text{Result} = dp[0][X]$$

* **情况二：$X > 1000$**
  我们需要找到最小的步骤 $k$ ($1 \le k \le N$)，使得在该步骤时情绪值首次降到 $1000$ 以下。即：
  $$\text{最小的 } k \quad \text{满足} \quad pref[k] \ge X - 1000$$

  根据 $k$ 是否存在，分为以下两种转移：
  1. **如果存在这样的 $k$ （即 $k \le N$）**：
     计算降到 $1000$ 以下后的剩余情绪值 $rem = X - pref[k]$，然后从第 $k$ 步空降进入 DP 表：
     $$\text{Result} = dp[k][X - pref[k]]$$
  2. **如果不存在这样的 $k$ （即 $pref[N] < X - 1000$）**：
     说明直到所有礼物收完，情绪值依然大于 $1000$，期间只发生了单调减少：
     $$\text{Result} = \max(0, X - pref[N])$$
