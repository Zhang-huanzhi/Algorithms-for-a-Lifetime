
### 3. 为什么这道题必须用“逆推”？

这是本题最精妙的地方。

如果高桥君的初始情绪值 $X > 1000$，他会先连续失望，在第 $k$ 步时，情绪值第一次降到了 $rem \le 1000$。

此时，我们需要知道：**高桥君从第 $k$ 步开始，带着情绪值 $rem$，在收完剩下的礼物后，最终会是多少？**

* 如果是**顺推 DP**，我们只算出了“从第 0 步出发”的情况，对于“中途从第 $k$ 步出发”的情况，顺推 DP 是无能为力的。
* 但因为我们使用的是**逆推 DP**，`dp[k][rem]` 恰好代表的就是**“从第 $k$ 步出发，情绪值为 $rem$ 的未来结局”**！

我们可以**不从第 0 步开始查表，而是直接在任意步骤 $k$ “空降”进入 DP 表**，瞬间获取未来的答案。这就是逆推动态规划在这道题中展现的核心威力。
