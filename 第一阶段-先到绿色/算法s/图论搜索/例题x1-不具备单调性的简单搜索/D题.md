### D - XOR 最短路径 (XOR Shortest Walk)
**运行时间限制：** 2 秒 / **内存限制：** 1024 MiB

**分值：** 400 分

#### 问题描述
给定一个包含 $N$ 个顶点和 $M$ 条边的有向图。顶点编号从 1 到 $N$，边编号从 1 到 $M$。第 $i$ 条边是从顶点 $A_i$ 到顶点 $B_i$，权重为 $W_i$ 的有向边。

请找出从顶点 1 到顶点 $N$ 的所有路径（walk）中，路径所包含边的权重进行按位 XOR（异或）运算后的最小值。

**关于路径（walk）的定义：**
直观上，路径是指“从顶点 1 到顶点 $N$ 的通路，允许重复经过顶点或边”。精确来说，路径是由边序列 $(e_1, \dots, e_k)$ 组成的，且满足以下所有条件：
1. $e_1$ 的起点为顶点 1。
2. 对于所有 $1 \le i < k$，边 $e_i$ 的终点与边 $e_{i+1}$ 的起点相同。
3. $e_k$ 的终点为顶点 $N$。

**关于按位 XOR 运算：**
非负整数 $A, B$ 的按位 XOR 运算（记作 $A \text{ XOR } B$）定义如下：
将 $A$ 和 $B$ 表示为二进制，若 $2^k$ 位（$k \ge 0$）上的数字只有一个为 1，则结果的该位为 1；否则为 0。
例如：$3 \text{ XOR } 5 = 6$（二进制运算为 $011 \text{ XOR } 101 = 110$）。
一般地，对于 $k$ 个非负整数 $p_1, p_2, \dots, p_k$，其按位 XOR 定义为 $(\dots((p_1 \text{ XOR } p_2) \text{ XOR } p_3) \text{ XOR } \dots \text{ XOR } p_k)$，且结果与运算顺序无关。

#### 约束条件
* $2 \le N \le 1000$
* $0 \le M \le 1000$
* $1 \le A_i, B_i \le N$
* $0 \le W_i < 2^{10}$
* 所有输入均为整数。

#### 输入
输入通过标准输入按以下格式给出：
$N \ M$
$A_1 \ B_1 \ W_1$
$A_2 \ B_2 \ W_2$
$\vdots$
$A_M \ B_M \ W_M$

#### 输出
* 如果不存在从顶点 1 到顶点 $N$ 的路径，请输出 `-1`。
* 如果存在路径，请输出路径中所有边权重按位 XOR 的最小值。

---

#### 输入示例 1
```
3 3
1 2 4
2 3 5
1 3 2
```
**输出示例 1**
```
1
```
*解释：路径（边 1，边 2）的权重 XOR 值为 $4 \text{ XOR } 5 = 1$。*

#### 输入示例 2
```
4 4
1 4 7
4 2 2
2 3 4
3 4 1
```
**输出示例 2**
```
0
```
*解释：路径（边 1，边 2，边 3，边 4）的权重 XOR 值为 $7 \text{ XOR } 2 \text{ XOR } 4 \text{ XOR } 1 = 0$。注意：路径中可以包含顶点 $N$。*

#### 输入示例 3
```
999 4
1 2 9
2 1 8
1 2 7
1 1 6
```
**输出示例 3**
```
-1
```
*解释：如果不存在从顶点 1 到顶点 $N$ 的路径，请输出 -1。*
