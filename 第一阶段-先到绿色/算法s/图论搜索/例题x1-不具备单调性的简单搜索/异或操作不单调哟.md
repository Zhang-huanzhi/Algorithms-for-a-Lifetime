XOR 运算**不具备单调性**

**“不同为 1，相同为 0”**。

python中，异或操作，简单的 

``` python
	a = 5   # 二进制: 0101
	b = 3   # 二进制: 0011
	
	# 计算过程:
	#   0 1 0 1
	# ^ 0 0 1 1
	# ---------
	#   0 1 1 0  (结果为 6)
	
	print(a ^ b)  # 输出: 6
```

写异或的时候注意优先级哟，^ 的优先级比较低

``` python
	# 错误写法：
	if x ^ y == 0:  # 等同于 x ^ (y == 0)，这通常不是你想要的
	
	# 正确写法：
	if (x ^ y) == 0: # 先计算异或，再进行判断
```
