**二维前缀和**（2D Prefix Sum）是算法竞赛中非常经典且高效的技巧。

它的核心作用是：**在 $O(1)$ 的超快时间内，查询矩阵中任意“子矩形区域”的所有元素之和**，前提是花 $O(HW)$ 的时间进行预处理建表。

---

### 一、 初始化
假设原网格 $A$ 大小为 $H \times W$，坐标范围为 $1 \le i \le H, 1 \le j \le W$。
需要创建大小为 $(H + 1) \times (W + 1)$ 的二维前缀和数组 `S`，并全部初始化为 `0`：
```python
S = [[0] * (W + 1) for _ in range(H + 1)]
```

---

### 二、 建表公式（两种方式）

#### 方式 1：行列分别累加法（原地建表，省空间）
直接在原数组 `A` 上依次进行行向和列向的累加，累加后的结果即为前缀和，无需额外开辟空间。

1. **行向累加**（对于所有 $1 \le i \le H, 1 \le j \le W$）：
   $$A[i][j] = A[i][j] + A[i][j - 1]$$
2. **列向累加**（对于所有 $1 \le i \le H, 1 \le j \le W$）：
   $$A[i][j] = A[i][j] + A[i - 1][j]$$

```python
# 1. 横向累加
for i in range(1, H + 1):
    for j in range(1, W + 1):
        A[i][j] += A[i][j - 1]

# 2. 纵向累加
for i in range(1, H + 1):
    for j in range(1, W + 1):
        A[i][j] += A[i - 1][j]
```

#### 方式 2：容斥原理递推法（构建到新数组 `S`）
利用二维前缀和的容斥原理，将原数组 `A` 的前缀和计算并存储到新数组 `S` 中（对于所有 $1 \le i \le H, 1 \le j \le W$）：

$$S[i][j] = S[i - 1][j] + S[i][j - 1] - S[i - 1][j - 1] + A[i][j]$$

```python
# 递推构建新前缀和数组 S
for i in range(1, H + 1):
    for j in range(1, W + 1):
        S[i][j] = (
            S[i - 1][j] + S[i][j - 1] - S[i - 1][j - 1] + A[i][j]
        )
```

---

### 三、 区间查询公式

对于查询子矩形区域 $(x_1, y_1)$ 到 $(x_2, y_2)$（左上角到右下角，闭区间）内所有元素之和：

$$\text{Sum} = S[x_2][y_2] - S[x_1 - 1][y_2] - S[x_2][y_1 - 1] + S[x_1 - 1][y_1 - 1]$$

```python
# 计算子矩形 (x1, y1) 到 (x2, y2) 的元素和
total_sum = (
    S[x2][y2] - S[x1 - 1][y2] - S[x2][y1 - 1] + S[x1 - 1][y1 - 1]
)
```
