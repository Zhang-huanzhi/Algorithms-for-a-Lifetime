### 1. 如何进行深拷贝？（Python 简要写法）

* **通用方法**（适用于任何复杂结构）：
  ```python
  import copy

  new_grid = copy.deepcopy(grid)
  ```
* **二维数组快速方法**（算法题中常用，速度较快）：
  ```python
  new_grid = [row[:] for row in grid]
  ```

---

### 2. 为什么算法中排斥深拷贝？

* **极其耗时（TLE）**：拷贝需要遍历原数组的每一个元素。如果数组很大且在循环中反复拷贝，时间复杂度会暴增。例如 $2000 \times 2000$ 的数组拷贝 $20$ 万次，计算量高达八千亿次，必然超时。
* **极其耗内存（MLE）**：频繁创建新的大数组会瞬间吃光计算机内存，导致程序崩溃。

### 3. 推荐如何处理？（替代方案）

算法中推荐使用**“原地修改 + 恢复现场（撤销操作）”**，而不是靠拷贝来保存状态。

* **核心步骤**：
  1. **做操作**：直接修改原数组（例如：将受影响区域的数据 `-1`）。
  2. **记答案**：计算并记录当前状态的答案。
  3. **撤销操作**：把刚才修改的数据改回去（例如：将受影响区域的数据 `+1`）。

* **优势**：全程**零内存复制**，只做极少量的加减法运算，时间复杂度从 $O(\text{数组大小})$ 降为 $O(\text{修改区域大小})$，速度提升成百上千倍。
