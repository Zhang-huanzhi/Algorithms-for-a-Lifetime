**二维差分**（2D Difference Array）是算法竞赛中非常经典且高效的技巧。

它的核心作用是：**在 $O(1)$ 的超快时间内，对矩阵的“某一个子矩形区域”进行批量加减操作**，最后再用 $O(HW)$ 的时间统一还原出整个网格的值。


### 一、 初始化
假设网格大小为 $H \times W$，坐标范围为 $1 \le i \le H, 1 \le j \le W$。
需要创建大小为 $(H + 2) \times (W + 2)$ 的二维数组 `diff`，并全部初始化为 `0`：
```python
diff = [[0] * (W + 2) for _ in range(H + 2)]
```

---

### 二、 打标记
对于将子矩形区域 $(u, l)$ 到 $(d, r)$（左上角到右下角，闭区间）内的所有元素加上 $v$：
```python
diff[u][l] += v
diff[u][r + 1] -= v
diff[d + 1][l] -= v
diff[d + 1][r + 1] += v
```

---

### 三、 还原公式（两种方式）

#### 方式 1：行列分别累加法（原地还原，省空间）
直接在 `diff` 数组上依次进行行向和列向的累加，还原后的结果保留在 `diff` 中。

1. **行向累加**（对于所有 $1 \le i \le H, 1 \le j \le W$）：
   $$\text{diff}[i][j] = \text{diff}[i][j] + \text{diff}[i][j - 1]$$
2. **列向累加**（对于所有 $1 \le i \le H, 1 \le j \le W$）：
   $$\text{diff}[i][j] = \text{diff}[i][j] + \text{diff}[i - 1][j]$$

```python
# 1. 横向累加
for i in range(1, H + 1):
    for j in range(1, W + 1):
        diff[i][j] += diff[i][j - 1]

# 2. 纵向累加
for i in range(1, H + 1):
    for j in range(1, W + 1):
        diff[i][j] += diff[i - 1][j]
```

#### 方式 2：容斥原理递推法（还原到新数组 `grip`）
利用二维前缀和的容斥原理，将还原结果输出到另一个同样大小的二维数组 `grip` 中（对于所有 $1 \le i \le H, 1 \le j \le W$）：

$$\text{grip}[i][j] = \text{grip}[i - 1][j] + \text{grip}[i][j - 1] - \text{grip}[i - 1][j - 1] + \text{diff}[i][j]$$

```python
# 还原到新数组 grip
for i in range(1, H + 1):
    for j in range(1, W + 1):
        grip[i][j] = (
            grip[i - 1][j] + grip[i][j - 1] - grip[i - 1][j - 1] + diff[i][j]
        )
```
