**题目：矩形染色统计**

给定一个 `n x m` 的网格，初始时所有格子的颜色值都是 `0`。  
接下来有 `q` 次操作，每次操作会把一个子矩形内所有格子的颜色值都加上 `1`。

操作结束后，再给定一个整数 `k`，你需要统计：**最终颜色值恰好等于 `k` 的格子有多少个。**

**输入格式**
第一行四个整数 `n, m, q, k`

接下来 `q` 行，每行四个整数 `x1, y1, x2, y2`，表示对左上角为 `(x1, y1)`、右下角为 `(x2, y2)` 的子矩形内所有格子加 `1`。

保证：
- `1 <= x1 <= x2 <= n`
- `1 <= y1 <= y2 <= m`

**输出格式**
输出一个整数，表示最终颜色值恰好等于 `k` 的格子数。

**数据范围**
- `1 <= n, m <= 1000`
- `1 <= q <= 2 * 10^5`
- `0 <= k <= q`

**样例输入**
```text
3 4 3 2
1 1 2 3
2 2 3 4
1 3 3 3
```

**样例输出**
```text
3
```

**样例解释**
最终网格是：
```text
1 1 2 0
1 2 3 1
0 1 2 1
```
恰好等于 `2` 的格子有 `3` 个。
