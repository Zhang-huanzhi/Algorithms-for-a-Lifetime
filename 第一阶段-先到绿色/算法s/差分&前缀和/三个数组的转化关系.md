## 基本定义

- **原始数组 arr**: [a₀, a₁, a₂, a₃, ...]
- **前缀和数组 brr**: [b₀, b₁, b₂, b₃, ...] 其中 bᵢ = a₀ + a₁ + ... + aᵢ
- **差分数组 crr**: [c₀, c₁, c₂, c₃, ...] 其中 cᵢ = aᵢ - aᵢ₋₁ (c₀ = a₀)

## 转换关系

**原始数组 → 前缀和数组**

```
brr[i] = brr[i-1] + arr[i]  (或 brr[i] = sum(arr[0..i]))
```

**原始数组 → 差分数组**

```
crr[0] = arr[0]
crr[i] = arr[i] - arr[i-1]  (i > 0)
```

**前缀和数组 → 原始数组**

```
arr[0] = brr[0]
arr[i] = brr[i] - brr[i-1]  (i > 0)
```

**差分数组 → 原始数组**

```
arr[i] = crr[0] + crr[1] + ... + crr[i]  (对差分数组求前缀和)
```

## 记忆技巧

- 前缀和 ↔ 原始：**求和 ↔ 作差**
- 差分 ↔ 原始：**作差 ↔ 求和**
- 前缀和和差分互为"逆运算"

所有转换都是 **O(n)** 时间复杂度，因为都只需要遍历数组一遍，每个元素做 O(1) 的加法或减法运算。
