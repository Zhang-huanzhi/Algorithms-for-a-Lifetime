双指针（滑动窗口）是算法中非常经典且高效的方法。根据**窗口大小是否随数据内容动态变化**，我们可以将其分为 **“大小固定”** 与 **“大小可变”** 两大类。

以下是对这两类双指针的简要总结和对比：

---

### 一、 大小固定（固定大小的滑动窗口）

#### 1. 核心特征
* **窗口宽度**：由题目中的**空间、下标差或常数**决定（例如“长度为 $K$ 的子数组”、“距离在 $[L, R]$ 之间的点对”）。
* **步调一致**：左右指针保持固定的相对距离，以相同的速度向右平移。

#### 2. 代码模板与特点
* **单层循环**：通常**不需要嵌套循环**。右指针向右移动一步，左指针必然同步向右移动一步。
* **$O(1)$ 更新**：每次移动，只需要处理“一个新元素滑入，一个旧元素滑出”。
* **结构示例**：
  ```python
  for r in range(n):
      # 1. 新元素滑入窗口
      add(s[r])
      # 2. 过期元素滑出窗口 (l = r - K)
      if r - K >= 0:
          remove(s[r - K])
      # 3. 统计当前窗口状态
      query()
  ```

#### 3. 适用场景
* 限制条件是**“几何距离、下标范围、固定长度”**。
* 典型题目：本题（Comfortable Distance）、长度为 $K$ 的子数组最大和、滑动窗口平均值。

---

### 二、 大小可变（可变大小的滑动窗口）

#### 4. 核心特征
* **窗口宽度**：由**窗口内的内容/状态**决定（例如“和 $\ge S$ 的最短子数组”、“不含有重复字符的最长子串”）。
* **步调不一致**：左右指针独立移动，窗口大小在不断地伸缩（变大、变小）。

#### 5. 代码模板与特点
* **嵌套循环（`while` 嵌套在 `for` 中）**：
  * **右指针（快指针）**负责向右开拓，寻找可行解（或打破可行状态）。
  * **左指针（慢指针）**负责向右收缩，寻找局部最优解（或恢复可行状态）。
* **均摊时间复杂度**：虽然有嵌套循环，但因为左右指针都只向右移动，不回退，所以每个元素最多进出窗口各一次，时间复杂度依然是 $O(N)$。
* **结构示例**：
  ```python
  l = 0
  for r in range(n):
      add(s[r]) # 扩展窗口
      while condition_met(): # 条件满足时，收缩左边界以寻找最优解
          update_ans()
          remove(s[l])
          l += 1
  ```

#### 6. 适用场景
* 限制条件是**“内容状态、数值总和、字符频次、去重”**。
* 典型题目：第一题（Truck Driver）、无重复字符的最长子串（LeetCode 3）、长度最小的子数组（LeetCode 209）。

---

### 三、 对比总结表

| 维度 | 固定大小滑动窗口 | 可变大小滑动窗口 |
| :--- | :--- | :--- |
| **窗口宽度** | **恒定**（由题目距离/长度决定） | **动态变化**（由窗口内的数据状态决定） |
| **左右指针移动** | 匀速、同向、步调一致 | 独立移动、步调不一（右指针探索，左指针收缩） |
| **循环结构** | 单层循环（$O(1)$ 的进出更新） | 双重循环（`for` 嵌套 `while`，双指针追赶） |
| **核心技巧** | **代数变形**（确定进出元素的下标） | **单调性**（确定什么时候该收缩左边界） |
| **适用限制条件** | 下标差、时间间隔、固定步长 | 元素和、字符频次、不重复性 |

在实际解题时，**先看限制条件是“空间距离（固定）”还是“内部数据状态（可变）”**，就能快速决定使用哪种模板。
