### C - Count Close Pairs

时间限制: 2 秒 / 内存限制: 1024 MiB
分值: 300 分

#### 问题描述
本题是一道**交互题**（即你编写的程序与评测程序通过标准输入输出进行交互）。

在数轴上，有 $N$ 个点 $1, 2, \dots, N$，它们自左向右依次排列。

最开始，系统只会给出整数 $N$。
之后，你可以向评测程序进行**最多 $2N$ 次**如下形式的询问：
* 选择满足 $1 \le i < j \le N$ 的整数 $i, j$，询问点 $i$ 与点 $j$ 之间的距离是否小于等于 $1$。

请输出距离小于等于 $1$ 的两点组的个数，即满足 $1 \le i < j \le N$ 且点 $i$ 与点 $j$ 之间的距离小于等于 $1$ 的整数对 $(i, j)$ 的数量。

#### 数据范围
* $2 \le N \le 10^3$
* $N$ 是整数

#### 输入与输出

首先，从标准输入中读取表示点数目的整数 $N$。

```text
N
```

接下来，你可以向评测程序重复上述询问，最多 $2N$ 次。
询问应以以下格式输出到标准输出。这里，$i, j$ 必须是满足 $1 \le i < j \le N$ 的整数。

```text
? i j
```

作为对该询问的回答，你将从标准输入中获得以下两者之一：

```text
Yes
```
或者
```text
No
```

其中，`Yes` 表示点 $i$ 与点 $j$ 之间的距离小于等于 $1$；`No` 表示点 $i$ 与点 $j$ 之间的距离大于 $1$。

当你确定了问题的答案 $X$ 时，请以以下格式输出解答，然后立即结束程序。

```text
! X
```

#### 注意事项
* 每次输出后，请务必在末尾添加换行符并**刷新标准输出缓冲区（flush）**。否则，评测结果可能会判定为超时（TLE）。
* 如果在交互过程中进行了非法输出，或者程序中途异常终止，则评测结果是未知的。
* 输出答案后请立即结束程序，否则评测结果是未知的。
* 点的位置以及最终答案在交互开始前就已确定，不会根据你的提问而发生改变（即评测程序是非自适应的）。

#### 交互示例

以下是当 $N=3$，点 $1, 2, 3$ 的坐标分别为 $0, 0.7, 1.5$ 时的交互示例。（点 $1, 2, 3$ 的实际坐标不会直接输入给你的程序。）

| 输入 | 输出 | 说明 |
| :--- | :--- | :--- |
| `3` | | 给出 $N$ 的值。 |
| | `? 1 2` | 询问点 1 和点 2 之间的距离是否小于等于 1。 |
| `Yes` | | 评测程序回答，两点距离小于等于 1。 |
| | `? 1 3` | 询问点 1 和点 3 之间的距离是否小于等于 1。 |
| `No` | | 评测程序回答，两点距离大于 1。 |
| | `? 2 3` | 询问点 2 和点 3 之间的距离是否小于等于 1。 |
| `Yes` | | 评测程序回答，两点距离小于等于 1。 |
| | `! 2` | 回答满足条件的点对数量为 2。 |

在此示例中，询问次数为 3 次，满足最多 $2N=6$ 次的要求。回答的点对数量也是正确的，因此在此之后立即结束程序即可被判定为答案正确。

# Code - 双指针
``` python
import sys  
  
  
def main():  
    n = int(sys.stdin.readline().strip())  
  
    ans = 0  
    r = 1  
  
    # 依次让每一个点 l 作为左端点  
    for l in range(1, n + 1):  
        # 保证右指针至少在左指针的位置（因为自己到自己距离为 0 <= 1）  
        r = max(r, l)  
  
        # 尝试将右指针向右扩展  
        while r < n:  
            # 始终询问 l 和 r + 1（因为 r >= l，所以 r + 1 必然严格大于 l，满足 i < j 限制）  
            print(f"? {l} {r + 1}", flush=True)  
            res = sys.stdin.readline().strip()  
  
            if res == "Yes":  
                r += 1  # 扩展成功，继续尝试下一个点  
            else:  
                break  # 扩展失败（距离 > 1），停止当前 l 的扩展  
  
        # 此时，以 l 为左端点，最远能连到 r。  
        # 那么符合条件的右端点有：l+1, l+2, ..., r，共 (r - l) 个  
        ans += r - l  
  
    # 输出最终答案  
    print(f"! {ans}", flush=True)  
  
  
if __name__ == "__main__":  
    main()
```
