在 Python 中，字符串和列表的切片操作（`s[start:end]`）遵循**“左闭右开”**的原则，这是写代码时极易忽视但又至关重要的一个细节。

简单来说，**“左闭右开”**意味着：
* **包含**左边界的字符 `s[start]`
* **不包含**右边界的字符 `s[end]`（实际只取到 `s[end - 1]`）

---

### 用一个极简的例子理解：

假设字符串 `s = "abc"`，长度为 3，索引分别为 `0, 1, 2`。

* `s[0:2]` $\rightarrow$ 取索引 `0` 和 `1` 的字符 $\rightarrow$ 结果是 `"ab"`（不包含索引 `2` 的 `'c'`）。
* `s[0:3]` $\rightarrow$ 取索引 `0`、`1`、`2` 的字符 $\rightarrow$ 结果是 `"abc"`（包含到最后一个字符 `'c'`）。

### 为什么之前的暴力代码会漏掉字符？

在您最初的暴力代码中：
```python
for i in range(n):
    for j in range(i + 1, n):  # j 最大只能取到 n - 1
        s_sub = s[i:j]         # 切片只取到索引 j - 1
```

由于 `j` 的最大值是 `n - 1`，那么切片 `s[i:j]` 最大只能取到 `s[i : n-1]`。
根据左闭右开原则，这个切片实际拿到的最右端字符索引是 `n - 2`。

这就导致**字符串的最后一个字符（索引为 `n - 1` 的字符）在所有的子串中被彻底漏掉了**。

### 黄金法则：
在 Python 中，如果您想通过切片获取包含索引 `i` 到索引 `j`（包含 `j` 本身）的子串，切片的写法必须是：
$$\text{s[i : j + 1]}$$
