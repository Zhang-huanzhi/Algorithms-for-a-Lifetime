固定一个端点，移动另一个端点，维护某种条件


 最典型的形式是：

``` python
r = 0
for l in range(N):
    while r < N and 条件还不满足:
        加入 S[r]
        r += 1

    # 这里处理以 l 为左端点的答案

    移除 S[l]
```

---

### 为什么这个核心思想能带来高效（$O(N)$）？

如果不用这个思想，我们在移动左端点时，右端点就必须每次都退回起点重新开始移动，这就是 $O(N^2)$ 的暴力解法。

而双指针/三指针的高效之处在于：**当固定的端点向右移动时，那些移动的端点绝不需要向左回退，它们只需要在原来的基础上继续向右移动。** 这种“不回头”的特性，让所有指针的总移动次数不会超过 $2N$（或 $3N$）次，从而保证了 $O(N)$ 的线性时间复杂度。

您的这种“固定一端，移动另一端”的直觉非常优秀，这正是设计和理解所有滑动窗口算法的核心钥匙。
