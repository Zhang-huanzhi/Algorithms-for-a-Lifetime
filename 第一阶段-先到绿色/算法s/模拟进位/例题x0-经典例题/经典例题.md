### C - Prefixes Sum
**时间限制：** 2.0 sec / **内存限制：** 1024 MiB  
**配点：** 350 点

#### 【问题描述】
给定一个长度为 $N$ 且仅由数字字符 `1` 到 `9` 组成的字符串 $S$。  
对于 $i = 1, 2, \dots, N$，定义 $X_i$ 为由 $S$ 的前 $i$ 个字符所组成的十进制整数（即 $S$ 的长度为 $i$ 的前缀）。

请计算并输出以下表达式的值：
$$\sum_{i=1}^N X_i = X_1 + X_2 + \dots + X_N$$

---

#### 【数据范围】
* $1 \le N \le 2 \times 10^5$
* $S$ 是长度为 $N$ 的字符串，且其中的每个字符均为 `1` 到 `9` 的数字。
* 输入的值均为整数。

---

#### 【输入格式】
输入从标准输入给出，格式如下：
```text
N
S
```

---

#### 【输出格式】
输出一行，表示 $\sum_{i=1}^N X_i$ 的计算结果。

---

### 【样例说明】

#### 样例 1
**输入：**
```text
3
123
```
**输出：**
```text
136
```
**解释：**
* $X_1 = 1$
* $X_2 = 12$
* $X_3 = 123$
* 答案为 $1 + 12 + 123 = 136$。

---

#### 样例 2
**输入：**
```text
4
9999
```
**输出：**
```text
11106
```
**解释：**
* $X_1 = 9$
* $X_2 = 99$
* $X_3 = 999$
* $X_4 = 9999$
* 答案为 $9 + 99 + 999 + 9999 = 11106$。

---

#### 样例 3
**输入：**
```text
10
1234567891
```
**输出：**
```text
1371742096
```
**解释：**
* $1 + 12 + 123 + 1234 + 12345 + 123456 + 1234567 + 12345678 + 123456789 + 1234567891 = 1371742096$。


# Code AC 进位模拟
``` python
import math  
import sys  
  
def main():  
  
    n = int(sys.stdin.readline().strip())  
    arr = sys.stdin.readline().strip()  
  
    pre = [0] * (n + 1)  
    for i in range(1, n + 1):  
        pre[i] = pre[i - 1] + int(arr[i - 1])  
  
    ans = []  
    carry = 0  
    for i in range(n, 0, -1):  
        total = pre[i] + carry  
        ans.append(total % 10)  
        carry = total // 10  
  
    while carry > 0:  
        ans.append(carry % 10)  
        carry //= 10  
  
    ans.reverse()  
    print(''.join(map(str, ans)))  
  
  
if __name__ == "__main__":  
    main()
```
