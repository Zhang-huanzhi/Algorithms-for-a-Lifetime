### 一、什么是“竖向加法”？

**竖向加法（Column-wise Addition / Carry Resolution）** 的核心逻辑是：**将大数相加的过程解耦为两个独立的阶段**。

```text
阶段一：算每一列的毛和（粗糙累加）
阶段二：从个位向高位跑一遍进位（精细规整）
```

#### 标准流程三部曲：
1. **统一坐标系（小端对齐，Little-Endian）**：
   * 下标 `k` 代表位权 $10^k$（即 `col[0]` 代表个位 $10^0$，`col[1]` 代表十位 $10^1$，依此类推）。
2. **纵向累加（各显神通）**：
   * 无论通过**差分数组**、**前缀和**还是**组合计数**，算出每一列的总和 `col[k]`（此时 `col[k]` 可以是任意大非负整数，比如 `500000`）。
3. **单向进位（标准规整）**：
   * 线性扫描 `col` 数组，执行 `total = col[k] + carry`，提取 `% 10`，进位 `// 10`。
   * 最后清空剩余进位并翻转输出。

### 二、通用工业级模板代码（Python）

你可以直接收藏并复制这个函数，几乎适用于所有需要纵向加法的题目：

```python
def vertical_addition(column_sums: list[int], base: int = 10) -> str:
    """
    竖向加法通用函数
    
    参数:
        column_sums: 列表，column_sums[k] 表示第 base^k 位（0为个位）上所有数的累加和
        base: 进制基数，默认为十进制 (base=10)
        
    返回:
        格式化后的标准大数字符串（最高位在最前）
    """
    ans = []
    carry = 0

    # 1. 从个位 (10^0) 向高位依次处理
    for val in column_sums:
        total = val + carry
        ans.append(total % base)
        carry = total // base

    # 2. 处理超出原最高位的剩余进位（关键：用 while）
    while carry > 0:
        ans.append(carry % base)
        carry //= base

    # 3. 清理可能产生的前导 0（例如运算结果为 0 时保留一个 '0'）
    while len(ans) > 1 and ans[-1] == 0:
        ans.pop()

    # 4. 翻转数组（从「低位在前」转为「高位在前」）并拼接输出
    ans.reverse()
    return ''.join(map(str, ans))
```

### 三、实战：如何生成 `column_sums`？（3 大最常见套路）

有了上述模板后，解题时你唯一需要关心的就是**如何用 $O(N)$ 算出 `column_sums` 数组**。

#### 套路 1：前缀/后缀规律题（用前缀和）
* **代表题**：$S$ 的所有前缀数之和（如上一题）。
* **核心代码**：
  ```python
  # pref[i] 是 S[0..i] 的数字和
  # S 长度为 n，个位 (10^0) 对应 pref[n-1]，十位对应 pref[n-2]...
  column_sums = [pref[n - 1 - k] for k in range(n)]
  result = vertical_addition(column_sums)
  ```

#### 套路 2：区间重复/覆盖题（用差分数组）
* **代表题**：多个形如 $11\dots1$ 的数相加（如最开始的 Repunit 题）。
* **核心代码**：
  ```python
  # 每个 A_i 相当于在区间 [0, A_i - 1] 的每一位上都 +1
  diff = [0] * (max_a + 2)
  for a in arr:
      diff[0] += 1
      diff[a] -= 1

  # 前缀和还原出每一位上的 1 的总个数
  column_sums = [0] * max_a
  curr = 0
  for k in range(max_a):
      curr += diff[k]
      column_sums[k] = curr

  result = vertical_addition(column_sums)
  ```

#### 套路 3：所有连续子串形成的数字求和（用贡献乘数）
* **代表题**：给定数字串 $S$，求所有子串形成的整数之和。
* **规律**：第 $i$ 个字符 $S[i]$ 会出现在 $(i + 1)$ 个前缀里，并在长度为 $L$ 的后缀中作为第 $10^k$ 位出现。
* **核心代码**：
  ```python
  # S[i] 在其作为第 10^k 位（k = n - 1 - i）时，出现的总次数为 (i + 1) 次
  n = len(s)
  column_sums = [0] * n
  for i in range(n):
      k = n - 1 - i  # 距离末尾的距离，即位权 10^k
      column_sums[k] = int(s[i]) * (i + 1)

  result = vertical_addition(column_sums)
  ```

### 四、C++ 高性能竞赛模板（供参考）

如果在打 C++ 比赛，由于没有原生大数，这套模板更为重要：

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

string vertical_addition(const vector<long long>& column_sums, int base = 10) {
    string ans = "";
    long long carry = 0;

    for (long long val : column_sums) {
        long long total = val + carry;
        ans.push_back((total % base) + '0');
        carry = total / base;
    }

    while (carry > 0) {
        ans.push_back((carry % base) + '0');
        carry /= base;
    }

    while (ans.size() > 1 && ans.back() == '0') {
        ans.pop_back();
    }

    reverse(ans.begin(), ans.end());
    return ans.empty() ? "0" : ans;
}
```
