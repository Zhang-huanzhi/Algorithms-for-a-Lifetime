### E - Sum of Average

**运行时间限制：** 2 秒 / **内存限制：** 1024 MiB

**分值：** 450 分

#### 问题描述

给出一个正整数 $N$ 和一个长度为 $N$ 的整数序列 $A = (A_1, A_2, \dots, A_N)$。

定义 $f(l, r)$ 为 $A_l, A_{l+1}, \dots, A_r$ 的算术平均值。

请计算：
$$ \sum_{1 \le l \le r \le N} f(l, r) $$
对 $998244353$ 取模后的结果。

**有理数模 998244353 的定义**  
在本题的限制条件下，可以证明所求的有理数表示为最简分数 $\frac{P}{Q}$ 时，满足 $Q \not\equiv 0 \pmod{998244353}$。因此，存在唯一的整数 $R$ 满足 $R \times Q \equiv P \pmod{998244353}$ 且 $0 \le R < 998244353$。请输出这个整数 $R$。

#### 数据范围

* $1 \le N \le 5 \times 10^5$
* $0 \le A_i < 998244353$
* 输入的所有值均为整数。

#### 输入格式

输入按以下格式从标准输入给出：

$$
N \\
A_1 \ A_2 \ \dots \ A_N
$$

#### 输出格式

输出答案。

---

#### 输入样例 1
```text
2
2 3
```

#### 输出样例 1
```text
499122184
```

**样例 1 解释：**  
* $f(1, 1) = 2$
* $f(1, 2) = \frac{2+3}{2} = \frac{5}{2}$
* $f(2, 2) = 3$

因此，
$$ \sum_{1 \le l \le r \le N} f(l, r) = 2 + \frac{5}{2} + 3 = \frac{15}{2} $$
在模 $998244353$ 意义下，$\frac{15}{2}$ 对应的值为 $499122184$，因此输出 $499122184$。

# 优雅代码 AC
``` python
import sys  
  
def main():  
      
    n = int(input())  
    a = list(map(int, input().split()))  
    MOD = 998244353  
  
    # 1. 计算前缀和数组 b，对应公式中的 B_i    b = [0] * (n + 1)  
    for i in range(n):  
        b[i + 1] = (b[i] + a[i]) % MOD  
  
    # 2. 预处理调和数数组 h，对应公式中的 H_i    h = [0] * (n + 1)  
    for i in range(1, n + 1):  
        # h[i] = h[i-1] + 1/i (模意义下即 i 的逆元)  
        h[i] = (h[i - 1] + pow(i, MOD - 2, MOD)) % MOD  
  
    # 3. 根据最终合并后的公式进行 O(N) 一次性求和  
    ans = 0  
    for i in range(n + 1):  
        # 累加 (H_i - H_{N-i}) * B_i        ans += b[i] * (h[i] - h[n - i])  
        ans %= MOD  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```
