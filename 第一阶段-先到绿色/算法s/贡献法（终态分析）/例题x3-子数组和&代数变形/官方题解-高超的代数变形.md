这份官方题解采用了一种非常经典且优雅的数学技巧：**改变求和顺序（交换求和号）**。通过这种方法，将原本需要 $O(N^2)$ 或 $O(N)$ 的复杂计算，简化为了一个非常简洁的 $O(N)$ 级公式。

以下是对该题解的详细推导和代码解释：

---

### 一、 核心概念与定义

1. **调和数（Harmonic Numbers） $H_n$**：
   定义 $H_n = \sum_{k=1}^{n} \frac{1}{k}$ 为前 $n$ 个正整数倒数的和（特别地，规定 $H_0 = 0$）。
   在模意义下，$\frac{1}{k}$ 对应 $k$ 的乘法逆元。

2. **前缀和 $B_n$**：
   令 $B_0 = 0$，对于 $n \ge 1$，令 $B_n = \sum_{k=1}^{n} A_k$（即序列 $A$ 的前缀和）。
   这样，任何一个区间 $[l, r]$ 的元素之和可以表示为 $B_r - B_{l-1}$。
   因此，区间平均值 $f(l, r)$ 可以写成：
   $$f(l, r) = \frac{B_r - B_{l-1}}{r - l + 1}$$

---

### 二、 数学推导过程

我们需要计算所有区间的平均值之和：
$$ \sum_{1 \le l \le r \le N} f(l, r) = \sum_{1 \le l \le r \le N} \frac{B_r - B_{l-1}}{r - l + 1} $$

我们可以将分子拆开，分为两部分分别求和：
$$ \sum_{1 \le l \le r \le N} \frac{B_r}{r - l + 1} - \sum_{1 \le l \le r \le N} \frac{B_{l-1}}{r - l + 1} $$

接下来，分别对这两部分**改变求和顺序**：

#### 第一部分：计算包含 $B_r$ 的项
我们改变循环顺序，先枚举右端点 $r$，再枚举左端点 $l$（此时 $l$ 的范围是 $1 \le l \le r$）：
$$ \sum_{1 \le l \le r \le N} \frac{B_r}{r - l + 1} = \sum_{r=1}^{N} \sum_{l=1}^{r} \frac{B_r}{r - l + 1} = \sum_{r=1}^{N} B_r \left( \sum_{l=1}^{r} \frac{1}{r - l + 1} \right) $$

观察内层循环 $\sum_{l=1}^{r} \frac{1}{r - l + 1}$：
当 $l$ 从 $1$ 递增到 $r$ 时，分母 $r - l + 1$ 刚好从 $r$ 递减到 $1$。
所以内层循环其实就是：
$$ \frac{1}{r} + \frac{1}{r-1} + \dots + \frac{1}{1} = H_r $$
因此，第一部分可以简化为：
$$ \sum_{r=1}^{N} H_r B_r $$

#### 第二部分：计算包含 $B_{l-1}$ 的项
同理，我们先枚举左端点 $l$，再枚举右端点 $r$（此时 $r$ 的范围是 $l \le r \le N$）：
$$ \sum_{1 \le l \le r \le N} \frac{B_{l-1}}{r - l + 1} = \sum_{l=1}^{N} \sum_{r=l}^{N} \frac{B_{l-1}}{r - l + 1} = \sum_{l=1}^{N} B_{l-1} \left( \sum_{r=l}^{N} \frac{1}{r - l + 1} \right) $$

观察内层循环 $\sum_{r=l}^{N} \frac{1}{r - l + 1}$：
当 $r$ 从 $l$ 递增到 $N$ 时，分母 $r - l + 1$ 刚好从 $1$ 递增到 $N - l + 1$。
所以内层循环其实就是：
$$ \frac{1}{1} + \frac{1}{2} + \dots + \frac{1}{N - l + 1} = H_{N - l + 1} $$
因此，第二部分可以简化为：
$$ \sum_{l=1}^{N} H_{N - l + 1} B_{l-1} $$

#### 合并两部分
将两部分合并，我们得到总和为：
$$ \sum_{r=1}^{N} H_r B_r - \sum_{l=1}^{N} H_{N - l + 1} B_{l-1} $$

为了将两项合写进同一个循环，我们统一使用下标 $i$：
* 对于第一项 $\sum_{r=1}^{N} H_r B_r$，令 $i = r$。因为 $B_0 = 0, H_0 = 0$，我们可以将范围扩展为 $i$ 从 $0$ 到 $N$。
* 对于第二项 $\sum_{l=1}^{N} H_{N - l + 1} B_{l-1}$，令 $i = l - 1$。当 $l$ 从 $1$ 到 $N$ 时，$i$ 从 $0$ 到 $N-1$。该项变为 $H_{N-i} B_i$。由于当 $i = N$ 时 $H_{N-N} = H_0 = 0$，我们同样可以将范围扩展为 $i$ 从 $0$ 到 $N$。

由此得到最终的极其简洁的求和公式：
$$ \sum_{i=0}^{N} (H_i - H_{N-i}) B_i $$

---

### 三、 代码逐行解析

以下是题解中给出的 Python 3 实现：

```python
n = int(input())
a = list(map(int, input().split()))
MOD = 998244353

# 1. 计算前缀和数组 b，对应公式中的 B_i
b = [0] * (n + 1)
for i in range(n):
    b[i + 1] = (b[i] + a[i]) % MOD

# 2. 预处理调和数数组 h，对应公式中的 H_i
h = [0] * (n + 1)
for i in range(1, n + 1):
    # h[i] = h[i-1] + 1/i (模意义下即 i 的逆元)
    h[i] = (h[i - 1] + pow(i, MOD - 2, MOD)) % MOD

# 3. 根据最终合并后的公式进行 O(N) 一次性求和
ans = 0
for i in range(n + 1):
    # 累加 (H_i - H_{N-i}) * B_i
    ans += b[i] * (h[i] - h[n - i])
    ans %= MOD

print(ans)
```

### 总结
该解法通过数学变形，避免了对每个区间进行单独处理，而是直接计算了每个前缀和 $B_i$ 对最终答案的贡献系数。最终时间复杂度由暴力的 $O(N^2)$ 降为了 $O(N \log (\text{MOD}))$（瓶颈在计算逆元），能够非常轻松地通过本题。
