**贡献法（Contribution Method）**是算法竞赛中一种非常强大且常用的思维方式。

它的核心思想是：**与其去计算“每个过程/每个动作”产生了多少代价，不如去计算“每个静态元素”对最终答案贡献了多少代价。**

在这道题中，贡献法体现在：我们将目光从**“高桥君的移动步骤”**移开，转而静态地去观察**“每一扇门”**。

---

### 视角转换：从“动作视角”到“贡献视角”

#### 1. 动作视角（不推荐，容易超时）
* “高桥君在第 1 步打开了门 $A$（代价 +1）。”
* “高桥君在第 5 步跨过了门 $A$。”
* “高桥君在第 10 步又锁上了门 $A$（代价 +1）。”
* **缺点**：我们需要跟踪时间线，计算每个时间点发生的动作。

#### 2. 贡献视角（本题采用的贡献法）
我们直接盯着第 $i$ 扇门，问自己一个问题：
> **“在整个游戏过程中，为了让所有门锁上，第 $i$ 扇门必须被操作几次？”**

根据高桥君的最优足迹区间 $[L, R]$，第 $i$ 扇门在最终答案（操作总数）中的**贡献**被彻底固定为以下三种情况之一：

| 门 $i$ 所在的位置 | 门 $i$ 的初始状态 $L_i$ | 这扇门对最终答案的**贡献（操作次数）** | 为什么？ |
| :--- | :--- | :--- | :--- |
| **区间内部** ($L \le i < R$) | $0$ (开) | **+1** | 必须跨越它，并在最后顺手锁上它。 |
| | $1$ (关) | **+2** | 必须先开锁才能过去，最后还要锁上它。 |
| **区间边界** ($i = L-1$ 或 $i = R$) | $0$ (开) | **+1** | 站在边界房间顺手把它锁上。 |
| | $1$ (关) | **+0** | 本来就是锁的，高桥君也无需过去，不用操作。 |
| **区间外部** ($i < L-1$ 或 $i > R$) | $1$ (关) | **+0** | 碰不到它，它本来就是锁的。 |
| | $0$ (开) | **不可行（非法）** | 碰不到它，它却开着，无法完成任务。 |

---

### 贡献法的威力在哪里？

通过这种视角转换，我们把一个**“动态的时间序列问题”**，成功解耦成了一个**“静态的元素求和问题”**：

$$ \text{最少操作总数} = \sum_{i=0}^{n-1} (\text{门 } i \text{ 的贡献}) $$

因为每一扇门的贡献只取决于**它与区间 $[L, R]$ 的相对位置**。

1. **解耦了状态**：每扇门对答案的贡献是**独立**的。第 3 扇门贡献多少，只看它自己在不在 $[L, R]$ 内部，不需要管第 2 扇门或者第 4 扇门此时是开是关。
2. **消除了时间轴**：我们不需要管高桥君是“先去左边还是先去右边”，因为无论他以什么顺序走，只要他走过的最远范围是 $[L, R]$，每扇门被开闭的次数（贡献）都是唯一确定的。

在写代码时，第 4、5、6 步的循环和判断，本质上就是**在依次累加每扇门的贡献值**。这就是“贡献法”在这一题中的完美体现。
