这份官方题解的思路非常精妙，它通过一个**数学等式**将问题进行了极大的简化。

以下为您详细讲解这份题解的推导过程和背后的逻辑：

---

### 一、 核心概念定义
为了方便讨论，题解首先对两种操作进行了命名：
* **闭操作**：把开着的门锁上（`0` $\to$ `1`）。
* **开操作**：把锁着的门打开（`1` $\to$ `0`）。

### 二、 妙用等式：简化目标函数
设：
* $K$ 为**初始时**开着的门（`0` 门）的数量。
* $O$ 为整个过程中进行的**开操作**总次数。
* $C$ 为整个过程中进行的**闭操作**总次数。

因为每次“开操作”会让开着的门增加 $1$，每次“闭操作”会让开着的门减少 $1$。
由于最终的目标是**所有的门都处于关闭状态**（即最后开着的门数量为 $0$），我们可以列出以下关系式：
$$\text{最终开着的门数} = K + O - C = 0$$

由此可得：
$$C = K + O$$

那么，总的操作次数（开操作 + 闭操作）为：
$$\text{总操作次数} = C + O = (K + O) + O = K + 2O$$

**关键结论**：
因为初始开门数 $K$ 是一个固定常数，所以**要想让总操作次数最少，我们只需要让“开操作”的次数 $O$ 最少即可**。

---

### 三、 转化必要条件：什么时候才能把门全关上？
高桥君要能关上所有的门，必要且充分的条件是：
> 在我们做完所有的**开操作**后，所有开着的门必须形成一个**连续的区间** $\{i \mid X \le i \le Y\}$，且这个区间必须能够触及起点 $R$（即满足 $X \le R$ 且 $R-1 \le Y$）。

**为什么必须是连续区间？**
如果开着的门是连续的，高桥君就可以畅通无阻地走到这个区间的某一个最边缘端点。然后，他可以一边往另一端走，一边顺手把身后的门锁上（只做闭操作，不再做任何开操作），直至走到另一端将所有的门完美锁上，且自己不会被卡住。

---

### 四、 如何用最少的“开操作”达成这个条件？
既然最终开着的门必须是一个包含所有初始 `0` 门的连续区间，那么这个区间的左端点至少要到达最左边的 `0` 门，右端点至少要到达最右边的 `0` 门。

设：
* $x$ 为最左边的 `0` 门的位置（即最小的 $i$ 使得 $L_i = 0$）。
* $y$ 为最右边的 `0` 门的位置（即最大的 $i$ 使得 $L_i = 0$）。

为了用最少的“开操作”把 $x$ 到 $y$ 之间的通道全部打通：
1. **如果 $x$ 在起点 $R$ 的左边**（即 $x \le R-1$）：
   我们必须把门 $x, x+1, \dots, R-1$ 全部打开。
2. **如果 $y$ 在起点 $R$ 的右边**（即 $y \ge R$）：
   我们必须把门 $R, R+1, \dots, y$ 全部打开。

在这两个范围内，原本就是 `0` 的门不需要操作，**原本是 `1` 的门则必须进行 $1$ 次开操作**。

---

### 五、 总结与算法实现

基于官方题解的逻辑，最少操作次数的计算方法极其简单：

1. 找到最左边 `0` 门的位置 $x$，和最右边 `0` 门的位置 $y$。
   *(如果全图没有 `0` 门，直接输出 0)*
2. 确定需要打通的区间：
   * 如果 $x \le R-1$，左边需要打通的区间为 $[x, R-1]$。
   * 如果 $y \ge R$，右边需要打通的区间为 $[R, y]$。
3. 统计这两个区间内**原本为 `1` 的门的数量**，这就是最少的开操作次数 $O$。
4. 统计全图原本为 `0` 的门的数量 $K$。
5. 最终答案即为：$K + 2O$。

这与我们之前通过区间收缩推导出的公式 $count0 + 2 \times count1$ 在数学上是完全等价的，但官方题解通过 $C = K + O$ 的推导，证明过程更加简洁科学。
