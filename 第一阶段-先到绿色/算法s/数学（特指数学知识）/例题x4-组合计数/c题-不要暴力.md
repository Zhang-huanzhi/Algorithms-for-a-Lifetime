### C - Odd One Subsequence

时间限制: 2 秒 / 内存限制: 1024 MiB

#### 问题描述
给你一个长度为 $N$ 的整数序列 $A = (A_1, A_2, \dots, A_N)$。

请计算满足 $1 \le i < j < k \le N$ 且符合以下条件的整数三元组 $(i, j, k)$ 的数量：

* $A_i, A_j, A_k$ 中**恰好包含 $2$ 种**不同的值。也就是说，在这三个数中，有两个数相等，而剩下的另一个数与它们不同。

#### 约束条件
* $3 \le N \le 2 \times 10^5$
* $1 \le A_i \le N$
* 输入的所有值均为整数。

#### 输入格式
输入通过标准输入按以下格式给出：

$$N$$
$$A_1 \quad A_2 \quad \dots \quad A_N$$

#### 输出格式
输出满足条件的整数三元组的数量。

---

#### 输入样例 1
```text
5
3 2 5 2 2
```

#### 输出样例 1
```text
6
```
**样例说明 1**：
例如，当 $(i,j,k)=(1,2,4)$ 时，对应的数值为 $A_1=3, A_2=2, A_4=2$，其中恰好包含 $2$ 和 $3$ 这 $2$ 种不同的值，因此满足条件。
包括这一组在内，满足条件的组共有：
$(1,2,4), (1,2,5), (1,4,5), (2,3,4), (2,3,5), (3,4,5)$，共 $6$ 组。
因此输出 $6$。

#### 输入样例 2
```text
3
1 1 1
```

#### 输出样例 2
```text
0
```
**样例说明 2**：
也有可能不存在任何满足条件的组。
