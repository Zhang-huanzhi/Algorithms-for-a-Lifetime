在 $10^9 \times 10^9$ 这种极大规模的网格上，如果我们直接引入任意形状的“迷宫式”障碍物，问题会退化成求最短路（如 BFS、Dijkstra），从而无法在 $10^9$ 级别的时间和空间内解决。

因此，适合二分答案的**“障碍物/限制区”**版本，通常会将障碍物抽象为**“大片无法停留的区域”**，或者**“只有特定安全区可以作为终点”**。

下面为您设计一个非常经典的**“安全区域（Safe Zone）限制版”**。在这个版本中，障碍物覆盖了除一个特定矩形以外的所有地方，最终的汇聚点必须在该安全区内。

---

### 扩展版题目：King's Summit (安全区域版)

#### 题目描述
在一个 $10^9$ 行 $10^9$ 列的网格上，有 $N$ 个人，最初时刻为 $0$。第 $i$ 个人最初位于格子 $(R_i, C_i)$。每个人每秒可以向 8 邻域方向移动 1 步。

由于大部分区域受到了核辐射（视为障碍区域），**他们最终必须在指定的“安全区”内汇聚**。
安全区是一个矩形，由左下角 $(X_1, Y_1)$ 和右上角 $(X_2, Y_2)$ 确定。只有满足 $X_1 \le x \le X_2$ 且 $Y_1 \le y \le Y_2$ 的格子 $(x, y)$ 才是安全区。

在移动过程中，大家**可以途径核辐射区（障碍区）**，但是**最终汇聚的那个格子必须在安全区内**。

求所有人能安全汇聚到安全区内同一个格子所需的最小整数时刻 $T$。

#### 输入格式
输入通过标准输入按以下形式给出：
> $N$  
> $X_1$ $Y_1$ $X_2$ $Y_2$  
> $R_1$ $C_1$  
> $R_2$ $C_2$  
> $\vdots$  
> $R_N$ $C_N$  

#### 输出格式
输出一个整数，表示所有人能安全聚集在安全区内所需的最小时刻 $T$。如果无论如何都无法在安全区内汇聚，输出 `-1`（本题由于安全区范围可能很大，通常一定有解）。

---

### 二分判定（check）的核心逻辑

引入安全区后，我们在时间 $T$ 下的判定逻辑变为了：
**“所有人的可达区域的交集，与安全区本身是否有交集？”**

1. **对于 $X$ 轴**：
   * 所有人能在时间 $T$ 内到达的 $X$ 区间交集为 $[L_{all}, R_{all}]$，其中：
     $$L_{all} = \max(R_i - T), \quad R_{all} = \min(R_i + T)$$
   * 这个交集必须与安全区的 $X$ 轴范围 $[X_1, X_2]$ 有重合。
   * 重合的条件是：
     $$\max(L_{all}, X_1) \le \min(R_{all}, X_2)$$

2. **对于 $Y$ 轴**：
   * 同理，所有人能在时间 $T$ 内到达的 $Y$ 区间交集为 $[B_{all}, T_{all}]$，其与安全区 $[Y_1, Y_2]$ 重合的条件是：
     $$\max(B_{all}, Y_1) \le \min(T_{all}, Y_2)$$

只要上述两个维度的重合条件同时满足，就说明在安全区内存在至少一个格子，所有人都能在 $T$ 秒内走到。

### 二分答案解法代码 (Python)

```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    if not data:
        return
    
    n = int(data[0])
    # 安全区边界
    x1, y1 = int(data[1]), int(data[2])
    x2, y2 = int(data[3]), int(data[4])
    
    people = []
    for i in range(n):
        r = int(data[5 + 2 * i])
        c = int(data[6 + 2 * i])
        people.append((r, c))
        
    # 预先找出所有人的最大/最小坐标，优化 check 函数的效率
    # 这样在 check 中就不需要每次都跑一个 O(N) 的循环了，可以将 check 优化到 O(1)
    max_r = max(p[0] for p in people)
    min_r = min(p[0] for p in people)
    max_c = max(p[1] for p in people)
    min_c = min(p[1] for p in people)

    # 判定函数：时间为 limit_time 时，可达交集与安全区是否有交集
    def check(limit_time):
        # 1. 计算所有人能到达的 X 轴公共区间
        l_all = max_r - limit_time
        r_all = min_r + limit_time
        
        # 2. 判断该公共区间与安全区 [x1, x2] 是否有交集
        if max(l_all, x1) > min(r_all, x2):
            return False
            
        # 3. 计算所有人能到达的 Y 轴公共区间
        b_all = max_c - limit_time
        t_all = min_c + limit_time
        
        # 4. 判断该公共区间与安全区 [y1, y2] 是否有交集
        if max(b_all, y1) > min(t_all, y2):
            return False
            
        return True

    # 二分查找时间 T
    low = 0
    # 极端情况下，可能需要横跨整个网格才能到达安全区，所以上界设为 10^9 级别
    high = 2 * 10**9  
    ans = -1
    
    while low <= high:
        mid = (low + high) // 2
        if check(mid):
            ans = mid       # 当前时间可行
            high = mid - 1  # 尝试更短时间
        else:
            low = mid + 1   # 时间不够，需要延长
            
    print(ans)

if __name__ == '__main__':
    main()
```

### 💡 算法亮点
在优化后的代码中，我们利用了最大/最小值的单调性质，在 `check` 函数外部提前提取了 `max_r`, `min_r`, `max_c`, `min_c`。
这使得 `check` 函数的执行时间从 $O(N)$ 降到了 **$O(1)$**。
整道题的运行总复杂度为 $O(N + \log(\text{Max\_Coordinate}))$，即使面对 $N = 2 \times 10^5$ 且有复杂边界限制的情况，也能在几毫秒内极速运行完毕
