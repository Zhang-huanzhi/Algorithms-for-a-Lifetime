为了使**二分答案（Binary Search）**成为解题的**必要且最自然的手段**，我们需要对原题引入一个变量：**速度差异**。

以下是为您重新设计的扩展版题目描述。在这个版本中，由于每个人速度不同，我们无法再使用简单的“两点差值除以2”的 $O(1)$ 公式，而必须使用二分答案。

---

### 扩展版题目：King's Summit (速度差异版)

#### 题目描述
有一个 $10^9$ 行 $10^9$ 列的网格，网格的上从上往下第 $i$ 行、从左往右第 $j$ 列的格子表示为 $(i, j)$。

网格上有 $N$ 个人，最初时刻为 $0$。
* 第 $i$ 个人最初位于格子 $(R_i, C_i)$。
* **第 $i$ 个人拥有不同的移动速度 $V_i$**。这意味着，在 1 单位时间内，第 $i$ 个人最多可以向 8 邻域方向移动 $V_i$ 步（即他在时刻 1 可以到达与其切比雪夫距离不超过 $V_i$ 的任意格子）。
* 每个人在时刻 $T$（$T$ 为非负整数）可以到达的最大切比雪夫距离为 $V_i \times T$。

请问：**全员在同一个格子集合所需的最小整数时刻 $T$ 是多少？**

#### 输入格式
输入通过标准输入按以下形式给出：
> $N$  
> $R_1$ $C_1$ $V_1$  
> $R_2$ $C_2$ $V_2$  
> $\vdots$  
> $R_N$ $C_N$ $V_N$  

#### 输出格式
输出一个整数，表示所有人能聚集到同一格子所需的最小时刻 $T$。

#### 数据范围
* $1 \le N \le 2 \times 10^5$
* $1 \le R_i, C_i \le 10^9$
* $1 \le V_i \le 10^9$ （新增：每个人的速度，数值越大移动越快）
* 所有输入均为整数。

---

### 为什么此扩展版必须用二分答案？

在原题中，所有人的速度都默认是 $1$。由于速度相同，最优的相遇点一定在“最左”和“最右”两人的中点，因此直接用最远距离除以 $2$ 即可。

但在**速度差异版**中：
* 速度慢的人（$V_i$ 极小）走得慢，他能达到的范围很小。
* 速度快的人（$V_i$ 极大）走得快，他能达到的范围很大。
* 最优的汇聚点不再是几何中心。它会**偏向速度慢的人**，因为速度快的人可以多跑一些路来迁就速度慢的人。

由于每个人的 $V_i$ 不同，每个人的可达范围区间 $[R_i - V_i \cdot T, R_i + V_i \cdot T]$ 的大小在随着 $T$ 的增加以**不同的速度扩张**。我们无法用一个简单的数学公式在 $O(1)$ 时间内算出最优的 $T$。

但是，**“可行性”关于时间 $T$ 具有单调性**：
* 如果在 $T$ 秒内大家能聚齐，那么在 $T+1$ 秒内也一定能聚齐。
* 如果在 $T$ 秒内大家无法聚齐，那么在 $T-1$ 秒内更无法聚齐。

这种单调性完美契合了**二分答案**。

### 二分答案解法代码 (Python)

针对此扩展题，利用二分答案的完整 AC 代码实现如下：

```python
import sys

def main():
    # 快速读入
    input = sys.stdin.read
    data = input().split()
    if not data:
        return
    
    n = int(data[0])
    people = []
    
    # 读入每个人的位置 R, C 以及速度 V
    for i in range(n):
        r = int(data[1 + 3 * i])
        c = int(data[2 + 3 * i])
        v = int(data[3 + 3 * i])
        people.append((r, c, v))
        
    # 判定函数：在限定时间 limit_time 内，全员是否能聚集在某一点
    def check(limit_time):
        max_left = float('-inf')
        min_right = float('inf')
        max_bottom = float('-inf')
        min_top = float('inf')
        
        for r, c, v in people:
            # 速度为 v 的人在 limit_time 时间内能走的最大距离是 v * limit_time
            max_dist = v * limit_time
            
            # 动态更新 X 轴和 Y 轴的交集区间
            max_left = max(max_left, r - max_dist)
            min_right = min(min_right, r + max_dist)
            max_bottom = max(max_bottom, c - max_dist)
            min_top = min(min_top, c + max_dist)
            
            # 如果任何一个轴的交集区间变空（左边界 > 右边界），说明无法汇聚
            if max_left > min_right or max_bottom > min_top:
                return False
                
        return True

    # 开始二分查找时间 T
    low = 0
    # 因为坐标最大 10^9，最慢速度为 1，所以最坏情况 10^9 秒也足够全员相遇
    high = 10**9  
    ans = high
    
    while low <= high:
        mid = (low + high) // 2
        if check(mid):
            ans = mid       # 当前时间可行，记录并尝试更短的时间
            high = mid - 1
        else:
            low = mid + 1   # 当前时间不可行，需要更长的时间
            
    print(ans)

if __name__ == '__main__':
    main()
```
