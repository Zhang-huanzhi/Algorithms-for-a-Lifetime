### 题目名称：Sum of All-Pairs XOR Sums

#### 题目描述
给定一个长度为 $N$ 的整数序列 $A = (A_1, A_2, \dots, A_N)$。
请你计算所有满足 $1 \le i < j \le N$ 的整数对 $(i, j)$ 的异或和之和。
即：$\sum_{i=1}^{N-1} \sum_{j=i+1}^{N} (A_i \oplus A_j)$。
由于答案可能很大，请对 $10^9 + 7$ 取模。

#### 约束条件
- $2 \le N \le 3 \times 10^5$
- $0 \le A_i \le 10^9$
- 所有输入均为整数

#### 样例输入
```
3
1 2 3
```

#### 样例输出
```
6
```
**样例说明**：
- $A_1 \oplus A_2 = 1 \oplus 2 = 3$
- $A_1 \oplus A_3 = 1 \oplus 3 = 2$
- $A_2 \oplus A_3 = 2 \oplus 3 = 1$
总和 = $3 + 2 + 1 = 6$。

---

### 解题提示
1.  **不能暴力**：$O(N^2)$ 会超时。
2.  **按位拆分**：考虑每一个二进制位（第 0 到 60 位）。
3.  **计算贡献**：对于第 $k$ 位，如果数组中有 $c$ 个数字在该位是 `1`，那么有多少个对子 $(i, j)$ 在这一位异或结果是 `1`？（提示：一个选 `1`，一个选 `0`）。
4.  **求和**：每一位的贡献为：`(该位为1的对子数) * (2^k)`。
