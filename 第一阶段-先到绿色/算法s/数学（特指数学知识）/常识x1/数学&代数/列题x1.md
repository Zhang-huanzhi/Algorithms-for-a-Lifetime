# C - XOR Index Pair

## 题目描述

高桥君（Takahashi）得到了一个长度为 N 的整数序列 A = (A₁, A₂, …, Aₙ)。

请你找出满足以下条件的整数对 (i, j) 的数量：
- 1 ≤ i < j ≤ N
- Aᵢ ⊕ Aⱼ = i ⊕ j

其中，⊕ 表示按位异或运算（bitwise XOR）。

## 约束条件

- 2 ≤ N ≤ 3 × 10⁵
- 0 ≤ Aᵢ ≤ 10⁹
- 所有输入均为整数

## 输入格式

```
N
A₁ A₂ ... Aₙ
```

## 输出格式

输出满足条件的整数对的数量。

## 样例

### 样例输入 1
```
5
1 2 3 4 5
```

### 样例输出 1
```
2
```

### 样例输入 2
```
4
0 0 0 0
```

### 样例输出 2
```
6
```

### 样例输入 3
```
6
5 3 6 2 7 1
```

### 样例输出 3
```
1
```
