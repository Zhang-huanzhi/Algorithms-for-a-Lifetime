### 题目名称：Sum of All Subarray Sums

#### 题目描述
给定一个长度为 $N$ 的整数序列 $A = (A_1, A_2, \dots, A_N)$。
请你计算所有连续子数组的元素之和的总和。
由于答案可能很大，请对 $10^9 + 7$ 取模。

**定义**：
子数组 $A[i..j]$ ($1 \le i \le j \le N$) 的和为 $\sum_{k=i}^{j} A_k$。
你需要计算：$\sum_{i=1}^{N} \sum_{j=i}^{N} (\sum_{k=i}^{j} A_k)$。

#### 约束条件
- $1 \le N \le 2 \times 10^5$
- $0 \le A_i \le 10^9$
- 所有输入均为整数

#### 输入格式
```
N
A_1 A_2 ... A_N
```

#### 输出格式
输出所有子数组和的总和，对 $10^9 + 7$ 取模。

---

### 样例输入 1
```
3
1 2 3
```

### 样例输出 1
```
20
```
**样例 1 说明**：
子数组有：
- `[1]` (和为 1)
- `[2]` (和为 2)
- `[3]` (和为 3)
- `[1, 2]` (和为 3)
- `[2, 3]` (和为 5)
- `[1, 2, 3]` (和为 6)
总和 = $1+2+3+3+5+6 = 20$。
