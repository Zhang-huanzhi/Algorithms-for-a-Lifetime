在算法竞赛中，数学和代数的考查通常不是为了考公式，而是为了**降低复杂度**

一般会给一个公式，你需要转化，目标是一侧只包含一个Ai，这样就可以只遍历一遍了。

**变量去耦合**

有一些是偏底层的，比如说底层异或，可以让你将一个很匪夷所思的东西优化。

---
### 1. 移项与关系转化（等式/不等式变形）
这是最常见的考法，目的是为了将 $O(N^2)$ 的配对问题转化为 $O(N)$ 的计数问题。
*   **套路**：将涉及两个下标 $i, j$ 的等式，通过代数移项，使等号左边只含 $i$，右边只含 $j$。
*   **例子**：
    *   $A_i - A_j = i - j \implies A_i - i = A_j - j$
    *   $A_i + A_j = K \implies A_i = K - A_j$
    *   $A_i \cdot A_j = K \implies A_i = K / A_j$（需考虑整除）

### 2. 数论与余数（同余定理）
考查你对数字除法性质的理解。
*   **套路**：$(A_i - A_j) \pmod K = 0 \implies A_i \equiv A_j \pmod K$。
*   **应用**：统计子数组和能被 $K$ 整除的个数（前缀和 + 同余）。

### 3. 贡献法（代数求和）
从侧面观察每个元素对最终结果的贡献，而不是直接暴力计算。
*   **套路**：$\sum_{i=1}^N \sum_{j=i+1}^N f(i, j) \implies \sum_{i=1}^N (A_i \times \text{出现次数})$。
*   **例子**：计算所有子数组的最小值之和（单调栈 + 贡献法）。

### 4. 进制与位运算
利用二进制的特性。
*   **套路**：异或是不进位加法。按位拆分（Contribution bit-by-bit），将整体运算拆解为 32 个独立的位运算。

针对你提供的文件，这里是用“移项/代数转化”思维实现的该题代码：

````python
// filepath: demo-x1.py
# ...existing code...
def main():
    # 读取 N
    line1 = sys.stdin.readline()
    if not line1: return
    n = int(line1.strip())
    
    # 读取序列 A
    line2 = sys.stdin.readline()
    if not line2: return
    a = list(map(int, line2.split()))
    
    # 核心转换：A[i] ^ A[j] = i ^ j  => A[i] ^ i = A[j] ^ j
    # 我们为每个位置计算特征值 val ^ index (从1开始)
    counts = Counter()
    for i, val in enumerate(a):
        feature = val ^ (i + 1)
        counts[feature] += 1
    
    # 计算具有相同特征值的元素对数 C(k, 2)
    ans = 0
    for k in counts.values():
        ans += k * (k - 1) // 2
        
    print(ans)

if __name__ == "__main__":
    main()
````

### 为什么要学这些？
1.  **突破性能瓶颈**：数学转化是 O(N²) 到 O(N) 的关键。
2.  **减少空间开销**：通过代数简化，可以避免存储复杂的中间状态。
3.  **精确性**：利用余数或位运算性质，可以避免浮点数精度带来的错误。
