### 1. 第一档：真·暴力（O(N²)）

**代码示例：**
```python
# 找 N 以内的质数
for i in range(2, n + 1):
    for j in range(2, i):  # 从 2 检查到 i-1
        if i % j == 0:
            break
```

**复杂度分析：**
- 外层循环：跑 N 次
- 内层循环：平均跑 N/2 次
- 总复杂度：$N \times (N/2)$，也就是 $O(N^2)$

**评价：** 这是完全不懂数学的"纯体力活"

---

### 2. 第二档：带数学优化的朴素解法（O(N√N)）

**核心数学发现：** 如果一个数 $i$ 不是质数，它必然有一个因子小于或等于 $\sqrt{i}$

**例子：** 判断 100 是不是质数
- 它的因子对有：(2, 50), (4, 25), (5, 20), (10, 10)
- 发现：在 10（$\sqrt{100}$）之后出现的因子（如 20, 25, 50），其实在前面已经和较小的因子匹配过了

**结论：** 你只需要检查到 $\sqrt{i}$ 就可以了

**代码示例：**
```python
for i in range(2, n + 1):
    # 内层循环只跑到 根号i
    for j in range(2, int(i**0.5) + 1):
        if i % j == 0:
            break
```

**复杂度分析：**
- 外层循环：跑 N 次
- 内层循环：跑 $\sqrt{i}$ 次
- 总复杂度：$\sum \sqrt{i} \approx \int \sqrt{x} \, dx = O(N\sqrt{N})$

**评价：** 这是"懂点数学"的体力活

---

### 3. 第三档：埃氏筛法（O(N log log N)）

埃氏筛法完全抛弃了"判断每一个数是不是质数"的思路，改成了**"批量抹除"**。它的效率高到接近 $O(N)$（线性时间）。

---

## 数值对比：差距有多大？

假设我们要处理 **N = 1,000,000**（100万）：

| 算法 | 复杂度 | 计算量 | 运行时间 |
|------|--------|--------|----------|
| **真·暴力** | $O(N^2)$ | $1,000,000 \times 1,000,000 = 1,000,000,000,000$ (1万亿次) | 电脑跑废了也出不来 |
| **优化朴素** | $O(N\sqrt{N})$ | $1,000,000 \times 1,000 = 1,000,000,000$ (10亿次) | 大约 10~30 秒，算法题会 TLE（超时）|
| **埃氏筛法** | $O(N \log \log N)$ | 大约 $4,000,000$ (400万次) | 不到 0.1 秒，瞬间完成 |
