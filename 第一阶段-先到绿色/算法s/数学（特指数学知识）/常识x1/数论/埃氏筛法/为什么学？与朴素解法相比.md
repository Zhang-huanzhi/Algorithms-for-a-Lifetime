
| 场景             | 朴素解法           | 埃氏筛法               |
| -------------- | -------------- | ------------------ |
| **找 1-100 质数** | 检查约 500 次      | 标记约 70 次           |
| **找 1-10⁶ 质数** | 检查约 500 万次     | 标记约 200 万次         |
| **时间复杂度**      | $O(n\sqrt{n})$ | $O(n \log \log n)$ |

| 特性 | 朴素解法 (Trial Division) | 埃氏筛法 (Eratosthenes) |
|------|--------------------------|------------------------|
| **核心逻辑** | 判断每一个数是不是质数 | 排除所有不是质数的数 |
| **复杂度** | $O(N\sqrt{N})$ | $O(N \log \log N)$ (接近线性) |
| **优势场景** | 只需要判断一个很大的数是不是质数 | 需要知道一个范围内所有的质数 |
| **缺点** | 范围查询时慢得无法忍受 | 需要额外的内存空间来存标记数组 |
