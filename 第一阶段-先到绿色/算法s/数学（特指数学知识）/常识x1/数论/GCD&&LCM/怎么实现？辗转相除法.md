**两个数的公约数，也必然是它们差的公约数**

这就是为什么 $\gcd(a, b) = \gcd(b, a - b)$ 成立，而取模本质上就是连续减法的优化版本。


---
``` python
def gcd(a, b):
    while b != 0:       
        a, b = b, a % b 
    return a            
```

``` python
def gcd_naive(a: int, b: int) -> int:
    """
    朴素解法：暴力枚举 (Brute Force)
    效率：较低，当数字巨大时会非常慢
    """
    # 从 a 和 b 中较小的那个数开始往下找
    limit = min(a, b)
    
    for i in range(limit, 0, -1):
        if a % i == 0 and b % i == 0:
            return i
            
    return 1 # 理论上最小也是 1
```

``` python
def gcd_recursive(a: int, b: int) -> int:
    """
    辗转相除法：递归实现
    逻辑：gcd(a, b) = gcd(b, a % b)
    """
    # 递归终止条件：当余数为 0 时，b 就是最大公约数
    if b == 0:
        return a
    return gcd_recursive(b, a % b)
```
