## AtCoder 风格算法题：糖果分配

### 题目描述

有 $N$ 个小朋友排成一排，你有 $K$ 颗糖果要分给他们。

每个小朋友**至少得到 1 颗**糖果，且所有糖果必须分完。

问：有多少种不同的分配方案？

答案对 $10^9 + 7$ 取模。

---

### 输入格式

```
N K
```

- $1 \leq N \leq 10^6$
- $N \leq K \leq 10^6$

---

### 输出格式

输出方案数模 $10^9 + 7$ 的结果。

---

### 样例输入输出

**样例 1：**
```
输入：
3 5

输出：
6
```

**解释：**  
3 个小朋友分 5 颗糖，每人至少 1 颗：
- (1, 1, 3)
- (1, 2, 2)
- (1, 3, 1)
- (2, 1, 2)
- (2, 2, 1)
- (3, 1, 1)

共 6 种方案。

---

**样例 2：**
```
输入：
4 10

输出：
84
```

---

**样例 3：**
```
输入：
100000 100000

输出：
1
```

**解释：** 每人恰好 1 颗，只有 1 种方案。

---

**样例 4：**
```
输入：
10 100000

输出：
546898535
```

### 参考解法

<details>
<summary>点击查看提示</summary>

**数学建模：**
- 先给每人 1 颗，剩余 $K - N$ 颗
- 问题转化为：把 $K - N$ 颗糖分给 $N$ 个人（可以为 0）
- 这是**插板法**：$C(K-1, N-1)$

**关键：** 计算组合数需要用**逆元**代替除法！

</details>

<details>
<summary>点击查看完整代码</summary>

```python
MOD = 10**9 + 7

def solve(n, k):
    # 组合数 C(k-1, n-1) = (k-1)! / ((n-1)! * (k-n)!)
    
    # 计算分子: (k-1) * (k-2) * ... * (k-n+1)
    numerator = 1
    for i in range(k - 1, k - n, -1):
        numerator = (numerator * i) % MOD
    
    # 计算分母: (n-1)!
    denominator = 1
    for i in range(1, n):
        denominator = (denominator * i) % MOD
    
    # 用逆元代替除法
    inv = pow(denominator, MOD - 2, MOD)
    return (numerator * inv) % MOD

# 读取输入
n, k = map(int, input().split())
print(solve(n, k))
```

**时间复杂度：** $O(N + \log MOD)$

</details>

### 知识点

- ✅ 组合数学（插板法）
- ✅ 逆元（费马小定理）
- ✅ 大数取模

**核心：** 不能直接算 `factorial(k-1) // (factorial(n-1) * factorial(k-n))`，必须用逆元！
