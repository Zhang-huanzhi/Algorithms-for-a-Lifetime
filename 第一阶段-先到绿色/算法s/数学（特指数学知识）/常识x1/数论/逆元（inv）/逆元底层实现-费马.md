逆元主要通过**费马小定理**和**快速幂算法**来实现。

**原因：** 算法题中最常见的模数（如 $10^9 + 7$）都是**质数**。

$$\text{inv}(a) = a^{\text{MOD}-2} \pmod{\text{MOD}}$$


 模运算世界
$$10 \div 2 \pmod{7} = 10 \times (2\text{的逆元}) \pmod{7}$$

具体计算：
- 2 的逆元（模 7）= 4（因为 $2 \times 4 = 8 \equiv 1 \pmod{7}$）
- $10 \div 2 \pmod{7} = 10 \times 4 \pmod{7} = 40 \pmod{7} = 5$

**代码：**
```python
MOD = 10**9 + 7

def mod_inv(a, mod=MOD):
    """计算 a 的逆元"""
    return pow(a, mod - 2, mod)

# 使用示例
inv_3 = mod_inv(3)
print(inv_3)  # 3 的逆元

# 验证
print((3 * inv_3) % MOD)  # 输出：1
```
