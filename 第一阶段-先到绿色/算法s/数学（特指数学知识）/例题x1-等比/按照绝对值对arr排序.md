在 Python 中，按照绝对值对数组 `arr` 进行排序极其简单，主要有两种写法：

### 1. 写法一：直接修改原数组（推荐，省内存）
```python
arr.sort(key=abs)
```

### 2. 写法二：不修改原数组，生成一个新数组
```python
sorted_arr = sorted(arr, key=abs)
```

---

### 原理解释：
* **`key=abs`**：`key` 参数指定了一个函数（这里是内置的绝对值函数 `abs`）。
* Python 在排序时，会先计算每个元素的绝对值（作为排序的“权重”），然后根据绝对值从小到大排序，但**最终移动并保留在数组里的，依然是带有原正负号的数字**。

**例子：**
* 排序前：`[-3, 1, -2, 5]`
* 排序后：`[1, -2, -3, 5]` （对应的绝对值顺序是 `1 < 2 < 3 < 5`）
