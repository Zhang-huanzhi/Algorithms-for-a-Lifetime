在算法竞赛中，平面几何（Computational Geometry）一向被认为是最容易因“细节”而翻车的板块。很多时候，思路是正确的，却因为精度、边界或公式写错而导致无数次 WA。

为了高效、准确地解决平面几何算法题，建议牢记以下**六大核心准则**：

---

### 准则一：能用整数，绝不用浮点数（避免精度灾难）

浮点数（`float`/`double`）在计算机中是用二进制近似表示的，这会带来微小的截断误差。多次运算累加后，误差会变大，导致 `==` 判断失效。

* **距离比较**：不要比 $d$，而是比较 $d^2$。
  * *Bad*: `if math.sqrt(dx**2 + dy**2) == r:`
  * *Good*: `if dx**2 + dy**2 == r**2:`
* **表示直线**：避免使用斜截式 $y = kx + b$，改用一般式 $Ax + By = C$。这样 $A, B, C$ 都可以保持为整数。
* **判定平行/垂直**：不要计算斜率 $k_1$ 和 $k_2$。
  * 平行判定：用叉积 $dx_1 \cdot dy_2 == dx_2 \cdot dy_1$。
  * 垂直判定：用点积 $dx_1 \cdot dx_2 + dy_1 \cdot dy_2 == 0$。

---

### 准则二：严防“退化情况”（Degenerate Cases）

几何题的测试数据里，出题人一定会放大量的“恶心”边界数据。写完算法后，必须代入以下场景检查是否会崩：

* **三点共线**：计算三角形、多边形或外接圆时，三个点是否可能在同一条直线上？
* **重合点**：输入给出的不同点，其坐标是否可能完全相同？
* **垂直与水平线**：斜率是否存在？（若使用除法，分母是否可能为 0？）
* **线段长度为 0**：线段的两个端点重合，导致方向向量变成 $(0, 0)$。

在设计逻辑时，**优先使用无需分类讨论的向量公式（如叉积）**，它们通常能天然兼容上述各种退化情况。

---

### 准则三：浮点数比较必须使用 `eps`（容差）

如果题目避不开除法、开方或三角函数，必须使用浮点数，那么**绝对不能直接用 `<`、`>` 比较大小**。

必须定义一个极小的常数 `eps`（通常设为 $10^{-9}$ 或 $10^{-12}$）：

```python
eps = 1e-9

def sgn(x):
    """判断 x 的正负符号"""
    if abs(x) < eps:
        return 0  # 视为 0
    return 1 if x > 0 else -1

# 比较 a 和 b 是否相等
# 不要写 a == b，写：
if abs(a - b) < eps:
    pass

# 比较 a 是否大于 b
# 不要写 a > b，写：
if a - b > eps:
    pass
```

---

### 准则四：以“向量”和“CCW”作为基本构件

不要针对每个问题都现推公式。应该将所有的几何操作拆解为以“向量”和 **CCW（判定点在线段哪一侧）** 为核心的原子操作。

只要掌握了 `ccw(A, B, C)`（即向量 $\vec{AB}$ 和 $\vec{AC}$ 的叉积）：
* 判断线段是否相交？只需判断 $C, D$ 是否在 $AB$ 两侧，且 $A, B$ 是否在 $CD$ 两侧（利用 `ccw` 变号）。
* 寻找凸包（Convex Hull）？利用 `ccw` 判定旋转方向是否一直向左。
* 点是否在线段上？利用 `ccw == 0`（共线）且点在端点坐标区间内。

把复杂的几何题拆解为这几个稳定、无 bug 的基础函数，能极大降低出错率。

---

### 准则五：保持变量定义与顺序的高度一致性

这也是你上一道题踩坑的地方。
在写公式时，**一定要在纸上先写明基准顺序**。例如：
* 所有的向量差，统一规定为“后减前”：$\vec{AB} = B - A$。
* 所有的常数项，统一规定为“后减前”：$c = B^2 - A^2$。

在代码实现时，哪怕只是复制粘贴代码，也要仔细核对变量名（如 $x_1, y_1, x_2, y_2$）是否和公式里推导的顺序完全一致。

---

### 准则六：画图辅助与极值思考

在草稿纸上画图时，不要只画最完美的、规整的图形（比如正三角形、正方形）。

* **画极端图形**：试着画极扁的三角形、几乎平行的线段、极度接近的圆。
* **手动模拟**：用手指向代表向量，模拟叉积的旋转，确认正负号（逆时针为正，顺时针为负）是否与你的代码逻辑一致。
