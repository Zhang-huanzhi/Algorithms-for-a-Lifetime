### 1. 圆的表示方法

在算法中，表示一个圆通常有两种数据结构选择：

1. **圆心 + 半径（最常用）**：
   在平面直角坐标系中，圆心为 $O(x_0, y_0)$，半径为 $r$ 的圆方程为：
   $$(x - x_0)^2 + (y - y_0)^2 = r^2$$
   在算法中，我们通常保存 $(x_0, y_0)$ 和 $r$。如果输入都是整数，为了避免浮点数，我们可以直接保存 **$r^2$（半径的平方）**。

2. **一般式**：
   $$x^2 + y^2 + Dx + Ey + F = 0$$
   这种表示法在处理“圆与圆相减（求公共弦/根轴）”时非常方便。

---

### 2. 点与圆的位置关系

给定一个点 $P(x, y)$ 和圆 $C$（圆心为 $O(x_0, y_0)$，半径为 $r$）：

* **点在圆外**：$|OP| > r \iff (x - x_0)^2 + (y - y_0)^2 > r^2$
* **点在圆上**：$|OP| = r \iff (x - x_0)^2 + (y - y_0)^2 = r^2$
* **点在圆内**：$|OP| < r \iff (x - x_0)^2 + (y - y_0)^2 < r^2$

**竞赛技巧**：完全不需要对距离开平方。直接计算 $\Delta x^2 + \Delta y^2$ 并与 $r^2$ 进行整数比较，即可做到 100% 精确。

---

### 3. 直线与圆的位置关系

给定一条直线 $Ax + By + C = 0$ 和圆 $(x - x_0)^2 + (y - y_0)^2 = r^2$。圆心到直线的距离公式为：
$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

* **相离**（0个交点）：$d > r$
* **相切**（1个交点）：$d = r$
* **相交**（2个交点）：$d < r$

#### 避免浮点数的判定技巧
为了避免计算 $\sqrt{A^2 + B^2}$，我们可以将 $d > r$ 两边平方：
$$\frac{(Ax_0 + By_0 + C)^2}{A^2 + B^2} > r^2 \iff (Ax_0 + By_0 + C)^2 > r^2(A^2 + B^2)$$

通过这个不等式，你可以**只使用整数乘法**就判定出直线与圆的相交关系。

---

### 4. 圆与圆的位置关系

设两个圆的圆心分别为 $O_1, O_2$，半径分别为 $r_1, r_2$。令圆心距 $d = |O_1O_2|$。

两圆的五种位置关系及判定条件（同样可以用平方避开开方）：

1. **外离**（4条公切线）：$d > r_1 + r_2 \iff d^2 > (r_1 + r_2)^2$
2. **外切**（3条公切线）：$d = r_1 + r_2 \iff d^2 = (r_1 + r_2)^2$
3. **相交**（2条公切线）：$|r_1 - r_2| < d < r_1 + r_2 \iff (r_1 - r_2)^2 < d^2 < (r_1 + r_2)^2$
4. **内切**（1条公切线）：$d = |r_1 - r_2| \iff d^2 = (r_1 - r_2)^2$（且 $d \neq 0$）
5. **内含**（无公切线）：$d < |r_1 - r_2| \iff d^2 < (r_1 - r_2)^2$

### 5. 根轴与公共弦（Radical Axis）

这是解决“两圆相交”相关问题时极强大的工具。

假设有两个圆的方程：
$$C_1: x^2 + y^2 + D_1x + E_1y + F_1 = 0$$
$$C_2: x^2 + y^2 + D_2x + E_2y + F_2 = 0$$

我们将两式相减（即消去二次项 $x^2 + y^2$），会得到一个一次方程：
$$(D_1 - D_2)x + (E_1 - E_2)y + (F_1 - F_2) = 0$$

这在几何上代表一条直线，被称为这两个圆的**根轴**。

#### 根轴的惊人性质：
* **如果两圆相交**：根轴就是**穿过两个交点的直线（公共弦所在直线）**。
* **如果两圆相切**：根轴就是两圆的**公切线**。

#### 算法妙用：求两圆交点
求两个二次方程 $C_1 = 0$ 和 $C_2 = 0$ 的交点在代数上很麻烦。但通过相减，我们可以先算出根轴的线性方程 $L$。
接着，将问题转化为**求直线 $L$ 与圆 $C_1$ 的交点**（联立一次方程和二次方程），计算难度会大幅降低。

### 6. 三点定圆（外接圆）

任意三个不在同一直线上的点 $A, B, C$ 能够唯一确定一个圆。

#### 算法求法：
* 联立线段 $AB$ 的中垂线和 $BC$ 的中垂线。
* 这两条中垂线的交点即为圆心 $O$。
* 圆心到任意一点的距离即为半径 $r$。

#### Python 示例（求解三点外接圆圆心）：
虽然可以通过复杂的几何公式一步求出，但最稳妥、最不易出错的方法依然是**联立两组一次方程**：

```python
def get_circumcenter(A, B, C):
    # A, B, C 为 (x, y) 格式的元组
    # 线段 AB 的中点和方向向量
    mid_AB = ((A[0] + B[0]) / 2, (A[1] + B[1]) / 2)
    d_AB = (A[0] - B[0], A[1] - B[1])  # 垂直于中垂线的向量
    
    # 线段 BC 的中点和方向向量
    mid_BC = ((B[0] + C[0]) / 2, (B[1] + C[1]) / 2)
    d_BC = (B[0] - C[0], B[1] - C[1])
    
    # 中垂线 1: d_AB[0]*x + d_AB[1]*y = c1
    c1 = d_AB[0] * mid_AB[0] + d_AB[1] * mid_AB[1]
    # 中垂线 2: d_BC[0]*x + d_BC[1]*y = c2
    c2 = d_BC[0] * mid_BC[0] + d_BC[1] * mid_BC[1]
    
    # 联立求解二元一次方程组 (克莱姆法则)
    D = d_AB[0] * d_BC[1] - d_AB[1] * d_BC[0]
    if abs(D) < 1e-9:
        return None  # 三点共线，无法构成圆
        
    ox = (c1 * d_BC[1] - c2 * d_AB[1]) / D
    oy = (d_AB[0] * c2 - d_BC[0] * c1) / D
    return (ox, oy)
```

### 7. 经典算法：最小覆盖圆（Minimum Enclosing Circle）

**问题描述**：给定平面上的 $N$ 个点，求一个半径最小的圆，使得所有 $N$ 个点都在这个圆的内部或圆周上。

这是一个非常经典的几何问题，存在一个被称为 **Welzl 算法** 的随机化算法，其期望时间复杂度为惊人的 **$O(N)$**。

#### 算法思想（增量法）：
1. 首先将所有点随机打乱（Random Shuffle）。
2. 令初始圆 $C$ 为前两个点确定的圆（以它们为直径）。
3. 遍历后续的每个点 $P_i$：
   * 如果 $P_i$ 已经在当前的圆 $C$ 内，则什么都不做。
   * 如果 $P_i$ 在圆 $C$ 外，说明新加入的 $P_i$ 必然在新的最小覆盖圆的**边界（圆周）上**。
   * 此时，我们需要以 $P_i$ 为基准，重新在 $P_1 \dots P_{i-1}$ 中寻找另外 1 个或 2 个边界点来确定新圆。

这个算法通过递归实现，虽然听起来要重复计算，但数学上可以证明，因为点被随机打乱了，触发“点在圆外并重新画圆”的概率极低，平均每个点只需要常数次操作。
