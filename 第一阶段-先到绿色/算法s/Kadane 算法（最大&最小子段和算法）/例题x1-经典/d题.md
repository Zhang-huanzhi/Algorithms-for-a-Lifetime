### D - Flip to Gather
**执行时间限制:** 2 sec / **内存限制:** 1024 MiB

**配点:** 400 点

#### 问题描述
给定一个长度为 $N$ 的仅由 0 和 1 组成的字符串 $S$。

你可以执行以下操作任意次数（包括 0 次）：
* 选择一个满足 $1 \le i \le N$ 的整数 $i$，当 $S_i$ 为 0 时将其修改为 1，为 1 时修改为 0。

你的目标是使 $S$ 中包含的 1 至多构成一个连续的区间。请计算达成目标所需的最小操作次数。

更严格地说，目标是使 $S$ 变成满足以下条件的字符串：存在一对整数 $(l, r)$ 同时满足以下两个条件。请计算达成目标所需的最小操作次数。
* $1 \le l \le r \le N+1$
* 对于所有满足 $1 \le i \le N$ 的整数 $i$，$S_i = 1$ 与 $l \le i < r$ 等价。

可以证明，一定能在有限次操作内达成目标。

输入将给出 $T$ 个测试用例，请分别计算每个用例的答案。

#### 约束条件
* $1 \le T \le 20000$
* $1 \le N \le 2 \times 10^5$
* $S$ 是仅由 0 和 1 组成的长度为 $N$ 的字符串
* 在每个输入文件中，所有测试用例的 $N$ 的总和不超过 $2 \times 10^5$
* $T, N$ 均为整数

#### 输入格式
输入通过标准输入按以下格式给出：
```text
T
case_1
case_2
⋮
case_T
```
$case_i$ 表示第 $i$ 个测试用例，其格式如下：
```text
N
S
```

#### 输出格式
共输出 $T$ 行。
第 $i$ 行（$1 \le i \le T$）输出第 $i$ 个测试用例的答案。

---

#### 输入样例 1
```text
3
5
10011
10
1111111111
7
0000000
```

#### 输出样例 1
```text
1
0
0
```
**样例 1 解释：**
* 在第 1 个测试用例中，如果将 $S_1$ 修改为 0（变为 `00011`），则所有的 1 构成了一个连续的区间。如果不进行任何修改，原字符串是不满足条件的。因此，最小操作次数为 1。
* 在第 2 个测试用例中，$S$ 中连 1 个 0 都没有，天然符合条件，无需进行任何操作。因此答案为 0。
* 在第 3 个测试用例中，$S$ 中连 1 个 1 都没有，同样符合条件（至多 1 个区间，此时为 0 个），无需操作。因此答案为 0。
