### 第一步：明确我们的目标和代价
假设我们最终找到了一个最优的区间，起点是 $L$，终点是 $R$。
我们的目标是：让区间 $[L, R]$ 里面全是 `1`，区间外面全是 `0`。

那么我们总共需要操作（翻转）多少次呢？
总翻转次数包含两部分：
1. **区间外的 `1`**：它们不该出现，必须全部翻转成 `0`。
2. **区间内的 `0`**：它们破坏了连续的 `1`，必须全部翻转成 `1`。

所以，得到核心公式 1：
> **总操作次数 = (区间外的 `1` 的数量) + (区间内的 `0` 的数量)**

### 第二步：神奇的数学替换
“区间外的 `1` 的数量” 每次选择不同的区间都会变，不好直接计算。
但是，我们知道一个永恒的真理：
> **区间外的 `1` = 总共的 `1` - 区间内的 `1`**

把这个真理代入到核心公式 1 中：
总操作次数 = **(总共的 `1` - 区间内的 `1`)** + 区间内的 `0` 的数量

稍微把括号换个位置，得到核心公式 2：
> **总操作次数 = 总共的 `1` + (区间内的 `0` 的数量 - 区间内的 `1` 的数量)**

### 第三步：转化问题
仔细看核心公式 2：**“总共的 `1`”** 对于给定的字符串来说，是一个**固定不变的常数**！

既然“总共的 1”是固定的，那我们想要让“总操作次数”最小，就等价于：
**我们要找到一个区间 $[L, R]$，使得 (区间内的 `0` 的数量 - 区间内的 `1` 的数量) 尽可能地小（越负越好）！**

怎么求这个式子的最小值呢？我们可以给字符赋“权重”：
* 如果遇到 `0`，权重记为 **+1** （因为它会增加总操作次数）
* 如果遇到 `1`，权重记为 **-1** （因为它能抵消操作次数，让总数变小）

这样一来，任何一个区间 $[L, R]$ 内的 `0` 的数量减去 `1` 的数量，就**恰好等于这个区间内权重的求和！**

问题完美转化：
**将字符串中的 `0` 变成 `+1`，`1` 变成 `-1`。求这个新数组的“最小连续子数组和”。**
只要找出这个最小和，最后加上“总共的 `1`”，就是答案！

### 第四步：拿例子验证一下

我们用输入例 1 的字符串：`1 0 0 1 1` 来走一遍。

**1. 基础数据：**
* 字符串：`1 0 0 1 1`
* 总共的 `1` 的数量 = **3**
* 转化为权重数组：`[-1, +1, +1, -1, -1]`

**2. 寻找最小连续子数组和：**
我们来看看不同的区间选择对应的结果：
* 如果选整个数组 `[-1, +1, +1, -1, -1]`，和是：`-1`
  * 操作次数 = 3 + (-1) = 2。（实际意义：把两个 0 翻转成 1。变为 `11111`，代价是 2）
* 如果选前三个 `[-1, +1, +1]`，和是：`+1`
  * 操作次数 = 3 + 1 = 4。（实际意义：把 100 变成 111，后面的 11 变成 00，代价是 4）
* **如果选最后两个 `[-1, -1]`，和是：`-2`** （这是整个数组里能找到的最小的连续和）
  * 操作次数 = 3 + (-2) = **1**。（实际意义：让最后两个 `1` 保持为区间，把开头的第一个 `1` 翻转成 `0`。变为 `00011`，代价是 1）。

完美吻合！答案就是 1。

### 第五步：关于求“最小连续子段和”的代码逻辑 (Kadane 算法)

在线性时间 $O(N)$ 内求最小子段和，我们用一个变量 `current_sum` 边走边累加。
逻辑是：**“如果前面的累加和变成了正数，那是累赘，直接丢弃，重新从 0 开始算。”**

```python
total_ones = s.count('1') # 统计总共的 1

min_sum = 0     # 记录历史出现的最小和（最多是0，代表我们选个"空区间"，全变0）
current_sum = 0 # 记录当前累加的和

for char in s:
    val = 1 if char == '0' else -1
    current_sum += val
    
    # 【核心贪心逻辑】
    # 我们想要的是越负越好的和。
    # 如果 current_sum > 0，说明这段区间里的 0 比 1 多。
    # 带着这个正数往后加，只会把后面的结果“拖后腿”（变大）。
    # 所以不如直接把 current_sum 清零，从下一个字符重新开始作为一个新区间的起点。
    if current_sum > 0:
        current_sum = 0 
        
    # 时刻更新我们遇到过的最小值
    if current_sum < min_sum:
        min_sum = current_sum

# 最终公式
ans = total_ones + min_sum
```

**为什么 `min_sum` 初始值是 `0` 呢？**
因为题目允许最终没有 `1`（全是 `0`）。全是 `0` 意味着我们选择的 $1$ 的区间长度为 $0$（空区间），空区间的和就是 $0$。如果数组里不管怎么选，和都是正数（比如原串全是 `0`），那 `min_sum` 就保持为 `0`，总代价就是 `total_ones + 0`，也就是把原串里所有的 `1` 都翻转成 `0`。
