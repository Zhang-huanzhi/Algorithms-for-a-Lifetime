### 数学上的对比

* **优化前（暴力）**：
  $$\text{总复杂度} = \sum_{day=1}^{M} (\text{全量扫描 } N \text{ 只鸟}) = M \times N$$

* **优化后（事件驱动 + 增量）**：
  $$\text{总复杂度} = \sum_{day=1}^{M} (\text{天数推进常数消耗 } O(1)) + \sum_{all\_events} (\text{处理单次改变 } O(1))$$
  因为总事件数 $\le N$，所以：
  $$\text{总复杂度} = O(M) + O(N) = O(N + M)$$

### 简言之
优化前，我们是**“每天都看所有人”**（$M \times N$）；
优化后，我们变成了**“每天只看今天变了的人，没人变就不看”**。因为一辈子总共只有 $N$ 个人会变，所以总工作量变成了 **“活了 $M$ 天 + 动了 $N$ 次”**（$N + M$）。
