**D - Long Waiting / 漫长的等待**

**执行时间限制:** 2 sec / **内存限制:** 1024 MiB
**分数:** 400 分

### 问题描述

有一家餐厅，最多可以同时容纳 $K$ 位客人。餐厅门前有一条小路，用于排队等候。

在时刻 $0$，店内没有客人，等候队列为空。

今天预计有 $N$ 组团体客人到来，按照到达的先后顺序，依次被编号为 $1$ 到 $N$。
第 $i$ 组团体客人共有 $C_i$ 人，在时刻 $A_i$ 会加入到等候队列的末尾。此外，这组客人在进店之后，会经过 $B_i$ 个单位时间离开餐厅。

每组客人都将在同时满足以下 $2$ 个条件的最早时刻，离开队列并进入餐厅：
1. 该组客人在队列的最前方。也就是说，该组客人是当前等候队列中最早加入的。
2. 该组客人与店内所有客人（包含恰好在该时刻进店的，不包含恰好在该时刻离开的）的总人数合计不超过 $K$ 人。

请计算每组客人进店的时刻。

### 约束条件

- $1 \le N \le 3 \times 10^5$
- $1 \le K \le 10^7$
- $1 \le A_i, B_i \le 10^7 \ (1 \le i \le N)$
- $A_1 < \dots < A_N$
- $1 \le C_i \le K \ (1 \le i \le N)$
- 输入的所有值均为整数

### 输入

输入通过标准输入给出，格式如下：
> $N$ $K$
> $A_1$ $B_1$ $C_1$
> $\vdots$
> $A_N$ $B_N$ $C_N$

### 输出

输出 $N$ 行。
第 $i$ 行 $(1 \le i \le N)$ 输出一个整数，表示第 $i$ 组团体客人进店的时刻。

各组客人的进店和离店流程如下：
- 时刻 $30$：第 $1$ 组客人加入队列后立刻进店，店内共有 $3$ 名客人。
- 时刻 $60$：第 $2$ 组客人加入队列后立刻进店，店内共有 $7$ 名客人。
- 时刻 $90$：第 $3$ 组客人加入队列。
- 时刻 $105$：第 $2$ 组客人离店，店内剩余 $3$ 名客人。紧接着，第 $3$ 组客人进店，店内共有 $8$ 名客人。
- 时刻 $120$：第 $4$ 组客人加入队列后立刻进店，店内共有 $10$ 名客人。
- 时刻 $150$：第 $3$ 组客人离店，店内剩余 $5$ 名客人。
- 时刻 $165$：第 $4$ 组客人离店，店内剩余 $3$ 名客人。
- 时刻 $330$：第 $1$ 组客人离店，店内变为 $0$ 名客人。

``` python
import heapq  
import sys  
  
  
def main():  
  
    n, k = map(int, sys.stdin.readline().split())  
  
    arr = []  
    curr_seats = 0  
    curr_time = 0  
  
    for i in range(n):  
        a, b, c = map(int, sys.stdin.readline().split())  
  
        # 核心修复点：时间不能倒流！  
        curr_time = max(curr_time, a)  
  
        # 1. 先清理当前时间及以前离开的客人  
        while arr and arr[0][0] <= curr_time:  
            leave_time, count = heapq.heappop(arr)  
            curr_seats -= count  
  
        # 2. 如果座位不够，不断等待下一波人离开  
        while curr_seats + c > k:  
            leave_time, count = heapq.heappop(arr)  
            curr_time = leave_time  # 时间往后推移  
            curr_seats -= count  
  
            # 同一时刻离开的客人一起清理  
            while arr and arr[0][0] <= curr_time:  
                lt, cnt = heapq.heappop(arr)  
                curr_seats -= cnt  
  
        # 3. 进店  
        print(curr_time)  
        curr_seats += c  
        heapq.heappush(arr, (curr_time + b, c))  
  
  
if __name__ == '__main__':  
    main()
```
