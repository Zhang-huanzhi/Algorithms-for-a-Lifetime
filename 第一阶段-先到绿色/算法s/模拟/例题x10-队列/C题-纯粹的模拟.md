### C - 蛋包饭餐厅 (Omelette Restaurant)

时间限制: 2 秒 / 内存限制: 1024 MiB  
分值 : 300 分

#### 题目描述
AtCoder 餐厅自开业起连续营业了 $N$ 天。

在开业后的第 $i$ 天 ($1 \le i \le N$)，餐厅会按顺序进行以下活动：

1. **第 $i$ 天早晨**：进货 $A_i$ 个鸡蛋。
2. **第 $i$ 天中午**：使用 $B_i$ 个鸡蛋。此时，优先使用当前库存中**最早进货的鸡蛋**（先进先出）。
3. **第 $i$ 天晚上**：丢弃所有**进货已满 $D$ 天及以上**的鸡蛋（即在第 $j$ 天进货的鸡蛋，若在第 $j+D$ 天晚上仍有剩余，则会被全部丢弃）。

已知在第 1 天早晨之前餐厅没有鸡蛋库存，且在每天中午鸡蛋的数量都足够使用（不会出现不够用的情况）。

请求出在第 $N$ 天晚上的操作结束后，餐厅里还剩下多少个鸡蛋。

共有 $T$ 组测试用例，请分别求出每组测试用例的答案。

#### 制约条件
- $1 \le T \le 2 \times 10^5$
- $1 \le D \le N \le 2 \times 10^5$
- $1 \le A_i, B_i \le 10^9$
- 在 $N$ 天中的每个中午，鸡蛋数量都不会不足。
- 在单个输入中，所有测试用例的 $N$ 的总和不超过 $2 \times 10^5$。
- 输入数据均为整数。

#### 输入格式
输入通过标准输入按以下格式给出：

> $T$  
> $\text{case}_1$  
> $\text{case}_2$  
> $\vdots$  
> $\text{case}_T$  

每个测试用例 $\text{case}_i$ 的格式如下：

> $N$ $D$  
> $A_1$ $A_2$ $\dots$ $A_N$  
> $B_1$ $B_2$ $\dots$ $B_N$  

#### 输出格式
输出共 $T$ 行。  
第 $i$ 行 ($1 \le i \le T$) 输出第 $i$ 个测试用例的答案。

---

#### 样例 1

**输入**
```text
3
3 1
7 2 3
1 3 2
3 2
7 2 3
1 3 2
2 1
2 1
1 2
```

**输出**
```text
3
5
0
```

**样例解释**

在第 1 个测试用例中，各天的具体情况如下：
- 起初餐厅没有鸡蛋。
- **第 1 天早晨**：进货 7 个鸡蛋（库存：第 1 天进货的 7 个）。
- **第 1 天中午**：使用 1 个鸡蛋（库存：第 1 天进货的 6 个）。
- **第 1 天晚上**：没有需要丢弃的鸡蛋（库存：第 1 天进货的 6 个）。
- **第 2 天早晨**：进货 2 个鸡蛋（库存：第 1 天进货的 6 个，第 2 天进货的 2 个）。
- **第 2 天中午**：使用 3 个鸡蛋，优先使用第 1 天的（库存：第 1 天进货的 3 个，第 2 天进货的 2 个）。
- **第 2 天晚上**：丢弃第 1 天进货的鸡蛋（库存：第 2 天进货的 2 个）。
- **第 3 天早晨**：进货 3 个鸡蛋（库存：第 2 天进货的 2 个，第 3 天进货的 3 个）。
- **第 3 天中午**：使用 2 个鸡蛋，优先使用第 2 天的（库存：第 3 天进货的 3 个）。
- **第 3 天晚上**：没有需要丢弃的鸡蛋（第 2 天进货的鸡蛋已全部被使用）（库存：第 3 天进货的 3 个）。

因此，第 3 天晚上操作结束后剩余 3 个鸡蛋，第 1 行输出 `3`。

注意：在第 2 个测试用例中，$D=2$，第 1 天进货的鸡蛋是在第 3 天晚上被丢弃。输出的是丢弃处理之后的剩余数量。


# Code
``` python
import math  
import sys  
from collections import deque  
  
  
def main():  
  
    t = int(sys.stdin.readline().strip())  
  
    outs = []  
    for _ in range(t):  
        n, d = map(int, sys.stdin.readline().strip().split())  
        arr = list(map(int, sys.stdin.readline().strip().split()))  
        brr = list(map(int, sys.stdin.readline().strip().split()))  
  
        q = deque()  
  
        for i in range(n):  
  
            # 早上  
            q.append([arr[i], i])  
  
            # 中午  
            x = brr[i]  
            while x > 0 and q:  
                if x >= q[0][0]:  
                    x -= q[0][0]  
                    q.popleft()  
                else:  
                    q[0][0] -= x  
                    x = 0  
  
            # 晚上  
            while q and i - q[0][1] >= d:  
                q.popleft()  
  
        ans = 0  
        while q:  
            x = q.pop()  
            ans += x[0]  
  
        outs.append(ans)  
  
    print('\n'.join(map(str, outs)))  
  
if __name__ == "__main__":  
    main()
```
