``` python
import sys  
  
def main():  
  
    t = int(sys.stdin.readline().strip())  
    for _ in range(t):  
        n, h = map(int, sys.stdin.readline().strip().split())  
  
        # 直接贪心模拟  
        state = True  
        curr_height = h  
        curr_time = 0  
        for i in range(n):  
            t, l, u = map(int, sys.stdin.readline().strip().split())  
  
            avail_t = curr_time - t  
  
            if curr_height >= u:  
                if avail_t >= (curr_height - u):  
                    curr_height = u  
                    curr_time = t  
                    continue  
                else:  
                    state = False  
                    # break  
  
            if curr_height <= l:  
                if avail_t >= (l - curr_height):  
                    curr_height = l  
                    curr_time = t  
                    continue  
                else:  
                    state = False  
                    # break  
  
        if state:  
            print("Yes")  
        else:  
            print("No")  
  
if __name__ == "__main__":  
    main()
```

---

简单来说，这个单点贪心代码不对，原因有两点：

1. **逻辑漏洞：** 当高桥君当前的高度已经处于目标区间内部时，你的代码**完全没有更新时间和高度**，直接废掉了这段可用的飞行时间。

2. **后效性（最致命的错误）：** 
   你让高桥君每次都站在**刚好及格**的临界点上（刚好压在上限 $u$ 或下限 $l$ 上）。
   但实际上，**“现在刚好及格”并不等于“未来好应付”**。你现在图省力不往高处飞，等下一个目标突然要求极高的时候，你就没有足够的时间爬升了。

**正确思路：** 不要死板地定在一个点，而是要维护一个 **“当前我所有可能处于的高度范围”** 。只要这个范围不为空，就说明后面总有路可走。
