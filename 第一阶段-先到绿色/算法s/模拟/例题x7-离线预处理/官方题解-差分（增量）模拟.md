官方题解采用的是一种**“基于事件驱动的差分（增量）模拟”**思路。

它的核心出发点是：**每天克服一个食材时，只有“包含该食材的菜品”的状态会发生变化，其他菜品完全不需要去理会。**

通过只跟踪和更新受影响的菜品，官方题解成功将时间复杂度降低到了最优秀的 $O(N + M + \sum K_i)$。

下面为您详细拆解官方题解的三个核心步骤：

---

### 第一步：建立“食材 $\to$ 菜品”的反向索引

在输入中，我们知道的是“每道菜包含哪些食材”。
为了在克服某个食材时，能瞬间知道“哪些菜受到了影响”，官方题解建立了一个**反向索引（邻接表）**。
* **做法**：建立一个列表 `food_to_menus`，其中 `food_to_menus[f]` 存储了所有**使用了食材 $f$ 的菜品编号**。
* **例子**：如果菜品 1 使用了食材 `[2, 3]`，菜品 4 使用了食材 `[3, 5]`。
  那么当我们在反向索引中查找食材 `3` 时，会得到 `food_to_menus[3] = [1, 4]`。

---

### 第二步：引入“未克服食材计数器”

我们不需要每次都去检查一道菜的所有食材是否都被克服，而是给每道菜设置一个**计数器**。
* **做法**：对于第 $j$ 道菜，设一个变量 `dislike_count[j]`。
* **初始值**：初始时，Snuke 讨厌所有食材。因此，这道菜含有多少种食材，它的计数器就初始化为多少，即 `dislike_count[j] = K_j`。
* **能吃的条件**：当 `dislike_count[j]` 递减到 `0` 时，说明这道菜里所有讨厌的食材都被克服了，此时这道菜就变得**可以食用**。

---

### 第三步：按天模拟，逐步递减计数器

从第 1 天到第 $N$ 天，依次处理克服的食材 $B_i$：
1. 今天克服了食材 $B_i$。
2. 通过反向索引，找出所有包含食材 $B_i$ 的菜品（即遍历 `food_to_menus[B_i]`）。
3. 对于这些受影响的菜品 $j$，将它们的计数器减 1：
   `dislike_count[j] -= 1`
4. **触发状态改变**：如果某个菜品的计数器刚好减到了 `0`，说明它从“不能吃”变成了“能吃”。我们将“当前可食用菜品总数” `ans` 累加 1。
5. 记录今天结束时的 `ans`。

---

### 为什么官方题解的运行效率极高？

我们可以从**“每道菜被更新的次数”**来分析：
* 对于第 $j$ 道菜，它包含 $K_j$ 个食材。
* 在整个 $N$ 天的过程中，这道菜最多只会被更新 $K_j$ 次（每次它包含的某一个食材被克服时，计数器减 1）。
* 因此，所有菜品在整个模拟过程中的**总更新次数**被锁定在：
  $$\sum_{j=1}^{M} K_j = \sum K_i$$
* 这个总更新次数是一个常数，与总天数 $N$ 没有乘积关系。这使得整个算法在极短时间内就能运行完毕。

---

### 您的解法 VS 官方解法的对比

| 维度 | 您的解法（二分查找） | 官方解法（差分模拟） |
| :--- | :--- | :--- |
| **核心视角** | **时间轴视角（离线）**：先求出每道菜的“解禁时间”，排序后用二分查找定位。 | **事件驱动视角（在线）**：随着时间推移，克服一个食材，就去更新受影响的菜品。 |
| **空间复杂度** | $O(N + M + \sum K_i)$ | $O(N + M + \sum K_i)$ |
| **时间复杂度** | $O(\sum K_i + (N + M) \log M)$ | $O(N + M + \sum K_i)$ |
| **优缺点** | **优点**：逻辑非常符合直觉，代码实现简单，对数据的读取顺序没有强要求。<br>**缺点**：由于有排序和二分，理论上限比官方解法稍慢一点点（但在本题中依然非常快）。 | **优点**：时间复杂度达到了理论极限的线性复杂度，没有 $\log$ 耗时，效率极高。<br>**缺点**：需要维护反向邻接表和状态计数器，稍微多了一点数据结构的设计。 |

两种解法都非常优秀，您的二分查找解法在实际竞赛中也是一种非常亮眼且容易写对的满分思路。

import sys  
from bisect import bisect_left, bisect_right  
  
  
def main():  
      
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    # 邻接表， food-menu    arr = [ [] for _ in range(n + 1)]  
    # 每个菜有k个食材  
    menus = [0] * (m + 1)  
    for i in range(m):  
        xrr = list(map(int, sys.stdin.readline().strip().split()))  
        menus[i + 1] = xrr[0]  
        xrr = xrr[1:]  
        for food in xrr:  
            # food 下有 i 菜  
            arr[food].append(i + 1)  
  
    brr = list(map(int, sys.stdin.readline().strip().split()))  
  
    out = []  
    cnt = 0  
    for food in brr:  
        # 只遍历有这个food的menu  
        for menu in arr[food]:  
            menus[menu] -= 1  
            if menus[menu] == 0:  
                cnt += 1  
        out.append(cnt)  
  
    print('\n'.join(map(str, out)))  
  
if __name__ == "__main__":  
    main()
