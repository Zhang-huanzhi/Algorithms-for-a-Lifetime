之所以必须要“动态维护”，是因为随着我们从左向右移动，**“不被覆盖的门槛”（即 $Y$ 的警戒线）是在不断变严格（变小）的。**

我们无法用一个**单一、固定**的 $Y$ 值作为全场的标准。

为了让你彻底明白，我们用一个最简单的例子来推导：

假设有三个排好序的点：
- **点 A**：$(1, 10)$
- **点 B**：$(2, 5)$
- **点 C**：$(3, 8)$

---

### 如果我们“不动态维护”（也就是固定一个 $Y$ 值）

#### 尝试 1：用第一个点的 $Y$ 值（10）作为固定标准
* 对 **点 B $(2, 5)$**：我们和 $10$ 比，$5 < 10$，符合条件。
* 对 **点 C $(3, 8)$**：我们仍和 $10$ 比，$8 < 10$，符合条件。

**结果错误！**
点 C 实际上被点 B $(2, 5)$ 覆盖了（因为 $2 < 3$ 且 $5 < 8$）。
为什么会错？因为当点 B $(2, 5)$ 出现后，**它把警戒线拉低到了 $5$**。之后的点不仅要比 $10$ 小，还必须比 $5$ 小，才不会被点 B 覆盖。

#### 尝试 2：用全场最小的 $Y$ 值（5）作为固定标准
* 对 **点 B $(2, 5)$**：我们和 $5$ 比，$5 < 5$ 不成立，不符合条件。

**结果又错了！**
点 B 左边只有点 A $(1, 10)$，点 A 的 $Y$ 坐标是 $10$，根本盖不住点 B。点 B 应该是符合条件的。

---

### 为什么必须“动态”？（警戒线的传递）

通过上面的尝试，你会发现这个“门槛”是动态变化的：

1. 刚开始（在点 A 之前），没有点。门槛是 $\infty$。
2. 遇到 **点 A $(1, 10)$**：它没有被覆盖。同时，它树立了一个新门槛：**接下来的点 $Y$ 必须小于 $10$**。
3. 遇到 **点 B $(2, 5)$**：它的 $Y = 5 < 10$，成功通关！因为它的 $Y$ 只有 $5$，它树立了一个**更严格的新门槛**：**接下来的点 $Y$ 必须小于 $5$**。
4. 遇到 **点 C $(3, 8)$**：它的 $Y = 8$，无法通过刚才点 B 设下的 $5$ 门槛（被点 B 覆盖了）。

这就是“动态维护”的真谛：**每当我们发现一个符合条件的点，它就会把“不被覆盖”的门槛拉得更低（ $Y$ 变得更小）**。如果不用变量动态去记录这个“最新、最严格的门槛”，我们就无法正确判断后面的点。
