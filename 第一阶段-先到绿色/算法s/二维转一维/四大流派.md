在算法和数据结构中，**“二维转一维”** 是一种极为经典的**降维打击**思想。无论是为了**降低时间复杂度**，还是为了**节省空间开销**，抑或是为了**套用成熟的一维数据结构**，降维都是最核心的破局手段。

根据应用场景的不同，二维转一维的技巧主要可以分为以下 **4 大流派**：

---

### 流派一：行/列压缩（边界固定法）—— 本题所用的技巧
这是解决**“子矩阵/长方形区域统计”**类问题的黄金法则。

* **核心思想**：
  在二维矩阵中，长方形有四个边界（上 $r_1$、下 $r_2$、左 $c_1$、右 $c_2$）。我们通过双重循环**强行固定其中一维的两个边界**（比如上下边界 $r_1, r_2$），然后将夹在中间的所有行，按列累加（或求最大值、最小值、异或等），压缩成一个长度为 $W$ 的一维数组。
* **为什么能降维**：
  一旦上下边界固定，长方形的上下拉伸范围就被锁死了，它现在只能在左右方向上滑动。这在物理意义上就退化成了一个**一维区间的滑动问题**。
* **典型应用**：
  * **二维最大子矩阵和**：固定上下边界 $r_1, r_2$，列压缩后，使用一维的最大子段和算法（Kadane 算法，可在 $O(W)$ 时间解决）。
  * **本题（矩阵子区域和为 $K$）**：固定上下边界后，利用一维前缀和在 $O(W)$ 时间解决。
* **口诀**：**“双针固定上下行，列向压缩变一维，套用一维成熟套路。”**

---

### 流派二：坐标铺平（Flat Mapping）
这是解决**“网格图论与数据结构套用”**的必备技巧。

* **核心思想**：
  将一个 $H \times W$ 的二维网格中的每一个格子 $(r, c)$（其中 $0 \le r < H, 0 \le c < W$），映射成一个唯一的、范围在 $[0, H \times W - 1]$ 之间的一维整数 $idx$。
  * **映射公式（二维转一维）**：
    $$idx = r \times W + c$$
  * **逆映射公式（一维转二维）**：
    $$r = idx // W, \quad c = idx \% W$$
* **为什么能降维**：
  许多高级数据结构（如**并查集 DSU**、**线段树 Segment Tree**、**图邻接表**）在设计之初都是为一维线性空间服务的。通过坐标铺平，我们可以直接把二维网格套进这些结构里，而不需要重新写一套二维的版本。
* **典型应用**：
  * **网格图连通性（如岛屿数量）**：将格子映射成一维节点，直接使用一维并查集做合并操作。
  * **矩阵快速幂**：将 $N \times N$ 的状态矩阵铺平，参与矩阵乘法计算。

---

### 流派三：滚动数组（Space DP Compression）
这是**“动态规划（DP）空间复杂度优化”**的终极武器。

* **核心思想**：
  在二维 DP（如 $dp[i][j]$）中，我们发现计算第 $i$ 行的状态时，**仅仅依赖于第 $i-1$ 行（或前几行）的状态**，而与更早之前的历史状态无关。此时，我们可以把第一维 $i$ 删掉，只保留一维数组 `dp[j]`，通过反复覆盖这一维数组来完成计算。
* **为什么能降维**：
  将空间复杂度从 $O(N \times M)$ 暴降到 $O(M)$ 或 $O(N)$。在很多空间限制极严（如 64MB）的题目中，这是不超内存的唯一办法。
* **典型应用**：
  * **01 背包问题**：未优化的状态转移方程是 $dp[i][j] = \max(dp[i-1][j], dp[i-1][j-w] + v)$。由于只依赖上一行，倒序遍历 $j$ 时可以压缩为一维 $dp[j] = \max(dp[j], dp[j-w] + v)$。
  * **最长公共子序列（LCS）/ 编辑距离**。

---

### 流派四：扫描线算法（Scanline / 投影法）
这是**“计算几何与区间合并”**的灵魂技巧。

* **核心思想**：
  在二维平面上有许多矩形或几何图形。我们假想有一根垂直的“扫描线”从左向右横扫过整个平面。
  * 扫描线在 $X$ 轴（一维）的移动代表“时间”或“事件触发点”；
  * 在每一个事件点（比如遇到了矩形的左边界或右边界），我们只需要维护扫描线在 $Y$ 轴（一维）上的投影区间。
* **为什么能降维**：
  它把一个静态的二维平面图形覆盖问题，转化为了**一维线段在时间轴上的动态变化问题**。
* **典型应用**：
  * **矩形面积并 / 矩形周长并**：利用扫描线配合一维线段树，在 $O(N \log N)$ 的极高效率下求出成百上千个重叠矩形的总面积。

---

### 总结：什么时候用什么技巧？

当你面对一个二维问题感到棘手时，可以这样思考：

1. 如果是**求子矩阵、子长方形的某种性质**（和、最大、最小），尝试**流派一（行/列压缩）**。
2. 如果要在网格图上**用并查集、建图、写最短路**，尝试**流派二（坐标铺平）**。
3. 如果写出了二维 DP 发现**空间超了**，尝试**流派三（滚动数组）**。
4. 如果是**重叠的矩形、区间、几何覆盖**，尝试**流派四（扫描线）**。
