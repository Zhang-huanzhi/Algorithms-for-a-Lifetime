### D - Neighbor Distance  
时间限制: 4 秒 / 内存限制: 1024 MiB  
分值: 400 分

#### 题目描述
有一个数轴。最初，人 $0$ 独自一人站在坐标 $0$ 处。

接下来，人 $1, 2, \dots, N$ 将依此顺序到达并站在数轴上。  
人 $i$ 站在坐标 $X_i$ 处。已知 $X_i \ge 1$，且所有人的坐标 $X_i$ 两两不同。

每当有新的人到达时，请回答以下问题：

> 假设当前数轴上站着人 $0, 1, \dots, r$ 共 $r+1$ 个人。  
> 此时，定义 $d_i$ 为“距离人 $i$ 最近的另一个人的距离”。  
> 更严谨地，定义 $d_i = \min_{0 \le j \le r, j \neq i} |X_i - X_j|$。  
> 求所有 $d_i$ 的总和，即 $\sum_{i=0}^{r} d_i$。

#### 约束条件
* 输入均为整数
* $1 \le N \le 5 \times 10^5$
* $1 \le X_i \le 10^9$
* 若 $i \neq j$，则 $X_i \neq X_j$

#### 输入格式
输入通过标准输入给出，格式如下：

$$N$$
$$X_1 \quad X_2 \quad \dots \quad X_N$$

#### 输出格式
输出 $N$ 行。  
其中第 $i$ 行（$1 \le i \le N$）应输出在人 $i$ 到达时的问答答案。

#### 样例说明 1
在此样例中，共有 $10$ 个人依次到达。  
以下对前 $4$ 个人到达时的情况进行说明：

* **人 $1$ 到达时**，坐标 $0, 5$ 处有人。  
  每个人的最近距离分别为：人 $0$（在 $0$）到人 $1$（在 $5$）距离为 $5$；人 $1$ 到人 $0$ 距离为 $5$。  
  所求的和为 $5 + 5 = 10$。
* **人 $2$ 到达时**，坐标 $0, 2, 5$ 处有人。  
  每个人的最近距离分别为：人 $0$（在 $0$）最近是人 $2$（在 $2$），距离为 $2$；人 $2$ 最近是人 $0$，距离为 $2$；人 $1$（在 $5$）最近是人 $2$，距离为 $3$。  
  所求的和为 $2 + 2 + 3 = 7$。
* **人 $3$ 到达时**，坐标 $0, 2, 5, 7$ 处有人。  
  所求的和为 $2 + 2 + 2 + 2 = 8$。
* **人 $4$ 到达时**，坐标 $0, 2, 4, 5, 7$ 处有人。  
  所求的和为 $2 + 2 + 1 + 1 + 2 = 8$。
