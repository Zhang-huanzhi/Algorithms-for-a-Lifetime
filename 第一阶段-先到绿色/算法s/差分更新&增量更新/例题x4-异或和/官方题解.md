这份官方题解的思路非常巧，核心在于**利用 XOR 的性质做 $O(1)$ 的增量更新**，以及**利用“均摊复杂度（Amortized Complexity）”的思想来避免操作 2 的暴力遍历**。

下面为你详细拆解题解的核心逻辑和代码：

---

### 一、 核心思路拆解

设当前整个数组 $A$ 的按位异或和为 $ans$（即 $ans = A_1 \oplus A_2 \oplus \dots \oplus A_N$）。

#### 技巧 1：如何 $O(1)$ 更新全局 XOR 和？

根据异或运算的性质（$p \oplus p = 0$）：
* 如果要把数组中的某个数 $A_x$ 修改为新的值 $A_x'$，我们**不需要重新遍历整组数据**。
* 只需要将当前异或和 $ans$ **先异或上旧值 $A_x$**（相当于把旧值从异或和中抹去），**再异或上新值 $A_x'$**。
* 即：$\text{新 } ans = \text{旧 } ans \oplus A_x \oplus A_x'$。

因此：
* **加 1 操作（$A_x \to A_x + 1$）**：更新公式为 `ans = ans ^ A[x] ^ (A[x] + 1)`
* **减 1 操作（$A_x \to A_x - 1$）**：更新公式为 `ans = ans ^ A[x] ^ (A[x] - 1)`

这个更新操作的时间复杂度是 **$O(1)$**。

---

#### 技巧 2：如何高效处理“操作 2”（全局减 1）？

如果每次遇到操作 2 都去遍历整个长度为 $N$ 的数组，复杂度是 $O(N \times Q)$，会严重超时（TLE）。

**关键观察**：
1. 操作 2 **只对大于等于 1 的数**生效。
2. 初始时所有元素都是 0。
3. 我们只需要维护一个集合 `idxs`，记录**当前所有非零元素的下标**。

**集合 `idxs` 如何维护？**
* **操作 1（给 $A_x$ 加 1）**：
  * 如果加 1 前 $A_x == 0$，说明它从 0 变成了 1，**把它加入集合 `idxs`**。
  * 如果加 1 前 $A_x > 0$，它本来就在集合里，集合无需改变。
* **操作 2（所有非零数减 1）**：
  * **只遍历 `idxs` 集合中的元素**（即非零元素），依次将它们减 1，并用技巧 1 实时更新全局 XOR 和 `ans`。
  * 减完之后，过滤掉那些变成了 0 的元素（将它们移出集合 `idxs`）。

---

### 二、 为什么这样做不会超时？（复杂度分析）

你可能会担心：如果 `idxs` 很大，操作 2 遍历 `idxs` 难道不会超时吗？

这里用到了**均摊复杂度分析**：
1. 初始时，`idxs` 为空，数组全为 0。
2. **一个下标被加入 `idxs` 的总次数**：每次操作 1 最多向 `idxs` 中添加 1 个元素。整个过程最多有 $Q$ 次操作 1，所以 `idxs` 累计被添加元素的次数不超过 $Q$。
3. **操作 2 中循环执行的总次数**：在操作 2 中，循环每执行一次，就会有一个非零元素减 1。**一个元素被减去的总次数，绝不可能超过它被加上的总次数**。
4. 因此，**所有操作 2 的循环次数加起来，整个程序运行期间最多不超过 $Q$ 次**！

* **总时间复杂度**：$O(N + Q)$，完全可以在 2 秒内跑完。
* **总空间复杂度**：$O(N)$。

---

### 三、 Python 代码逐行解析

结合上面的思路，再看这份代码就非常清晰了：

```python
import sys
input = sys.stdin.readline

n, q = map(int, input().split())
idxs = []       # 存储当前非零元素的下标
a = [0] * n     # 对应数组 A，初始全 0
ans = 0         # 全局 XOR 和，初始 0 ^ 0 ^ ... ^ 0 = 0

for _ in range(q):
    data = list(map(int, input().split()))
    if data[0] == 1:
        x = data[1] - 1  # 转化为 0-indexed 下标
        
        # 如果原来是 0，加 1 后变为非零，记录其下标
        if a[x] == 0:
            idxs.append(x)
        
        # O(1) 增量更新全局 XOR 和：先异或旧值，再异或新值
        ans ^= a[x] ^ (a[x] + 1)
        a[x] += 1
        
    else: # 操作 2
        # 只遍历当前非零的元素
        for v in idxs:
            # O(1) 增量更新全局 XOR 和
            ans ^= a[v] ^ (a[v] - 1)
            a[v] -= 1
        
        # 重新构建 idxs，过滤掉减完后变成 0 的元素
        idxs = [v for v in idxs if a[v] != 0]
        
    print(ans)
```

### 总结
这道题的精髓在于：**不要被“全局操作”吓到**。通过将视角转变为“只对非零元素操作”，并结合 XOR 的可逆消除性质，巧妙地把看似 $O(N \times Q)$ 的暴力做法优化到了 $O(N + Q)$。
