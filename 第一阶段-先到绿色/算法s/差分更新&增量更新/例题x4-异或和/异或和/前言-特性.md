### 1. 基础三大基本性质（基石）

设 $\oplus$ 表示按位异或（C++/Python 中的 `^`）：

| 性质名称 | 数学公式 | 竞赛解读与直观理解 |
| :--- | :--- | :--- |
| **1. 自消性（归零律）** | $A \oplus A = 0$ | **核心！** 任何数和自己异或，结果直接归零（彻底抵消）。 |
| **2. 保留性（零元）** | $A \oplus 0 = A$ | 任何数与 $0$ 异或，保持不变（$0$ 是异或世界的“不干涉元素”）。 |
| **3. 交换律与结合律** | $A \oplus B = B \oplus A$<br>$(A \oplus B) \oplus C = A \oplus (B \oplus C)$ | 异或的顺序**完全不影响结果**，你可以随意打乱、分组、单独修改某一项。 |

### 2. 算法竞赛四大“大招”（必背套路）

#### 招式一：$O(1)$ 动态修改与撤销（本题核心）
在维护全局异或和 $S = A_1 \oplus A_2 \oplus \dots \oplus A_N$ 时，如果把 $A_x$ 从 **旧值 $old$** 修改为 **新值 $new$**：

* **公式**：`S = S ^ old ^ new`
* **本质**：
  * `S ^ old` 相当于**把旧贡献删掉**（利用 $old \oplus old = 0$ 抵消掉旧值）。
  * `^ new` 相当于**把新贡献加入**。
* **类比普通加法**：
  * 普通加法：$S_{新} = S_{旧} - old + new$ （用减法撤销，用加法加入）
  * 异或加法：$S_{新} = S_{旧} \oplus old \oplus new$ （**撤销和加入全用 `^`**）

---

#### 招式二：前缀异或和（像前缀和一样求区间异或）
类似于普通数组的“前缀和”，我们可以维护前缀异或数组 $P$：
$P_i = A_1 \oplus A_2 \oplus \dots \oplus A_i$

* **求区间 $[L, R]$ 的异或和**：
  * **公式**：$\text{XOR}(L..R) = P_R \oplus P_{L-1}$
  * **原理**：$P_R$ 包含了 $1 \dots R$，$P_{L-1}$ 包含了 $1 \dots L-1$。两者异或时，$1 \dots L-1$ 的部分**全部被自消性干掉了**，只剩下 $L \dots R$。

---

#### 招式三：按位奇偶性（按位拆分拆解）
如果把所有数字按二进制拆开，观察第 $k$ 位：
* **结论**：全局异或和的第 $k$ 位是 $1$ $\iff$ **所有元素中第 $k$ 位是 $1$ 的个数为“奇数”**。
* **代码逻辑**：
  ```python
  # 错误逻辑：if count != 0 (这是 OR 按位或)
  # 正确逻辑：if count % 2 == 1 (这是 XOR 按位异或)
  ```

---

#### 招式四：不用额外变量交换两个数
利用自消性，可以在不借助临时变量 `temp` 的情况下交换 $a$ 和 $b$：
```python
a = a ^ b
b = a ^ b  # 此时 b = (a ^ b) ^ b = a
a = a ^ b  # 此时 a = (a ^ b) ^ a = b
```

### 3. 一句话记忆卡片（备忘口诀）

> 1. **异或没有减法，因为异或自己就是减法！** （`S ^ x` 就是扣除 `x`）
> 2. **奇数个 1 异或为 1，偶数个 1 异或为 0。**
> 3. **改动单点不重算，`S ^ old ^ new` 瞬间搞定。**
