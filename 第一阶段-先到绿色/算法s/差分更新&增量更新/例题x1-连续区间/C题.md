### C - 黑色区间

**时间限制：** 3 秒  
**内存限制：** 1024 MiB  
**分值：** 350 分

---

### 问题描述
有 $N$ 个格子从左到右排成一排，初始状态下所有格子均为白色。

请依次处理 $Q$ 个查询。
在第 $i$ 个查询中，给定一个 $1$ 到 $N$ 之间的整数 $A_i$，执行以下操作：
反转从左起第 $A_i$ 个格子的颜色。即：如果该格子是白色的，则涂成黑色；如果该格子是黑色的，则涂成白色。
操作完成后，统计当前黑色格子构成的“连续区间”的个数。

这里，黑色格子构成的“连续区间”是指满足以下所有条件的整数对 $(l, r)$ ($1 \le l \le r \le N$)：
1. 从左起第 $l, l+1, \dots, r$ 个格子均为黑色。
2. $l=1$ 或者从左起第 $(l-1)$ 个格子是白色。
3. $r=N$ 或者从左起第 $(r+1)$ 个格子是白色。

### 约束条件
* $1 \le N, Q \le 5 \times 10^5$
* $1 \le A_i \le N$
* 输入均为整数

### 输入
输入通过标准输入按以下格式给出：
> $N \ Q$
> $A_1 \ A_2 \ \dots \ A_Q$

### 输出
请输出 $Q$ 行。
第 $i$ 行（$1 \le i \le Q$）输出第 $i$ 个查询后的答案。

---

### 输入输出示例

**示例 1**
* 输入：
  ```
  5 7
  2 3 3 5 1 5 2
  ```
* 输出：
  ```
  1
  1
  1
  2
  2
  1
  1
  ```
* 说明：
  * 第 1 次操作：格子 2 变黑。连续区间：(2,2)，共 1 个。
  * 第 2 次操作：格子 3 变黑。连续区间：(2,3)，共 1 个。
  * 第 3 次操作：格子 3 变白。连续区间：(2,2)，共 1 个。
  * 第 4 次操作：格子 5 变黑。连续区间：(2,2), (5,5)，共 2 个。
  * 第 5 次操作：格子 1 变黑。连续区间：(1,2), (5,5)，共 2 个。
  * 第 6 次操作：格子 5 变白。连续区间：(1,2)，共 1 个。
  * 第 7 次操作：格子 2 变白。连续区间：(1,1)，共 1 个。

**示例 2**
* 输入：
  ```
  1 2
  1 1
  ```
* 输出：
  ```
  1
  0
  ```
* 说明：第 2 次操作后所有格子均为白色，输出 0。

**示例 3**
* 输入：
  ```
  3 3
  1 3 2
  ```
* 输出：
  ```
  1
  2
  1
  ```
