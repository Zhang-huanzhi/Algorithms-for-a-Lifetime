它的核心思想是：**“不记录每一个被占用的格子，而是只记录每一个成功放置的方块的左上角坐标，并通过数学关系快速判定重叠。”**

下面为您详细拆解和讲解这篇题解的逻辑：

---

### 1. 核心概念：用“左上角坐标”代表整个方块
一个方块的大小是 $2 \times 2$，它占用了 4 个格子。我们不需要把这 4 个格子的坐标都存下来，只需要用它的**左上角坐标 $(r, c)$** 就可以唯一代表这个方块。
题解中将这个方块称为 **“方块 $(r, c)$”**。

---

### 2. 核心原理：方块重叠的数学判定
题解给出了一个关键的数学定理：
> 方块 $(r_1, c_1)$ 和方块 $(r_2, c_2)$ 重叠，**当且仅当**满足以下条件：
> $$|r_1 - r_2| \le 1 \quad \text{且} \quad |c_1 - c_2| \le 1$$

#### 为什么是这个条件？
我们可以从行（上下）和列（左右）两个方向来理解：
* **行方向重叠**：
  * 方块 1 占用的行是 $[r_1, r_1+1]$。
  * 方块 2 占用的行是 $[r_2, r_2+1]$。
  * 如果这两个区间有交集，则必须满足 $r_1 - 1 \le r_2 \le r_1 + 1$，写成绝对值就是 $|r_1 - r_2| \le 1$。
* **列方向重叠**：
  * 同理，方块 1 占用的列是 $[c_1, c_1+1]$，方块 2 占用的列是 $[c_2, c_2+1]$。
  * 区间有交集必须满足 $|c_1 - c_2| \le 1$。

只有当行和列同时重叠时，两个方块才会真正重叠。因此，只要两个方块的左上角在横向和纵向上的距离都不超过 $1$，它们就会冲突。

---

### 3. 判定方法：只需检查周围 9 个位置
根据上面的重叠条件，如果我们想在 $(r, c)$ 尝试放置一个新方块，我们**只需要检查是否存在一个已经放好的方块 $(r', c')$**，其左上角满足：
$$r - 1 \le r' \le r + 1 \quad \text{且} \quad c - 1 \le c' \le c + 1$$

这对应的实际上是以 $(r, c)$ 为中心的 **$3 \times 3$ 范围内的 9 个九宫格位置**：
$$\begin{matrix}
(r-1, c-1) & (r-1, c) & (r-1, c+1) \\
(r, c-1) & \mathbf{(r, c)} & (r, c+1) \\
(r+1, c-1) & (r+1, c) & (r+1, c+1)
\end{matrix}$$

如果这 9 个坐标中，**没有任何一个**出现在已经成功放置的方块左上角集合里，那么当前方块 $(r, c)$ 就可以安全放置。

---

### 4. 数据结构选择：哈希集合（Hash Set）
为了实现快速查找，我们需要一种数据结构，能够高效地：
1. **查询**某个坐标 $(r', c')$ 是否存在。
2. **插入**新的方块坐标 $(r, c)$。

在 Python 中，内置的 `set`（集合）基于哈希表实现，其查询和插入的平均时间复杂度均为 $O(1)$，非常符合要求。

---

### 5. 官方题解思路的 Python 代码实现

相比于我们之前“记录每一个占用的格子（集合大小最大为 $4M$）”的思路，官方题解“只记录方块左上角（集合大小最大为 $M$）”的做法**内存占用更小，效率更高**。

以下是按照官方题解思路编写的 Python 代码：

```python
import sys

def main():
    n, m = map(int, sys.stdin.readline().strip().split())

    # 仅存储已成功放置方块的左上角坐标 (r, c)
    placed_blocks = set()
    ans = 0

    for _ in range(m):
        r, c = map(int, sys.stdin.readline().strip().split())

        # 检查周围 3x3 区域的 9 个候选左上角坐标
        has_overlap = False
        for dr in [-1, 0, 1]:
            for dc in [-1, 0, 1]:
                nr = r + dr
                nc = c + dc
                # 如果这个相邻位置已经有方块的左上角，说明会发生重叠
                if (nr, nc) in placed_blocks:
                    has_overlap = True
                    break
            if has_overlap:
                break

        # 如果不重叠，说明可以放置
        if not has_overlap:
            ans += 1
            placed_blocks.add((r, c))

    print(ans)

if __name__ == "__main__":
    main()
```

### 总结
官方题解通过将 $2 \times 2$ 的实体简化为单个点 $(r, c)$，并将“图形相交问题”转化为了“点与点之间的曼哈顿/切比雪夫距离问题”，从而将每次操作的冲突检测压缩到了固定的 9 次哈希表查询，是一种非常标准且优雅的在线算法优化技巧。
