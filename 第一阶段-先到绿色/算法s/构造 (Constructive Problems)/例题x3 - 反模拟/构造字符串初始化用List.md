在 Python 中构造字符串时，**强烈推荐使用 `s = []`（列表）逐步添加，最后用 `''.join(s)` 拼接**，而不是直接用 `s = ''` 进行字符串累加（`s += char`）。

这主要是出于**运行效率（性能）**的考虑。以下是详细原因：

### 1. 为什么不推荐 `s = ''`（字符串累加）？

在 Python 中，**字符串是不可变对象（Immutable）**。
当你写 `s += char` 时，Python 并不是直接在原字符串后面加上一个字符，而是：
1. 在内存中申请一块**新的空间**。
2. 把旧字符串的内容复制过去。
3. 加上新字符。
4. 销毁旧字符串。

如果要构造一个长度为 $N$ 的字符串，这种方式会导致大量的内存申请和数据复制，时间复杂度会退化到 **$O(N^2)$**。当 $N$ 达到 $10^5$ 级别时，程序会变得极慢，甚至导致超时（TLE）。

---

### 2. 为什么推荐 `s = []`（列表 append）？

**列表是可变对象（Mutable）**。
当你写 `s.append(char)` 时，Python 的列表底层有自动扩容机制，它的单次添加操作平均时间复杂度是 **$O(1)$**。

当你把所有字符都放进列表后，调用 `''.join(s)`，Python 会**一次性**申请足够大的内存，把列表里的字符拼成一个完整的字符串。这种方法的时间复杂度是 **$O(N)$**，效率非常高。

---

### 两种写法的对比

#### 推荐写法（高效 $O(N)$）：
```python
s_list = []
for i in range(100000):
    s_list.append('A')  # O(1) 操作
s = ''.join(s_list)     # 一次性拼接，极其高效
```

#### 不推荐写法（低效 $O(N^2)$）：
```python
s = ''
for i in range(100000):
    s += 'A'  # 每次都在内存中复制并新建字符串，极慢！
```

### 总结
* 如果你要**动态、一个字符一个字符地构建一个长字符串**，请务必初始化为 `s = []`，最后用 `''.join(s)` 转换为字符串。
* 只有当字符串非常短（比如只有几个字符），或者你不需要频繁修改它时，直接用 `s = ''` 才不会影响性能。
