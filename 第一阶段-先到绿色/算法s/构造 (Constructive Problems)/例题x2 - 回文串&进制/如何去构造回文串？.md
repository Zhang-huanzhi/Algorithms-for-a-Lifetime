**左半边** 称为 **“种子”（Seed）**。

``` python
seed = "456"
rev_seed = seed[::-1]

even_pal = seed + rev_seed       # 结果: "456654"
odd_pal = seed + rev_seed[1:]    # 结果: "45654"
```


---

注意：

1. **前导零陷阱（Leading Zeros）**
    
    - 在数字中，010 看起来是个回文串，但在数学概念中，数字不能以 0 开头。这道题（双进制回文）就隐性要求了最高位不能是 0。
        
    - 对策：我们用来做“种子”的循环变量 i（从 1 开始递增），本身就不会以 0 开头，所以构造法天然避开了前导零的问题。
        
2. **字符串比较 vs 数组比较**
    
    - **十进制**：可以直接用 str(num) == str(num)[::-1]，这是最快的。
        
    - **其他进制**：千万不要轻易转成字符串！如果转成 16 进制，余数 10 会占用两个字符，翻转时会变成 01，导致逻辑彻底崩溃。
        
    - 对策：像你代码里写的那样，用 List（列表/数组）保存余数，用 arr == arr[::-1] 判断，这是绝对安全、通用的做法。
