### C - Palindromic in Both Bases / 双进制回文数
时间限制: 3 秒 / 内存限制: 1024 MiB

分值：350 分

#### 题目描述
$414$ 的十进制表示是 $414$，这是一个回文数。此外，$414$ 的八进制表示是 $636$，这也是一个回文数。基于此，请解决以下问题：

给定正整数 $A$ 和 $N$。求所有满足以下条件的整数 $x$（$1 \le x \le N$）之和：
* $x$ 的十进制表示和 $A$ 进制表示均不含前导零，且两者均为回文数。

此外，可以证明在题目的限制条件下，答案小于 $2^{63}$。

#### 数据范围
* $2 \le A \le 9$
* $1 \le N \le 10^{12}$
* 输入的所有数值均为整数。

#### 输入格式
输入按以下格式从标准输入给出：
> $A$
> $N$

#### 输出格式
输出一行，表示满足条件的整数之和。

---

#### 输入样例 1
```text
8
1000
```

#### 输出样例 1
```text
2155
```
满足条件的整数有 $1, 2, 3, 4, 5, 6, 7, 9, 121, 292, 333, 373, 414, 585$ 共 $14$ 个，其总和为 $2155$。

#### 输入样例 2
```text
8
999999999999
```

#### 输出样例 2
```text
914703021014
```

#### 输入样例 3
```text
6
999999999999
```

#### 输出样例 3
