我们可以把 **“后缀最值预处理”** 拆成三个词来理解：
1. **后缀（Suffix）**：从数组的某个位置开始，一直到数组**末尾**结束的连续子数组。
2. **最值（Maximum）**：最大值（或最小值）。
3. **预处理（Precomputation）**：在正式回答查询之前，提早把所有可能用到的答案算好存起来。

简单来说，它的目的就是：**提早算好“从每一个位置到末尾的最大值是多少”，并存进一个表格里。**

---

### 一、 一个直观的例子

假设我们有 4 个人的身高：`H = [15, 26, 3, 12]`

* 如果我们想知道：
  * 从第 3 个人到末尾的最大身高（即区间 `[3, 12]`） $\rightarrow$ 最大值是 **12**
  * 从第 2 个人到末尾的最大身高（即区间 `[3, 3, 12]`） $\rightarrow$ 最大值是 **12**
  * 从第 1 个人到末尾的最大身高（即区间 `[26, 3, 12]`） $\rightarrow$ 最大值是 **26**
  * 从第 0 个人到末尾的最大身高（即区间 `[15, 26, 3, 12]`） $\rightarrow$ 最大值是 **26**

#### 怎么高效地算出这些值？——“从后往前看”

如果我们从前往后看，每次都要重新数一遍，很慢。
但如果**从后往前看**，逻辑就会变得极其简单：

1. **最后一个人**（第 3 个，身高 12）：从他到末尾只有他自己，最大值显然是 **12**。
2. **倒数第二个人**（第 2 个，身高 3）：从他到末尾的最大值，等于“他自己的身高（3）”和“他后面那群人的最大值（12）”中较大的那个：
   $$\max(3, 12) = 12$$
3. **倒数第三个人**（第 1 个，身高 26）：从他到末尾的最大值，等于“他自己的身高（26）”和“他后面那群人的最大值（12）”中较大的那个：
   $$\max(26, 12) = 26$$
4. **第一个人**（第 0 个，身高 15）：从他到末尾的最大值，等于“他自己的身高（15）”和“他后面那群人的最大值（26）”中较大的那个：
   $$\max(15, 26) = 26$$

最终，我们得到了一个预处理数组：
`suf_max = [26, 26, 12, 12]`

这个数组的递推关系就是：
```python
suf_max[i] = max(H[i], suf_max[i + 1])
```
