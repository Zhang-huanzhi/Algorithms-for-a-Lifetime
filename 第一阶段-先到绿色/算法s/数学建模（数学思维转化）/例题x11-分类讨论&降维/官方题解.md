这份官方题解的核心思想是**“分类讨论 + 降维枚举（$O(N)$ 解决）”**。

下面为你详细拆解题解的逻辑和数学推导：

---

### 一、 核心难点与破局思路

题目要求统计在矩形范围 $L \le x \le R$ 且 $D \le y \le U$ 内，满足 $\max(|x|, |y|)$ 为**偶数**的点 $(x, y)$ 数量。

直接两重循环枚举 $x$ 和 $y$ 需要 $O((R-L)(U-D)) \approx 10^6 \times 10^6 = 10^{12}$ 次计算，会超时。

因为有 $\max(|x|, |y|)$，我们可以通过**大小比较**把平面拆分成两部分：
1. **$|x| > |y|$ 的区域**：此时 $\max(|x|, |y|) = |x|$。
2. **$|x| \le |y|$ 的区域**：此时 $\max(|x|, |y|) = |y|$。

只要分别算出这两种情况下的黑色格子数量，最后**相加**就是答案。

---

### 二、 情况 1：计算 $|x| > |y|$ 的黑色格子数

在 $|x| > |y|$ 时：
* $\max(|x|, |y|) = |x|$。
* 要想格子是黑色，只需要 **$|x|$ 为偶数**（即 $x$ 为偶数）。
* 条件 $|x| > |y|$ 等价于：$$-|x| < y < |x| \iff -|x| + 1 \le y \le |x| - 1$$

此时，我们**枚举每一个偶数 $x$**（$L \le x \le R$ 且 $x$ 是偶数）：
对于固定的 $x$，合法的 $y$ 必须同时满足：
1. $-|x| + 1 \le y \le |x| - 1$ （由于 $|x| > |y|$）
2. $D \le y \le U$ （题目给定的矩形范围）

求这两个区间的交集：
* $y$ 的下界：$y_{\min} = \max(-|x| + 1, D)$
* $y$ 的上界：$y_{\max} = \min(|x| - 1, U)$

因此，对于这个固定的 $x$，合法的整数 $y$ 的个数可以直接 $O(1)$ 算出来：
$$\text{count} = \max(0, y_{\max} - y_{\min} + 1)$$

由于 $x$ 最多只有 $R - L + 1 \le 2 \times 10^6$ 个，枚举偶数 $x$ 的时间复杂度为 **$O(R - L)$**。

---

### 三、 情况 2：计算 $|x| \le |y|$ 的黑色格子数

这与情况 1 完全对称！
在 $|x| \le |y|$ 时：
* $\max(|x|, |y|) = |y|$。
* 要想格子是黑色，只需要 **$y$ 为偶数**。
* 条件 $|x| \le |y|$ 等价于：$$-|y| \le x \le |y|$$

我们**枚举每一个偶数 $y$**（$D \le y \le U$ 且 $y$ 是偶数）：
对于固定的 $y$，合法的 $x$ 必须同时满足：
1. $-|y| \le x \le |y|$
2. $L \le x \le R$

求交集：
* $x$ 的下界：$x_{\min} = \max(-|y|, L)$
* $x$ 的上界：$x_{\max} = \min(|y|, R)$

对于这个固定的 $y$，合法的整数 $x$ 的个数为：
$$\text{count} = \max(0, x_{\max} - x_{\min} + 1)$$

枚举偶数 $y$ 的时间复杂度为 **$O(U - D)$**。

---

### 四、 为什么不会漏数、也不会重复计数？

1. **不重复**：
   * 第一部分严格要求 $|x| > |y|$；
   * 第二部分要求 $|x| \le |y|$。
   * 一个是严格大于 $>$, 一个是小于等于 $\le$，两个集合互斥，绝对不会把同一个点算两次。
2. **不遗漏**：
   * 任何实数/整数对 $(x, y)$，要么 $|x| > |y|$，要么 $|x| \le |y|$，涵盖了整个平面的所有点。

---

### 五、 参考 Python 代码

```python
import sys

def main():
    L, R, D, U = map(int, sys.stdin.readline().split())
    ans = 0

    # 1. 统计 |x| > |y| 且 |x| 为偶数的情况
    for x in range(L, R + 1):
        if x % 2 == 0:
            ax = abs(x)
            # y 范围: [-ax + 1, ax - 1] 与 [D, U] 取交集
            y_min = max(-ax + 1, D)
            y_max = min(ax - 1, U)
            if y_max >= y_min:
                ans += (y_max - y_min + 1)

    # 2. 统计 |x| <= |y| 且 |y| 为偶数的情况
    for y in range(D, U + 1):
        if y % 2 == 0:
            ay = abs(y)
            # x 范围: [-ay, ay] 与 [L, R] 取交集
            x_min = max(-ay, L)
            x_max = min(ay, R)
            if x_max >= x_min:
                ans += (x_max - x_min + 1)

    print(ans)

if __name__ == '__main__':
    main()
```

### 复杂度
* **时间复杂度**：$O((R - L) + (U - D)) \approx 2 \times 10^6$，在 Python 中 2 秒内可轻松通过。
* **空间复杂度**：$O(1)$，常数空间。
