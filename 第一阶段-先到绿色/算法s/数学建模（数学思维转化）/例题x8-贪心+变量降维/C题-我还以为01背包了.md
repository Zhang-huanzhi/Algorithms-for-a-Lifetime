### C - Reindeer and Sleigh 2

**时间限制**：2 秒 / **内存限制**：1024 MiB  
**分值**：350 分

#### 题目描述
有 $N$ 只驯鹿和 1 个雪橇。
第 $i$ 只驯鹿的重量为 $W_i$，力量为 $P_i$。

对于每一只驯鹿，你需要选择让它“**拉雪橇**”或者“**坐雪橇**”。
但是必须满足：**拉雪橇的驯鹿的力量之和**必须**大于等于** **坐雪橇的驯鹿的重量之和**。

请问最多可以让多少只驯鹿坐在雪橇上？

本题包含 $T$ 组测试数据，请对每组数据求解。

#### 数据范围
* $1 \le T \le 10^5$
* $1 \le N \le 3 \times 10^5$
* $1 \le W_i, P_i \le 10^9$
* 输入均为整数
* 一个输入文件中所有测试数据的 $N$ 之和不超过 $3 \times 10^5$

#### 输入格式
输入按以下格式从标准输入给出：

> $T$  
> $\text{case}_1$  
> $\text{case}_2$  
> $\vdots$  
> $\text{case}_T$  

每组测试数据 $\text{case}_i$ 的格式如下：

> $N$  
> $W_1$ $P_1$  
> $W_2$ $P_2$  
> $\vdots$  
> $W_N$ $P_N$  

#### 输出格式
输出 $T$ 行。  
第 $i$ 行输出第 $i$ 组测试数据的答案。

**样例说明 1**：  
对于第 1 组测试数据：
若让第 3 只驯鹿拉雪橇，第 1 和第 2 只驯鹿坐雪橇，则：
* 拉雪橇的驯鹿力量之和为 $P_3 = 9$；
* 坐雪橇的驯鹿重量之和为 $W_1 + W_2 = 3 + 4 = 7$。

因为 $9 \ge 7$，所以满足条件。无法让所有 3 只驯鹿都坐在雪橇上，因此答案为 $2$。

# AC Code
``` python
import sys  
  
def main():  
  
    t = int(sys.stdin.readline().strip())  
  
    out = []  
    for _ in range(t):  
        n = int(sys.stdin.readline().strip())  
        arr = []  
        sum_power = 0  
        for _ in range(n):  
            w, p = map(int, sys.stdin.readline().strip().split())  
            arr.append((w, p))  
            sum_power += p  
  
        arr.sort(key= lambda x:(x[0] + x[1]))  
  
        curr = 0  
        cnt = 0  
        for weight, power in arr:  
            curr += (weight + power)  
            if curr > sum_power:  
                break  
  
            cnt += 1  
  
        out.append(cnt)  
  
    print('\n'.join(map(str, out)))  
  
if __name__ == "__main__":  
    main()
```
