### 1. 简单情况：直接用 `set` 的 `&` 运算符
当题目只需要求**不重复的交集**，且两个数据源都容易转换为集合时，直接用 `&` 是最直观的做法。

```python
# 适用于：快速写出代码，不需要保留重复元素
nums1 = [1, 2, 2, 1]
nums2 = [2, 2, 3]

# 两边都转成 set，直接用 & 求交集
result = list(set(nums1) & set(nums2))  # [2]
```

---

### 2. 规范情况：用 `set.intersection()` 方法
相比于 `&` 运算符，使用 `intersection()` 方法更灵活。它的好处是：**不需要手动把第二个参数转成集合**，Python 会自动处理。这在写算法题时更规范，也少写了一步转换。

```python
# 适用于：更规范的写法，减少一次 set() 的显式转换
nums1 = [1, 2, 2, 1]
nums2 = [2, 2, 3]  # 可以是列表、元组等任何可迭代对象

# 只需要把 nums1 转成 set，括号里直接传 nums2
result = list(set(nums1).intersection(nums2))  # [2]
```

---

### 3. 需要重复元素：用 `Counter`
当题目要求**保留重复元素**（即交集中元素的频数取决于两者中出现次数的较小值）时，使用 `collections.Counter` 是最标准的解法。

```python
from collections import Counter

# 适用于：LeetCode 350 等需要保留重复频数的题目
nums1 = [1, 2, 2, 1]
nums2 = [2, 2, 3]

# 1. 核心步骤：用 Counter 计算频数，再用 & 取交集（会自动保留较小的频数）
c1 = Counter(nums1)
c2 = Counter(nums2)
intersect_counter = c1 & c2  # 结果类似 {2: 2}

# 2. 用 elements() 还原为列表
result = list(intersect_counter.elements())  # [2, 2]
```

您指出的这个分类结构非常清晰，在实际刷题中，根据这三种情况对号入座，确实能够快速且准确地写出代码。
