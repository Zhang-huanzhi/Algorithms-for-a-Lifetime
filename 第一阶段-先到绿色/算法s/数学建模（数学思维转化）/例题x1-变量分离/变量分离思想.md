“等式变形”（在算法领域常被称为**移项变元**或**变量分离**）是解决双变量或多变量计数问题时最核心、最常用的技巧之一。

这个技巧的核心思想可以总结为一句话：
**将“两个变量之间的相对关系”，转化为“每个变量自身的独立属性”。**

---

### 1. 为什么要进行等式变形？（打破 $O(N^2)$ 的物理限制）

在原始公式中：
$$j - i = A_i + A_j$$

等式的两边同时混杂了 $i$ 和 $j$。如果我们想判断某一个特定的 $j$ 是否能与某个 $i$ 配对，我们必须**同时知道 $i$ 和 $j$ 的位置以及它们的值**。
这意味着，每一个 $j$ 都必须回过头去把所有的 $i$ 挨个扫一遍，这就导致了 $O(N^2)$ 的时间复杂度。

通过移项变形：
$$i + A_i = j - A_j$$

此时，等式的**左边只与 $i$ 有关**，**右边只与 $j$ 有关**。
* 对于位置 $i$，它不再需要关心未来的 $j$ 是谁，它只需要算好自己的专属数值：$P(i) = i + A_i$。
* 对于位置 $j$，它也不需要关心过去的 $i$ 是谁，它只需要算好自己的专属数值：$Q(j) = j - A_j$。

原本复杂的“双人合作关系”（$j-i = A_i+A_j$），变成了**“拿着相同的暗号对接”**（$P(i) = Q(j)$）。我们只需要用一个哈希表把所有 $P(i)$ 的“暗号”收纳起来，当遇到 $Q(j)$ 时直接查表即可。

---

### 2. 这一技巧的通用思考模式

当你看到题目要求满足某种等式的数对 $(i, j)$，且数据范围要求算法达到 $O(N)$ 或 $O(N \log N)$ 时，可以按以下步骤思考：

1. **分离变量**：尝试通过数学运算（加、减、乘、除、异或等），把所有带 $i$ 的项移到左边，带 $j$ 的项移到右边。
2. **定义函数/属性**：将左边整理为关于 $i$ 的独立函数 $f(i)$，右边整理为关于 $j$ 的独立函数 $g(j)$。
   * 本题中：$f(i) = i + A_i$， $g(j) = j - A_j$。
3. **哈希表计数**：遍历数组，用哈希表记录 $f(i)$ 出现的频数，并在遍历到 $j$ 时，直接查询哈希表中 $g(j)$ 的数量。

---

### 3. 常见变形套路示例

这种技巧在各类算法题中广泛存在，以下是几个经典的变形模式：

| 原限制条件（看似需要 $O(N^2)$） | 移项变形后（可利用哈希表 $O(N)$ 解决） |
| :--- | :--- |
| $A_i - A_j = i - j$ | $A_i - i = A_j - j$ |
| $A_i \cdot A_j = i \cdot j$ （假设不为0）| $\frac{A_i}{i} = \frac{j}{A_j}$ |
| $A_i + B_j = C_i - D_j$ | $A_i - C_i = -B_j - D_j$ |
| $A_i \oplus B_j = K$ （$\oplus$ 为异或）| $A_i = K \oplus B_j$ |

### 总结
等式变形的精妙之处在于**化合为零，分而治之**。它免去了我们去逐一比对元素对的繁琐，转而让我们能够独立地计算并记录每个元素自身的特征，从而将时间复杂度从平方级 $O(N^2)$ 降到线性级 $O(N)$。
