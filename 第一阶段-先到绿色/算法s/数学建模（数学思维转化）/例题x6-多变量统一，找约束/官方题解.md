官方题解（Editorial）提供了一个**更加精妙、代码实现更简单**的视角。

我们之前的方法是从“全局总重量 $W$”入手，而官方题解是从**“以第 1 个孩子为基准（以小见大）”**入手。

下面为你详细拆解官方题解的推导逻辑：

---

### 第一步：排序（简化问题）

首先，对 $A$ 数组按升序（从小到大）排序，即：
$$A_1 \le A_2 \le \dots \le A_N$$
排序不会影响最终答案，但这样做让 **$A_1$ 成为了糖果总数最小的孩子**。

---

### 第二步：建立“第 1 个孩子”与“第 $k$ 个孩子”的关系

设孩子 $i$ 分到的大糖果数量为 $x_i$（满足 $0 \le x_i \le A_i$）。

根据题目“所有孩子糖果总重量相等”，我们把**第 1 个孩子**和**第 $k$ 个孩子**的重量公式列出来：
$$(A_1 - x_1)X + x_1Y = (A_k - x_k)X + x_kY$$

把这个方程移项，解出 $x_k$：
$$x_k = x_1 - \frac{(A_k - A_1)X}{Y - X}$$

我们把右边减去的那一大串记为 $D_k$：
$$D_k = \frac{(A_k - A_1)X}{Y - X}$$

于是我们得到了一个极度简洁的关系式：
$$x_k = x_1 - D_k$$

> **关键洞察**：
> 注意看 $D_k$ 的公式，**$D_k$ 的值只由已知条件（$A_k, A_1, X, Y$）决定，与未知数 $x_1, x_k$ 无关！**
> 这意味着：**第 $k$ 个孩子分的大糖果数量，比第 1 个孩子刚好少 $D_k$ 个**。

---

### 第三步：判断是否有解（必要条件）

由于大糖果数量必须是合法的非负整数，对每个 $k$，必须满足以下两个条件：

1. **$D_k$ 必须是整数**：
   因为 $x_1$ 和 $x_k$ 都是整数，它们的差 $D_k$ 也必须是整数。
   也就是说：$(A_k - A_1)X$ 必须能被 $(Y - X)$ 整除。如果不能整除，直接判定无解，输出 `-1`。

2. **$D_k \le A_1$**：
   因为 $x_k = x_1 - D_k$，且大糖果数量不能为负（$x_k \ge 0$），所以 $x_1 \ge D_k$。
   而第 1 个孩子最多只能拿 $A_1$ 个大糖果（$x_1 \le A_1$）。
   如果连最大允许的 $x_1 = A_1$ 都满足不了 $x_1 \ge D_k$（即 $D_k > A_1$），那么孩子 $k$ 的大糖果数量就必定会变成负数！
   因此，必须满足 $D_k \le A_1$，否则判定无解，输出 `-1`。

---

### 第四步：贪心求解（充分条件与答案）

既然对所有的 $k$，都有：
$$x_k = x_1 - D_k$$

要让**所有孩子的大糖果总和 $\sum x_k$ 尽可能大**，显然只需要让 **$x_1$ 尽可能大**！

$x_1$ 最大能取多少？根据定义，$x_1$ 最大只能取 $A_1$（即第 1 个孩子**全部拿大糖果**）。

因此，最优解直接确定：
* 令 $x_1 = A_1$
* 则 $x_k = A_1 - D_k$

最终答案就是所有 $x_k$ 的累加和：
$$\text{Ans} = \sum_{k=1}^N (A_1 - D_k)$$

---

### 官方题解代码实现（非常短）

如果你用官方题解的思路写 Python 代码，会比之前更简洁：

```python
import sys


def main():
    n, x, y = map(int, sys.stdin.readline().strip().split())
    a = list(map(int, sys.stdin.readline().strip().split()))

    # 1. 排序，让 a[0] 成为最小值 A_1
    a.sort()

    a1 = a[0]
    dy = y - x
    ans = 0

    # 2. 遍历每个孩子，计算 D_k 并检查
    for ak in a:
        num = (ak - a1) * x

        # 条件 1：必须能整除
        if num % dy != 0:
            print(-1)
            return

        dk = num // dy

        # 条件 2：D_k 不能超过 A_1
        if dk > a1:
            print(-1)
            return

        # 累加 x_k = A_1 - D_k
        ans += a1 - dk

    print(ans)


if __name__ == "__main__":
    main()
```

### 两种思路的对比总结

| 思路 | 视角 | 好处 |
| :--- | :--- | :--- |
| **我们之前的思路** | **全局重量 $W$** | 逻辑非常符合直觉，不需要预先排序。 |
| **官方题解思路** | **以最小的 $A_1$ 为基准** | 极其优雅，省去了余数向下取整的调整，代码逻辑更清晰。 |

官方题解的核心精髓就在于：**利用排序锁定“瓶颈孩子”（$A_1$），直接假设他全拿大糖果（$x_1 = A_1$），以此推导其他人！**
