### C - Candy Tribulation

**时间限制：** 2 秒 / **内存限制：** 1024 MiB  
**分值：** 350 分

#### 题目描述
你有无限量的两种糖果：小糖果和大糖果。小糖果的重量为 $X$ 克，大糖果的重量为 $Y$ 克。大糖果比小糖果重（即 $X < Y$）。

有 $N$ 个孩子，他们的编号分别为 $1$ 到 $N$。

你决定按照以下条件将糖果分发给他们：

* 对于每个 $i = 1, \dots, N$，分发给孩子 $i$ 的两类糖果的总数量**恰好**为 $A_i$ 个。
* 分发给这 $N$ 个孩子**每个人**的糖果**总重量都相等**。

请判断是否存在满足条件的分配方案。如果存在，请求出所有满足条件的方案中，分发的大糖果数量的最大可能值。

#### 数据范围 / 制约条件
* $2 \le N \le 2 \times 10^5$
* $1 \le A_i \le 10^9$
* $1 \le X < Y \le 10^9$
* 输入的所有数值均为整数。

#### 输入格式
输入按以下格式从标准输入给出：

> $N$ $X$ $Y$  
> $A_1$ $\dots$ $A_N$

#### 输出格式
如果不存在满足条件的分配方案，输出 `-1`。  
如果存在满足条件的分配方案，输出分发的大糖果数量的最大可能值。

---

#### 样例 1
**输入**
```text
3 6 8
11 10 13
```

**输出**
```text
18
```

**样例说明 1**  
按照如下方式分发糖果，可以使分发给每个孩子的糖果总重量完全相等：
* **孩子 1**：分发 4 个小糖果和 7 个大糖果。总重量为 $6 \times 4 + 8 \times 7 = 80$ 克。
* **孩子 2**：分发 0 个小糖果和 10 个大糖果。总重量为 $6 \times 0 + 8 \times 10 = 80$ 克。
* **孩子 3**：分发 12 个小糖果和 1 个大糖果。总重量为 $6 \times 12 + 8 \times 1 = 80$ 克。

这种方案中，一共分发了 $18$ 个大糖果。  
不存在能分发超过 $18$ 个大糖果且满足条件的方案，因此答案为 $18$。

``` python
import sys  
  
def main():  
    n, x, y = map(int, sys.stdin.readline().strip().split())  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    d = y - x  
    a_max = max(arr)  
    a_min = min(arr)  
  
    # 1. 检查余数条件：所有 (X * A_i) % D 必须相同  
    rem = (x * arr[0]) % d  
    for a in arr:  
        if (x * a) % d != rem:  
            print(-1)  
            return  
  
    # 2. 求出重量 W 的理论上限：Y * A_min  
    w_ub = y * a_min  
  
    # 3. 将上限向下调整，使其余数与 (X * A_1) % D 一致  
    w = w_ub - ((w_ub - x * arr[0]) % d)  
  
    # 4. 检查调整后的 W 是否满足下限条件：W >= X * A_max  
    if w < x * a_max:  
        print(-1)  
        return  
  
    # 5. 计算并输出大糖果的总数量  
    ans = sum((w - x * a) // d for a in arr)  
    print(ans)  
  
  
if __name__ == "__main__":  
    main()
```
