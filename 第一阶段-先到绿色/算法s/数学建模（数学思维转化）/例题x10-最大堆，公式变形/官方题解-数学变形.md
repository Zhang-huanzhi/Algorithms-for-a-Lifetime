官方题解的思路非常精妙且优雅。它通过数学变形，将一个看似需要复杂分类讨论的问题，简化为了一个**普通的优先队列（堆）**问题。

下面为您详细拆解官方题解的逻辑：

---

### 一、 核心数学变形

对于在时刻 $t_0$ 插入、初始电量为 $w_0$ 的电池，在当前的时刻 $t$（满足 $t \ge t_0$），它的电量公式为：
$$w = \min(w_0 + (t - t_0), \, V)$$

我们可以把括号拆开，并重新组合：
$$w = \min(t + (w_0 - t_0), \, V)$$

此时，我们定义一个每个电池专属的常数 $u_0$：
$$u_0 := w_0 - t_0$$

代入后，电量公式变为了：
$$w = \min(t + u_0, \, V)$$

---

### 二、 关键性质分析

#### 1. 单调性
在任意给定的查询时刻 $t$，函数 $f(u_0) = \min(t + u_0, \, V)$ 关于 $u_0$ 是**广义单调递增**的（即非严格单调递增）。

这意味着：对于任意两个电池 $A$ 和 $B$，如果 $u_A > u_B$，那么在任何时刻 $t$，电池 $A$ 的电量都必然**大于或等于**电池 $B$ 的电量：
$$\min(t + u_A, \, V) \ge \min(t + u_B, \, V)$$

#### 2. 决策的贪心选择
既然 $u_0$ 较大的电池在任何时刻的电量都**大于或等于** $u_0$ 较小的电池：
*   如果我们要排出“电量最大”的电池，我们**只需要贪心地选择当前所有电池中 $u_0$ 最大的那一个**。
*   即使存在多个电池电量同时达到上限 $V$ 的情况（此时它们电量相等），我们依然可以直接选择其中 $u_0$ 较大的那个，这不会影响结果的正确性。

---

### 三、 结论与算法设计

因为“电量最大”的电池永远是 “$u_0$ 最大”的电池，所以：
1.  **类型 1（插入）**：计算该电池的 $u_0 = w_q - t_q$，将其放入一个**最大堆**中。
2.  **类型 2（弹出）**：直接从最大堆中弹出 $u_0$ 最大的电池。该电池在时刻 $t$ 的实际电量即为 $\min(t + u_0, \, V)$。

这个转化非常漂亮，它不仅不需要区分电池是否“充满”，也**不需要使用懒惰删除**。每个电池只需要进出一次堆，时间复杂度仅为 $O(Q \log Q)$。

---

### 四、 基于官方题解的 Python 代码实现

使用该方法编写的代码会极其简练：

```python
import heapq
import sys

def main():
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    q = int(input_data[0])
    v = int(input_data[1])

    # Python 的 heapq 默认是最小堆
    # 我们存入 -u_0 从而实现最大堆
    max_heap = []
    
    idx = 2
    outs = []
    for _ in range(q):
        op = input_data[idx]
        if op == '1':
            t = int(input_data[idx+1])
            w = int(input_data[idx+2])
            idx += 3
            
            # 计算 u_0 = w - t
            u0 = w - t
            heapq.heappush(max_heap, -u0)
            
        elif op == '2':
            t = int(input_data[idx+1])
            idx += 2
            
            if not max_heap:
                outs.append(-1)
            else:
                # 取出最大 u_0 的电池
                max_u0 = -heapq.heappop(max_heap)
                # 计算其当前时刻的实际电量
                current_w = min(t + max_u0, v)
                outs.append(current_w)

    print('\n'.join(map(str, outs)))

if __name__ == "__main__":
    main()
```
