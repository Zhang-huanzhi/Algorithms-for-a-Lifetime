### D - Chargers

时间限制: 2 秒 / 内存限制: 1024 MiB

分值 : 400 分

#### 题目描述

有一个拥有无限个插槽的充电器。在时刻 $0$ 时，所有插槽都是空的。

电池的最大容量为 $V$。只要电池插入插槽，它就会以速度 $1$ 进行充电，直到电量达到最大容量（也就是说，每经过 $1$ 个单位时间，电量就增加 $1$）。

请依次处理 $Q$ 个查询。  
第 $q$ 个查询以以下格式给出。此外，保证 $t_1 < \dots < t_Q$。

*   **类型 1 (`1 t_q w_q`)**：在时刻 $t_q$，将一个初始电量为 $w_q$ 的电池插入一个空插槽中。
*   **类型 2 (`2 t_q`)**：在时刻 $t_q$，从插槽中取出一个当前电量最多的电池，并输出该电池的电量。如果当前没有任何插槽中有电池，则输出 `-1`。

#### 数据范围

*   $1 \le Q \le 3 \times 10^5$
*   $1 \le V \le 10^9$
*   在类型 1 的查询中，$1 \le t_q \le 10^9$
*   在类型 1 的查询中，$0 \le w_q \le V$
*   在类型 2 的查询中，$1 \le t_q \le 10^9$
*   $t_1 < \dots < t_Q$
*   输入的所有值均为整数。

#### 输入格式

输入按以下格式从标准输入给出：

$$Q \quad V$$
$$\text{query}_1$$
$$\vdots$$
$$\text{query}_Q$$

其中，$\text{query}_q$ 表示第 $q$ 个查询，以以下两种格式之一给出：

`1 t_q w_q`

`2 t_q`

#### 输出格式

设类型 2 的查询数量为 $x$，输出 $x$ 行。

第 $k$ 行（$1 \le k \le x$）应当输出第 $k$ 个类型 2 查询所得到的值。

**样例 1 说明：**

按以下顺序处理 7 个查询：

*   在时刻 $15$，插入一个电量为 $60$ 的电池。此时，充电器中有一个电量为 $60$ 的电池。
*   在时刻 $25$，插入一个电量为 $80$ 的电池。此时，充电器中电池的电量分别为 $70$ 和 $80$。
*   在时刻 $30$，充电器中电池的电量分别为 $75$ 和 $85$。其中，取出电量最多的电池（电量为 $85$）。
*   在时刻 $45$，插入一个电量为 $0$ 的电池。此时，充电器中电池的电量分别为 $0$ 和 $90$。
*   在时刻 $60$，充电器中电池的电量分别为 $15$ 和 $100$（另一块电池已在时刻 $55$ 达到最大容量 $100$）。其中，取出电量最多的电池（电量为 $100$）。
*   在时刻 $70$，充电器中仅剩一个电量为 $25$ 的电池。取出该电池（电量为 $25$）。
*   在时刻 $80$，充电器中没有插入任何电池，因此输出 `-1`。

# SB代码
``` python
import heapq
import sys

def main():

    q, v = map(int, sys.stdin.readline().strip().split())

    # 时间驱动模拟
    curr = 0
    # 随时返回最大，最大堆呀
    arr = []
    outs = []
    for _ in range(q):
        line = list(sys.stdin.readline().strip().split())

        op = line[0]

        if op == '1':
            t, w = int(line[1]), int(line[2])
            heapq.heappush(arr, [-w, w, t])

        if op == '2':
            t = int(line[1])

            for i in range(len(arr)):

                arr[i][0] = -arr[i][1] - t + arr[i][2]
                arr[i][0] = max(-v, arr[i][0])

            heapq.heapify(arr)

            if arr:
                out = heapq.heappop(arr)
            else:
                out = [1]

            outs.append(-out[0])

    print('\n'.join(map(str, outs)))



if __name__ == "__main__":
    main()
```

# AC Code
``` python
import heapq  
import sys  
  
def main():  
  
    q, v = map(int, sys.stdin.readline().strip().split())  
  
    # 随时返回最大，最大堆呀  
    arr = []  
    outs = []  
    for _ in range(q):  
        line = list(sys.stdin.readline().strip().split())  
  
        op = line[0]  
  
        if op == '1':  
            t, w = int(line[1]), int(line[2])  
            heapq.heappush(arr, -(w - t))  
  
        if op == '2':  
            t = int(line[1])  
  
            if arr:  
                x = heapq.heappop(arr)  
  
                x = max(x - t, -v)  
            else:  
                x = 1  
            outs.append(-x)  
  
    print('\n'.join(map(str, outs)))  
  
  
if __name__ == "__main__":  
    main()
```
