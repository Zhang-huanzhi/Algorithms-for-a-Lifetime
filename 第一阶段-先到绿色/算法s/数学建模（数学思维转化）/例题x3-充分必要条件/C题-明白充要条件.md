
### C - AtCoder AAC Contest
Time Limit: 2 sec / Memory Limit: 1024 MiB

分数：300 分

#### 问题描述
高桥君有一些字符。起初，高桥君拥有 $n_A$ 个 `A`、$n_B$ 个 `B` 和 $n_C$ 个 `C`。

高桥君可以通过使用 **1 个 `A`、1 个 `C` 以及任意 1 个其他字符（共计 3 个字符）** 来举办一场比赛。具体来说：
* 使用 2 个 `A` 和 1 个 `C` 可以举办 AAC 比赛。
* 使用 `A`、`B`、`C` 各 1 个可以举办 ABC 比赛。
* 使用 1 个 `A` 和 2 个 `C` 可以举办 ACC 比赛。

高桥君希望利用现有的字符，尽可能多地举办比赛。请问高桥君最多可以举办多少场比赛？

本题包含 $T$ 组测试数据，请对每组测试数据分别进行求解。

#### 数据范围
* $1 \le T \le 2 \times 10^5$
* 对于每组测试数据：
  * $0 \le n_A \le 10^9$
  * $0 \le n_B \le 10^9$
  * $0 \le n_C \le 10^9$
* 所有输入均为整数。

#### 输入格式
输入通过标准输入给出，格式如下：

$$T$$
$$\text{testcase}_1$$
$$\text{testcase}_2$$
$$\vdots$$
$$\text{testcase}_T$$

每个测试数据 $\text{testcase}_i$ （$1 \le i \le T$）的格式如下：

$$n_A \quad n_B \quad n_C$$

#### 输出格式
输出共 $T$ 行。第 $i$ 行（$1 \le i \le T$）输出第 $i$ 个测试数据的答案（最多可举办的比赛数量）。

#### 样例输入 1
```text
5
3 1 2
100 0 0
1000000 1000000 1000000
31 41 59
1000000000 10000 1
```

#### 样例输出 1
```text
2
0
1000000
31
1
```

#### 样例说明 1
在第 1 组测试数据中，可以举办 1 次 AAC 和 1 次 ABC，共计 2 次比赛。因此第 1 行输出 `2`。
