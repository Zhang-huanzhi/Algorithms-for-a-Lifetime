### C - AtCoder Riko

**时间限制**: 2 秒 / **内存限制**: 1024 MiB  
**分值**: 350 分

#### 问题描述
给定一个长度为 $N$ 的正整数序列 $A = (A_1, A_2, \dots, A_N)$。

请找出所有可能满足以下情况的正整数 $L$。

AtCoder 公司发售了一款棒状零食“AtCoder Riko”。起初，杯子里装有若干根长度为 $L$ 的 AtCoder Riko。高桥君摇晃了杯子，导致每根 AtCoder Riko 都变成了以下两种状态之一：
* 保持原样，仍为一根长度为 $L$ 的 AtCoder Riko。
* 断裂为两根 AtCoder Riko，且这两根的长度之和为 $L$。需要注意的是，断裂后的每根 AtCoder Riko 的长度也必须是正整数。

摇晃杯子后，杯中共有 $N$ 根 AtCoder Riko，其中第 $i$ 根的长度为 $A_i$。  
保证输入的数据中，至少存在一个满足上述条件的正整数 $L$。

#### 数据范围
* $1 \le N \le 3 \times 10^5$
* $1 \le A_i \le 10^9$
* 保证至少存在一个满足条件的 $L$。
* 所有输入的值均为整数。

#### 输入格式
输入按以下格式从标准输入给出：

$$N$$
$$A_1 \quad A_2 \quad \dots \quad A_N$$

#### 输出格式
在单行中输出所有满足条件的 $L$，按升序排列，中间用空格隔开。

---

#### 样例输入 1
```text
4
10 5 5 10
```

#### 样例输出 1
```text
10 15
```
**样例解释 1**：  
* 若 $L = 10$：起初杯中装有 3 根长度为 $10$ 的 AtCoder Riko。在摇晃后，其中 1 根断裂为两根长度为 $5$ 的 AtCoder Riko，其余两根保持原样。此时杯中的长度序列为 $10, 5, 5, 10$，满足条件。
* 若 $L = 15$：起初杯中装有 2 根长度为 $15$ 的 AtCoder Riko。在摇晃后，每一根都分别断裂为长度为 $5$ 和 $10$ 的两根。此时可以得到两组 $5$ 和 $10$，即 $10, 5, 5, 10$，满足条件。
* 除 $10$ 和 $15$ 之外，没有其他 $L$ 满足条件。

---

```text
3
4 4 4
```

#### 样例输出 2
```text
4
```

import sys
import bisect
from collections import Counter, deque
import math
import itertools
import heapq



def main():
    n = int(sys.stdin.readline().strip())
    arr = list(map(int, sys.stdin.readline().strip().split()))

    arr.sort()

    candidate1 = arr[-1]
    candidate2 = arr[-1] + arr[0]

    brr = []

    def check(target_L):
        l = 0
        r = n-1
        while l <= r:
            if arr[r] == target_L:
                r -=1
            elif l < r and arr[l] + arr[r] == target_L:
                l +=1
                r -=1
            else:
                return False
        return True

    if check(candidate1):
        brr.append(candidate1)
    if check(candidate2):
        brr.append(candidate2)

    print(*brr)

if __name__ == "__main__":
    main()
