结论：在网格大小超过 200×200 时，在 Python 中不建议使用递归 DFS。

虽然上面的递归代码在设置了 sys.setrecursionlimit 后可以通过，但在 Python 中，递归非常慢且耗内存。

在参加 AtCoder 或其他算法竞赛时，处理 1000×1000 级别的网格，建议练习使用显式栈（Stack）的迭代 DFS 或队列（Queue）的 BFS。
