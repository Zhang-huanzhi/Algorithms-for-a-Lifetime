### 1. 容器选择：使用字典 (Hash Map)

不要用列表或队列，直接用一个字典来存储。

*   **Key (键)**：状态本身（本题中是**坐标**）。
*   **Value (值)**：该状态下的最优结果（本题中是**经过 0 的最大次数**）。

```python
# 初始状态：在坐标 0.5，经过 0 的次数为 0
dp = {0.5: 0}
```

### 2. 滚动更新：双容器模式

为了防止在遍历字典的同时修改它（这会导致错误），我们每一轮迭代都创建一个新的空字典用于存放本轮产生的新状态。

```python
for length in arr:
    new_dp = {} # 每一轮都开一个新的，用来存放本轮产生的所有坐标
    for pos, cnt in dp.items():
        # ... 计算 next_pos 和 new_cnt ...
```

### 3. 更新逻辑：取最大值 (The Max Logic)

这是“压缩/合并”状态的灵魂。当多条不同的路径到达同一个新坐标时，我们只保留那个带来了更优结果（即更大 `cnt` 值）的路径。通过 `if` 判断或 `max()` 函数即可实现。

**核心写法：**
```python
# 如果新状态 new_cnt 比 new_dp 中记录的更好，或者 new_dp 中还没有这个状态，就更新它
if new_cnt > new_dp.get(next_pos, -1):
    new_dp[next_pos] = new_cnt
```

### 简要总结代码模板

1.  **初始化状态**
    ```python
    dp = {初始状态: 初始价值}
    ```

2.  **遍历每一个阶段**（例如 N 轮移动）
    ```python
    for item in arr:
        new_dp = {}
    ```

3.  **遍历当前所有可能的状态**（此时状态已经过去重）
    ```python
    for state, value in dp.items():
    ```

4.  **尝试所有可能的转移**（例如向左/向右）
    ```python
    for choice in [左, 右]:
        new_state = 计算新状态(state, choice)
        new_value = 计算新价值(value, 状态转移)
    ```

5.  **合并！如果新状态已存在，只保留更优的那个**
    ```python
    if new_value > new_dp.get(new_state, -1):
        new_dp[new_state] = new_value
    ```

6.  **用新状态覆盖旧状态，进入下一轮**
    ```python
    dp = new_dp
    ```

---

> #### 为什么这叫“压缩”？
>
> 因为它把 **“指数级增长的路径”** 压缩成了 **“有限数量的状态”**。
>
> 在朴素的暴力搜索中，**路径**是主角；在这个动态规划解法中，**坐标（状态）**是主角。只要最终坐标相同，无论你是通过哪条路径到达的，我们都将它们视为同一个状态并进行合并，只保留最优的那个。
