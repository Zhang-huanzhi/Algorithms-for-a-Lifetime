### D - 勇往直前  
  
**时间限制：** 2 秒 / **内存限制：** 1024 MiB  
  
**分值：** 425 分  
  
#### 问题描述  
  
在一个 `H` 行 `W` 列的网格中，高桥君可以在其中上下左右移动。  
从上往下第 `i` 行、从左往右第 `j` 列（1≤i≤H, 1≤j≤W）的格子状态由字符 `S_i,j` 表示。  
`S_i,j` 是 `#`, `.`, `o`, `x`, `S`, `G` 中的一种。  
  
*   `S_i,j = '#'`：**墙壁**。无法进入这个格子。  
*   `S_i,j = '.'`：**普通路径**。可以自由进出。进入此格后，可以移动到上、下、左、右任一相邻的格子（如果存在且不是墙壁）。  
*   `S_i,j = 'o'`：**直行格**。进入此格后，**必须**与上一步以**相同的方向**继续移动。  
*   `S_i,j = 'x'`：**转向格**。进入此格后，**必须改变方向**移动。注意，180度掉头回到来的格子也算作改变方向。  
*   `S_i,j = 'S'`：**起点**。高桥君最初所在的位置。这个格子的行为与普通路径 `.` 相同。  
*   `S_i,j = 'G'`：**终点**。高桥君的目标位置。这个格子的行为与普通路径 `.` 相同。  
  
网格中保证有且仅有一个 `S` 和一个 `G`。  
  
高桥君希望从起点 `S` 开始，通过重复地向相邻格子移动，最终到达终点 `G`。请你判断这是否可能。如果可能，请输出一个满足条件的移动路径，且移动步数（即路径长度）**不超过 5 × 10<sup>6</sup>**。  
  
可以证明，如果存在一条可行的路径，那么一定存在一条长度不超过 5 × 10<sup>6</sup> 的路径。此外，只要路径长度满足要求，你**不需要**找出最短路径。  
  
#### 约束条件  
  
*   1 ≤ H, W ≤ 1000  
*   `S_i,j` 是 `#`, `.`, `o`, `x`, `S`, `G` 中的一种。  
*   `S` 和 `G` 在网格中各只出现一次。  
*   H, W 是整数。  
  
#### 输入  
  
输入将通过标准输入按以下格式给出：  
```  
H W  
S_1,1 S_1,2 ... S_1,W  
S_2,1 S_2,2 ... S_2,W  
...  
S_H,1 S_H,2 ... S_H,W  
```  
  
#### 输出  
  
如果无法到达终点，输出一行 `No`。  
  
如果可以到达终点，则：  
1.  第一行输出 `Yes`。  
2.  第二行输出一个代表移动路径的字符串 `T`。  
  
字符串 `T` 必须满足以下所有条件：  
*   `T` 的长度 `|T|` 在 1 到 5 × 10<sup>6</sup> 之间。  
*   `T` 的每个字符都是 `U`, `D`, `L`, `R` 中的一个，分别代表向上、向下、向左、向右移动。  
*   对于 `1 ≤ i ≤ |T|`，第 `i` 次移动后，高桥君不能移出网格边界。  
*   整个移动过程中不能违反任何格子的规则。  
*   在第 `|T|` 次移动后，高桥君必须位于终点 `G`。在此之前经过终点也是允许的。  
  
---  
  
#### 输入样例 1  
```  
3 5  
.#...  
.Sooo  
..x.G  
```  
  
#### 输出样例 1  
```  
Yes  
DRUUDDRR  
```  
将第 `i` 行第 `j` 列的格子记为 `(i,j)`。  
按照样例输出的路径，移动顺序为：`(2,2) → (3,2) → (3,3) → (2,3) → (1,3) → (2,3) → (3,3) → (3,4) → (3,5)`，最终到达终点。  
其他合法的路径，如 `DRUURLRRDD` 也是正确答案。  
但是，由于不能在 `(3,3)` 这个 `x` 格子上直行，所以像 `DRRR` 这样的路径是不合法的。
