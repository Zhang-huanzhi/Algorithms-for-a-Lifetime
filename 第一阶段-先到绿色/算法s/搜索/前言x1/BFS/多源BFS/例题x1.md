### D - 逃生路线
**执行时间限制: 2 秒 / 内存限制: 1024 MiB**

**分数 : 400 分**

#### 问题描述
有一天，参观电影院的高桥君决定在馆内所有的地板上画上指向最近紧急出口的箭头。

给定一个纵向 H 格、横向 W 格的网格。从上往下第 i 行、从左往右第 j 列的格子称为 (i,j)。
每个格子的状态由以下任一字符 S<sub>i,j</sub> 表示。

*   `.` : 通道格
*   `#` : 墙壁格
*   `E` : 紧急出口

对于任意通道格 (i,j)，(i,j) 与最近紧急出口的距离 d(i,j) 定义如下：

> 从 (i,j) 出发，通过反复移动到上下左右相邻的非墙壁格来到达紧急出口时，所需的最少移动次数。

在此，保证对于输入给定的网格，所有通道格的 d(i,j) 都是可以定义的。也就是说，对于所有通道格 (i,j)，至少存在一个仅通过通道格即可到达的紧急出口。

此时，请为所有通道格画上“上、下、左、右”任一方向的箭头，以满足以下条件：

> 对于每个通道格 (i,j)，从 (i,j) 的状态开始，执行以下操作 d(i,j) 次后，能够到达紧急出口。
>
> *   按照当前所在格子画的箭头方向移动 1 格。（但是，不能移动到墙壁格或网格之外。）

#### 约束
*   2 ≤ H ≤ 1000
*   2 ≤ W ≤ 1000
*   S<sub>i,j</sub> 是 `.`、`#` 或 `E`
*   对于所有通道格 (i,j)，都能够从该处到达某个紧急出口
*   H, W 是整数

#### 输入
输入按以下格式从标准输入给出。
```
H W
S_1,1 S_1,2 ... S_1,W
S_2,1 S_2,2 ... S_2,W
...
S_H,1 S_H,2 ... S_H,W
```

#### 输出
画上箭头后，格子 (i,j) 的状态为 T<sub>i,j</sub>。
T<sub>i,j</sub> 是以下之一：

*   `^` : 画有上箭头的通道格
*   `v` : 画有下箭头的通道格
*   `<` : 画有左箭头的通道格
*   `>` : 画有右箭头的通道格
*   `#` : 墙壁格
*   `E` : 紧急出口

请按以下格式输出。
```
T_1,1 T_1,2 ... T_1,W
T_2,1 T_2,2 ... T_2,W
...
T_H,1 T_H,2 ... T_H,W
```
如果存在多个答案，输出任意一个都将被视为正确。

---

#### 输入示例 1
```
3 4
...E
.#..
....
```

#### 输出示例 1
```
>>>E
^#>^
>>>^
```
我们来确认输出示例中 (2,3) 的情况是否满足问题描述的条件。
(2,3) 与最近紧急出口的距离是 2。并且，按照输出示例中画的箭头移动，可以通过 2 次移动到达紧急出口。
可以确认其他通道格也满足问题描述的条件。
