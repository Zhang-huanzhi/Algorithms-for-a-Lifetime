``` python
for row in res:

```

当然无论你怎么写，时间复杂度基本上都是O(H×W)：
只是说写两个for循环会有很多的IO操作，多次调用Print会比较耗时，不太好

### 1. 性能优化：减少 I/O 操作次数

在 Python 中，`print` 是一个相对昂贵的操作。

*   **低效写法：**
    ```python
    for i in range(h):for i in range(h):
        for j in range(w):
            print(res[i][j], end="") # 频繁调用 print
        print() # 每行结束后再换行
    ```
    如果网格是 1000 × 1000，这意味着你要调用 10<sup>6</sup> 次 `print` 函数。在 Python 中，每一次 `print` 调用都会涉及缓冲区刷新、系统调用等开销。在 2 秒的时间限制下，海量的 `print` 调用极大概率会导致 TLE（超时）。

*   **高效写法：**
    ```python
    for row in res:
        print("".join(row))
    ```
    这里只调用了 H 次 `print`（即 1000 次）。`"".join(row)` 在内存中将整行拼接成一个字符串，然后一次性交给标准输出。这极大减轻了 I/O 负担，是处理大规模网格输出的标准操作。

### 2. 内存与可读性：`join` 的威力

`res` 是一个二维列表（即 `[[...], [...], [...]]`）。

*   `"".join(row)` 的作用是将列表 `row` 中的所有字符（如 `['>', '>', 'E']`）合并为一个完整的字符串（即 `">>E"`）。
*   这种处理方式在逻辑上非常清晰：它直接符合题目要求的“按行输出”的格式。

### 3. Python 列表的特性

*   在 Python 中，列表的元素拼接（通过 `join`）是在底层 C 代码中实现的，速度非常快。
*   如果你直接 `print(row)`，Python 会打印出 `['>', '>', 'E']`（带方括号和逗号，这明显不符合题目输出格式要求）。
*   `"".join(row)` 正好去掉了多余的符号，把列表还原成了题目要求的“紧凑字符串格式”。
