**核心原则： 当你发现自己在循环中反复计算 sum(arr[i+1:]) 时，就该用后缀和优化了**

| 特性  | 前缀和                                | 后缀和                                |
| --- | ---------------------------------- | ---------------------------------- |
| 方向  | 从左到右                               | 从右到左                               |
| 公式  | `prefix[i] = prefix[i-1] + arr[i]` | `suffix[i] = suffix[i+1] + arr[i]` |
| 查询  | `[0, i]` 的和                        | `[i, n-1]` 的和                      |
| 适用  | 大多数场景                              | 逆序、从后向前的问题                         |
