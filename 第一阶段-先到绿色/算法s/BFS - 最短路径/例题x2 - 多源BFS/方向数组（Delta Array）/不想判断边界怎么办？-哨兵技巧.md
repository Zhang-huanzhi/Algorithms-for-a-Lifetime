
降维打击 —— “围墙/哨兵”技巧（Padding / Sentinel）
其实写网格题最烦的，根本不是枚举方向，而是那句 `if 0 <= nr < h and 0 <= nc < w:`。这句判断在最内层循环会被执行几百万次。

**怎么消灭这句恶心的边界判断？答案是：给地图建一圈“围墙”！**

题目输入如果是：
```text
#.#
.#.
```
我们在读入的时候，故意在外面包一圈永远不会触发条件的符号（比如本题中，我们包一圈 `.`）：
```text
.....
.#.#.
..#..
.....
```
**代码实现：**
```python
h, w = map(int, input().split())

# 建立一个 (h+2) x (w+2) 的加大版地图，外层全是 '.'
arr = [['.'] * (w + 2) for _ in range(h + 2)]

for i in range(1, h + 1):
    row = list(input().strip())
    for j in range(1, w + 1):
        arr[i][j] = row[j - 1]

# 之后遍历真实地图区域时 (1 到 h, 1 到 w)，永远不需要再判断边界！
for i in range(1, h + 1):
    for j in range(1, w + 1):
        for dr, dc in directions:
            # 放心大胆地直接取，绝对不会数组越界 (IndexError)！
            if arr[i + dr][j + dc] == '#':
                pass
```
**评价：** 这是非常高阶的代码洁癖技巧！它去掉了内层循环的分支预测（Branching），不仅让代码清爽无比，还能让程序运行速度微微提升。在 C++ / Java 中这种技巧极其常用。
