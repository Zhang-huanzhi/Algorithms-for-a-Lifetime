
### 技巧 4：终极降维 —— 1D 数组压平（Flatten）
在一些性能要求极高的图论题（或者寻路算法）中，二维数组 `arr[r][c]` 的访问速度其实是不如一维数组 `arr[index]` 的。
我们可以把 $H \times W$ 的二维地图，变成一个长度为 $H \times W$ 的一维数组。

* 坐标转换：`(r, c)` -> `index = r * W + c`
* 向上走一步 `(r-1, c)` -> `index - W`
* 向下走一步 `(r+1, c)` -> `index + W`
* 向左走一步 `(r, c-1)` -> `index - 1`

**此时，方向数组变成了常数：**
```python
# 四向
directions = [-w, w, -1, 1] 

for step in directions:
    next_idx = current_idx + step
    # 直接用一维索引访问
```
**评价：** 适合高级图论和状态压缩 DP。结合前面的“围墙”技巧，你可以把网格完全变成一个一维数组，写出世界上执行效率最快的 BFS。
