
# D - Repeatedly Repainting 

时间限制: 2 秒 / 内存限制: 1024 MiB  
分值: 425 分

### 问题描述

有一个 $H$ 行 $W$ 列的网格。我们用 $(i,j)$ 表示从上数第 $i$ 行、从左数第 $j$ 列的格子。

每个格子都被涂成了白色或黑色。网格的初始状态由 $H$ 个长度为 $W$ 的字符串 $S_1, S_2, \dots, S_H$ 给出。如果 $S_i$ 的第 $j$ 个字符是 `.`，则格子 $(i,j)$ 为白色；如果 $S_i$ 的第 $j$ 个字符是 `#`，则格子 $(i,j)$ 为黑色。

你需要执行以下操作 $10^{100}$ 次：

* 同时对所有格子按照以下规则进行颜色重绘：
  * **对于操作前被涂成白色的格子**：当且仅当其邻域中存在被涂成黑色的格子时，它才会被重绘为黑色。这里，格子 $(x,y)$ 与格子 $(x',y')$ 相邻是指一个格子处于另一个格子的 8-邻域中，即满足 $\max(|x-x'|, |y-y'|)=1$。
  * **对于操作前被涂成黑色的格子**：会被重绘为白色。

请在所有操作完成后，求出每个格子的最终颜色。

### 限制条件

* $1 \le H \times W \le 10^6$
* $H, W$ 是正整数。
* $S_i$ 是长度为 $W$ 且仅由 `.` 和 `#` 组成的字符串。

### 输入格式

输入按以下格式从标准输入给出：

$$H \quad W$$  
$$S_1$$  
$$S_2$$  
$$\vdots$$  
$$S_H$$

### 输出格式

输出 $H$ 行。

每行输出一个长度为 $W$ 且仅由 `.` 和 `#` 组成的字符串。

第 $i$ 行字符串的第 $j$ 个字符应当表示在进行 $10^{100}$ 次操作后格子 $(i,j)$ 的颜色：如果为白色则输出 `.`，如果为黑色则输出 `#`。

---

### 样例输入 1

```text
3 4
#.#.
.#..
#...
```

### 样例输出 1

```text
#.#.
.#..
#..#
```

* 初始时，网格如下：
  ```text
  #.#.
  .#..
  #...
  ```
* 进行 1 次操作后，网格如下：
  ```text
  .###
  #.#.
  .##.
  ```
* 进行 $10^{100}$ 次操作后，网格状态如样例输出所示。


### 样例输出 2

```text
...

...
```
