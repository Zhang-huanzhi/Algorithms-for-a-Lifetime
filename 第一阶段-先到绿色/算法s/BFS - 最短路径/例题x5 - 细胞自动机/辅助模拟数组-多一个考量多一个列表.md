在修改后的 Python 代码中，一共创建了 **5 个** 主要的一维数组（或列表结构），每个数组分工明确，共同实现了高效的 $O(HW)$ 模拟。

以下是这些数组的详细清单及具体用途：

---

### 1. `arr` (输入网格)
- **类型**：一维列表（大小为 $H \times W$）
- **用途**：存储从标准输入读取的原始网格字符（`#` 或 `.`）。
- **作用**：仅用于初始化的第一步，帮助我们找出哪些格子一开始就是黑色的（即字符为 `#` 的格子）。初始化完成后，该数组不再被使用。

---

### 2. `black` (黑白状态标记数组)
- **类型**：布尔型一维数组（大小为 $H \times W$，初始值全为 `False`）
- **用途**：记录每个格子**当前是否已经是黑色**。
- **作用**：
  - 防止重复处理：在扩散时，只有 `black[v] == False` 的白格才会被波及并累加计数。
  - 最终计数：在程序结束时，有多少个元素的 `black` 值为 `True`，最终答案就是多少。

---

### 3. `cnt` (邻居黑格计数器)
- **类型**：整型一维数组（大小为 $H \times W$，初始值全为 `0`）
- **用途**：记录**每个白格周围目前紧邻着几个黑格**。
- **作用**：
  - 状态转移判定：在每一步结束时，只有 `cnt[v] == 1` 的白格才能通过判定，变为黑格。
  - 自动淘汰：一旦某个格子的 `cnt[v]` 累加到了 $2$ 或以上，它即使继续被波及，由于不满足 `cnt[v] == 1`，将永远不会变黑。

---

### 4. `last_step` (步骤去重数组)
- **类型**：整型一维数组（大小为 $H \times W$，初始值全为 `-1`）
- **用途**：记录每个白格**上一次是在哪一步（哪个 step）被波及并加入 `affected` 列表的**。
- **作用**：
  - **同一步骤内去重**：在同一步中，一个白格可能会被多个不同的邻居同时波及。如果不去重，这个白格会被重复放入 `affected` 列表，导致多余的计算。
  - 我们通过判断 `last_step[v] != step`，来确保在第 `step` 步中，每个被波及的白格**只被加入 `affected` 列表一次**。
  - 使用整型数组记录步骤，比每次创建一个 Python `set`（集合）去重在性能上要快得多。

---

### 5. `curr_q` / `next_q` (BFS 队列列表)
- **类型**：动态一维列表（存储格子的索引）
- **用途**：存放**在当前步骤（或下一步骤）中刚刚变黑、需要向外扩散的格子**。
- **作用**：
  - 驱动 BFS 的层级搜索：每一轮循环只处理 `curr_q` 里的格子，处理完后将 `next_q` 赋值给 `curr_q` 进入下一轮，直到队列为空，扩散结束。
