这个写法之所以能实现“把行变成列”，是由 Python 中的两个核心机制配合完成的：
1. **`*`（解包操作符 / Unpacking）**
2. **`zip()` 函数的聚合特性**

我们通过一个具体的例子来拆解它的执行过程：

---

### 假设我们有这样一个网格：
```python
arr = [
    ['A', 'B', 'C'],  # 第 0 行
    ['D', 'E', 'F'],  # 第 1 行
    ['G', 'H', 'I']   # 第 2 行
]
```

---

### 第一步：`*arr` 解包（把大列表拆散）

`*arr` 的作用是把外层列表“脱掉”，将里面的每一行作为**独立的参数**传给函数。

所以：
```python
zip(*arr)
```
**等价于显式写出每一行：**
```python
zip(
    ['A', 'B', 'C'],  # 参数 1 (行 0)
    ['D', 'E', 'F'],  # 参数 2 (行 1)
    ['G', 'H', 'I']   # 参数 3 (行 2)
)
```

---

### 第二步：`zip()` 按照索引“纵向打包”

`zip()` 函数的基本规则是：**从传入的每个参数中，依序取出相同位置的元素拼在一起。**

* **第 1 次取（取各行的第 0 个元素）**：
  从第 0 行取 `'A'`，第 1 行取 `'D'`，第 2 行取 `'G'` $\rightarrow$ 打包为 `('A', 'D', 'G')`（**这正是第 0 列！**）
* **第 2 次取（取各行的第 1 个元素）**：
  从第 0 行取 `'B'`，第 1 行取 `'E'`，第 2 行取 `'H'` $\rightarrow$ 打包为 `('B', 'E', 'H')`（**这正是第 1 列！**）
* **第 3 次取（取各行的第 2 个元素）**：
  从第 0 行取 `'C'`，第 1 行取 `'F'`，第 2 行取 `'I'` $\rightarrow$ 打包为 `('C', 'F', 'I')`（**这正是第 2 列！**）

---

### 第三步：`list(...)` 生成结果

`zip` 默认返回一个迭代器，套上 `list()` 后，最终得到：

```python
[
    ('A', 'D', 'G'),  # 原来的第 0 列
    ('B', 'E', 'H'),  # 原来的第 1 列
    ('C', 'F', 'I')   # 原来的第 2 列
]
```

---

### 总结本质
`zip()` 天生就是**“垂直对齐打包”**的工具。  
传入多行数据 $\rightarrow$ `zip` 把每一行的第 $j$ 个元素捏在一起 $\rightarrow$ 自然就变成了**“列”**。
