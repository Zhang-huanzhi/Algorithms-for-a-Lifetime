这篇官方题解的核心思想是：**“正难则反” + “多源 BFS（广度优先搜索）”**。

下面为你详细拆解这篇题解的思考过程、算法原理以及代码实现。

---

### 一、 核心解题思路

#### 1. 快速判断哪些是“安全的空格子”
- **条件**：格子 $(i, j)$ 所在的一整行（第 $i$ 行）和一整列（第 $j$ 列）都**不能有任何炸弹**。
- **做法**：
  - 用两个数组 $r[i]$ 和 $c[j]$ 分别记录第 $i$ 行、第 $j$ 列是否含有炸弹。
  - 先遍历一次整个网格，如果遇到 `#`，就把对应的 $r[i]$ 和 $c[j]$ 标记为 $1$。
  - 之后，只要 $r[i] == 0$ 且 $c[j] == 0$，就说明 $(i, j)$ 是一个**安全的空格子**。
  - 这一步的时间复杂度是 $O(HW)$。

#### 2. 为什么不能从每个空格子出发搜索？（暴力法的缺陷）
- 如果我们对每一个空格子都做一次 BFS，去寻找离它最近的安全空格子：
  - 每次 BFS 最坏需要 $O(HW)$ 的时间；
  - 共有 $HW$ 个格子，总时间复杂度会达到 $O((HW)^2) \approx (5 \times 10^5)^2 = 2.5 \times 10^{11}$，**必然超时 (TLE)**。

#### 3. 思维转换：等价逆向思考
因为图中的移动是**无向的**（可以从 A 走到 B，就能用同样步数从 B 走到 A）：
> **“从空格子 $(i, j)$ 出发，能在 $K$ 步内到达某个安全的空格子”**  
> **等价于**  
> **“从某个安全的空格子出发，能在 $K$ 步内到达空格子 $(i, j)$”**

因此，问题转换为了：**求所有安全的空格子到网格中各空格子的最短距离**。

#### 4. 多源 BFS（Multi-source BFS）
- 如果我们只有一个起点，把起点加入队列，距离设为 0。
- 现在我们有**多个安全空格子作为起点**：
  - 我们把**所有的安全空格子同时作为起点**，将它们初始距离都设为 $0$，并**一次性全部放进 BFS 队列**中。
  - 然后执行标准的 BFS 扩散。
- 这样，每个格子只会被访问一次，求出的距离就是**距离它最近的那个安全空格子的最短距离**。
- 时间复杂度直接降为 **$O(HW)$**，完美在 2 秒内通过！

### 二、 Python 代码逐行详解

```python
from collections import deque

h, w, k = map(int, input().split())
s = [input() for _ in range(h)]

# r[i] 记录第 i 行有没有炸弹，c[j] 记录第 j 列有没有炸弹
r = [0] * h
c = [0] * w
for i in range(h):
    for j in range(w):
        if s[i][j] == "#":
            r[i] = 1
            c[j] = 1

# d[i][j] 记录格子 (i, j) 到最近安全空格子的最短距离，初始为 -1 表示未访问
d = [[-1] * w for i in range(h)]
q = deque()

# 找出所有的“安全空格子”，把它们作为多源 BFS 的起点加入队列
for i in range(h):
    for j in range(w):
        if r[i] == c[j] == 0:  # 所在行和所在列都没有炸弹
            d[i][j] = 0
            q.append((i, j))

ans = 0

# 多源 BFS 过程
while q:
    i, j = q.popleft()
    
    # 如果当前格子的最短距离 <= K，则计入答案
    if d[i][j] <= k:
        ans += 1
    
    # 向上、下、左、右四个方向扩散
    for ni, nj in ((i-1, j), (i+1, j), (i, j-1), (i, j+1)):
        # 边界检查
        if 0 <= ni < h and 0 <= nj < w:
            # 必须是空格子 '.' 且没有被访问过 (d == -1)
            if s[ni][nj] == "." and d[ni][nj] == -1:
                d[ni][nj] = d[i][j] + 1
                q.append((ni, nj))

print(ans)
```

### 三、 复杂度分析

- **时间复杂度**：$O(H \times W)$  
  - 找炸弹行/列：$O(HW)$
  - 找到所有安全格子并入队：$O(HW)$
  - BFS 遍历：每个格子最多入队/出队一次，每个格子检查 4 个方向，因此为 $O(HW)$。
  - 总计算量约 $5 \times 10^5$，耗时在 0.2~0.5 秒左右。
- **空间复杂度**：$O(H \times W)$  
  - 需要存储地图 $S$、距离数组 $d$ 以及队列 $q$。
