
提取网格中所有“列”最常用的 **3 种简单写法**以及对应的时间复杂度：

---

### 方法 1：`zip(*arr)` （Python 最地道写法）

利用解包和 `zip` 直接把二维网格“行列互换”（转置）：

```python
# 假设 arr 是 H 行 W 列的字符串/二维列表
cols = list(zip(*arr))
```
* **拿到的结果**：`cols[j]` 就是第 $j$ 列所有元素组成的元组（tuple）。
* **时间复杂度**：$O(H \times W)$  
* **优点**：只有一行代码，极其简洁；底层是 C 实现，运行速度非常快。

---

### 方法 2：列表推导式（提取单单一列）

如果**只想要某特定的第 $j$ 列**，直接用推导式抽取每一行的第 $j$ 个元素：

```python
col_j = [row[j] for row in arr]
```
* **时间复杂度**：
  * 只拿第 $j$ 列：$O(H)$
  * 如果把每一列都拿出来：$O(H \times W)$
* **优点**：直观，不需要提取整个矩阵，随用随取。

---

### 方法 3：基础双重循环（先枚举列，再枚举行）

```python
cols = []
for j in range(w):
    col = [arr[i][j] for i in range(h)]
    cols.append(col)
```
* **时间复杂度**：$O(H \times W)$
* **特点**：最符合直觉的遍历方式，但在 Python 中速度略慢于 `zip(*arr)`。

---

### 总结对比

| 方法              | 代码示例                      | 提取全部列的时间复杂度     | 适用场景                  |
| :-------------- | :------------------------ | :-------------- | :-------------------- |
| **`zip(*arr)`** | `cols = list(zip(*arr))`  | $O(H \times W)$ | **最推荐**，需要处理所有列时最快最简洁 |
| **推导式**         | `[row[j] for row in arr]` | $O(H)$ (单列)     | 只需要提取 **某单独一列** 时     |
| **双重循环**        | 嵌套 `for`                  | $O(H \times W)$ | 传统写法，任何语言通用           |
