### C - Puddles (水洼)
**时间限制**: 2 秒 / **内存限制**: 1024 MiB  
**分值**: 300 分

#### 题目描述
有一个高 $H$ 行、宽 $W$ 列的网格。  
从上往下数第 $i$ 行、从左往右数第 $j$ 列的格子，若 $S_{i,j}$ 为 `#` 则被涂成黑色；若为 `.` 则被涂成白色。

请计算由白色格子组成的、四方向连通的区域中，被黑色格子包围的区域数量。

更严格的定义如下：
* 用 $(i, j)$ 表示从上往下第 $i$ 行、从左往右第 $j$ 列的格子。
* 称两个格子 $(i, j)$ 与 $(i', j')$ **相邻**，当且仅当 $|i - i'| + |j - j'| = 1$。
* 称一个白色格子的集合 $C$ 是**连通**的，当且仅当对于 $C$ 中的任意两个格子 $c, c'$，都可以仅通过在属于 $C$ 的相邻格子之间移动，从而从 $c$ 到达 $c'$。
* 称非空的**极大**白色格子连通集合为白色格子的**连通分量（连通块）**。
* 请计算**不包含**网格最外圈（即第 $1$ 行、第 $H$ 行、第 $1$ 列、第 $W$ 列）中任何格子的白色格子连通分量的数量。

#### 约束条件
* $3 \le H, W \le 10^3$
* $H, W$ 均为整数
* $S_{i,j}$ 为 `#` 或 `.`

#### 输入格式
输入通过标准输入按以下格式给出：

```
H W
S_{1,1}S_{1,2}…S_{1,W}
⋮
S_{H,1}S_{H,2}…S_{H,W}
```

#### 输出格式
输出答案。

---

### 输入样例 1
```text
5 15
##########..###
#...#######.###
####....###..##
######.########
########....###
```

### 输出样例 1
```text
ti2
```
**样例 1 解释**：  
满足条件的连通块共有 $2$ 个：
1. 由第 $2$ 行第 $2, 3, 4$ 列构成的包含 $3$ 个格子的区域；
2. 由第 $3$ 行第 $5, 6, 7, 8$ 列以及第 $4$ 行第 $7$ 列构成的共包含 $5$ 个格子的区域。

# AC Code
``` python
import sys  
  
  
def main():  
    # 读入 H, W    h, w = map(int, sys.stdin.readline().strip().split())  
  
    arr = []  
    for _ in range(h):  
        arr.append(sys.stdin.readline().strip())  
  
    visited = [[False] * w for _ in range(h)]  
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]  
  
    ans = 0  
    for r in range(h):  
        for c in range(w):  
            # 只有遇到【未访问过的白格】才开始启动 BFS            if arr[r][c] == "." and not visited[r][c]:  
                state = False  # 记录是否碰到了边界  
                q = [(r, c)]  
                visited[r][c] = True  
  
                # 原地遍历连通块  
                for cr, cc in q:  
                    if cr == 0 or cr == h - 1 or cc == 0 or cc == w - 1:  
                        state = True  
  
                    for dr, dc in directions:  
                        nr = cr + dr  
                        nc = cc + dc  
  
                        if (  
                            0 <= nr < h  
                            and 0 <= nc < w  
                            and arr[nr][nc] == "."  
                            and not visited[nr][nc]  
                        ):  
                            visited[nr][nc] = True  
                            q.append((nr, nc))  
  
                # 只有遍历完这个白格连通块后，没碰到边界才让 ans + 1                
                if not state:  
                    ans += 1  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```
