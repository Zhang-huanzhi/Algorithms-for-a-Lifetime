### 一、泛洪填充（Flood Fill）是什么？

**一句话定义**：从一个**起点（种子点）**开始，像**倒水蔓延（洪水泛滥）**一样，向四周把所有**相连且具有相同属性的区域**全部找出来的算法。

* **经典场景**：电脑“画图”软件里的**油漆桶工具**。你在某个闭合图形里点一下，颜色就会从这个点向四周扩散，把整片区域涂满，遇到不同颜色的轮廓线条就停下来。

### 二、这道题的具体体现（概念与代码的 1 对 1 映射）

在题目《C - Puddles》中，我们找“水洼”的过程，**本质上就是一次又一次的泛洪填充**。我们可以把代码中的每一部分和泛洪填充的概念严格对应起来：

| 泛洪填充的核心要素 | 现实中的比喻 | 本题中的具体体现（代码对应） |
| :--- | :--- | :--- |
| **起点（种子点）** | 往哪个地方倒第一桶水 | 双重循环找到的**未访问过的白格**：<br>`if arr[r][c] == '.' and not visited[r][c]:` |
| **水流蔓延规则** | 水往低处的相邻区域流 | **上下左右 4 个方向**扩散：<br>`directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]` |
| **蔓延的介质** | 水只能流在相连的水道里 | 只有邻居也是**白格 `.`** 水才能流过去：<br>`if arr[nr][nc] == '.':` |
| **阻挡的墙壁** | 遇到堤坝/墙壁水流停下 | **黑格 `#`** 就是墙壁，水流无法穿过 |
| **染色/标记** | 水流过的地方会被打湿 | **标记为已访问**，防止水往回流死循环：<br>`visited[nr][nc] = True` |
| **本题的附加任务** | 观察水有没有漏到地图外面 | 蔓延时只要有任何一滴水到了**最外圈边界**，就说明漏了：<br>`if cr == 0 or cr == h - 1 ...: state = True` |

### 三、直观动图般的执行过程

假设网格中有这样一个局部白格区域：
```text
# # # # #
# . . . #
# . . # #
# # # # #
```

1. **落下一滴水（起点）**：程序扫描到第 2 行第 2 列的 `.`，把它加入队列，标记为已访问。
2. **泛洪扩散（Fill）**：
   * 从这个点向上下左右蔓延，上方是 `#`（墙，走不通），左方是 `#`（墙，走不通）；
   * 右方和下方是 `.`（可以流过去），将它们加入队列并标记。
3. **直到填满（连通块结束）**：
   * 随着队列不断推进，这一整片由 $5$ 个 `.` 组成的白格区域全被“浸润”（全变成 `visited = True`）。
   * 水流被周围一圈 `#` 彻底挡住，无法再向外扩展，本次泛洪结束。
4. **结算**：检查发现这 $5$ 个格子的坐标**没有一个在网格最外层边缘**，说明水完全被黑格锁在池塘里了——**找到了一个合格的水洼，答案 $+1$**！
