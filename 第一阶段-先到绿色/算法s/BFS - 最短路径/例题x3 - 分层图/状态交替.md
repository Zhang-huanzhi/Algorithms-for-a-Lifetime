在实际代码编写中，状态交替（Toggle）根据状态的数据类型，通常有以下 4 种最经典的简短写法：

### 1. 0 和 1 双态交替（最常用）
如果状态用整型 `0` 和 `1` 表示：
```python
# 方法 A：减法（直观）
state = 1 - state

# 方法 B：位运算（更高效，支持多状态位反转）
state ^= 1
```

### 2. 布尔值交替
如果状态用 `True` 和 `False` 表示：
```python
state = not state
```

### 3. 多个状态循环交替（如 3 个或以上状态：0 $\to$ 1 $\to$ 2 $\to$ 0）
如果状态在 $N$ 个数字之间循环轮转，使用**模运算 `%`**：
```python
# 状态在 0, 1, 2 之间循环
state = (state + 1) % 3 
```

### 4. 复杂自定义状态交替（如 'A' $\to$ 'B' $\to$ 'C' $\to$ 'A'）
如果是特定字符或非数字状态，使用**哈希表（字典）**预设好映射关系：
```python
next_map = {'A': 'B', 'B': 'C', 'C': 'A'}

# 一步完成交替
state = next_map[state] 
```
