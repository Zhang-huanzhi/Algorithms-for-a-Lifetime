面对这道题，一个标准的、由浅入深的解题思考路径通常可以分为以下四个阶段：

---

### 第一阶段：阅读题目，理清游戏规则
首先，我们要用直白的话把游戏翻译成一个清晰的数学模型：
1. **地图**：一个有向图，每个点有出边，每个点有一个属性（`A` 或 `B`）。
2. **流程**：Alice 先手，Bob 后手。两个人轮流移动同一个棋子，每人移动 $K$ 次（总共移动 $2K$ 步）。
3. **胜负**：棋子停在 `A`，Alice 赢；停在 `B`，Bob 赢。
4. **目标**：求出在双方都聪明绝顶的前提下，从起点 `1` 开始，谁有必胜策略。

---

### 第二阶段：观察数据范围，决定解题方向
在算法竞赛中，**数据范围决定了算法的上限**。
* 顶点数 $N$ 和边数 $M$ 在 $2 \times 10^5$ 级别，这说明我们遍历一次图（$O(N + M)$）是完全没问题的。
* 关键在于 **$K$ 的范围**。
  * 如果 $K \le 10^9$：我们不可能一步步模拟。必须去寻找图中的环、强连通分量，或者用倍增法、矩阵快速幂来加速。
  * 看到 **$K \le 10$**：这是一个极强的暗示。$K$ 如此之小，意味着游戏总共最多只有 $20$ 步。我们完全不需要任何复杂的加速算法，**直接一步步倒推模拟**就是最简单、最不易出错的方法。

---

### 第三阶段：逆向思考，确立状态与转移（核心）
确定了要倒推模拟后，我们开始构建算法逻辑：

#### 1. 为什么不能正着推？
因为正着推时，站在起点我们无法预测未来的步子。这就好比下棋，你必须考虑对方后续的所有应对，才能决定现在走哪一步。

#### 2. 怎么倒着推？
因为游戏在第 $2K$ 步结束时，胜负是瞬间确定的。所以**终点（第 $2K$ 步）的胜负状态是唯一已知的确定信息**。我们必须以终点为基准，往回倒推。

* **状态定义**：
  我们用一个布尔数组 `dp[u]` 表示：**如果当前棋子在节点 $u$，且游戏马上要轮到当前玩家操作，Alice 是否必胜**。

* **初始化（第 0 步，游戏刚结束）**：
  由于不需再走，胜负直接揭晓：
  * 如果 $S[u] == 'A'$，Alice 赢，`dp[u] = True`。
  * 如果 $S[u] == 'B'$，Bob 赢（Alice 输），`dp[u] = False`。

* **状态转移（往回倒推一步）**：
  我们需要模拟 $K$ 次“Bob 走，然后 Alice 走”的逆向过程。

  * **逆向撤销 Bob 的操作**：
    假设棋子在 $u$，轮到 Bob 决策。Bob 的目标是让 Alice 输（走向一个 `dp[v] == False` 的邻居）。
    * **转移逻辑**：只要 $u$ 的邻居里有任意一个 $v$ 满足 `dp[v] == False`，聪明的 Bob 就会走过去。此时对于 Alice 来说，在 $u$ 点就是必败的。
    * **公式**：`dp_new[u] = False`（如果存在 $v \in G[u]$ 使得 `dp[v] == False`）；否则为 `True`。

  * **逆向撤销 Alice 的操作**：
    假设棋子在 $u$，轮到 Alice 决策。Alice 的目标是让自己赢（走向一个 `dp[v] == True` 的邻居）。
    * **转移逻辑**：只要 $u$ 的邻居里有任意一个 $v$ 满足 `dp[v] == True`，聪明的 Alice 就会走过去。此时在 $u$ 点 Alice 必胜。
    * **公式**：`dp_new[u] = True`（如果存在 $v \in G[u]$ 使得 `dp[v] == True`）；否则为 `False`。

---

### 第四阶段：代码实现与空间优化
1. **邻居的表示**：用有向图的邻接表 `G[u]` 存储。由于我们是从 $u$ 考虑下一步去哪里，所以只需要标准的前向邻接表（即从 $u$ 指向 $v$ 的边）。
2. **空间优化**：因为每一次转移（$dp_{new}$）只依赖于上一步的状态（$dp_{old}$），我们不需要保留历史所有的 DP 数组，只需要准备一个临时数组 `ep` 来计算新状态，计算完后直接覆盖 `dp = ep` 即可。

最后，倒推 $K$ 次（共 $2K$ 步）后，`dp[0]`（即顶点 1）的值就是最终答案。如果是 `True` 输出 `Alice`，否则输出 `Bob`。

---

### 💡 总结一句话的解题直觉：
**“因为步数 $K$ 极小，所以我们从确定的游戏终点状态出发，利用博弈论的必胜/必败逻辑，像撤销电影镜头一样，一帧一帧地把游戏画面往回倒带，直到退回起点。”**
