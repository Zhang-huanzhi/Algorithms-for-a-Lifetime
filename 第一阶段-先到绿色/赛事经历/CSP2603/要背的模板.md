### 二维前缀和后缀
这 `4` 个式子的应用场景可以这样记：

```python
pre[i][j] = pre[i - 1][j] + pre[i][j - 1] - pre[i - 1][j - 1] + arr[i][j]
```
用途：`已知原矩阵`，预处理出 `二维前缀和`，以后可以快速查询任意子矩形和。

```python
query = pre[x2][y2] - pre[x1 - 1][y2] - pre[x2][y1 - 1] + pre[x1 - 1][y1 - 1]
```
用途：在 `前缀和已经求好` 的前提下，`O(1)` 查询某个子矩形的和。

```python
diff[i][j] = arr[i][j] - arr[i - 1][j] - arr[i][j - 1] + arr[i - 1][j - 1]
```
用途：`已知原矩阵`，反推出它的 `二维差分数组`。考试里不一定常用，但如果题目先给了初始矩阵，又要做很多矩形修改，这个就有用。

```python
arr[i][j] = diff[i][j] + arr[i - 1][j] + arr[i][j - 1] - arr[i - 1][j - 1]
```
用途：对 `二维差分` 做完很多次矩形修改以后，`还原最终矩阵`。


对矩形 (x1, y1) ~ (x2, y2) 整体加 c：

``` python
	diff[x1][y1] += c
	diff[x2 + 1][y1] -= c
	diff[x1][y2 + 1] -= c
	diff[x2 + 1][y2 + 1] += c
```

``` python
from collections import deque

def bfs(start, n, g):
    dist = [-1] * (n + 1)
    q = deque([start])
    dist[start] = 0

    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)

    return dist
```

``` python
from collections import deque

def bfs(grid, sx, sy, tx, ty):
    n = len(grid)
    m = len(grid[0])
    dist = [[-1] * m for _ in range(n)]
    q = deque([(sx, sy)])
    dist[sx][sy] = 0

    dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    while q:
        x, y = q.popleft()
        if x == tx and y == ty:
            return dist[x][y]

        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < m and grid[nx][ny] != '#' and dist[nx][ny] == -1:
                dist[nx][ny] = dist[x][y] + 1
                q.append((nx, ny))

    return -1
```

``` python
import sys  
  
def main():  
  
    h, w = map(int, sys.stdin.readline().strip().split())  
  
    arr = []  
  
    for _ in range(h):  
        arr.append(list(sys.stdin.readline().strip()))  
  
    class DSU:  
        def __init__(self, n):  
            self.parent = list(range(n))  
            self.size = [1] * n  
  
        def find(self, x):  
            if self.parent[x] != x:  
                self.parent[x] = self.find(self.parent[x])  
            return self.parent[x]  
  
        def union(self, a, b):  
            ra = self.find(a)  
            rb = self.find(b)  
            if ra == rb:  
                return  
            if self.size[ra] < self.size[rb]:  
                ra, rb = rb, ra  
            self.parent[rb] = ra  
            self.size[ra] += self.size[rb]  
  
    def idx(i, j):  
        return i * w + j  
  
    OUT = h * w  
    dsu = DSU(h * w + 1)  
  
    for i in range(h):  
        for j in range(w):  
            if arr[i][j] == '#':  
                continue  
  
            cur = idx(i, j)  
  
            if i == 0 or i == h - 1 or j == 0 or j == w - 1:  
                dsu.union(cur, OUT)  
  
            if i > 0 and arr[i - 1][j] == '.':  
                dsu.union(cur, idx(i-1, j))  
  
            if j > 0 and arr[i][j-1] == '.':  
                dsu.union(cur, idx(i, j - 1))  
  
    out_root = dsu.find(OUT)  
    roots = set()  
  
    for i in range(h):  
        for j in range(w):  
            if arr[i][j] == '.':  
                r = dsu.find(idx(i, j))  
                if r != out_root:  
                    roots.add(r)  
  
    print(len(roots))
```

### 单调队列

**题目名称：最佳信号覆盖区**

**题目背景**  
某通讯公司要在一条笔直的高速公路旁建设一个连续的信号覆盖区。公路被划分为了 `n` 个基站建设点，每个点都有一个“环境干扰值” `a[i]`：

- 如果为负数，表示有干扰，会削弱信号

受限于设备功率，信号覆盖区的连续长度不能超过 `k`，也就是说可以选择长度为：

```text
1, 2, ..., k
```

中的任意一段连续区域。

---

**题目描述**  
请你帮通讯公司选定一段连续的区间，使得这段区间内所有基站点的环境干扰值之和最大。

---

**输入格式**  
第一行包含两个整数：

```text
n k
```

满足：

```text
1 <= k <= n <= 10^5
```

第二行包含 `n` 个整数：

```text
a1 a2 ... an
```

表示每个点的环境干扰值，满足：

```text
-10^4 <= ai <= 10^4
```

**输出格式**  
输出一个整数，表示长度不超过 `k` 的连续子段和的最大值。

**示例输入**
```text
6 3
1 -3 5 1 -2 3
```

**示例输出**
```text

```

code:
``` python
import sys
from collections import deque

def main():
    input = sys.stdin.readline
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    pre = [0] * (n + 1)
    for i in range(1, n + 1):
        pre[i] = pre[i - 1] + a[i - 1]

    ans = -math.inf
    q = deque([0])  # 存前缀和下标，且对应 pre 值单调递增

    for i in range(1, n + 1):
        # 保证区间长度 <= k，即 j >= i-k
        while q and q[0] < i - k:
            q.popleft()

        # 当前右端点 i，最佳左端点是窗口内最小前缀和
        ans = max(ans, pre[i] - pre[q[0]])

        # 维护前缀和单调递增
        while q and pre[q[-1]] >= pre[i]:
            q.pop()
        q.append(i)

    print(ans)

if __name__ == "__main__":
    main()
```

### 树状数组
那就按你这个模板风格来。  
给你一道非常经典的树状数组题：**逆序对**。

**题目：求逆序对个数**

给定一个长度为 `n` 的数组 `a`，求有多少对下标 `(i, j)` 满足：

```python
i < j 且 a[i] > a[j]
```

这类二元关系统计题，是树状数组最经典的应用之一。

**样例输入**
```text
5
3 1 4 2 5
```

**样例输出**
```text
3
```

**解释**

逆序对有：

- `(3, 1)`
- `(3, 2)`
- `(4, 2)`

所以答案是 `3`。

---

**做法**

从左到右扫描数组。

当扫描到 `a[i]` 时：

- 前面一共已经有 `i` 个数（若从 `0` 开始计）
- 其中 `<= a[i]` 的个数可以用树状数组求出来
- 那么前面 `> a[i]` 的个数就是当前产生的逆序对数量

因为数值可能很大，要先 **离散化**。

---

**代码**

```python
import sys

class FenwickTree:
    def __init__(self, n):
        self.size = n
        self.tree = [0] * (n + 1)

    def update(self, i, delta):
        """在第 i 个位置加上 delta (i 从 1 开始)"""
        while i <= self.size:
            self.tree[i] += delta
            i += i & (-i)

    def query(self, i):
        """查询前缀和 [1, i]"""
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & (-i)
        return s

    def query_range(self, l, r):
        """查询区间和 [l, r]"""
        return self.query(r) - self.query(l - 1)

def main():
    input = sys.stdin.readline
    n = int(input())
    arr = list(map(int, input().split()))

    # 离散化
    vals = sorted(set(arr))
    rank = {v: i + 1 for i, v in enumerate(vals)}

    ft = FenwickTree(len(vals))
    ans = 0

    for i, x in enumerate(arr):
        rx = rank[x]
        # 前面已有 i 个数，其中 <= x 的有 ft.query(rx)
        # 所以 > x 的有 i - ft.query(rx)
        ans += i - ft.query(rx)
        ft.update(rx, 1)

    print(ans)

if __name__ == "__main__":
    main()
```

1. `单点修改 + 区间求和`
2. `区间修改 + 单点查询`

### DFS
**题目：求树的直径**

给定一棵有 `n` 个结点的无向树，结点编号为 `1 ~ n`。  
树的直径定义为：**树上任意两点之间的最长简单路径长度**。

请输出这棵树的直径长度。

**输入格式**
```text
n
u1 v1
u2 v2
...
u(n-1) v(n-1)
```

表示一棵有 `n` 个点的无向树，每条边长度都为 `1`。

**样例输入**
```text
6
1 2
2 3
2 4
4 5
5 6
```

**样例输出**
```text
4
```

**解释**

最长路径可以是：

```text
3 -> 2 -> 4 -> 5 -> 6
```

一共 `4` 条边，所以直径是 `4`。

---

**经典做法：两次 DFS**

结论很重要，直接背：

1. 先从任意一点出发 `DFS`，找到离它最远的点 `A`
2. 再从 `A` 出发 `DFS`，找到离 `A` 最远的点 `B`
3. `A -> B` 的距离就是树的直径

---

**代码**

```python
import sys
sys.setrecursionlimit(10**7)

def main():
    input = sys.stdin.readline
    n = int(input())

    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    far_node = 1
    max_dist = 0

    def dfs(u, parent, dist):
        nonlocal far_node, max_dist
        if dist > max_dist:
            max_dist = dist
            far_node = u

        for v in g[u]:
            if v != parent:
                dfs(v, u, dist + 1)

    # 第一次 DFS：找一个端点 A
    dfs(1, 0, 0)
    A = far_node

    # 第二次 DFS：从 A 出发找最远点，得到直径
    max_dist = 0
    dfs(A, 0, 0)

    print(max_dist)

if __name__ == "__main__":
    main()
```

### 质数
核心思想是：**每个合数只会被它“最小的质因子”筛掉一次。**
普通的筛法（埃氏筛）中，同一个合数会被多个质因子重复筛除（例如 12 同时被 2 和 3 筛掉），造成了浪费。欧拉筛通过一个巧妙的条件，强制让合数只被筛一次。

基于：
**整数唯一分解定理**
乘法交换律

任何合数都有他对应的一个最小因子。 
``` python
def linear_sieve(n):  
    is_prime = [True] * (n + 1)  
    primes = []  
    is_prime[0] = is_prime[1] = False  
  
    for i in range(2, n + 1):  
        if is_prime[i]:  
            primes.append(i)  
        for p in primes:  
            if i * p > n:  
                break  
            is_prime[i * p] = False  
            if i % p == 0:  
                break  
    return primes
```

``` python
def is_prime(n):
```

---

**样例输入 1**
```text
5
1 5
1 7
1 8
2 7
1 3
```

**样例输出 1**
```text
1
2
3
1
2
```

**样例说明**

庭院中的树木数量变化如下：

- 添加一棵高度为 `5` 的树。此时庭院中有 `1` 棵树，高度为 `5`。
- 添加一棵高度为 `7` 的树。此时庭院中有 `2` 棵树，高度为 `5, 7`。
- 添加一棵高度为 `8` 的树。此时庭院中有 `3` 棵树，高度为 `5, 7, 8`。
- 删除所有高度不超过 `7` 的树。此时庭院中只剩下高度为 `8` 的 `1` 棵树。
- 添加一棵高度为 `3` 的树。此时庭院中有 `2` 棵树，高度为 `8, 3`。


code:
``` python
import heapq
import math
import sys
from collections import deque, defaultdict, Counter

sys.setrecursionlimit(1000000)

def main():

    n = int(sys.stdin.readline().strip())

    pq = []
    for i in range(n):
        x, y = map(int, sys.stdin.readline().strip().split())

        if x == 1:
           heapq.heappush(pq, y)
           print(len(pq))

        elif x == 2:

            while pq and pq[0] <= y:
                heapq.heappop(pq)

            print(len(pq))

if __name__ == "__main__":
    main()
```

| 方法                                  | 功能描述               | 时间复杂度         | 返回类型   | 备注              |
| :---------------------------------- | :----------------- | :------------ | :----- | :-------------- |
| **`heapq.heapify(x)`**              | 将列表 `x` **原地**转换为堆 | $O(N)$        | `None` | 直接修改传入的列表       |
| **`heapq.heappush(heap, item)`**    | 将 `item` 压入堆中      | $O(\log N)$   | `None` | -               |
| **`heapq.heappop(heap)`**           | 弹出并返回堆中**最小**的元素   | $O(\log N)$   | 元素类型   | 弹出后会重新调整堆       |
| **`heapq.heappushpop(heap, item)`** | 先压入 `item`，再弹出堆顶   | $O(\log N)$   | 元素类型   | 返回值为压入值或原堆顶     |
| **`heapq.heapreplace(heap, item)`** | 先弹出堆顶，再压入 `item`   | $O(\log N)$   | 元素类型   | 弹出值可能比 `item` 大 |
| **`heapq.nlargest(n, iter)`**       | 返回前 `n` 个最大的元素列表   | $O(N \log n)$ | `List` | 结果列表按降序排列       |
| **`heapq.nsmallest(n, iter)`**      | 返回前 `n` 个最小的元素列表   | $O(N \log n)$ | `List` | 结果列表按升序排列       |

### 大小可变的时间窗口
给你一道非常经典的 **可变大小滑动窗口 / 双指针** 题。

**题目：最短连续子数组**

给定一个长度为 `n` 的正整数数组 `a`，以及一个正整数 `S`。  
请你找到一个 **连续子数组**，使它的元素和 `>= S`，并且长度尽可能短。  
输出这个最短长度；如果不存在这样的子数组，输出 `0`。

**输入格式**
```text
n S
a1 a2 ... an
```

**样例输入**
```text
6 7
2 3 1 2 4 3
```

**样例输出**
```text
2
```

**解释**

和至少为 `7` 的最短连续子数组是：

```text
4 3
```

长度为 `2`。

---

**思路**

这是最经典的 **可变窗口**：

- 右指针不断向右扩张，让窗口和变大
- 只要当前窗口和已经 `>= S`，就尽量移动左指针缩小窗口
- 在缩小过程中更新答案

因为数组全是正整数，所以窗口右移后，和只会增大；左移后，和只会减小，满足单调性，所以双指针成立。

---

**代码**

```python
import sys

def main():
    input = sys.stdin.readline
    n, S = map(int, input().split())
    a = list(map(int, input().split()))

    left = 0
    cur_sum = 0
    ans = n + 1

    for right in range(n):
        cur_sum += a[right]

        while cur_sum >= S:
            ans = min(ans, right - left + 1)
            cur_sum -= a[left]
            left += 1

    print(ans if ans != n + 1 else 0)

if __name__ == "__main__":
    main()
```

---
```python
for right in range(n):
    把 a[right] 加进窗口

    while 当前窗口满足条件:
        更新答案
        缩小左端点
```

### 滑动时间窗口
C - Comfortable Distance  
  
时间限制：2 秒 / 内存限制：1024 MiB  
  
分值：300 分  
  
题目描述  
  
给定一个长度为 N 的、由小写英文字母组成的字符串 S。  
  
请你求出满足以下所有条件的整数对 (i, j) 的个数：  
  
1. 1 ≤ i ≤ j ≤ N    
2. S_i = S_j    
3. L ≤ j - i ≤ R  
  
约束  
  
- 2 ≤ N ≤ 5 × 10^5    
- 1 ≤ L ≤ R ≤ N - 1    
- N, L, R 为整数  - S 是一个长度为 N 的小写英文字母字符串  
  
输入  
  
输入从标准输入按如下格式给出：  
  
N L R    
S  
  
输出  
  
输出答案。  
  
输入样例 1  
  
6 2 4    
aabcba  
  
输出样例 1  
  
2  
  
满足题意全部条件的整数对为 (i, j) = (2, 6), (3, 5)，共 2 个。  
  
``` python
import sys
from collections import defaultdict

def main():
    n, l, r = map(int, sys.stdin.readline().strip().split())
    s = sys.stdin.readline().strip()

    # 固定范围的滑动窗口
    window = defaultdict(int)
    ans = 0

    for i in range(n):
        if i - l >= 0:
            window[s[i - l]] += 1

        if i - r - 1 >= 0:
            window[s[i - r - 1]] -= 1

        ans += window[s[i]]

    print(ans)

if __name__ == "__main__":
    main()

```

### 时间 datatime
`CSP/CCF` 里时间相关题常见是这几类：

**常见考法**

- `时间加减`
  例如给你一个日期时间，加上若干分钟、小时、天，问最后结果。
- `时间差`
  给两个时刻，求相差多少秒、分钟、天。
- `字符串时间解析`
  输入像 `"2024-03-01 08:30:00"`，要转成可计算形式。
- `跨天 / 跨月 / 跨年`
  尤其会卡 `2 月`、闰年、月末、年末。
- `排序 + 时间线`
  给一堆事件开始结束时间，问同时在线人数、区间覆盖、是否冲突。
- `模拟时钟`
  按规则推进时间，比如每隔 `k` 分钟触发一次。
- `时间窗口`
  某事件发生前后 `x` 分钟内算有效，常和双指针/队列一起出。
- `日期是否合法`

### 正则
会，但一般 **不会考很重的正则理论**，更可能考的是：

- 会不会写简单模式
- 会不会用正则做匹配、提取、替换
- 会不会分清什么时候该用正则，什么时候直接字符串处理更简单

你考前重点看这些就够了。

**高概率考法**

- `合法性判断`
  比如手机号、日期、编号、学号、车牌、字符串格式是否合法。
- `信息提取`
  从一行文本里提取数字、单词、日期、IP 片段之类。
- `批量替换`
  把连续空格压成一个空格，把某类符号统一替换。
- `分割`
  按多个分隔符切字符串。
- `简单模式匹配`
  某串是否满足某种结构，比如“若干字母 + 若干数字”。

**最该背的符号**

- `.`：任意单个字符
- `\d`：数字
- `\w`：字母数字下划线
- `\s`：空白字符
- `[abc]`：三选一
- `[a-z]`：小写字母
- `[^0-9]`：非数字
- `*`：前一个出现 `0` 次或多次
- `+`：前一个出现 `1` 次或多次
- `?`：前一个出现 `0` 次或 `1` 次
- `{n}`：恰好 `n` 次
- `{m,n}`：`m ~ n` 次
- `^`：开头
- `$`：结尾
- `()`：分组
- `|`：或

**考试里最容易错的点**

- `match` 不是“全匹配”，它只是**从开头匹配**
- 真想判断整个串，优先用 `fullmatch`
- 正则里很多字符有特殊含义，像 `.` `*` `?` `(` `)` `[` `]`
- 想匹配字面量点号，要写 `\.`
- Python 里正则最好写成原始字符串：

```python
r"\d+"
```

而不是：

```python
"\\d+"
```

**一个典型坑**

```python
re.match(r"\d+", "123abc")
```

这会成功，但它只说明“开头有数字”，  
不说明整个串都是数字。

所以比赛里做合法性判断时，优先：

```python
re.fullmatch(r"\d+", s)
```

**CSP/CCF 里更现实的建议**

很多题 **即使能用正则，也不一定最优**。

比如：

- 判断全是数字：直接 `isdigit()`
- 判断前缀后缀：直接 `startswith()` / `endswith()`
- 分割固定格式：直接 `split()`
- 替换固定字符：直接 `replace()`

所以你要记一句：

**正则适合处理“模式很多、结构不固定”的字符串；固定格式优先普通字符串函数。**

### 单调栈
给你一道最经典的单调栈题：**下一个更大元素**。

**题目**

给定一个长度为 `n` 的数组 `a`，对每个位置 `i`，求它右边第一个比 `a[i]` 大的元素下标。  
如果不存在，输出 `-1`。

**输入格式**
```text
n
a1 a2 ... an
```

**样例输入**
```text
5
2 1 2 4 3
```

**样例输出**
```text
4 3 4 -1 -1
```

**解释**

- 位置 `1` 的值是 `2`，右边第一个更大的数是位置 `4` 的 `4`
- 位置 `2` 的值是 `1`，右边第一个更大的数是位置 `3` 的 `2`
- 位置 `3` 的值是 `2`，右边第一个更大的数是位置 `4` 的 `4`
- 位置 `4` 后面没有更大的
- 位置 `5` 后面没有更大的

---

**单调栈模板**

这题的核心就是维护一个 **单调递减栈**，栈里存下标。

当当前元素 `a[i]` 比栈顶对应值大时，说明当前元素就是栈顶那个位置的“右边第一个更大元素”。

---

**代码**

```python
import sys

def main():
    input = sys.stdin.readline
    n = int(input())
    a = list(map(int, input().split()))

    ans = [-1] * n
    stack = []  # 存下标，保持 a[stack] 单调递减

    for i in range(n):
        while stack and a[stack[-1]] < a[i]:
            idx = stack.pop()
            ans[idx] = i + 1   # 题目输出下标，转成 1-based
        stack.append(i)

    print(*ans)

if __name__ == "__main__":
    main()
```

---

**你背的时候记这个模板就行**

```python
stack = []

for i in range(n):
    while stack and a[stack[-1]] < a[i]:
        idx = stack.pop()
        ans[idx] = i
    stack.append(i)
```

含义：

- 栈里放“还没找到答案”的位置
- 当前数一旦更大，就把前面比它小的都结算掉

---

**单调栈常见用途**

- 右边第一个更大元素
- 右边第一个更小元素
- 左边第一个更大/更小元素
- 柱状图最大矩形
- 子数组最小值 / 最大值贡献


### Dijstra 

**题目：最便宜的旅行**

有 `n` 个城市，`m` 条双向道路。每条道路连接两个城市，经过这条路需要花费一定费用。  
现在你要从城市 `1` 出发到城市 `n`，求最少花费。

如果无法到达，输出 `-1`。

---

**输入格式**
```text
n m
u1 v1 w1
u2 v2 w2
...
um vm wm
```

- `1 <= n, m <= 2 * 10^5`
- `1 <= w`
- 图是无向图

---

**样例输入**
```text
5 6
1 2 2
1 3 4
2 3 1
2 4 7
3 5 3
4 5 1
```

**样例输出**
```text
6
```

---

**解释**

从 `1` 到 `5` 的最短路可以是：

```text
1 -> 2 -> 3 -> 5
```

费用为：

```text
2 + 1 + 3 = 6
```

---

**代码**

```python
import sys
import heapq

def dijkstra(n, g, start):
    INF = 10**18
    dist = [INF] * (n + 1)
    dist[start] = 0
    pq = [(0, start)]

    while pq:
        d, u = heapq.heappop(pq)

        if d != dist[u]:
            continue

        for v, w in g[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))

    return dist

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    g = [[] for _ in range(n + 1)]

    for _ in range(m):
        u, v, w = map(int, input().split())
        g[u].append((v, w))
        g[v].append((u, w))

    dist = dijkstra(n, g, 1)

    print(dist[n] if dist[n] != 10**18 else -1)

if __name__ == "__main__":
    main()
```

---

**和前一题相比，这题更像考试点在于**

- 图是无向图，要双向加边
- 只问起点到终点，不一定要输出所有点
- 容易包装成“公路、花费、时间、体力、危险值”之类

---

**看到这些词就想到 Dijkstra**

- 最少花费
- 最短时间
- 最小代价
- 从 1 到 n
- 边权非负

### 逆元
**什么时候需要逆元？**

当题目：

- 要对 `mod` 取模
- 但公式里出现了 `除法`

这时就需要逆元。

典型场景：

- `a / b`
- `sum / n`
- `p / q`
- 组合数里的 `/ k!`

**怎么用？**

把除法：

```python
a / b
```

改成：

```python
a * inv(b) % mod
```

如果 `mod` 是质数，最常用写法：

```python
inv(b) = pow(b, mod - 2, mod)
```

所以直接写：

```python
a * pow(b, mod - 2, mod) % mod
```

**一句话记忆**

> 模意义下不能直接除，除法要改成乘逆元。
