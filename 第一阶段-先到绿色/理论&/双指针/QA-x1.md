下面这些更像修士考试里可能出现的“算法理解问答”，用来检查自己是否真的懂双指针。

1. 什么是双指针？

答：在数组、字符串或链表上维护两个位置，通过移动指针减少重复枚举。常见形式有相向指针、同向指针（滑动窗口）和快慢指针。

2. 双指针一定是 `O(n)` 吗？

答：不一定。若两个指针都只单调移动且各最多移动 `n` 次，整体是 `O(n)`；若每次移动都重新扫描一段区间，或指针会反复回退，则可能是 `O(n^2)`。

3. 为什么下面看似双重循环的滑动窗口是 `O(n)`？

```
l = 0
for r = 0 .. n-1:
    加入 a[r]
    while 条件不满足:
        移除 a[l]
        l++
```

答：`r` 只从左到右走 `n` 次，`l` 也只从左到右走最多 `n` 次。总移动次数不超过 `2n`，因此是 `O(n)`。

4. 已排序数组中如何判断是否有两数之和等于 `K`？

答：设 `l = 0, r = n - 1`。若 `a[l] + a[r] = K`，找到答案；若和小于 `K`，`l++`；若和大于 `K`，`r--`。

5. 上题中，为什么“和太大时右指针左移”不会漏解？

答：数组有序。若 `a[l] + a[r] > K`，则对任意 `i >= l` 都有 `a[i] + a[r] >= a[l] + a[r] > K`。因此 `r` 不可能和当前及右侧任何元素组成答案，可以安全左移。

6. 双指针的核心前提是什么？

答：存在可利用的单调性，能证明一次移动某个指针后，被跳过的候选不可能成为答案。单调性常来自排序、非负元素、窗口计数的增减规律等。

7. 什么是滑动窗口？

答：同向双指针维护连续区间 `[l, r]`。通常右指针扩大窗口，左指针在窗口不符合条件时缩小窗口，并维护窗口内的和、元素种类数或频次等信息。

8. 全为非负数的数组中，求和不超过 `K` 的最长子数组，为什么可以滑窗？

答：窗口右扩时区间和不会减小；窗口左缩时区间和不会增大。因此和超过 `K` 时不断移动左端，能恢复合法窗口且不会遗漏更优解。

9. 数组允许负数时，为什么“和不超过 `K`”的滑窗通常不能直接用？

答：右扩后总和可能变小，左缩后总和也可能变大，单调性消失。此时“超了就移动左指针”的判断不再可靠，常需前缀和、哈希表、单调队列等方法。

10. 滑动窗口中常见的循环不变量是什么？

答：例如“每次处理完内层循环后，当前窗口 `[l, r]` 满足和不超过 `K`”；或“窗口中每个元素频次满足题目限制”。循环不变量用于证明算法每一步都正确。

11. 求“最长满足条件的连续子数组”和“最短满足条件的连续子数组”，指针移动有什么区别？

答：两者都是右端扩张，但更新答案的时机不同。最长题通常在窗口合法时更新；最短题通常在窗口刚合法后尽量移动左端缩小，并在缩小前更新答案。

12. 双指针能用于非连续子序列问题吗？

答：可以，例如排序后找两数之和、三数之和；但滑动窗口通常处理的是连续子数组/子串。必须先区分题目要求的是 `subarray/substring` 还是 `subsequence`。

13. 快慢指针与滑动窗口有什么区别？

答：快慢指针通常利用移动速度差或固定距离，如判断链表环、找链表中点；滑动窗口则维护一个连续区间及其状态。两者都属于双指针，但证明方式不同。

14. 链表判环中，快慢指针为何一定会相遇？

答：若有环，快指针每步比慢指针多走一步；进入环后，它们之间的距离模环长每次减少一，因此最多经过一个环长就会相遇。若无环，快指针会先到达空指针。

15. 双指针的空间复杂度通常是多少？

答：若只维护少量指针、和或计数器，额外空间是 `O(1)`。若窗口需要哈希表记录字符频次，则额外空间取决于字符集或不同元素数量。

16. 哪些信号说明应考虑双指针？

答：题目出现“有序数组”“连续子数组/子串”“最长/最短区间”“至多/至少 `K` 个”“原地去重”“两个端点”“非负数组”等描述时，都值得先检查是否存在单调性。

17. 哪些情况不该硬用双指针？

答：指针移动无法安全排除候选、窗口状态不单调、数组含负数且目标与区间和有关、需要枚举不连续选择时，应考虑前缀和、哈希、二分、DP 或图算法。

你可以把最核心的答题模板记成四句：

```
利用的单调性是什么？
移动该指针时，排除了哪些不可能的情况？
循环不变量是什么？
两个指针各移动多少次，因此复杂度是多少？
```

修士考试里，能把这四句说清楚，比会背“双指针模板”更重要。
