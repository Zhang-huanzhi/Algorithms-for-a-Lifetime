``` python
import sys  
  
def main():  
  
    n, x = map(int, sys.stdin.readline().strip().split())  
  
    arr = []  
    for _ in range(n):  
        a, b = map(int, sys.stdin.readline().strip().split())  
        arr.append((a, b))  
  
    ans = 0  
    # 暴力， 有 2 ** n给状态， 二进制枚举  
    for i in range(1 << n):  
        curr_cal = 0  
        curr_del = 0  
  
        for j in range(n):  
            if (i >> j) & 1:  
                curr_cal += arr[j][0]  
                curr_del += arr[j][1]  
  
        if curr_cal <= x:  
            ans = max(curr_del, ans)  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```

### 原理一：状态的“一一映射”（为什么能代表所有子集？）

二进制枚举的本质是**数学中的双射（一双一对应）**。

假设我们有 $N$ 个物品，对每个物品只有“选”或“不选”两种决定。
根据乘法原理，总方案数是 $\underbrace{2 \times 2 \times \dots \times 2}_{N\text{个}} = 2^N$ 种。

*   **计算机中的数字**：在内存中本来就是用二进制（由 0 和 1 组成）存储的。
*   **状态的表示**：一个长度为 $N$ 位的二进制数，它的每一位正好可以代表一个物品的选择状态（`1` 表示选，`0` 表示不选）。
*   **区间的对应**：从 $0$ 到 $2^N-1$ 的每一个十进制整数，其二进制表示都**唯一对应**着一种选择方案。

例如，当 $N=3$ 时，外层循环 `range(1 << n)` 遍历了 $0$ 到 $7$：
*   十进制 `5` $\rightarrow$ 二进制 `101` $\rightarrow$ 意味着：选第 0 个和第 2 个物品，不选第 1 个。
通过遍历这 $2^N$ 个整数，我们就相当于遍历了所有的选择方案。

### 原理二：`(i >> j) & 1` 的物理拆解（怎么知道选了谁？）

这是整个模板中最难理解、但最精妙的一行：
```python
if (i >> j) & 1:
```
它的作用是：**检查状态 $i$ 的第 $j$ 位（从右往左数，从 0 开始）是不是 1。**

我们以 **$i = 5$（二进制 `101`）** 为例，看看内层循环当 $j$ 从 $0$ 变到 $2$ 时发生了什么：

#### 1. 当 $j = 0$ 时（检查第 0 个物品）
*   `i >> 0`：将 `101` 右移 0 位，依然是 `101`。
*   `(i >> 0) & 1`：进行按位与操作：
    ```text
      1 0 1  (i >> 0)
    & 0 0 1  (1)
    --------
      0 0 1  (结果为 1，即 True)
    ```
*   **结论**：第 0 位是 1，说明**选择了**第 0 个物品。

#### 2. 当 $j = 1$ 时（检查第 1 个物品）
*   `i >> 1`：将 `101` 右移 1 位，最右边的 `1` 被丢弃，变成 `10`（二进制的 2）。
*   `(i >> 1) & 1`：进行按位与操作：
    ```text
      1 0  (i >> 1)
    & 0 1  (1)
    ------
      0 0  (结果为 0，即 False)
    ```
*   **结论**：第 1 位是 0，说明**没有选择**第 1 个物品。

#### 3. 当 $j = 2$ 时（检查第 2 个物品）
*   `i >> 2`：将 `101` 右移 2 位，变成 `1`。
*   `(i >> 2) & 1`：进行按位与操作：
    ```text
      1  (i >> 2)
    & 1  (1)
    ----
      1  (结果为 1，即 True)
    ```
*   **结论**：第 2 位是 1，说明**选择了**第 2 个物品。

通过 `i >> j`，我们把想要检查的那一位**“拉”到了最右边**；再通过 `& 1`，把除了最右边以外的其他所有位**“遮罩”抹零**。这样就能非常高效地得知这一位是 0 还是 1。

### 原理三：`1 << n` 的高效性

在数学上，我们写 $2^n$。在计算机中，我们写 `1 << n`。
*   `1` 的二进制是 `0000...0001`。
*   `1 << n` 代表把这个 `1` 向左移动 $n$ 位，右边补 $n$ 个 `0`。
*   例如 `1 << 3` 变成 `1000`（二进制），其值刚好是十进制的 $8$（即 $2^3$）。
*   位移运算是由计算机硬件直接支持的，执行速度极快。

### 模板的通用性（如何举一反三？）

这个模板之所以被称为“万能模板”，是因为当面对不同题目时，**你只需要修改最内层的业务逻辑**：

*   **如果题目要求“求和最大”**：就像你的代码一样，在内层累加属性，最后 `max(ans, curr_sum)`。
*   **如果题目要求“方案数”**：在外层定义 `cnt = 0`，如果内层算出来的状态符合条件，就 `cnt += 1`。
*   **如果题目要求“选出最少的物品满足条件”**：可以用 Python 的 `bin(i).count('1')` 快速算出当前状态选了几个物品，然后取 `min` 值。

掌握了这个模板及其位运算原理，在解决 $N \le 20$ 级别的组合、子集、开关、配对等问题时，你就能写得非常自信了。
