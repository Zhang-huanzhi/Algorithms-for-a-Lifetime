### 题目名称：Balanced Subarrays (平衡子数组)

#### 问题描述
高桥君得到了一个由 $N$ 个非负整数组成的序列 $A = (A_1, A_2, \dots, A_N)$。

如果一个**连续子数组** $A[l \dots r]$（$1 \le l \le r \le N$）内所有元素的按位异或和恰好等于 $0$，即满足：
$$A_l \oplus A_{l+1} \oplus \dots \oplus A_r = 0$$

高桥君就称这个区间 $[l, r]$ 是一个**“平衡子数组”**。

请帮助高桥君计算出，序列 $A$ 中一共有多少个不同的“平衡子数组”？

#### 输入格式
输入从标准输入给出，格式如下：
> $N$  
> $A_1$ $A_2$ $\dots$ $A_N$  

#### 输出格式
输出一个整数，表示平衡子数组的数量。

#### 数据范围
*   $1 \le N \le 2 \times 10^5$
*   $0 \le A_i \le 10^9$
*   所有输入均为整数。

---

### 输入输出样例

#### 样例 1
**输入：**
```text
4
1 2 3 0
```
**输出：**
```text
3
```
**样例说明：**
共有 3 个连续子数组的异或和为 0：
1.  区间 $[1, 3]$：$1 \oplus 2 \oplus 3 = 0$
2.  区间 $[4, 4]$：单个数字 $0$，其异或和为 $0$
3.  区间 $[1, 4]$：$1 \oplus 2 \oplus 3 \oplus 0 = 0$

#### 样例 2
**输入：**
```text
3
5 5 5
```
**输出：**
```text
2
```
**样例说明：**
*   区间 $[1, 2]$：$5 \oplus 5 = 0$
*   区间 $[2, 3]$：$5 \oplus 5 = 0$
共有 2 个满足条件的子数组。

---

### 💡 思考提示

1.  根据公式，$A[l \dots r]$ 的异或和为 $P[r] \oplus P[l-1]$（其中 $P$ 是异或前缀和）。
2.  要让 $P[r] \oplus P[l-1] = 0$，根据异或自反性，这意味着：**$P[r]$ 必须等于 $P[l-1]$**！
3.  因此，题目变成了：**在遍历前缀异或的过程中，前面有多少个相同的前缀异或值？**
4.  别忘了前缀和的初始状态：$P[0] = 0$ 先放入哈希表中。
