**异或前缀和（Prefix XOR）**是算法竞赛中处理“区间异或问题”的核心工具。

它的本质是：**将对“区间”的多次重复计算，转化为对“端点”的前缀预处理，从而在 $O(1)$ 时间内求出任意连续子区间的异或和。**

---

### 一、 什么是异或前缀和？

我们类比普通的前缀和（Prefix Sum）来理解：

| 类型 | 普通前缀和（Prefix Sum） | 异或前缀和（Prefix XOR） |
| :--- | :--- | :--- |
| **定义** | $S[i] = A_1 + A_2 + \dots + A_i$ | $P[i] = A_1 \oplus A_2 \oplus \dots \oplus A_i$ |
| **初始值（空前缀）** | $S[0] = 0$（加法的单位元） | $P[0] = 0$（异或的单位元，因为 $x \oplus 0 = x$） |
| **递推公式** | $S[i] = S[i-1] + A_i$ | $P[i] = P[i-1] \oplus A_i$ |
| **区间查询公式** | $\sum_{k=L}^{R} A_k = S[R] - S[L-1]$ | $\bigoplus_{k=L}^{R} A_k = P[R] \oplus P[L-1]$ |

---

### 二、 数学原理：为什么不是“减”而是“再异或一次”？

在普通加法中，我们要消除前 $L-1$ 个数的影响，必须使用它的逆运算——**减法**。

但在位运算中，异或运算具有**自反性**：
$$X \oplus X = 0$$
这意味着：**异或运算的逆运算就是它自己**。“异或两次”等于没有异或，它天生自带“消除”功能。

#### 严谨推导：
假设数组为 $A = [A_1, A_2, \dots, A_N]$：
1. 前 $R$ 项的异或和：
   $$P[R] = (A_1 \oplus A_2 \oplus \dots \oplus A_{L-1}) \oplus (A_L \oplus \dots \oplus A_R)$$
2. 前 $L-1$ 项的异或和：
   $$P[L-1] = (A_1 \oplus A_2 \oplus \dots \oplus A_{L-1})$$
3. 将两者异或：
   $$\begin{aligned}
   P[R] \oplus P[L-1] &= \Big( (A_1 \oplus \dots \oplus A_{L-1}) \oplus (A_L \oplus \dots \oplus A_R) \Big) \oplus (A_1 \oplus \dots \oplus A_{L-1}) \\
   &= \underbrace{(A_1 \oplus A_1)}_{0} \oplus \underbrace{(A_2 \oplus A_2)}_{0} \oplus \dots \oplus \underbrace{(A_{L-1} \oplus A_{L-1})}_{0} \oplus (A_L \oplus \dots \oplus A_R) \\
   &= 0 \oplus (A_L \oplus \dots \oplus A_R) \\
   &= A_L \oplus A_{L+1} \oplus \dots \oplus A_R
   \end{aligned}$$

因此，任意区间 $[L, R]$ 的异或和就是 **$P[R] \oplus P[L-1]$**。

### 三、 Python 代码实现

#### 1. 静态预处理（用于多次快速查询区间）
当题目给出 $Q$ 次询问，每次询问区间 $[L, R]$ 的异或和时：
```python
# 假设 arr 为输入的数组（0-indexed，长度为 N）
N = len(arr)
P = [0] * (N + 1)

# 预处理：O(N) 时间
for i in range(N):
    P[i + 1] = P[i] ^ arr[i]

# 查询：每次查询 O(1) 时间（假设 L, R 是 1-indexed）
def query(L, R):
    return P[R] ^ P[L - 1]
```

#### 2. 动态维护（配合哈希表使用）
如果只需要单向扫描统计子数组，可以连数组都不开，直接用一个变量 `curr_xor` 维护前缀异或：
```python
curr_xor = 0
for num in arr:
    curr_xor ^= num  # 此时 curr_xor 就是当前位置的 P[R]
    # 在此处进行哈希表统计或判断...
```

### 四、 常见考点与应用场景

在 AtCoder 中，异或前缀和通常出现在以下 3 种场景：

#### 场景 1：区间异或和的高速查询（基础题，ABC B/C 题）
* **题型**：给出一个数组和 $Q$ 个询问，每次给出一个区间 $[L, R]$，求区间异或和。
* **解法**：$O(N)$ 预处理异或前缀和，单次查询 $O(1)$，总耗时 $O(N + Q)$。

#### 场景 2：子数组异或和等于 $K$ 的计数问题（经典题，ABC C/D 题）
* **题型**：求有多少个连续子数组 $[L, R]$ 满足其异或和为 $K$。
* **解法**：
  转化条件：$P[R] \oplus P[L-1] = K \iff P[L-1] = P[R] \oplus K$。
  使用哈希表边遍历边统计历史中出现过多少个 $P[R] \oplus K$。

#### 场景 3：树上路径异或和（进阶拓展，ABC D/E 题）
* **原理**：在一棵带边权的树上，求任意两点 $u$ 和 $v$ 之间路径的异或和。
  设 $dist[x]$ 为从**根节点**到节点 $x$ 的路径异或和。
  由于从根到 $u$ 和从根到 $v$ 的路径中，公共祖先以上的部分会被**重复走两次**（异或两次等于 0 自动抵消）。
* **结论**：**$u$ 到 $v$ 的路径异或和就是 $dist[u] \oplus dist[v]$**。
  这一步甚至不需要求最近公共祖先（LCA），直接将树上路径问题变成了点对问题。

### 五、 核心易错点总结

1. **哨兵 $P[0] = 0$**：
   无论何时使用异或前缀和，一定要记住在未开始异或时，初始值是 $0$。在哈希表统计中表现为必须提前放入 `memo[0] = 1`。
2. **下标偏移**：
   前缀和数组 `P` 的长度通常开为 $N + 1$。
   * $P[0]$ 对应空前缀；
   * $P[i]$ 对应原数组前 $i$ 个元素（在 0-indexed 下对应原数组的 `arr[0 ... i-1]`）。
