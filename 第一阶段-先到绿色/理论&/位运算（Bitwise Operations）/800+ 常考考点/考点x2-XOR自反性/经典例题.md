在 AtCoder 800 左右评分的题目中，关于**异或（XOR）**的考点通常结合了“哈希表（Hash Map）”或“双指针”来降低时间复杂度。

最经典的一类题型是：**利用异或的自反性（$A \oplus B = C \iff A \oplus C = B$）进行等式变形，从而将 $O(N^2)$ 的暴力解法优化到 $O(N)$。**

---

### 题目名称：XOR Pairs (异或对)

#### 问题描述
给你一个长度为 $N$ 的正整数数组 $A = (A_1, A_2, \dots, A_N)$，以及一个非负整数 $X$。

请问有多少对索引 $(i, j)$ 满足以下条件：
1.  $1 \le i < j \le N$
2.  $A_i \oplus A_j = X$ （其中 $\oplus$ 表示按位异或运算）

#### 输入格式
输入从标准输入给出，格式如下：
> $N$ $X$  
> $A_1$ $A_2$ $\dots$ $A_N$  

#### 输出格式
输出一个整数，表示满足条件的索引对 $(i, j)$ 的数量。

#### 数据范围
*   $2 \le N \le 2 \times 10^5$
*   $0 \le X \le 10^9$
*   $0 \le A_i \le 10^9$
*   所有输入均为整数。

---

### 输入输出样例

#### 样例 1
**输入：**
```text
4 5
3 6 1 3
```
**输出：**
```text
2
```
**样例说明：**
我们要在数组 `[3, 6, 1, 3]` 中寻找异或结果等于 `5` 的数对。
*   $A_1 \oplus A_2 = 3 \oplus 6 = 5$ （满足条件）
*   $A_2 \oplus A_4 = 6 \oplus 3 = 5$ （满足条件）
其余数对的异或值均不为 5。因此输出为 2。

---

### 核心解题原理（为什么说这是异或经典？）

#### 1. 暴力解法为什么不行？
最直观的想法是双重循环枚举 $i$ 和 $j$，判断 $A_i \oplus A_j == X$。
由于 $N \le 2 \times 10^5$，双重循环的时间复杂度是 $O(N^2)$，计算次数约为 $4 \times 10^{10}$ 次，必然超时（TLE）。

#### 2. 异或的魔法变形
我们需要把等式 $A_i \oplus A_j = X$ 进行变形。
根据异或的性质，我们在等式两边同时异或 $A_i$：
$$(A_i \oplus A_i) \oplus A_j = A_i \oplus X$$
因为 $A_i \oplus A_i = 0$，且 $0 \oplus A_j = A_j$，所以等式等价于：
$$A_j = A_i \oplus X$$

**这意味着**：对于当前的数 $A_j$，我们不需要去和前面的所有数挨个异或，我们只需要知道：**在 $A_j$ 之前，有多少个数的值正好等于 $A_j \oplus X$**。

#### 3. 用哈希表（Counter）实现 $O(N)$
我们可以从左到右遍历数组，用一个哈希表记录已经遍历过的数字的出现次数：
*   遍历到 $A_j$ 时，直接在哈希表中查询目标值 `target = A_j ^ X` 已经出现了多少次。
*   将出现次数累加到答案中。
*   将当前的 $A_j$ 放入哈希表中，继续往后遍历。

---

### Python 参考代码

```python
import sys
from collections import Counter

def main():
    # 快速输入
    input = sys.stdin.read
    data = input().split()
    if not data:
        return
    
    N = int(data[0])
    X = int(data[1])
    A = [int(x) for x in data[2:]]
    
    ans = 0
    # count_map 用于存储已经遍历过的数字及其出现次数
    count_map = Counter()
    
    for num in A:
        # 我们需要找的目标数字是 target
        target = num ^ X
        
        # 如果 target 之前出现过，说明可以和当前的 num 配对
        if target in count_map:
            ans += count_map[target]
            
        # 将当前数字加入哈希表，供后面的数字配对
        count_map[num] += 1
        
    print(ans)

if __name__ == '__main__':
    main()
```

### 复杂度分析

*   **时间复杂度**：$O(N)$。我们只遍历了一次数组，哈希表的查询和插入操作在平均情况下是 $O(1)$ 的。对于 $N = 2 \times 10^5$，运行时间通常在 0.1 秒左右，非常高效。
*   **空间复杂度**：$O(N)$。在最坏情况下（数组中元素各不相同），哈希表最多需要存储 $N$ 个不同的键值对。
