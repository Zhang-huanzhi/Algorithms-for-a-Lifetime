
## 二进制 & 十进制转换速查表（Python）

|需求|写法|示例|
|---|---|---|
|十进制转二进制字符串|`bin(n)`|`bin(10) == '0b1010'`|
|去掉二进制前缀|`bin(n)[2:]`|`bin(10)[2:] == '1010'`|
|二进制转十进制|`int(s, 2)`|`int('1010', 2) == 10`|
|按指定位数补 `0`|`format(n, '0kb')`|`format(5, '08b') == '00000101'`|
|二进制格式化|`format(n, 'b')`|`format(10, 'b') == '1010'`|
|其他进制转十进制|`int(s, base)`|`int('17', 8) == 15`|

``` python
n = 13

binary = bin(n)[2:]       # '1101'
decimal = int(binary, 2)  # 13
padded = format(n, '08b') # '00001101'
```

### 手算规则

``` python
二进制 -> 十进制：
1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11

十进制 -> 二进制：
不断除以 2，记录余数，最后将余数逆序排列。
```

注意：`bin()` 返回的字符串带有前缀 `'0b'`；二进制字符串转整数时需要指定 `base=2`。

### Python 进制转换极简速查表

| 转换类型 | 代码写法 | 输入示例 $\to$ 输出示例 | 说明/适用场景 |
| :--- | :--- | :--- | :--- |
| **十进制 $\to$ 二进制 (带 `0b`)** | `bin(x)` | `5` $\to$ `'0b101'` | 快速查看二进制 |
| **十进制 $\to$ 纯二进制字符串** | `f"{x:b}"` | `5` $\to$ `'101'` | 打印/输出不带前缀的二进制 |
| **十进制 $\to$ 固定 $N$ 位补零二进制** | `f"{x:0Nb}"` *(如 `05b`)* | `5` $\to$ `'00101'` | **【高频】** 打印固定长度掩码/调试 |
| **二进制字符串 $\to$ 十进制整数** | `int(s, 2)` | `'101'` 或 `'0b101'` $\to$ `5` | **【高频】** 解析二进制输入 |
| **代码中直接写二进制数** | `x = 0b...` | `x = 0b101` $\to$ `x` 值为 `5` | 在代码里直观定义位掩码 |

---

### 注意事项

1. **类型区别：转换出来的都是字符串（`str`）**
   * `bin(5)` 或 `f"{5:b}"` 的返回结果是 **字符串**，不能直接进行 `&`、`|` 等位运算！
   * **❌ 错误写法**：`"101" & "011"` （字符串不能做位运算）
   * **✅ 正确做法**：直接对数字 `5 & 3` 进行位运算。

2. **负数的 `bin()` 结果不符合直觉**
   * Python 中 `bin(-5)` 输出的是 **`'-0b101'`**，而不是计算机底层的补码形式。
   * 如果想在 Python 中查看负数的 32 位补码二进制，需要做一步掩码：`f"{(-5) & 0xFFFFFFFF:032b}"`。

3. **`int(s, 2)` 严格限制字符集**
   * 字符串 `s` 中只能包含 `'0'`、`'1'`（或开头的 `'0b'`）。如果包含 `'2'` 或空格，会直接抛出 `ValueError`。
