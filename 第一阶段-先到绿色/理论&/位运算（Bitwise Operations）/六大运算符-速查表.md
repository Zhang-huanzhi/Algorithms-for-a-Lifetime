## 六大运算符

设整数 `a`、`b`：

| 运算符      | 名称   | 含义                    | 示例             |
| -------- | ---- | --------------------- | -------------- |
| `a & b`  | 按位与  | 两个位都为 `1` 时为 `1`      | `5 & 3 == 1`   |
| `a \| b` | 按位或  | 至少一个位为 `1`            | `5 \| 3 == 7`  |
| `a ^ b`  | 按位异或 | 两个位不同为 `1`            | `5 ^ 3 == 6`   |
| `~a`     | 按位取反 | `0` 与 `1` 互换          | `~5 == -6`     |
| `a << k` | 左移   | 左移 `k` 位，相当于乘 `2**k`  | `5 << 2 == 20` |
| `a >> k` | 右移   | 右移 `k` 位，相当于整除 `2**k` | `20 >> 2 == 5` |

``` python
a = 5  # 101
b = 3  # 011

print(a & b)   # 1，001
print(a | b)   # 7，111
print(a ^ b)   # 6，110
print(~a)      # -6
print(a << 2)  # 20
print(a >> 1)  # 2
```

## 常见位操作模板

``` python
# 判断第 k 位是否为 1
if x & (1 << k):
    pass

# 将第 k 位设为 1
x |= 1 << k

# 将第 k 位设为 0
x &= ~(1 << k)

# 翻转第 k 位
x ^= 1 << k

# 获取最低位的 1
lowbit = x & -x

# 统计二进制中 1 的个数
count = x.bit_count()

# 转换为二进制字符串
s = bin(x)       # 例如 '0b101'
s = bin(x)[2:]   # 去掉 '0b'
```

注意：

```
# Python 中 ~x 等于 -x - 1
~5 == -6
```

另外，`&`、`|` 是**位运算**，而 `and`、`or` 是**逻辑运算**，不要混用。

### 📊 Python 六大位运算符极简速查表

| 运算符 | 名称 | 一句话规则 | Python 示例 | 运算过程 (以 `5` 和 `3` 为例) | 结果 |
| :---: | :--- | :--- | :--- | :--- | :---: |
| **`&`** | **按位与** | 两个都是 1，才是 1 | `5 & 3` | `101 & 011` $\to$ `001` | **`1`** |
| **`\|`** | **按位或** | 只要有一个 1，就是 1 | `5 \| 3` | `101 \| 011` $\to$ `111` | **`7`** |
| **`^`** | **按位异或** | **不同**为 1，**相同**为 0 | `5 ^ 3` | `101 ^ 011` $\to$ `110` | **`6`** |
| **`~`** | **按位取反** | 0 变 1，1 变 0（对应负数） | `~5` | 公式：`-(5 + 1)` | **`-6`** |
| **`<<`** | **左移** | 整体左移，右边补 0 ($\times 2^k$) | `5 << 1` | `101` $\to$ `1010` | **`10`** |
| **`>>`** | **右移** | 整体右移，挤掉右边 ($\lfloor \div 2^k \rfloor$) | `5 >> 1` | `101` $\to$ `10` | **`2`** |

### ⚠️ Python 刷题（AtCoder）4 大核心注意事项

#### 1. 括号！括号！一定要加括号！（最容易发生的 Bug）
在 Python 中，**位运算符的优先级低于比较运算符（`==`, `<`, `>` 等）**。
* **❌ 错误写法**：`if x & 1 == 1:`
  * 实际会被解释为 `if x & (1 == 1):` $\to$ 变成了 `if x & True:`，逻辑直接出错！
* **✅ 正确写法**：`if (x & 1) == 1:` 或者简写为 `if x & 1:`

#### 2. 异或（`^`）的自消性（必背考点）
* `x ^ x = 0` （任何数异或自己都等于 0）
* `x ^ 0 = x` （任何数异或 0 保持不变）
* **应用**：若有一堆数，除了一个数出现 1 次外，其余都出现 2 次，把全部数 `^` 起来，相同的数全部抵消变成 0，剩下的就是那个单出的数！

#### 3. Python 的大数不溢出优势（利好 Python 选手）
* 在 C++ 中，`1 << 62` 会因为超过 32 位 `int` 范围而直接溢出报错（必须写成 `1LL << 62`）。
* 在 **Python** 中，整数精度是无限的，你可以直接写 `1 << 60` 或 `1 << 100`，绝不会溢出！这在 AtCoder 处理大范围数据时非常方便。

#### 4. 取反运算符 `~` 的计算公式
* 不要硬记二进制补码，在 Python 中直接记公式：**`~x` 等于 `-(x + 1)`**。
* 比如在数组索引中，`a[~i]` 正好可以用来访问倒数第 `i+1` 个元素（例如 `a[~0]` 就是 `a[-1]`，倒数第一个）。
