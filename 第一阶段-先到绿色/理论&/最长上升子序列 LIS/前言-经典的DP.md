**最长上升子序列**（**L**ongest **I**ncreasing **S**ubsequence，简称 **LIS**）是计算机科学与算法竞赛中最**经典、最基础**的**动态规划（DP）模型**之一。

在算法面试（如 LeetCode 第 300 题）和各类算法竞赛中，它都是必考的基础核心考点。

---

### 一、什么是 LIS？

给定一个序列，在**保持原有先后顺序**的前提下，选出一个子序列，使得其中的元素**严格单调递增**，求这个子序列的**最大长度**。

* **子序列 vs 子数组**：
  * **子数组/子串**：必须是连续的一段。
  * **子序列**：可以**不连续**，只要前后相对顺序不变即可。

#### 举个例子：
假设原数组为：`[10, 9, 2, 5, 3, 7, 101, 18]`
* 递增子序列有很多，比如 `[10, 101]`（长度 2）、`[2, 5, 7, 101]`（长度 4）、`[2, 3, 7, 18]`（长度 4）等。
* 最长上升子序列的长度为 **4**（例如 `[2, 3, 7, 101]`）。

---

### 二、LIS 的经典解法

解决 LIS 问题有两种经典的解法，分别对应不同的复杂度：

#### 1. 基础动态规划 —— $\mathcal{O}(N^2)$
这是学习 DP 状态设计的“教科书式”例题。
* **状态定义**：$dp[i]$ 表示以第 $i$ 个数结尾的最长上升子序列长度。
* **状态转移**：遍历 $i$ 前面的所有位置 $j$（$j < i$）：
  $$\text{如果 } A[j] < A[i] \implies dp[i] = \max(dp[i], dp[j] + 1)$$
* **适用场景**：$N \le 5000$ 左右的小规模数据。

#### 2. 贪心 + 二分查找 —— $\mathcal{O}(N \log N)$
当 $N \le 10^5 \sim 10^6$ 时，$O(N^2)$ 会超时，必须用更优的算法。
* **核心贪心思想**：为了让子序列尽可能长，我们希望序列里的每一个数字都**尽可能小**（增长得越慢，后面能塞进去的数就越多）。
* **算法维护**：维护一个数组 `tails`，其中 `tails[len]` 表示**长度为 `len` 的上升子序列的最小结尾值**。
  * 遍历数组，利用**二分查找**在 `tails` 中找到第一个 $\ge A[i]$ 的位置并替换它；如果都比它小，则扩展序列长度。

---

### 三、为什么说 LIS 是一个“知识点体系”？

因为围绕 LIS 衍生出了一整套算法题型与变体：

| 变体分类 | 典型问题/描述 |
| :--- | :--- |
| **基础变体** | **最长不下降子序列**（允许等于：$A_{i+1} \ge A_i$）、最长下降子序列 |
| **结构变体** | **最长双调子序列**（先增后减，如“合唱队形”问题） |
| **多维变体** | **二维 LIS**（如 LeetCode 354 俄罗斯套娃信封问题：宽度、高度均需递增） |
| **约束变体** | **固定步长 LIS**（**就是你刚才问的那道题！** 要求每次只能 $+1$，从而将二分退化为 $\mathcal{O}(1)$ 的哈希查找） |
| **输出路径** | 不仅求最长长度，还要输出具体的子序列方案 |

### 总结
* **本质**：在保持先后顺序的序列中，寻找单调递增子序列的最值问题。
* **核心工具**：动态规划、贪心、二分查找、单调性维护。
* **地位**：就像数据结构里的“二分查找”或图论里的“Dijkstra”一样，是每一个算法学习者**必须掌握的基石算法**。
