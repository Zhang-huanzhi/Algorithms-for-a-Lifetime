# 前言
做了多少题了400~470？

我从 ABC440 开始Rating，到现在 参赛到了469，今天晚上再参加470
刷题是从401开始系统性参加的，每天基本上都能做一题C或者D。（AB有顺手做，但不考虑），我现在都养成习惯了，每天不花一个多小时做算法题我都不舒服。

每天都至少有花费1h时间吧，最近几天因为Codex时间切分，导致算下来都有两个小时了， 结果还没有到800+绿色，我心里也苦呀，真如逆水行舟。

刷题基本上就是动脑思考十分钟，然后没思路就问Gemini，说实话，我也觉得自己自主思考的时间有点少了，但我每次rating还是有思考的，所以也没有过分的强迫自己。

我基本上有将我做过的C，D题全部归档过， 呃呃，好像最初的几次Rating归档到Pycharm工作区去了， 我后来也没有搬到obsidian里，反正都有归档。
到现在， 可以说我的笔记都已经略有雏形了， 虽然说SCM做得还是有点不太好，还需要系统性整理下文件夹。还好， 不必追求完美主义嘛，至少我每天有打开这个文件夹。

# 正文
我觉得已经可以进行到下一个阶段了， 就知识点突击复习导向，我好像先前笔记也有说这一点，说遇到一道题要做下此文件夹下的题，不过好像执行的也一般，又回到每天一道新题就行的阶段了。
这怎么说？ 我哪怕再次在这强调说实话也不一定能坚持下去。而且现状其实也不错。

再说一次吧，要针对知识点学习，甚至说，一周就这一个知识点，也行，不能只是过文件夹下的题，还要扩展思考，让Gemini改这道题条件，去发散思考。
比如说，我昨天做的那道 BFS图论搜索 + 虚拟节点（传送门）的题，你就可以去发散思考，思考，如果这道题有权重，最后求的是权重最大怎么办？或者求的是权重最小？权重为负的情况。这样扩展思考我认为是很有价值的。 当然这样扩展思考后，基本上都会设计一些更难的算法，估计就是E，F题了，这时候其实也没必要强迫自己去学习，但要有引子，有留痕，等800+后，突击E题就很容易连接上，估计能学得更快。

这里为了强调，补一下上一次的执行方案。
就是，留痕，知识点可以写到 理论& 这个文件夹下， 这个时候就不要求是真题原题了， 就将其抽象成一个只靠这个知识点的题，比如说BFS搜索，哪怕是ABC，一道算法题也很少只涉及一个知识点，基本上都是杂糅的，比如说这道BFS搜索+虚拟节点， 你当然可以将其抽象成BFS搜索，然后以这个为前言，写道 理论& 文件夹下， 只做抽象泛化理论学习。 

这样应该可以强迫自己进行理论学习， 专注于一个知识点。
时间上没必要给自己太多焦虑， 一个知识点花费一周也可以，现在也不是很急，年底800+都可以接受。
