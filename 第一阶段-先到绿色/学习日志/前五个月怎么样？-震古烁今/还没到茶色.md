
# 前言

很难想象，坚持了有五个月吧，居然c题都不能稳定做出。

第一次没做出C题，我还很愧疚，当时觉得天塌了，现在没做出C题，我居然能够接受了。

abc459 - c 我大概一辈子不会忘记你吧，震古烁今。

我这段时间是怎么学习的？

一开始好像是，ai对话找知识点，然后出例题，再了解，但发现ai出的题，太蠢了，而且非常同质化。

然后开始做abc的真题，主要做c，d题的笔记，记得是从401开始做的吧，现在到412了。基本上c题都有点做不出来，也都可以做笔记归档。自我感觉挺好的。

只是说有一个缺陷，就是我不太爱动脑子思考，基本上看个五分钟，写个暴力代码，或者没有思路，就直接开始问AI，找解法理解了，每次看到基本上都恍然大悟，然后自认为掌握了，后续也没有回看，也没有真正自己独立重做，写一遍代码。

这样每天只需要花四五十分钟个小时，基本上就ok。

再说说遇到的一个难题，笔记不知道归档在哪。我发现一个算法题，考察的知识点，思想，算法，数据结构，基本上都是多方面的，比如说，哈希表，桶，稀疏矩阵，这可能同时出现，我现在问你怎么做笔记？准备归档在哪？

我现在执行的策略是，取一个最重要的，至少是我认为最重要的，比如说，我认为这道题属于，构造题+贪心，我认为构造这个是更重要的，我就将其归档再我算法s里的构造里，然后还是以例题欸导向，建立一个文件夹（例题x1-贪心），再写下面涉及的更小的知识点。

我觉得这样很不错，打算继续执行这个策略。但是了，还有一个问题，就说我之前归档的笔记，没有体系化，属于是ai说啥我规啥，可能建立两个文件夹，一个叫做双指针，一个叫做时间窗口，但其实这两个可以并再一起的。先前的笔记其实记得也挺一坨的。

我打算不管，笔记乱就乱吧，谁说一定要保持绝对的秩序的，反正后面随便看，也随意修改，没必要强求秩序。欸，我还是只每天一道题吧，然后归档的时候再复习下此领域的文件，估计也要花费一定时间。看上去挺不错的。

我总结下，我现在采取的学习策略。

每天一题，问题导向，归档知识点，复习知识点。

不错，不过还需要进一步强调一些东西，那就是，给自己一点思考时间，不能总是说，看一道题，不到五分钟，就开始问ai找答案了，这样感觉不太好吧，。

立一些标准，必须遇到新problem必须思考20min，可以定给番茄钟。归档的时候，以一道题最重要的点为归档文件夹，然后命名例题xx-（其他知识点），有关这一道题其他有意思的技巧或者说算法思维，数据结构选择，可文件file形式。

就这样吧，再坚持三四个月，怎么这么难呀，拿一个绿色。
