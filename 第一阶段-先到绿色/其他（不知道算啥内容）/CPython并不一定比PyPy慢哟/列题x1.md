### C - 鱼骨 (Fishbones)  
  
**时间限制:** 2 秒 / **内存限制:** 1024 MiB  
  
**分值:** 300 分  
  
#### 问题描述  
  
艺术家高砂君创作了一个鱼骨形状的艺术品。  
  
这个艺术品由 **N** 根肋骨和 **1** 根脊椎组成。肋骨从 **1** 到 **N** 编号。  
  
高砂君计划在 **N+1** 根骨头上各写一个字符串，并满足以下所有条件：  
  
1.  写在脊椎上的字符串长度为 **N**。  
2.  对于每根肋骨 `i`（`i=1, ..., N`），满足以下条件：  
    *   写在肋骨 `i` 上的字符串长度为 `A_i`。  
    *   写在肋骨 `i` 上的字符串的第 `B_i` 个字符，必须与写在脊椎上的字符串的第 `i` 个字符一致。  
3.  写在 **N+1** 根骨头上的所有字符串，都必须从给定的 `S_1, ..., S_M` 中选择（可以重复使用）。  
4.  `S_1, ..., S_M` 是由小写英文字母组成的字符串，且互不相同。  
  
对于 `j=1, ..., M`，请回答以下问题：  
  
**是否存在一种满足条件的方案，使得写在脊椎上的字符串是 `S_j`？**  
  
#### 约束条件  
  
*   `N` 是整数  
*   `1 ≤ N ≤ 10`  
*   `A_i, B_i` 是整数 (`1 ≤ i ≤ N`)  
*   `1 ≤ B_i ≤ A_i ≤ 10` (`1 ≤ i ≤ N`)  
*   `M` 是整数  
*   `1 ≤ M ≤ 200000`  
*   `S_j` 是由小写英文字母组成的字符串 (`1 ≤ j ≤ M`)  
*   `1 ≤ |S_j| ≤ 10` (`1 ≤ j ≤ M`)  
*   `S_1, ..., S_M` 互不相同  
  
#### 输入  
  
输入格式如下：  
  
```  
N  
A_1 B_1  
...  
A_N B_N  
M  
S_1  
...  
S_M  
```  
  
#### 输出  
  
输出 M 行。  
  
第 `j` 行（`1 ≤ j ≤ M`），如果存在一种方案使得脊椎上的字符串为 `S_j`，则输出 `Yes`，否则输出 `No`。  
  
#### 输入样例 1  
  
```  
5  
5 3  
5 2  
4 1  
5 1  
3 2  
8  
retro  
chris  
itchy  
tuna  
crab  
rock  
cod  
ash  
```  
  
#### 输出样例 1  
  
```  
Yes  
Yes  
No  
No  
No  
No  
No  
No  
```  
  
**解释：**  
  
*   当脊椎上的字符串是 `retro` 时，可以通过在肋骨 `1, 2, 3, 4, 5` 上分别写下 `chris`, `retro`, `tuna`, `retro`, `cod` 来满足条件。  
    *   `retro` 的长度是 5。  
    *   对于每根肋骨：  
        1.  肋骨 1：`chris` 长度为 5，其第 3 个字符 `r` 与 `retro` 的第 1 个字符 `r` 一致。  
        2.  肋骨 2：`retro` 长度为 5，其第 2 个字符 `e` 与 `retro` 的第 2 个字符 `e` 一致。  
        3.  肋骨 3：`tuna` 长度为 4，其第 1 个字符 `t` 与 `retro` 的第 3 个字符 `t` 一致。  
        4.  肋骨 4：`retro` 长度为 5，其第 1 个字符 `r` 与 `retro` 的第 4 个字符 `r` 一致。  
        5.  肋骨 5：`cod` 长度为 3，其第 2 个字符 `o` 与 `retro` 的第 5 个字符 `o` 一致。  
  
*   当脊椎上的字符串是 `chris` 时，可以通过在肋骨 `1, 2, 3, 4, 5` 上分别写下 `itchy`, `chris`, `rock`, `itchy`, `ash` 来满足条件。  
  
#### 输入样例 2  
  
```  
5  
5 1  
5 2  
5 3  
5 4  
5 5  
8  
retro  
chris  
itchy  
tuna  
crab  
rock

```  
  
#### 输出样例 2
