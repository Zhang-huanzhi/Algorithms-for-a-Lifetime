**最常用的 Top 5：**
1. `d[key]` / `d.get(key, default)`
2. `d.items()` - 遍历
3. `d.pop(key)` / `del d[key]` - 删除
4. `key in d` - 判断
5. `d.update()` - 更新

---

**1. 访问和获取**
```python
d = {'a': 1, 'b': 2}

d['a']              # 1 - 直接访问（键不存在会报错）
d.get('a')          # 1 - 安全获取
d.get('c', 0)       # 0 - 不存在返回默认值
d.keys()            # dict_keys(['a', 'b'])
d.values()          # dict_values([1, 2])
d.items()           # dict_items([('a', 1), ('b', 2)])
```

**2. 添加和修改**
```python
d['c'] = 3          # 添加/修改键值对
d.update({'d': 4})  # 批量更新
d.setdefault('e', 5)  # 键存在返回值，不存在则设置
```

**3. 删除**
```python
del d['a']          # 删除键值对（不存在会报错）
d.pop('b')          # 删除并返回值
d.pop('x', None)    # 安全删除
d.popitem()         # 删除并返回最后一个键值对
d.clear()           # 清空
```

**4. 判断**
```python
'a' in d            # True - 键是否存在
'a' not in d        # False
len(d)              # 字典大小
```

**5. 遍历**
```python
for key in d:                    # 遍历键
for value in d.values():         # 遍历值
for key, value in d.items():     # 遍历键值对
```

**6. 复制**
```python
d2 = d.copy()       # 浅拷贝
```
