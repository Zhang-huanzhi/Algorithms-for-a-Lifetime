
### 3. 处理“一对多”的反向字典

如果一个 value 可能对应多个 key，可以使用 collections.defaultdict 来构造。

```python
from collections import defaultdict

my_dict = {'a': 1, 'b': 2, 'c': 1}
reverse_dict = defaultdict(list)

for k, v in my_dict.items():
    reverse_dict[v].append(k)

print(reverse_dict[1])  # 输出: ['a', 'c']
```
