### 2. 翻转字典（最常用）

如果你需要频繁地通过 value 查 key，最好的办法是预先创建一个反向字典。

复杂度：构建 $O(n)$，查询 $O(1)$

```python
my_dict = {'a': 1, 'b': 2, 'c': 3}

# 翻转
reverse_dict = {v: k for k, v in my_dict.items()}

# 查询
print(reverse_dict[1])  # 输出: 'a'
```

**注意**：这种方法要求原字典中的 value 必须是唯一的且可哈希的。如果有重复的 value，后面的 key 会覆盖前面的 key。
