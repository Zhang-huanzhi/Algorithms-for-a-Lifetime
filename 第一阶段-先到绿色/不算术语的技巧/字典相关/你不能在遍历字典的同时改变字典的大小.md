
# Why？
Python 的字典底层是**哈希表**。

当你遍历字典时，Python 内部有一个指针按顺序读取哈希表中的槽位。

- **如果你增加了元素**，哈希表可能会触发**扩容**并重新分配所有元素的位置。
- **如果你删除了元素**，槽位会发生变化。

如果允许在遍历时改变大小，指针就会错乱，导致**某些元素被重复遍历**、**某些元素被漏掉**，甚至引发内存崩溃。为了防止这种不可预测的错误，Python 内部有保护机制，一旦检测到字典大小改变，直接抛出 RuntimeError。

# 解决方案

 **遍历“快照”**
