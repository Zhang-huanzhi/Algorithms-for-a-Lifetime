## 字典安全取值技巧

**语法**：`dict.get(key, default)`

**作用**：取字典的值，如果键不存在返回默认值（不报错）

**常见用法**：
```python
cnt[x] = cnt.get(x, 0) + 1  # 计数器：有就+1，没有就从0开始
```

**等价于**：
```python
if x in cnt:
    cnt[x] += 1
else:
    cnt[x] = 1
```

**一句话**：`get(key, 默认值)` 避免 KeyError，常用于计数、累加等场景。
