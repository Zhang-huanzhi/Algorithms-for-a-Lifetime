对数据处理中，如果没有必要，尽量不要对其数据结构做出改变。

不要一会是int型，一会是浮点数float

---

## 1. 浮点除法（普通除法）：`/`

**功能：** 执行标准的数学除法。

**结果类型：** 即使操作数（被除数和除数）都是整数，结果也总是浮点数（float）。

**示例 (Python):**
```python
5 / 2  # → 2.5
4 / 2  # → 2.0
```

---

## 2. 整数除法（地板除法）：`//`

**功能：** 执行除法，然后将结果向负无穷大方向取整（即"地板"取整）。

**结果类型：** 如果操作数都是整数，结果是整数（int）。

**示例 (Python):**
```python
5 // 2   # → 2   (2.5 向下取整为 2)
4 // 2   # → 2
-5 // 2  # → -3  (-2.5 向下取整为 -3)
```
