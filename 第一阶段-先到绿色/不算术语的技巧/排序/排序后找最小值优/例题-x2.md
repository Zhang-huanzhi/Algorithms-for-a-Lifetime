# C - 排除和最小值  
  
**执行时间限制**：2 秒  **内存限制**：1024 MB    
**配点**：300 分  
  
## 问题描述  
  
有 N 个编号为 1 到 N 的球放在一个袋子里。球 i 上写有整数 $A_i$。  
  
需要处理 Q 个查询。  
  
对于每个查询，给定一个长度为 K 的数列 $B_1, B_2, \ldots, B_K$（所有 $B_i$ 都在 1 到 N 之间，且互不相同），执行以下操作：  
  
1. 将球 $B_1, B_2, \ldots, B_K$ 全部从袋子中取出  
2. 输出当前剩余在袋子里的球上写的整数的最小值（约束保证袋子不为空）  
3. 将取出的 K 个球全部放回袋子  
  
## 约束条件  
  
- $6 \leq N \leq 3 \times 10^5$  
- $1 \leq Q \leq 2 \times 10^5$  
- $1 \leq A_i \leq 10^9$  
- $1 \leq K \leq 5$  
- $1 \leq B_1 < B_2 < \cdots < B_K \leq N$  
- 所有查询的 K 值总和不超过 $4 \times 10^5$  
- 输入的所有值都是整数  
  
## 输入格式  
  
```  
N Q  
A_1 A_2 ... A_N  
query_1  
query_2  
⋮  
query_Q  
```  
  
每个查询的格式为：  
```  
K  
B_1 B_2 ... B_K  
```  
  
## 输出格式  
  
输出 Q 行。第 i 行输出第 i 个查询的答案。  
  
## 示例 1  
  
**输入**  
```  
6 6  
3 2 5 9 1 2  
2  
4 5  
5  
1 2 3 4 6  
3  
2 5 6  
4  
1 2 5 6  
1  
5  
3  
1 2 3  
```  
  
**输出**  
```  
2  
1  
3  
5  
2  
1  
```  
  
## 示例说明  
  
以第 1 个查询为例，取出球 4 和球 5 后，袋子中剩余以下 4 个球：  
  
- 球 1：写有 3  
- 球 2：写有 2  
- 球 3：写有 5  
- 球 6：写有 2  
  
因此，剩余球上整数的最小值是 **2**。
