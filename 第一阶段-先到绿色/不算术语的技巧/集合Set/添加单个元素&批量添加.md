
| 方法             | 添加数量 | 典型场景      |
| -------------- | ---- | --------- |
| `add(x)`       | 单个   | 遍历时逐个加    |
| `update(iter)` | 批量   | 把一整行数字加进去 |
| `\|=`          | 批量   | 合并两个 set  |


```python
seen = set()

# 遍历时逐个加
for x in arr:
    seen.add(x)

# 直接把一行全加进去
seen.update(arr)

# 初始化时直接转换
seen = set(arr)  # 从 list 直接建 set
```


---

**1. `add(x)` — 添加单个元素**

```python
s = {1, 2}
s.add(3)
print(s)  # {1, 2, 3}

s.add(2)  # 已存在，自动忽略
print(s)  # {1, 2, 3}
```

**2. `update(iterable)` — 批量添加**

接受任意可迭代对象（list、tuple、set、generator 都行）：

```python
s = {1, 2}
s.update([3, 4, 5])
print(s)  # {1, 2, 3, 4, 5}

s.update([3, 6], [7, 8])  # 可以传多个
print(s)  # {1, 2, 3, 4, 5, 6, 7, 8}
```
