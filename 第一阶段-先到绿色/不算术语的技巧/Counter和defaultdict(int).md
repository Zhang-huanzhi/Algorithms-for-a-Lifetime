
| 特性   | `Counter`                      | `defaultdict(int)`     |
| ---- | ------------------------------ | ---------------------- |
| 用途   | 专门用于**计数**                     | 通用的带默认值字典              |
| 默认值  | 固定为 `0`                        | 根据传入函数（如 `int`、`list`） |
| 额外方法 | `most_common()`、`elements()` 等 | 无                      |
