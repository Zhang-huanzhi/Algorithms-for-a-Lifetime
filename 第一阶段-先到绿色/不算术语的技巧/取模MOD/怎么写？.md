#### 1. 定义一个 MOD 常量

在代码的开头，定义一个全局常量来存储模数。这样做的好处是代码更清晰，且万一需要更换模数，只需修改一处。
``` python、
# 推荐使用大写字母表示常量
MOD = 1_000_000_007 
# 或者
MOD = 10**9 + 7
```

#### 2. 在每次“加法”和“乘法”后取模
这是最关键的一步。只要进行了可能让数值增大的运算，就要立刻 % MOD。

#### 3. 特别注意“减法”
减法可能会产生负数，而我们通常需要一个 [0, MOD-1] 范围内的正数结果。
**标准处理方法是：(a - b + MOD) % MOD**

这个技巧可以巧妙地将负数转为等价的正数。
``` python
# 错误: 可能产生负数
diff = (a - b) % MOD 

# 正确: 保证结果为正
diff = (a - b + MOD) % MOD
```
- **为什么有效？** 加上 MOD 再取模，对于正数结果没有影响（例如 (10 - 5 + 7) % 7 还是 5），但对于负数，它能保证括号内的值变为正数，从而得到正确的模结果（例如 (5 - 8 + 7) % 7 结果是 4）。
