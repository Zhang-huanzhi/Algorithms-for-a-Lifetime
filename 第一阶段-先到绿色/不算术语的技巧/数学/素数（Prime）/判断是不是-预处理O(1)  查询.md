**方案一：试除法 $O(\sqrt{n})$**
**方案二：性能最强（预处理 + $O(1)$ 查询）**

适用场景：  
题目给了你一个范围 $N$（例如 $N=10^6$ 或 $10^7$），并要求你多次询问“1 到 $N$ 之间的数是不是素数”。  
这是竞赛中“空间换时间”的标准做法。

---

**Python代码：**

```python
# 预处理：用埃氏筛或欧拉筛把 1 到 N 的所有素数标出来
MAXN = 1000001
is_prime = [True] * MAXN
is_prime[0] = is_prime[1] = False

def init_sieve():
    for i in range(2, int(MAXN**0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, MAXN, i):
                is_prime[j] = False

# 查询：直接通过数组下标访问
# if is_prime[x]:  # O(1) 的查询时间！
```

---

**复杂度：**  
- 预处理 $O(N\log\log N)$  
- 查询 $O(1)$

**优点：**  
如果你需要频繁判断某个数是不是素数，这比重复调用试除法快得多。
