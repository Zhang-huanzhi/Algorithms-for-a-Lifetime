试除法（Trial Division）

质因数分解本质上是：**“从小到大依次尝试，能除就除，除尽为止”**。

质因数分解的常规算法（试除法）时间复杂度为 $O(\sqrt{n})$。

---
**常用方法：**
1. 从2开始，依次尝试能否整除n。
2. 如果能整除，就不断除以该质数，直到不能整除为止。
3. 然后尝试下一个质数，直到 $\sqrt{n}$。
4. 如果最后n大于1，说明n本身是一个质数。

**Python代码示例：**

```python
def prime_factors(n):
    factors = []
    i = 2
    while i * i <= n:
        while n % i == 0:
            factors.append(i)
            n //= i
        i += 1
    if n > 1:
        factors.append(n)
    return factors

print(prime_factors(60))  # 输出: [2, 2, 3, 5]
```

**应用场景：**
- 判断一个数是否为质数
- 求最大公约数、最小公倍数
- 约数个数、约数之和等数论问题
