核心思想是：**每个合数只会被它“最小的质因子”筛掉一次。**
普通的筛法（埃氏筛）中，同一个合数会被多个质因子重复筛除（例如 12 同时被 2 和 3 筛掉），造成了浪费。欧拉筛通过一个巧妙的条件，强制让合数只被筛一次。

基于：
**整数唯一分解定理**
乘法交换律

任何合数都有他对应的一个最小因子。 

---
``` python
def linear_sieve(n):  
    is_prime = [True] * (n + 1)  
    primes = []  
    is_prime[0] = is_prime[1] = False  
  
    for i in range(2,n + 1):  
        if is_prime[i]:  
            primes.append(i)  
        for p in primes:  
            if i * p > n:  
                break  
            is_prime[i * p] = False  
            if i % p == 0:  
                break  
    return primes
```
