**一维区间求交集（Interval Intersection）**。

---
#### 1. 问题背景：为什么需要它？

我们经常会遇到这样的问题：

- “一个会议时间是 9:00-11:00，另一个是 10:00-12:00，它们重叠的时间段是？”
- “一个玩家的攻击范围是坐标 5 到 15，一个怪物的身体在坐标 12 到 18，攻击命中的范围是？”

这些问题本质上都是在问：  
给定两个区间 $[a, b]$ 和 $[c, d]$，它们的公共部分（交集）是什么？

---
### 2. 笨办法：一堆 if-else 的噩梦

一个没学过这个技巧的人，可能会开始疯狂地分类讨论：

- 如果 a 在 c 和 d 之间...
    
- 如果 c 在 a 和 b 之间...
    
- 如果两个区间一个包含另一个...
    
- 如果它们部分重叠...
    
- 如果它们刚好挨着...
    

写出来的代码会像下面这样，逻辑混乱，极易出错：

``` python
# 噩梦般的写法，千万别学
if a >= c and b <= d:
    # ...
elif c >= a and d <= b:
    # ...
elif a <= c and b >= c and b <= d:
    # ...
# 还有好几种情况...
```
