给你一个代表“总时长”的整数 TT，让你输出当前进度的时间戳。

若总时长为 210 秒，输出 00:03:30


``` python
	T = 3661  # 示例总时长
	h = T // 3600
	m = (T % 3600) // 60
	s = T % 60
	print(f"{h:02d}:{m:02d}:{s:02d}")  # 输出 01:01:01
```
