简单来说：`time` 是给**计算机**看的（偏底层、处理秒数），`datetime` 是给**人**看的（偏应用、处理年月日）。

实际上，`datetime` 库在底层很多地方是调用了 `time` 库的功能。

| 特性        | time 模块               | datetime 模块          |
| --------- | --------------------- | -------------------- |
| **视角**    | 计算机（秒、戳）              | 人类（年、月、日、时）          |
| **易用性**   | 较难，数字很多               | 极其友好，面向对象            |
| **主要用途**  | 性能测试、程序暂停 (sleep)     | 逻辑计算、日期转换            |
| **算法竞赛中** | 计算运行时间 (perf_counter) | 处理日期加减逻辑 (timedelta) |
### 为什么要搞两个？

- 如果你想知道“**这段算法代码跑了多少秒？**” —— 必须用 time。
    
- 如果你想知道“**2024年3月1号往后推50天是几号**？” —— 必须用 datetime。
