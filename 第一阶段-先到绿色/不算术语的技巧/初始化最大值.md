
| 场景   | 初值          | 作用               |
| ---- | ----------- | ---------------- |
| 求最小值 | `math.inf`  | 任何实际值都比它小，能被正确更新 |
| 求最大值 | `-math.inf` | 任何实际值都比它大，能被正确更新 |

**关键点：** 初始化为"极端值"，这样遍历数据时第一个值就能正确参与比较。

---

`inf` 是 **infinity**（无穷大）的缩写。

`math.inf` 在底层是一个特殊的**浮点数**，表示无穷概念，不是普通数（数的最大值）
**内存表示：**

- `math.inf` 是 `float` 类型
- 占 **8 个字节**（64位）
- 遵循 **IEEE 754 浮点数标准**
- 特定的位模式表示无穷大

**具体的位模式：**

对于双精度浮点数（64位）：

- 正无穷大 (`math.inf`)：`0111111111110000...0`（指数全1，尾数全0）
- 负无穷大 (`-math.inf`)：`1111111111110000...0`（符号位1，指数全1，尾数全0）

**`max_val = -math.inf`** 或 **`max_val = float('-inf')`**（两者等价）

- **`-math.inf` 或 `float('-inf')`** ✓（标准做法）
    
    - 简洁、通用
    - leetcode/竞赛程序常见
- **取第一个元素**（当数据量大时）
    
    - 避免浮点比较开销
    - 适合性能要求高的场景
