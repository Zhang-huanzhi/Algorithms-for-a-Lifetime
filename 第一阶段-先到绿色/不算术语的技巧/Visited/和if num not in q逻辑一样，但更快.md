检查是否重复入队

第一反应的逻辑肯定是， if num in q

但deque双端队列的 in q 是线性查找，是o（n）复杂度的，所以说，肯定会TLE，单开一个数组去标记状态可以实现o（1）

| 数据结构                 | `item in data_structure` 的时间复杂度 | 适用场景/备注                                                       |
| :------------------- | :------------------------------ | :------------------------------------------------------------ |
| **`list` / `array`** | **O(N)** (线性扫描)                 | **千万不要**用 `in` 来检查一个大列表！但用索引 `arr[i]` 访问是 O(1)。               |
| **`set` / `dict`**   | **O(1)** (平均，哈希查找)              | **非常适合**用来快速检查元素是否存在。                                         |
| **`deque`**          | **O(N)** (线性扫描)                 | `deque` 的优势在于两端 O(1) 的 `append` 和 `pop`，**绝不应该**用 `in` 来检查元素。 |
