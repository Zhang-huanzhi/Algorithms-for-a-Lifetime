### C - 稻草富翁  
  
**运行时间限制:** 2 秒 / **内存限制:** 1024 MiB  
  
**分值:** 300 分  
  
#### 问题描述  
  
存在从物品 1 到物品 N 的 N 种物品。开始时，高桥君只拥有物品 1。  
  
高桥君有 M 个朋友。  
对于第 i 个朋友 (1 ≤ i ≤ M)，如果将物品 A<sub>i</sub> 交给他，就可以得到物品 B<sub>i</sub>。  
  
请求出包括物品 1 在内，高桥君总共能获得多少种不同的物品。  
  
#### 限制条件  
  
*   2 ≤ N ≤ 3 × 10<sup>5</sup>  
*   1 ≤ M ≤ 3 × 10<sup>5</sup>  
*   1 ≤ A<sub>i</sub>, B<sub>i</sub> ≤ N  
*   A<sub>i</sub> ≠ B<sub>i</sub>  
*   所有输入值均为整数  
  
#### 输入  
  
输入将通过标准输入按以下格式给出：  
  
```  
N M  
A_1 B_1  
A_2 B_2  
...  
A_M B_M  
```  
  
#### 输出  
  
输出答案。  
  
#### 输入样例 1  
  
```  
5 5  
1 2  
2 3  
3 4  
2 4  
5 2  
```  
  
#### 输出样例 1  
  
```  
4  
```  
  
例如，可以通过以下操作获得物品 4：  
1.  将物品 1 交给第 1 个朋友，得到物品 2。  
2.  将物品 2 交给第 4 个朋友，得到物品 4。  
  
高桥君可以获得的物品是物品 1、2、3、4，共 4 种。因此，请输出 4。  
  
#### 输入样例 2  
  
```  
3 2  
2 1  
3 2  
```  
  
#### 输出样例 2  
  
```  
1  
```  
  
高桥君唯一能获得的物品是物品 1，共 1 种。  
  
#### 输入样例 3  
  
```  
7 8  
2 6  
2 5  
3 6  
1 6  
1 2  
5 6  
2 3  
3 7  
```  
  
#### 输出样例 3  
  
```  
6  
```
