 一、反向输出

| 对象类型        | 方法           | 示例                                    |
| ----------- | ------------ | ------------------------------------- |
| **字符串**     | `s[::-1]`    | `"abc"[::-1]` → `"cba"`               |
| **列表**      | `lst[::-1]`  | `[1,2,3][::-1]` → `[3,2,1]`           |
| **任意可迭代对象** | `reversed()` | `list(reversed([1,2,3]))` → `[3,2,1]` |

 二、反向遍历

| 场景           | 方法                       | 示例                               |
| ------------ | ------------------------ | -------------------------------- |
| **for 循环反向** | `for x in reversed(lst)` | 从后往前遍历                           |
| **range 反向** | `range(n-1, -1, -1)`     | `range(4, -1, -1)` → `4,3,2,1,0` |
| **直接切片**     | `for x in lst[::-1]`     | 创建反向副本再遍历（占空间）                   |

---

| 场景              | 推荐方法                     | 原因       |
| --------------- | ------------------------ | -------- |
| **反转字符串**       | `s[::-1]`                | 最简洁      |
| **反转列表（不改原列表）** | `lst[::-1]`              | 最简洁      |
| **反转列表（要改原列表）** | `lst.reverse()`          | 原地修改，省空间 |
| **只需遍历一次**      | `for x in reversed(lst)` | 省空间      |
