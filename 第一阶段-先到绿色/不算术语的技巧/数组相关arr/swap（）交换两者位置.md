| 方式                                | 速度    | 可读性   | 底层原理    |
| --------------------------------- | ----- | ----- | ------- |
| `a, b = b, a`                     | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 创建元组，解包 |
| `arr[i], arr[j] = arr[j], arr[i]` | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 同上      |
| 临时变量                              | ⭐⭐⭐   | ⭐⭐    | 多占存储空间  |

---

### **1️⃣ 最优雅：直接赋值（Python 独有）**
```python
a, b = b, a
```
- **原理**：Python 先计算右边的元组 `(b, a)`，再统一赋值给左边
- **无需临时变量**
- **竞赛推荐** ✅

### **2️⃣ 列表索引交换**
```python
arr[i], arr[j] = arr[j], arr[i]
```
- 同理，利用元组解包

### **3️⃣ 传统方式（借助临时变量）**
```python
temp = a
a = b
b = temp
```
- C/Java 的思路
- Python 中完全不需要
