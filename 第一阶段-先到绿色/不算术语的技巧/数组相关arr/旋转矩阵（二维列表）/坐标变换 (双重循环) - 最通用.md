这种方法逻辑最清晰，适用于任何编程语言。通过寻找旋转前后坐标 `(i, j)` 的映射关系来实现。

#### 顺时针 90 度公式

原本在 `(i, j)` 的元素，旋转后会出现在 `(j, N - 1 - i)`。

#### 实现代码

```python
def rotate_90_clockwise(M):
    n = len(M)
    # 初始化一个全是 0 的新矩阵
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            res[j][n - 1 - i] = M[i][j]
    return res
```
