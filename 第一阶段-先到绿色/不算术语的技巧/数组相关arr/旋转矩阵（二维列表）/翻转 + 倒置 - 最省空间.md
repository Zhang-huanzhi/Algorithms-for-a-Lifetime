如果你记不住复杂的坐标公式，可以记住旋转可以通过简单的“镜像翻转”组合而成。

#### 顺时针 90 度

1.  **上下翻转** (矩阵倒序)
2.  **转置** (主对角线镜像，行变列)

#### 实现代码

```python
# 假设 M 是你的矩阵
# 这是一个原地修改 (in-place) 的方法

# 1. 上下翻转
M.reverse()

# 2. 转置 (行变列)
for i in range(len(M)):
    for j in range(i + 1, len(M)):
        M[i][j], M[j][i] = M[j][i], M[i][j]
```
