这是 Python 中最简洁、最常用的方法，利用了 `zip` 函数和解包运算符 `*`。

#### 顺时针旋转 90 度

**步骤：**
1.  先上下翻转行序 (`[::-1]`)
2.  再进行转置 (`zip(*)`)

```python
# 假设 M 是你的矩阵
# 例如: M = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# 步骤：1. 先翻转行序 [::-1]； 2. 再进行转置 zip(*)
rotated = [list(row) for row in zip(*M[::-1])]
```

**解释：** `M[::-1]` 把矩阵的最后一行变成第一行，依此类推。然后 `zip(*...)` 将翻转后矩阵的行转换成列，从而实现顺时针旋转。

#### 逆时针旋转 90 度

**步骤：**
1.  先进行转置 (`zip(*)`)
2.  再上下翻转行序 (`[::-1]`)

```python
# 假设 M 是你的矩阵
# 例如: M = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# 步骤：1. 先转置 zip(*)； 2. 再翻转行序 [::-1]
rotated = [list(row) for row in zip(*M)][::-1]
```

**解释：** `zip(*M)` 先将矩阵的行和列互换（转置）。然后 `[::-1]` 将新矩阵的行序倒置，从而实现逆时针旋转。
