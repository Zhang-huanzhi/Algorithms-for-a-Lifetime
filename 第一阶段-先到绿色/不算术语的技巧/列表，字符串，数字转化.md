
| 操作     | 方法             | 时间复杂度       | 备注           |
| ------ | -------------- | ----------- | ------------ |
| 数字→字符串 | `str(num)`     | $O(\log n)$ | $n$ 是数字大小    |
| 字符串→数字 | `int(s)`       | $O(len)$    | `len` 是字符串长度 |
| 列表→字符串 | `''.join(lst)` | $O(n)$      | **推荐**       |
| 列表→字符串 | `s += item`    | $O(n^2)$    | **禁止**       |
| 字符串→列表 | `list(s)`      | $O(n)$      |              |
| 字符串→列表 | `s.split()`    | $O(n)$      |              |

**关键原则：** 在算法竞赛中，涉及字符串拼接时，永远使用 `join()`，避免在循环中使用 `+=`。
