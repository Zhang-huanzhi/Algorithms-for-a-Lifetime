在 Python 中，`round(p[1]/100, 2)` 虽然在数值上保留了两位小数，但它**不会在末尾补零**。

- 如果 `p[1] = 10` (即 0.1 元)，`round(10/100, 2)` 的结果是 `0.1`。使用 `print()` 输出时就是 `0.1`，而不是题目要求的 `0.10`。
- 如果 `p[1] = 0`，输出会是 `0.0`，而不是 `0.00`。

对于这种严格要求保留两位小数的题目，绝对不能使用 `round()`，而必须使用字符串格式化操作（比如 f-string 这个方案）。

---

- **若要计算四舍五入参与下一步运算** -> 用 `round()`
- **若要最后打印输出满足格式要求** -> 用格式化字符串 (`f"{val:.2f}"`)

### f-string (Python 3.6+)
这是目前最推荐、最简洁且最直观的写法。在变量后加上 `:.2f` 即可：
```python
value = 2.1
print(f"{value:.2f}")  # 输出: 2.10

value = 0
print(f"{value:.2f}")  # 输出: 0.00
```
*   `:` 表示格式化说明符的开始。
*   `.2` 表示保留两位小数。
*   `f` 表示浮点数（不足部分会自动用 0 补齐）。
