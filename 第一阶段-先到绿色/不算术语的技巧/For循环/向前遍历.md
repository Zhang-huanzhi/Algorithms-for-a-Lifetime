#### 1. 使用负索引切片（最常用）
```python
lst = [1, 2, 3, 4, 5]

# 反向遍历
for item in lst[::-1]:
    print(item)  # 5, 4, 3, 2, 1
```
**时间复杂度：** $O(n)$ - 需要创建反向列表副本

#### 2. 使用 reversed()（推荐）
```python
for item in reversed(lst):
    print(item)  # 5, 4, 3, 2, 1
```
**时间复杂度：** $O(1)$ 创建迭代器，$O(n)$ 遍历
**优势：** 不创建副本，内存高效

#### 3. 使用负步长 range()
```python
# 从最后一个索引到第一个
for i in range(len(lst) - 1, -1, -1):
    print(lst[i])  # 5, 4, 3, 2, 1
```
**适用场景：** 需要索引操作时

#### 4. 使用 enumerate() 反向
```python
for i, item in enumerate(reversed(lst)):
    print(f"索引 {len(lst)-1-i}: {item}")
```

### 快速对比

| 方法         | 代码                     | 内存    | 适用场景   |
| ---------- | ---------------------- | ----- | ------ |
| 切片         | `lst[::-1]`            | 创建副本  | 简单场景   |
| reversed() | `reversed(lst)`        | 不创建副本 | **推荐** |
| range()    | `range(len-1, -1, -1)` | 最少    | 需要索引   |
