`startswith()` 是 Python 的字符串方法，用来判断一个字符串是否以某个指定前缀开头。

---

**为什么用**  
因为它比手动写下标判断更简洁、更安全。  
例如判断是否以 `"--"` 开头，写：

```python
arr.startswith("--")
```

比写：

```python
arr[0] == "-" and arr[1] == "-"
```

更稳，不会因为字符串长度不够而越界报错。

**解决什么问题**  
它主要用来做**前缀匹配判断**，常见于：

- 参数解析
- 路径/文件名判断
- 命令格式识别
- 字符串分类处理

**时间复杂度**  
如果前缀长度是 `m`，那么时间复杂度是：

```text
O(m)
```

因为它最多检查前 `m` 个字符。  
像判断 `"--"` 这种很短的前缀时，基本可以看成常数时间。
