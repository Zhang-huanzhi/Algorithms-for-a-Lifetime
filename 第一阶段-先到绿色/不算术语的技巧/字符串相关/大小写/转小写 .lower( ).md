## 1. s.lower() 方法

这是**最常用的方法**。

**语法：**
```python
new_string = s.lower()
```

**返回值：**
- 返回一个全新的字符串对象
- 原字符串 `s` 不会被改变（因为 Python 中的字符串是不可变类型 immutable）
- 如果原字符串中本来就没有大写字母，依然会返回一个内容相同的新字符串

**时间复杂度：** O(N)
- 其中 N 是字符串的长度
- **原理：** Python 必须遍历字符串中的每一个字符，检查它是否是大写，如果是则转换

**空间复杂度：** O(N)
- 因为需要开辟一段新的内存空间来存储转换后的字符串

---

## 2. 特定位置转换（切片法）

如果你只想转第一个字符：

**语法：**
```python
ans = s[0].lower() + s[1:]
```

**返回值：** 返回拼接后的新字符串

**时间复杂度：** O(N)
- `s[0].lower()` 是 O(1)
- `s[1:]` 切片操作需要复制剩余的 N-1 个字符，复杂度是 O(N)
- 字符串拼接 `+` 也会产生 O(N) 的开销

**空间复杂度：** O(N)

---

## 3. 底层函数：ord() 和 chr()

在手写更底层算法时（例如不使用内置 API），你会用到这两个：

### ord(char)
- **返回值：** 整数（Unicode/ASCII 码点）
- **示例：** `ord('A')` 返回 `65`
- **时间复杂度：** O(1)

### chr(int)
- **返回值：** 单个字符的字符串
- **示例：** `chr(97)` 返回 `'a'`
- **时间复杂度：** O(1)

## 4. 算法性能对比表

| 操作 | 返回值类型 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|-----------|------|
| `s.lower()` | `str` (新) | O(N) | O(N) | 最快，C底层优化 |
| `s.upper()` | `str` (新) | O(N) | O(N) | 转大写 |
| `s.capitalize()` | `str` (新) | O(N) | O(N) | 首字母大写，其余小写 |
| `s.swapcase()` | `str` (新) | O(N) | O(N) | 大小写翻转 |
| `s[i] = 'a'` | 报错 | - | - | 禁止操作（不可变） |

## 5. 算法竞赛中的避坑指南

### ❌ 不要在循环里反复拼接字符串

**错误示范：** 复杂度会退化到 O(N²)
```python
res = ""
for char in s:
    res += char.lower()
```

**原因：** 每次 `+` 都会创建一个全新的字符串并复制前面的内容。

**正确做法：** 直接用 `s.lower()` 或者先存入列表 `[]` 最后用 `"".join(list)`。

### ✅ 处理本题 Handmaid 的最佳写法

```python
S = input().strip()
# 时间 O(N), 空间 O(N)
print("Of" + S.lower())
```

对于题目给出的 N ≤ 10，O(N) 的操作耗时不到 1ms，完全不用担心性能。
