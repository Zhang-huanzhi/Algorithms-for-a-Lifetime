#### 场景 3：大量输出时防超时（Fast I/O）
当题目要求输出 $10^5$ 行答案时，调用 $10^5$ 次 `print()` 非常耗时。
先把结果存起来，最后用换行符 `\n` 一次性打印，能提速好几倍。
```python
ans = []
for _ in range(100000):
    ans.append("YES") # 收集答案

# 用换行符作为分隔符，一次性全部输出
print("\n".join(ans))
```

**总结：** 做算法题时，看到**批量转换输出格式**、**大批量字符拼接**、**避免循环输出**，第一反应就应该用 `.join()`。
