### 模拟题：火星探测车指令解析

**【题目描述】**  
火星探测车初始坐标在二维平面的 (0, 0)。  
它接收到了一段从地球发来的长字符串指令。由于受到宇宙射线的干扰，指令中掺杂了大量的无用乱码（包含各种字母、数字和特殊符号）。

真正**有效**的移动指令格式**严格限定为**：

1. **一个大写字母**，且只能是 U、D、L、R 中的一个（分别代表 上、下、左、右）。
    
2. 紧接着必须是一个 **等号 =**。
    
3. 紧接着必须是 **一串数字**（代表移动的步数）。
    

例如：U=15 表示向上移动 15 步，R=3 表示向右移动 3 步。

任何不符合上述严格格式的子串统统视为乱码，应直接忽略。  
例如：

- u=10 （字母小写了，忽略）
    
- U-10 （不是等号，忽略）
    
- X=5 （X 不是方向字母，忽略）
    
- L=abc （等号后面不是数字，忽略）
    

**【输入格式】**  
一行字符串 S，长度不超过 

```
105105
```

，包含各种可见字符。

**【输出格式】**  
两个整数 x y，用空格隔开，表示探测车最终的坐标。  
(注：R 让 x 增加，L 让 x 减少；U 让 y 增加，D 让 y 减少)

**【样例输入】**


```
*aB!U=10#noiseX=5L=3!R=12@D=2&&U=05
```

**【样例输出】**

```
9 13
```

**【样例解释】**  
提取出的有效指令依次为：

1. U=10 (y 加上 10，坐标变为 0, 10)
    
2. L=3 (x 减去 3，坐标变为 -3, 10)
    
3. R=12 (x 加上 12，坐标变为 9, 10)
    
4. D=2 (y 减去 2，坐标变为 9, 8)
    
5. U=05 (y 加上 5，坐标变为 9, 13)  
    （注意：X=5 被忽略了）
