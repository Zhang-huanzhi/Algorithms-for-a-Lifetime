场景三：词法分析 / 切割表达式（写计算器必备）

动作：用管道符 | 把不同的规则并列起来。

返回值：按顺序切好的一维列表。

例题：大模拟常考的“表达式求值”，要把 "123+45*6" 切成数字和运算符。

代码（Python）：

```python
import re
s = "123+45*6"

# 规则：要么是连续数字 (\d+)，要么是加减乘除符号 ([+\-*/])
# 注意：减号在[] 里有特殊含义，需要加 \ 转义，或者放在最后面
res = re.findall(r"\d+|[+\-*/]", s)

print(res)
# 输出: ['123', '+', '45', '*', '6']
# 拿到这个干干净净的数组，直接往“单调栈”或者“后缀表达式”算法里套就行了！
```
