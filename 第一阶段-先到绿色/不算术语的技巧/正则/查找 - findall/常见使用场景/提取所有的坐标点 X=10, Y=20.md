场景二：提取成对/成组的数据（最常考！）

动作：规则里加多对括号 ( )。把你需要的各个部分分别括起来。

返回值：一个包含元组（Tuple）的列表。

例题：提取所有的坐标点 X=10, Y=20。

代码（Python）：

```python
import re
s = "noise X=10 jkl Y=20"

# 规则：一个大写字母 + 等号 + 连续数字。
# 我们只需要字母和数字，不需要等号，所以把字母和数字括起来！
res = re.findall(r"([A-Z])=(\d+)", s)

print(res) 
# 输出:[('X', '10'), ('Y', '20')]

# 算法处理逻辑：
for letter, num in res:
    print(f"变量 {letter} 的值是 {int(num)}")
```
