你可以把这些符号理解为 if 判断的简写：

1. **\d** ：等价于 if s[i] >= '0' and s[i] <= '9'（匹配单个数字）。
    
2. **[A-Z]** ：等价于 if s[i] >= 'A' and s[i] <= 'Z'（自定义集合，匹配括号里的任意一个字符）。
    
3. **+** ：等价于 while 循环，表示“**前面的字符至少出现 1 次，连续的一起带走**”。
    
    - 举例：\d+ 会把 "123" 当作一个整体切下来，而不是切成 '1', '2', '3'。
        
4. **()** ：**提取器**。如果你的规则很长，但你只想要其中的某一部分，就把它括起来。
    
5. **|** ：等价于 or。用于“要么匹配左边，要么匹配右边”。
