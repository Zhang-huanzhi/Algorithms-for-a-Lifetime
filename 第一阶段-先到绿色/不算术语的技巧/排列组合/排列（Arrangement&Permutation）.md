## 前言：排列 vs 组合

在写代码前，必须先分清逻辑：

- **组合 $C(n,k)$**：选出 $k$ 个人组成一个小组。比如：选 3 个审稿人。谁先被选、谁后被选没区别。（用 `math.comb`）
    
- **排列 $A(n,k)$**：选出 $k$ 个人并安排职务。比如：选 3 个人，分别担任"主审"、"副审"、"终审"。顺序变了，结果就不同。（用 `math.perm`）
    

---

## 知识点：math.perm(n, k)

### 1. 基本功能

- **用途**：计算从 $n$ 个不同元素中取出 $k$ 个元素进行排列的方案数，即数学中的 $A_n^k$（国内教材常用 $A$）或 $P_n^k$（国际通用 $P$）。
    
- **公式**： $$A(n,k) = n \times (n-1) \times \cdots \times (n-k+1) = \frac{n!}{(n-k)!}$$
    
- **版本**：Python 3.8+ 引入。
    

---

### 2. 核心特性

1. **自动处理边界**：和 `comb` 一样，如果 $k > n$，`math.perm(n, k)` 会自动返回 `0`。
    
2. **默认全排列**：如果只传一个参数 `math.perm(n)`，它会计算 $n$ 的全排列，等同于 $n!$（阶乘）。
    
3. **计算速度**：底层 C 语言实现，比你自己写循环计算 $n \times (n-1) \ldots$ 要快得多。
    

---

### 3. 代码示例

```python
from math import perm

# 1. 基础排列：从 10 人中选 3 人分别担任班长、副班长、学习委员
print(perm(10, 3))  # 10 * 9 * 8 = 720

# 2. 自动处理范围：只有 2 个人，却要排 3 个职位
print(perm(2, 3))   # 输出 0

# 3. 计算全排列：5 个人排排坐
print(perm(5))      # 5! = 120
```

## 对比总结（算法题避坑指南）

|特性|组合 $C(n,k)$ / $\binom{n}{k}$|排列 $A(n,k)$ / $P(n,k)$|
|---|---|---|
|**Python 函数**|`math.comb(n, k)`|`math.perm(n, k)`|
|**顺序**|不重要 (Order doesn't matter)|重要 (Order matters)|
|**典型关键词**|选出、小组、集合、样本|排名、分配、职务、序列|
|**公式关系**|$C(n,k) = A(n,k) / k!$|$A(n,k) = C(n,k) \times k!$|

## 小技巧

在做题时，如果你不确定该用哪个，就问自己一句话：

**"把选出来的这两个人交换一下位置，算不算一种新的情况？"**

- 如果**不算** → 用 `comb`
- 如果**算** → 用 `perm`
