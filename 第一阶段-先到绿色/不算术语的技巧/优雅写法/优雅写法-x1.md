## 前言：为什么要追求"优雅"的写法？

在算法竞赛中，**同样的逻辑，写法不同，结果可能天差地别**。

很多新手认为"能跑就行"，但实际上：

- **冗余的代码**更容易出 bug
- **不优雅的写法**降低调试效率
- **笨拙的逻辑**容易在复杂题目中翻车

优秀选手的代码往往简洁、清晰、不易出错。掌握这些"优雅写法"，不仅能提升代码质量，还能在紧张的比赛中节省时间、减少失误。

---

## 1. 布尔状态的切换（Toggle）

### ❌ 不够优雅的写法

```python
if is_online == True:
    is_online = False
elif is_online == False:
    is_online = True
```

**问题：**

- 代码冗长（4-5 行）
- 逻辑重复
- 容易漏写 `elif` 导致逻辑错误

---

### ✅ 推荐写法（Pythonic）

```python
is_playing = not is_playing
```

**优势：**

- 一行搞定
- 语义清晰（"取反"）
- 不会出错

## 2. 其他常见优化习惯

### 习惯 A：交换两个变量

#### ❌ 传统写法

```python
temp = a
a = b
b = temp
```

#### ✅ Python 推荐

```python
a, b = b, a
```

**优势：** 无需临时变量，一行完成交换。

---

### 习惯 B：判断奇偶性

#### ❌ 不够简洁

```python
if x % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

#### ✅ 更简洁

```python
print("偶数" if x % 2 == 0 else "奇数")
```

**或者：**

```python
is_even = (x % 2 == 0)  # 直接得到布尔值
```

---

### 习惯 C：初始化多个变量

#### ❌ 逐个赋值

```python
a = 0
b = 0
c = 0
```

#### ✅ 链式赋值

```python
a = b = c = 0
```

**或者需要不同值时：**

```python
a, b, c = 0, 1, 2
```

---

### 习惯 D：条件赋值

#### ❌ 冗长的 if-else

```python
if score >= 60:
    result = "及格"
else:
    result = "不及格"
```

#### ✅ 三元表达式

```python
result = "及格" if score >= 60 else "不及格"
```

---

### 习惯 E：累加/累乘

#### ❌ 手动写循环

```python
total = 0
for x in arr:
    total += x
```

#### ✅ 使用内置函数

```python
total = sum(arr)
```

**乘积：**

```python
from math import prod
product = prod(arr)  # Python 3.8+
```

---

### 习惯 F：查找最大/最小值及其索引

#### ❌ 手动遍历

```python
max_val = arr[0]
max_idx = 0
for i in range(len(arr)):
    if arr[i] > max_val:
        max_val = arr[i]
        max_idx = i
```

#### ✅ 使用内置函数

```python
max_val = max(arr)
max_idx = arr.index(max_val)
```

**或者一步到位：**

```python
max_idx = max(range(len(arr)), key=lambda i: arr[i])
max_val = arr[max_idx]
```

---

### 习惯 G：列表去重并保持顺序

#### ❌ 手动循环

```python
result = []
for x in arr:
    if x not in result:
        result.append(x)
```

#### ✅ 使用 dict.fromkeys

```python
result = list(dict.fromkeys(arr))
```

**注意：** `set(arr)` 会去重但不保持顺序。

---

### 习惯 H：多条件判断

#### ❌ 重复变量名

```python
if x == 1 or x == 2 or x == 3:
    print("小数字")
```

#### ✅ 使用 in

```python
if x in (1, 2, 3):
    print("小数字")
```

---

### 习惯 I：字典默认值

#### ❌ 先检查再赋值

```python
if key not in d:
    d[key] = 0
d[key] += 1
```

#### ✅ 使用 get 或 defaultdict

```python
# 方法 1
d[key] = d.get(key, 0) + 1

# 方法 2（推荐）
from collections import defaultdict
d = defaultdict(int)
d[key] += 1
```

---

## 3. 总结表格

|场景|❌ 不够优雅|✅ 推荐写法|
|---|---|---|
|布尔切换|`if x == True: x = False...`|`x = not x`|
|交换变量|`temp = a; a = b; b = temp`|`a, b = b, a`|
|三元表达式|`if 条件: x = a else: x = b`|`x = a if 条件 else b`|
|求和|`for x in arr: sum += x`|`sum(arr)`|
|求最大值索引|手动循环|`max(range(len(arr)), key=lambda i: arr[i])`|
|多条件判断|`x == 1 or x == 2 or x == 3`|`x in (1, 2, 3)`|

---

## 口诀

> **能一行写完，绝不写两行。**  
> **能用内置函数，绝不手写循环。**  
> **逻辑越简洁，bug 越少见。**

---

## 练习建议

1. **刷题时有意识地重构**：写完代码后问自己"能不能更简洁？"
2. **学习 Python 内置函数**：`sum()`, `max()`, `min()`, `any()`, `all()` 等
3. **熟悉标准库**：`collections`, `itertools`, `functools` 等模块有很多好用工具

**记住：优雅的代码 = 更少的 bug + 更快的调试 + 更高的分数！**
