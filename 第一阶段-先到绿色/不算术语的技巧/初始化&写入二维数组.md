## 初始化

```python
# 创建 m 行 n 列，全部填充为 0
dp = [[0] * n for _ in range(m)]

# 例如：3行4列
grid = [[0] * 4 for _ in range(3)]
```

## 写入/修改

```python
# 直接用下标赋值
grid[0][1] = 5      # 第0行第1列 = 5
grid[2][3] = 10     # 第2行第3列 = 10

# 在循环中修改
for i in range(m):
    for j in range(n):
        grid[i][j] = i + j  # 或其他计算
```

## 常见用途

```python
# 1. 动态规划表格
dp = [[0] * (n+1) for _ in range(m+1)]  # 多开1行1列方便处理边界

# 2. 标记访问过的位置
visited = [[False] * n for _ in range(m)]
visited[1][2] = True

# 3. 读取输入的二维数组（如矩阵题）
matrix = []
for _ in range(m):
    row = list(map(int, input().split()))
    matrix.append(row)
```

**记住**：
- 一定要用 `for _ in range()`，不要用 `* m` 复制整行
- `grid[行][列]` 的顺序
- 常见题型：最短路径、DP表、岛屿问题都会用到
