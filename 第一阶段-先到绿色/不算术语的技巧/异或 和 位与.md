最常见的，你先记这 5 个就够用了。算法题里真的经常见。

**1. 用 位与 判断奇偶**

原理：
- 偶数二进制最后一位是 0
- 奇数二进制最后一位是 1

写法：

    if x & 1:
        print("奇数")
    else:
        print("偶数")

这是位与最常见的用途之一。

**2. 用 位与 判断某一位是不是 1**

比如你想看第 k 位是否为 1：

    if x & (1 << k):
        print("第k位是1")
    else:
        print("第k位是0")

这个在二进制题、状态压缩题里特别常见。

你可以这样理解：
- 1 << k 就是“只让第 k 位亮起来”
- 再和 x 做 位与
- 如果结果不是 0，说明这一位原本就是 1

**3. 用 异或 找“只出现一次的数”**

这是异或最经典的题型。

比如数组里：
- 其他数都出现 2 次
- 只有 1 个数出现 1 次
- 找出这个数

写法：

    nums = [2, 3, 2, 4, 4]
    ans = 0
    for x in nums:
        ans ^= x
    print(ans)

结果是 3。

因为：
- 2 ^ 2 = 0
- 4 ^ 4 = 0
- 最后只剩下那个单独的数

你一定要记住这个性质：
- a ^ a = 0
- a ^ 0 = a

**4. 用 异或 翻转某一位**

比如把第 k 位翻转：
- 原来是 0，就变 1
- 原来是 1，就变 0

写法：

    x ^= (1 << k)

这个在“开关切换”“状态反转”里很常见。

对比一下：
- 检查某位：x & (1 << k)
- 翻转某位：x ^ (1 << k)

**5. 用 位运算做状态压缩**

这个你现在先知道意思就行。

比如有 4 个东西，每个东西只有“选”或“不选”两种状态。
那就可以用一个整数的二进制位来表示。

例如：
- 第 0 位表示第 0 个东西
- 第 1 位表示第 1 个东西
- 第 2 位表示第 2 个东西

常见操作：

判断是否选了第 k 个：

    if state & (1 << k):
        pass

选中第 k 个：

    state |= (1 << k)

取消第 k 个：

    state &= ~(1 << k)

翻转第 k 个：

    state ^= (1 << k)

这个在子集枚举、状压 DP、搜索题里很常见。

**新手最该优先会的结论**

先把这 3 个背熟最实用：

1. x & 1
   判断奇偶

2. x & (1 << k)
   判断第 k 位是不是 1

3. ans ^= x
   找数组里只出现一次的数

**一张小抄**

- 位与 &：更像“检查”
- 异或 ^：更像“抵消”或“翻转”

最常见模板：

    x & 1

    x & (1 << k)

    ans ^= x
