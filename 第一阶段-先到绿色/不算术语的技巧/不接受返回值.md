**绝对合法！** 而且在 Python（以及 C++、Java 等绝大多数主流语言中）这是**极其常见且标准的常规操作**。


在 Python 的内置函数里，有很多函数是有返回值的，但我们经常只让它做事，而**忽略**它的返回值：

### 1. 你平时其实经常这么干，只是没察觉！

在 Python 的内置函数里，有很多函数是有返回值的，但我们经常只让它做事，而**忽略**它的返回值：

**例子：list.pop()**  
pop() 函数的作用是删除列表的最后一个元素，**同时它会返回被删除的那个元素**。

- **接收返回值的情况**：你需要知道删了啥。
    
    ``` python
    nums = [1, 2, 3]
    last_num = nums.pop()  # last_num 是 3
    ```
    
- **不接收返回值的情况**：你只想删掉最后一个数字，根本不在乎删掉的是几。
    

    
    ``` python
    nums = [1, 2, 3]
    nums.pop()  # 合法！3 被返回了，但你没拿变量接，Python 就直接把它丢进垃圾桶了
    print(nums) # 输出 [1, 2]
    ```
    

你看，你直接写 nums.pop() 的时候，其实就是在“有返回值，但不接受返回值”，Python 运行得好好的！
