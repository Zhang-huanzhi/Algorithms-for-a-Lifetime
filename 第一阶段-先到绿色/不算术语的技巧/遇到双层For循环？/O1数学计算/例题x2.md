**分值：**425 分  
  
---  
  
## 题目描述  
  
有一个二维坐标平面，坐标为 $(x, y)$ 的格点按照如下规则染色：  
  
- 当 $\max(|x|, |y|)$ 为偶数时，该点被染为黑色；  
- 当 $\max(|x|, |y|)$ 为奇数时，该点被染为白色。  
  
请你求出满足 $L \leq x \leq R$ 且 $D \leq y \leq U$ 的整数对 $(x, y)$ 中，被染为黑色的点的个数。  
  
---  
  
## 约束条件  
  
- $-10^6 \leq L \leq R \leq 10^6$  
- $-10^6 \leq D \leq U \leq 10^6$  
- 输入的值均为整数  
  
---  
  
## 输入  
  
输入以如下格式从标准输入给出：  
  
```  
L R D U  
```  
  
---  
  
## 输出  
  
输出答案。  
  
---  
  
## 输入样例 1  
  
```  
-4 3 1 3  
```  
  
## 输出样例 1  
  
```  
10  
```  
  
如上图所示，所求答案为 10。  
  
---  
  
## 输入样例 2  
  
```  
-14 14 -14 14  
```  
  
## 输出样例 2  
  
```  
449  
```
