# D - Take ABC 2  
  
**执行时间限制：** 2 秒 / **内存限制：** 1024 MiB    
**配点：** 400 点  
  
## 问题描述  
  
给定一个仅由 A、B、C 三种字符组成的字符串 S。  
  
定义以下操作：  
  
- 选择满足 1 ≤ i < j < k ≤ |S| 且 S<sub>i</sub> = A，S<sub>j</sub> = B，S<sub>k</sub> = C 的三元组 (i, j, k)，  
- 移除 S 的第 i、j、k 个字符，将剩余字符按原来的顺序向左合并。  
  
请求出对字符串 S 最多可以执行多少次操作。  
  
## 约束条件  
  
- 1 ≤ |S| ≤ 10<sup>6</sup>  
- S 仅由 A、B、C 组成  
  
## 输入格式  
  
输入从标准输入按以下格式给出：  
  
```  
S  
```  
  
## 输出格式  
  
输出答案。  
  
## 样例输入 1  
  
```  
ABACBCC  
```  
  
## 样例输出 1  
  
```  
2  
```  
  
**说明：**  
  
可以按照以下方式执行 2 次操作：  
  
1. 对 ABACBCC，选择 (i, j, k) = (1, 2, 7) 执行操作，剩余字符串为 ACBC。  
2. 对 ACBC，选择 (i, j, k) = (1, 3, 4) 执行操作，剩余字符串为 C。  
  
无法执行 3 次以上的操作，因此答案是 2。  
  
## 样例输入 2  
  
```  
CBACBB  
```  
  
## 样例输出 2  
  
```  
0  
```  
  
## 样例输入 3  
  
```  
BBBAAABCBCBAACBBCAAC  
```  
  
## 样例输出 3  
  
```  
5  
```
