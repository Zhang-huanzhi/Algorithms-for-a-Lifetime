为了在算法竞赛和工程中彻底避免**下标混淆、越界（IndexError）、边界特判漏写**等问题，以下为你梳理一套**最严谨、最通用、形成肌肉记忆的「前缀和」与「差分」规范指南**。

---

# 一、核心心法：两者是互逆运算

| 操作 | 解决的问题 | 核心思想 | 查询耗时 | 修改耗时 |
| :--- | :--- | :--- | :--- | :--- |
| **前缀和** | **静态区间求和**（只查不改） | 空间换时间，把每个位置前所有数的和存下来 | **$O(1)$** | $O(N)$ |
| **差分** | **批量区间修改**（只改不查，最后统一查） | 记录相邻两个数之间的“变化量” | $O(N)$ | **$O(1)$** |

> **互逆关系**：  
> 原数组 $\xrightarrow{\text{求相邻差}}$ 差分数组 $\xrightarrow{\text{求前缀和}}$ 原数组

---

# 二、前缀和（Prefix Sum）规范

### 1. 黄金法则
* **前缀和必须保留第 0 位（$pre[0] = 0$），强制使用 1-based 下标！**  
  这样可以做到：**任何区间 $[L, R]$ 的求和永远是 `pre[R] - pre[L - 1]`，终身告别边界 `if` 特判。**

### 2. 命名与规范代码

```python
# 1. 命名规范
# 原数组: arr
# 前缀和: pre 或 pref

# 2. 初始化：大小为 n + 1，默认全 0
# pre[i] 表示原数组前 i 个元素的和（即 arr[0] ~ arr[i-1] 的总和）
pre = [0] * (n + 1)

# 3. 构造前缀和（遍历原数组的每一个元素）
for i in range(n):
    pre[i + 1] = pre[i] + arr[i]

# 4. 区间查询：求原数组第 L 个数到第 R 个数的和 (1 <= L <= R <= n)
# 无论 L 是否等于 1，统一使用公式：
ans = pre[R] - pre[L - 1]
```

# 三、差分数组（Difference Array）规范

### 1. 黄金法则
* **数组大小必须开到 $N + 2$**：因为右端点操作是 `diff[R + 1] -= x`，当 $R = N$ 时，下标会访问到 $N + 1$。
* **终身使用「原地还原」**：差分还原为原数组的过程**就是对差分数组求一次前缀和**，不需要新建额外数组。

---

### 2. 规范代码 A（最常见：1-based 闭区间 $[L, R]$，如天数 $1 \sim D$）

```python
# 1. 命名规范
# 差分数组: diff

# 2. 初始化：大小为 n + 2（防止 R+1 越界）
diff = [0] * (n + 2)

# 3. 区间修改：对闭区间 [L, R] 每个数增加 x (1 <= L <= R <= n)
# 左端点开始增加，右端点后一位减去
diff[L] += x
diff[R + 1] -= x

# 4. 原地还原（从第 1 位开始向后滚前缀和）
for i in range(1, n + 1):
    diff[i] += diff[i - 1]

# 5. 输出 / 使用
# diff[1 : n + 1] 即为最终还原后的结果
print('\n'.join(map(str, diff[1 : n + 1])))
```

---

### 3. 规范代码 B（0-based 时间段问题：左闭右开 $[L, R)$，如时刻 $0 \sim T$）

便利店员工上班问题（$[L, R)$ 表示在区间 $[L, R-1]$ 内都在店）：

```python
# 1. 初始化：时间从 0 到 T-1，开到 T + 2
diff = [0] * (t + 2)

# 2. 区间修改：在 [L, R) 时间段内 +1
# 等价于闭区间 [L, R-1] 内 +1：
# 左端点 L 加 1：diff[L] += 1
# 右端点 (R-1) 的下一位即 R 减 1：diff[R] -= 1
diff[L] += 1
diff[R] -= 1

# 3. 原地还原（从第 1 位开始累加前一位）
for i in range(1, t + 1):
    diff[i] += diff[i - 1]

# 4. 输出：取 0 到 T-1 共 T 个时刻
print('\n'.join(map(str, diff[:t])))
```

# 四、速查避坑自检清单

| 检查项 | 为什么这样写？ | 常见 Bug 警示 |
| :--- | :--- | :--- |
| **前缀和开 `N + 1`** | `pre[0] = 0` 作为哨兵位。 | 没留 0 位导致查 $[1, R]$ 时 `pre[L-1]` 变成 `pre[-1]`（取了末尾元素）。 |
| **差分开 `N + 2`** | `diff[R + 1]` 在 $R = N$ 时索引为 $N + 1$。 | 开 `N + 1` 导致报 `IndexError: list index out of range`。 |
| **差分原地累加** | `diff[i] += diff[i - 1]` 遍历 $1 \sim N$。 | 额外开 `arr` 容易搞混 `i` 和 `i + 1` 的下标偏移。 |
| **还原循环从 1 开始** | `for i in range(1, n + 1)` | 永远不要从 0 开始向前加，因为 `diff[0 - 1]` 会访问数组最后一个元素！ |
