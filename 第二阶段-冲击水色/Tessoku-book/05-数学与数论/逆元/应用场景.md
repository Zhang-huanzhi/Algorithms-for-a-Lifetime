在算法竞赛（尤其是 AtCoder、Codeforces、LeetCode 周赛）中，“除法取模”是一个**出现频率极高、但模板极其固定**的题型。

只要看到题目最后有：
> **“答案请对 $10^9+7$ 或 $998244353$ 取模”**

并且你在推导公式时遇到了**除号 $\div$ 或分数线**，请直接套用下面的体系：

---

### 一、 核心心法（建立条件反射）

> **在模运算的世界里，没有除号 `\`，所有的 `\ B` 都要翻译为 `* 逆元`。**
> 
> 在 Python 3.8+ 中，求逆元只需要这一行神仙内置代码：
> `pow(B, -1, MOD)`

---

### 二、 三大高频实操场景与代码模板

根据题目的类型，通常分为以下三种场景，你可以把它们直接作为“肌肉记忆”存进代码库：

#### 场景 1：单次除法 / 概率与期望题（最简单）

**典型题意：** 
* “求小明获胜的概率，化为最简分数 $\frac{P}{Q}$ 后输出结果模 $998244353$。”
* “某事件有 $A$ 种方案，总方案数是 $B$，求平均值或概率。”

**固定代码模板：**
```python
MOD = 998244353  # 或 1000000007

# 1. 算出分子和分母（中间可以随意取模，防止数字太大）
P = 算出的分子 % MOD
Q = 算出的分母 % MOD

# 2. 一行秒杀：P * (Q 的逆元) % MOD
ans = (P * pow(Q, -1, MOD)) % MOD

print(ans)
```

---

#### 场景 2：单次组合数计算（如 A30、B30）

**典型题意：**
* 题目只给出一组 $N, R$（或者给出一个网格 $H, W$），只要算一次 $C_n^r$。

**固定代码模板：**
```python
MOD = 1000000007

# 算阶乘对 MOD 取模
def fact(x):
    res = 1
    for i in range(2, x + 1):
        res = (res * i) % MOD
    return res

# 组合数公式：n! / (r! * (n-r)!)
def comb(n, r):
    if r < 0 or r > n:
        return 0
    numer = fact(n)
    deno = (fact(r) * fact(n - r)) % MOD
    # 分子 * 分母逆元
    return (numer * pow(deno, -1, MOD)) % MOD
```

---

#### 场景 3：多次查询组合数 / 动态规划中的批量组合数（进阶大杀器）

**典型题意：**
* 题目有 $T$ 组测试用例，或者有 $Q = 10^5$ 次询问组合数；
* 或者在 DP 的每一步都要调用 $C_n^r$。
* *此时如果你每次都用场景 2 的 `fact` 循环，一定会超时！*

**解决套路（预处理阶乘与逆元）：**
在程序刚开始时，花 $O(N)$ 算好一张表，之后每次查询只需 **$O(1)$** 查表。

**终极模板（建议收藏，打 AtCoder 经常直接整段粘贴）：**
```python
MOD = 1000000007
MAX_N = 200005  # 根据题目范围设定，通常取 N 的最大值 + 5

# 1. 预处理阶乘数组
fact = [1] * (MAX_N + 1)
for i in range(1, MAX_N + 1):
    fact[i] = (fact[i - 1] * i) % MOD

# 2. 预处理阶乘逆元数组
# 技巧：先求出最大那个阶乘的逆元，然后倒着往前推，极其高效！
inv_fact = [1] * (MAX_N + 1)
inv_fact[MAX_N] = pow(fact[MAX_N], -1, MOD)
for i in range(MAX_N - 1, -1, -1):
    inv_fact[i] = (inv_fact[i + 1] * (i + 1)) % MOD

# 3. 极速 O(1) 查询组合数
def comb(n, r):
    if r < 0 or r > n:
        return 0
    # 公式：n! * inv(r!) * inv((n-r)!)
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

# 主逻辑
def main():
    # 哪怕后面来 10 万次查询，也是瞬间秒杀！
    print(comb(10, 3))
    print(comb(100, 20))
```

### 三、 避坑指南（90% 的人常挂在这里）

遇到除法取模，切记以下 4 个“雷区”：

1. **绝对不要写普通的除法符号 `/` 或整除 `//`**
   * 哪怕你能整除（比如 `(6 // 2) % MOD` 虽然等于 3，但如果前面先模过，`2` 可能会变成别的值导致整除失效）。
   * 牢记：**除法在模意义下，一律改成 `* pow(..., -1, MOD)`**。

2. **分母算完后，求逆元前最好先 `% MOD`**
   * 虽然 Python 能够处理大数，但是为了规范和速度，先保证传进 `pow` 的是一个已经模过的、合法的正整数。

3. **分母取模后不能等于 0**
   * $0$ 是没有逆元的。如果你的分母算出来 `% MOD == 0`，`pow(0, -1, MOD)` 会直接报错（ZeroDivisionError）。如果遇到这种情况，检查是不是分子分母刚好包含模数 $MOD$ 的因子。

4. **减法取模注意负数**
   * 虽然 Python 自带的 `%` 会自动把负数转为正余数（例如 `-1 % 7 == 6`），但在 C++ 或做复杂转移时，有减法习惯加上模数再模：
     `ans = (A - B + MOD) % MOD`，养成好习惯绝不吃亏。

**“见模莫用除，逆元换倒数；**  
**内置 `pow(-1)`，两数相乘模。”**
