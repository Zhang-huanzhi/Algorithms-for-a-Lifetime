这个方法被称为**辗转相除法**（又称**欧几里得算法**，Euclidean Algorithm），它是人类历史上最古老、最著名的算法之一（记载于公元前 300 年欧几里得的《几何原本》）。

它的核心原理只有一句话：  
**两个整数的最大公约数，等于其中较小的数和两数相除余数的最大公约数。**

用数学公式表达即为：
$$\gcd(a, b) = \gcd(b, a \pmod b)$$

---

### 1. 数学原理解释

我们假设 $a$ 除以 $b$ 的商是 $q$，余数是 $r$（即 $r = a \pmod b$），那么可以写成：
$$a = q \cdot b + r \implies r = a - q \cdot b$$

**推导过程：**
1. **假设 $d$ 是 $a$ 和 $b$ 的任意一个公约数**：
   * 既然 $d$ 能整除 $a$，也能整除 $b$，那么根据 $r = a - q \cdot b$，$d$ 也必然能整除 $r$。
   * 这说明：**$a$ 和 $b$ 的公约数，一定是 $b$ 和 $r$ 的公约数**。

2. **反过来，假设 $d$ 是 $b$ 和 $r$ 的任意一个公约数**：
   * 既然 $d$ 能整除 $b$，也能整除 $r$，那么根据 $a = q \cdot b + r$，$d$ 也必然能整除 $a$。
   * 这说明：**$b$ 和 $r$ 的公约数，也一定是 $a$ 和 $b$ 的公约数**。

**结论**：  
“$a$ 与 $b$ 的公约数集合” 和 “$b$ 与 $r$ 的公约数集合” 是完全相同的！  
既然公约数完全相同，那么其中**最大的那个公约数（GCD）也必定相同**，即：
$$\gcd(a, b) = \gcd(b, a \pmod b)$$

---

### 2. 代码每一步在做什么？

```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a
```

以样例 1 中的 `a = 33, b = 88` 为例，追踪变量变化：

1. **第 1 次循环**：
   * 当前：`a = 33, b = 88`
   * `a % b = 33 % 88 = 33`（小除以大，余数就是它本身）
   * 执行 `a, b = b, a % b` 后：`a = 88, b = 33`  
     *注：如果一开始 $a < b$，这一步会自动将两者大小颠倒过来！*
2. **第 2 次循环**：
   * 当前：`a = 88, b = 33`
   * $88 \div 33 = 2 \dots 22$，余数为 $22$
   * 执行后：`a = 33, b = 22`
3. **第 3 次循环**：
   * 当前：`a = 33, b = 22`
   * $33 \div 22 = 1 \dots 11$，余数为 $11$
   * 执行后：`a = 22, b = 11`
4. **第 4 次循环**：
   * 当前：`a = 22, b = 11`
   * $22 \div 11 = 2 \dots 0$，余数为 $0$
   * 执行后：`a = 11, b = 0`
5. **循环结束**：
   * 此时 `b == 0`，退出循环。
   * 因为任何数与 $0$ 的最大公约数都是它本身（$\gcd(11, 0) = 11$），此时的 `a` 就是最终答案，返回 `11`。

### 3. 为什么它如此高效？

* 每次取模操作（`a % b`），新的余数一定**小于除数的一半**（在平均/两步之内）。
* 这意味着数值是以**指数级速度缩减**的。
* 即使数值达到 $10^9$，也只需要大约 **30 ~ 40 次**运算就能降到 0，耗时只需几微秒，因此彻底避免了暴力循环带来的超时问题。
