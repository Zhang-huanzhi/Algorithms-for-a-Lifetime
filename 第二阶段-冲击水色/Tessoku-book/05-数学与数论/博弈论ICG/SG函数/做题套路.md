### 第一步：花 3 秒判断能不能套这个模版
看题目是不是满足下面 3 点：
1. **两人轮流玩**，最后**没法操作的人判负**。
2. 游戏是由**很多个独立的“子游戏”**组成的（最常见的就是：$N$ 堆石子，你每次只能选某一堆操作）。
3. 双方**规则一样**（没有“先手只能走黑子，后手只能走白子”这种区别）。

只要全中，**直接无脑上 SG 套路**！

---

### 第二步：看单堆石子 $A_i$ 的数据范围（关键分水岭）

这是博弈论最绝的地方：**99% 的题目只会有两种情况**。

#### 情况 A：$A_i$ 比较小（$A_i \le 10^5$ 左右，比如 A34）
**做法：直接无脑写 DP 算 SG 数组。**

只要背下这个求 $\operatorname{mex}$ 的万能代码片段：

```python
# 1. 准备一个数组存每个石子数的 SG 值
sg = [0] * (max_A + 1)

# 2. 从小到大 DP
for i in range(1, max_A + 1):
    visited = set()
    # 把从 i 能一步走到的所有局面的 SG 值丢进 set
    # 比如本题只能拿 X 或 Y 个：
    if i >= X:
        visited.add(sg[i - X])
    if i >= Y:
        visited.add(sg[i - Y])
    
    # 算 mex：找集合里没有的最小自然数 (0, 1, 2...)
    m = 0
    while m in visited:
        m += 1
    sg[i] = m
```

---

#### 情况 B：$A_i$ 特别大（$A_i \le 10^9$ 或 $10^{18}$，比如 B34）
**做法：不要慌，出题人必留了规律！祭出大招——“打表找规律”！**

遇到这种题，千万不要去推导什么高深数学公式，**直接把情况 A 的代码复制到草稿本/本地运行，打印出前 30 个看一眼**：

```python
# 本地写个临时脚本跑一下：
for i in range(25):
    # 打印前 25 个石子的 SG 值
    print(f"石子数 {i}: sg = {sg[i]}")
```
你会惊奇地发现，输出结果一定是像这样**有规律循环**的：
```text
0, 0, 1, 1, 2,   0, 0, 1, 1, 2,   0, 0, 1, 1, 2 ...
```
一看：**周期是 5**！
那直接在正式提交的代码里写：
```python
pattern = [0, 0, 1, 1, 2]
def get_sg(x):
    return pattern[x % 5] # 取模搞定！
```

---

### 第三步：不管怎么算出的 SG，最后全员异或（收尾模版）

不管是通过情况 A 的 DP 算出来的，还是情况 B 取模算出来的，最后都只有这 4 行代码：

```python
ans = 0
for a in A:
    ans ^= get_sg(a)  # 把每一堆的 SG 值异或起来

if ans != 0:
    print("First")
else:
    print("Second")
```

---

### 总结口诀（把这几句话背下来）

1. **“多堆独立无路输，必是 SG 异或和”** —— 看到多堆石子独立操作，最终结果一定是求各堆 SG 的异或。
2. **“数字小就无脑 DP，数字大就打表找周期”** —— $A_i$ 小于 $10^5$ 暴力 mex，数字大到 $10^{18}$ 就打印前 30 个找循环节然后取模。
3. **“异或非 0 先手赢，异或等于 0 后手赢”** —— 永远不变的结论。

这就是博弈论做题的“工业化流水线”，不需要去想复杂的数学证明，照着这三步走就能拿满分！
