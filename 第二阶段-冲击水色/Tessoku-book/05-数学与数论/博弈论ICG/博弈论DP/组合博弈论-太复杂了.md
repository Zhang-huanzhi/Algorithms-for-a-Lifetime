在算法竞赛中，我们常说的“博弈论”，全称其实是**组合博弈论（Combinatorial Game Theory, CGT）**。它不研究经济学里那种“囚徒困境”或者心理战，而是研究**纯数学、逻辑严密的棋盘/石子游戏**。

要想打好博弈论的基础，你只需要掌握以下这套**“由浅入深”的核心概念体系**：

---

### 一、 基本前提：什么是“公平组合游戏”（ICG）？
算法竞赛中 90% 的博弈题都属于 **ICG（Impartial Combinatorial Games）**，它必须满足以下 4 个铁律：
1. **两人轮流行动**，没有平局。
2. **完全信息与无随机**：双方都能看到全局信息，没有“手牌/迷雾”，没有掷骰子。
3. **“公平”（Impartial）**：在同一个局面下，**两个人能走的合法规则完全一样**。
   * *反例*：象棋、围棋不是公平博弈，因为白方只能下白子，黑方只能下黑子。
   * *正例*：取石子游戏是公平博弈，场上剩 5 个石子，先手能拿 2 个，换成后手也一样能拿 2 个。
4. **有限步结束**：不存在无限死循环，最后一定会分出胜负。
5. **常规规则（Normal Play）**：**最后无法操作的人判负**（即谁拿到最后一个石子谁赢）。

---

### 二、 核心基石：必胜态（N点）与 必败态（P点）
这是你刚刚在 A32/B32 里用 DP 算的东西，学术上有严格的名字：

| 术语 | 英文全称 | 俗称 | 含义 |
| :--- | :--- | :--- | :--- |
| **P-position** | **P**revious-player-winning | **必败态** | **上一个人（刚刚走完的人）必胜** $\to$ 轮到我走，我必输。 |
| **N-position** | **N**ext-player-winning | **必胜态** | **下一个人（当前准备走的人）必胜** $\to$ 轮到我走，我必赢。 |

#### 判定三公理（极为重要！）：
1. **终点是 P 点**：已经无路可走的状态（如剩 0 个石子），直接判负，它是 P 点。
2. **只要有一步能走到 P，你就是 N**：
   * 只要存在合法的一招，能把对手丢进必败局面，当前就是必胜态（$\exists \to P \implies N$）。
3. **走哪一步都只能到 N，你就是 P**：
   * 如果无论你怎么走，对方接手后都是必胜态，那你只能认输（$\forall \to N \implies P$）。

> **与你刚才代码的对应关系**：
> `dp[i] == True` 就是 **N 点**；
> `dp[i] == False` 就是 **P 点**。

### 三、 经典三大博弈模型
掌握这三个模型，几乎就掌握了博弈论的一半套路：

#### 1. 巴什博弈（Bash Game）——“单堆石子，限额取”
* **规则**：只有一堆 $n$ 个石子，每次只能取 $1 \sim m$ 个。
* **规律（数论模运算）**：
  * 如果 $n \pmod{m + 1} == 0$，**后手必胜（P）**。
  * 否则，**先手必胜（N）**。
* **直观逻辑**：先手只要先拿走 $n \pmod{m+1}$ 个，之后对手拿 $x$ 个，先手就拿 $(m+1-x)$ 个，始终给对方留 $(m+1)$ 的倍数，把对方活活憋死。

#### 2. 尼姆博弈（Nim Game）——“多堆石子，无限取”
* **规则**：有 $K$ 堆石子，数量分别为 $A_1, A_2, \dots, A_K$。每次可以选**其中某一堆**，取走任意多个（至少 1 个，也可以整堆拿完）。
* **规律（二进制异或 / Nim 和）**：
  * 计算所有石子数的异或和：$S = A_1 \oplus A_2 \oplus \dots \oplus A_K$。
  * 若 $S = 0$，**后手必胜（P 点）**。
  * 若 $S \ne 0$，**先手必胜（N 点）**！
* **震撼之处**：看似神仙打架的多堆石子博弈，竟然可以用一个最底层的**异或（XOR）**在 $O(K)$ 时间内秒杀！这就是你马上在 A33 会学到的内容。

#### 3. 威佐夫博弈（Wythoff Game）——“两堆石子，可联动”
* **规则**：两堆石子，每次可以从一堆拿任意个，**或者从两堆同时拿走相同数量的石子**。
* **规律（黄金分割比）**：它的必败态奇异局势 $(a_k, b_k)$ 与无理数黄金比例 $\phi = \frac{\sqrt{5}+1}{2} \approx 1.618$ 深度绑定：
  $$a_k = \lfloor k \cdot \phi \rfloor, \quad b_k = a_k + k$$
  （这也是为什么它常被归入“数论/离散数学”的原因之一）。

### 四、 组合博弈论的终极武器：SG 函数（Sprague-Grundy）
如果游戏规则既不是纯巴什，也不是纯尼姆，而是“好几个复杂独立子游戏的组合”，该怎么办？

两位数学家证明了一个震惊学界的定理——**SG 定理**：
> **任何公平组合游戏（ICG），都可以等价转化为一堆特定数量的“尼姆石子堆”！**

#### 1. $\text{mex}$ 运算（Minimum Excluded value）
* 定义：一个自然数集合中**没有出现的最小非负整数**。
* 例如：
  * $\text{mex}(\{1, 2, 3\}) = 0$（0 没出现）
  * $\text{mex}(\{0, 1, 3, 5\}) = 2$（2 没出现）

#### 2. SG 值的定义
对于状态 $x$，如果它能转移到的所有后继状态集合为 $\{y_1, y_2, \dots\}$，那么：
$$SG(x) = \text{mex}(\{SG(y_1), SG(y_2), \dots\})$$
* **终局必败态**：$SG(0) = \text{mex}(\emptyset) = 0$。
* **普通状态**：
  * $SG(x) = 0 \iff$ **必败态（P 点）**
  * $SG(x) > 0 \iff$ **必胜态（N 点）**

#### 3. 终极奥义：多个独立游戏的“异或和”
如果局面由多个独立的子游戏组成（比如有 3 个棋盘同时玩），总局面的 SG 值为：
$$SG_{total} = SG(G_1) \oplus SG(G_2) \oplus SG(G_3)$$
* 若 $SG_{total} = 0$，先手必败；
* 若 $SG_{total} \ne 0$，先手必胜！

### 五、 做博弈题的“解题心法”（思维导图）

遇到一道新博弈题，请按以下顺序排查：
1. **看是不是经典模型**：
   * 只有一堆连续取？ $\to$ **巴什博弈（直接取模）**
   * 多堆石子随便拿？ $\to$ **尼姆博弈（异或和）**
2. **看数据规模（小数据 $N \le 10^5$）**：
   * 状态简单？ $\to$ **像 A32/B32 一样写 DP 递推**。
   * 状态由多个部件组成？ $\to$ **用 $\text{mex}$ 算每个部件的 SG 函数，最后异或起来**。
3. **看数据规模（超大数据 $N \ge 10^9$）**：
   * 电脑跑不动 DP 了 $\to$ **写个小程序打表打印前 50 项的胜负态，找周期/奇偶规律**。绝大多数超大数据的博弈题，手推 20 项就会发现惊人的周期性！
