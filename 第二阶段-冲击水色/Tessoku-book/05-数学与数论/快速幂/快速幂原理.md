快速幂的核心原理非常简单，就一句话：**利用指数的“二进制拆分”与底数的“平方翻倍”，把原本连乘 $N$ 次的计算，压缩到 $\approx \log_2 N$ 次搞定。**

我们可以用一个具体例子秒懂它的运行机制：

---

### 一、直观例子：如何计算 $3^{13}$？

普通人算 $3^{13}$，要做 12 次乘法：$3 \times 3 \times 3 \dots \times 3$。

但快速幂会把指数 **$13$ 拆成二进制**：
$$13 = 8 + 4 + 1 = (1101)_2$$

所以：
$$3^{13} = 3^{8 + 4 + 1} = 3^8 \times 3^4 \times 3^1$$

此时我们只需要两样东西：
1. **底数的翻倍序列**：每个数都是前一个数的**平方**，算一次平方只需要做 1 次乘法！
   * $3^1 = 3$
   * $3^2 = (3^1)^2 = 9$
   * $3^4 = (3^2)^2 = 81$
   * $3^8 = (3^4)^2 = 6561$
2. **看指数的二进制位**：
   * 指数二进制是 `1101`（从右往左看是 `1, 0, 1, 1`）：
     * 第 0 位是 1 $\to$ 结果乘上 $3^1$
     * 第 1 位是 0 $\to$ 跳过（不要 $3^2$）
     * 第 2 位是 1 $\to$ 结果乘上 $3^4$
     * 第 3 位是 1 $\to$ 结果乘上 $3^8$

**结果**：原本需要算 12 次，现在只需要做 **3 次平方 + 3 次乘法 = 6 次运算**！

---

### 二、代码是如何实现这个过程的？

对照着上面的逻辑看代码，就会非常清晰：

```python
def power(a, b):
    res = 1
    while b > 0:
        # 1. 检查 b 当前二进制最低位是否为 1
        if b & 1:
            res *= a       # 是 1，就把当前的底数乘进答案

        # 2. 底数自乘翻倍：a^1 -> a^2 -> a^4 -> a^8 ...
        a *= a             

        # 3. b 右移一位（相当于 b //= 2，看下一个二进制位）
        b >>= 1            
        
    return res
```

*加上取模 `MOD` 时，只需要在每一步乘法后加上 `% MOD` 即可，这就是“边乘边模”。*

### 三、为什么这叫“降维打击”？

* 如果 $b = 10^9$（十亿）：
  * **普通连乘**：做 $10^9$ 次运算，耗时约 **几十秒甚至超时崩溃**。
  * **快速幂**：$10^9$ 转成二进制只有 **30 位**。只需做 30 次平方和最多 30 次乘法，总共约 **60 次基本运算**，耗时约 **0.000001 秒（微秒级）**。
* 如果 $b = 10^{18}$：
  * 普通连乘需要算到地球毁灭。
  * 快速幂只需要大约 **60 次循环**，依然是微秒级瞬间算出！
