### 第一部分：数学基础概念（简单却最易错）

1. **什么是素数（质数）？**
   * 在大于 1 的自然数中，**除了 1 和它本身以外不再有其他因数**的数。
2. **致命常识陷阱**：
   * **`1` 既不是素数，也不是合数！**（规定 1 不是素数，是为了保证任何正整数的质因数分解具有唯一性）。
   * **`2` 是最小的素数，也是唯一的偶素数。**
   * 所有 $\le 1$ 的数（0、1、负数）全部不是素数。

### 第二部分：单个数的判定 —— 试除法（Trial Division）

#### 适用场景：
* 询问次数较少，或者被询问的数特别大（如 $X \le 10^{12}$），无法开数组预处理时。

#### 核心原理：
* 如果一个数 $X$ 是合数，它必定能分解为 $a \times b$。其中必有一个因子 $\le \sqrt{X}$。
* 因此只需从 $2$ 试除到 $\lfloor\sqrt{X}\rfloor$ 即可，时间复杂度为 **$O(\sqrt{X})$**。

#### 终极模板代码：
```python
import math


def is_prime(x: int) -> bool:
    if x < 2:
        return False
    # math.isqrt(x) 整数开方，避免浮点数精度误差
    # range(2, 2) 在 x=2 和 x=3 时为空区间，巧妙直接返回 True
    for i in range(2, math.isqrt(x) + 1):
        if x % i == 0:
            return False
    return True
```

### 第三部分：批量预处理 —— 埃氏筛法（Eratosthenes）

#### 适用场景：
* 给出上限 $N$（如 $N \le 10^6$），要求输出所有素数，或者需要 $O(1)$ 极速回答成千上万次查询（如 A26、B26）。

#### 核心哲学：
* **“素数的倍数一定是合数。”**

#### 两个不可不知的黄金优化：
1. **外层循环到根号**：外层只需遍历到 $\sqrt{N}$，因为大于 $\sqrt{N}$ 的合数早被前面的小素数筛掉了。
2. **内层循环平方起跳**：素数 $i$ 的倍数直接从 $i \times i$ 开始筛，因为比它小的倍数（$2i, 3i, \dots$）早就被之前的素数处理过了。

#### 复杂度：
* 时间：$O(N \log \log N)$（实际耗时与线性几乎没差别）。
* 空间：$O(N)$。

#### 经典标准模板（1200 分段无脑首选）：
```python
import math


def sieve(n: int) -> list[bool]:
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, math.isqrt(n) + 1):
        if is_prime[i]:
            # 必须一路划到 n 为止！
            for j in range(i * i, n + 1, i):
                is_prime[j] = False

    return is_prime
```

### 第四部分：Python 语言特性与防 RE 秘籍（高级避坑）

在严苛的竞赛环境下，$N \ge 10^7$ 时，Python 默认的 `list` 会暴露出致命缺陷：

#### 1. 内存陷阱与 `bytearray` 优化
* **普通列表 `[True] * N`**：存的是 64 位指针，每个元素吃 **8 字节**。$10^8$ 大小直接吃光 800MB 内存，引发 `MemoryError` 导致 **RE（运行错误）**。
* **`bytearray([1]) * N`**：原生连续内存块，每个元素实打实只占 **1 字节**。$10^8$ 大小仅占用 100MB，完美避开 256MB 内存限制。
* **使用准则**：`bytearray` 后续可以 100% 当作 `list` 用，`0` 当 `False`，`1` 当 `True`。

#### 2. CPython vs PyPy3 的环境抉择
* **在标准 Python 3 (CPython)**：没有 JIT，解释器 `for` 循环极慢。必须使用 **切片批量赋值**（`is_prime[i*i:n+1:i] = ...`）来调用底层的 C 代码加速。
* **在 PyPy3 (AtCoder 默认)**：拥有 JIT 编译器，普通的纯粹 `for` 循环会被直接编译成机器汇编，**跑得比切片还快**（因为切片会创建临时对象引发 GC 垃圾回收卡顿）。

### 第五部分：高维视野 —— 欧拉筛（线性筛）

#### 核心哲学：
* **“任何合数，必须且只能被它的【最小质因数】筛掉一次。”**
* 彻底消灭了埃氏筛中“同一个合数被不同质数重复标记”的冗余，达到严格的 **$O(N)$**。

#### 灵魂代码：
```python
if i % p == 0:
    break  # 保证最小质因子属性，不重复筛
```

#### 它真正的价值：
* 欧拉筛绝不仅仅是用来“找素数”，它的核心价值是在 $O(N)$ 时间内**批处理各种积性函数**（欧拉函数 $\phi$、莫比乌斯函数 $\mu$ 等）。
