根据不同的数据范围（$N$ 的大小）以及评测机的**时间限制（TL）** 与 **内存限制（ML** ， Python 埃氏筛主要有以下几个梯队的写法。

你可以根据题目给出的数据范围，直接“对号入座”选择最合适的版本：

---

### 版本一：经典通用版（手写好记，面试/常规比赛首选）
* **适用范围**：$N \le 10^6$
* **内存占用**：约 8 MB
* **运行耗时**：$\approx 0.15$ 秒
* **特点**：代码最干净，纯 Python 语法，不需要任何黑魔法，最不容易写错。

```python
import math


def sieve_v1(n: int) -> list[bool]:
    """返回长度为 n + 1 的布尔列表"""
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, math.isqrt(n) + 1):
        if is_prime[i]:
            # 标准双重循环，平方起跳
            for j in range(i * i, n + 1, i):
                is_prime[j] = False

    return is_prime
```

### 版本二：切片赋值加速版（解决 Python 循环慢的问题）
* **适用范围**：$10^6 < N \le 10^7$（内存限制 $\ge 256\text{ MB}$）
* **内存占用**：$10^7$ 时约占用 **80 MB**
* **运行耗时**：$10^7$ 仅需 $\approx 0.3 \sim 0.5$ 秒（比版本一快 10 倍以上）
* **特点**：利用 Python 底层 C 实现的**切片批量赋值**，绕过解释器循环，极速。

```python
import math


def sieve_v2(n: int) -> list[bool]:
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, math.isqrt(n) + 1):
        if is_prime[i]:
            # 计算切片元素个数并直接批量覆盖
            count = (n - i * i) // i + 1
            is_prime[i * i : n + 1 : i] = [False] * count

    return is_prime
```

### 版本三：`bytearray` 极限内存与速度版（竞赛扛卡常、防 RE 模版）
* **适用范围**：$10^7 < N \le 10^8$（且内存限制在 $256\text{ MB} \sim 512\text{ MB}$ 之间）
* **内存占用**：$10^7$ 仅 **10 MB**；$10^8$ 仅 **100 MB**（普通 list 在 $10^8$ 会直接爆内存报 RE）
* **运行耗时**：$10^8$ 约 **1.0 ~ 1.2 秒**
* **特点**：使用 1 字节无符号字符连续内存，兼备省内存和底层的 memcpy 效率。

```python
import math


def sieve_pypy(n: int) -> bytearray:
    # 1. 内存省到极致：1 个数字只占 1 字节
    is_prime = bytearray([1]) * (n + 1)
    is_prime[0] = is_prime[1] = 0

    # 2. 纯粹干净的循环：交给 PyPy JIT 编译成原生机器码，无任何临时对象开销
    for i in range(2, math.isqrt(n) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = 0

    return is_prime
```
