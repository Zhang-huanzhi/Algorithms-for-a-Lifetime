### B44 - Grid Operations（网格操作）

时间限制: 1 sec / 内存限制: 1024 MiB  
分值: 1000 分

#### 题目描述
有一个 $N \times N$ 的网格，从上往下第 $i$ 行、从左往右第 $j$ 列的格子 $(i, j)$ 中写有整数 $A_{i,j}$。请编写一个程序，处理以下 2 种操作：

* **交换操作**：给定整数 $x, y$，交换第 $x$ 行和第 $y$ 行。
* **获取操作**：给定整数 $x, y$，输出格子 $(x, y)$ 中所写的整数。

#### 约束条件
* $1 \le N \le 500$
* $1 \le Q \le 200000$
* $1 \le A_{i,j} \le 100$

#### 输入格式
输入按以下格式从标准输入中给出。

$\text{Query}_i$ 表示第 $i$ 次操作，若是交换操作则以 `1 x y` 的形式给出，若是获取操作则以 `2 x y` 的形式给出。

```text
N
A_{1,1} A_{1,2} ... A_{1,N}
...
A_{N,1} A_{N,2} ... A_{N,N}
Q
Query_1
...
Query_Q
```

#### 输出格式
请按顺序输出每次获取操作的答案。

---

#### 样例输入 1
```text
3
1 2 3
4 5 6
7 8 9
7
2 2 1
1 1 2
2 2 1
2 1 3
1 2 3
2 2 3
2 3 2
```

#### 样例输出 1
```text
4
1
6
9
2
```

网格的变化过程如下。

初始状态：
```text
1 2 3
4 5 6
7 8 9
```

通过第 2 次操作 `1 1 2` 交换第 1 行和第 2 行后的状态：
```text
4 5 6
1 2 3
7 8 9
```

通过第 5 次操作 `1 2 3` 交换第 2 行和第 3 行后的状态：
```text
4 5 6
7 8 9
1 2 3
```

---

#### 样例输入 2
```text
2
8 16
32 64
3
2 2 1
1 1 2
2 2 1
```

#### 样例输出 2
```text
32
8
```

# AC Code 逻辑映射
``` python
import sys  
from collections import deque  
  
def main():  
  
    n = int(sys.stdin.readline().strip())  
  
    grid = []  
    for _ in range(n):  
        arr = list(map(int, sys.stdin.readline().strip().split()))  
        grid.append(arr)  
  
    row = list(range(n + 1))  
    outs = []  
    q = int(sys.stdin.readline().strip())  
    for _ in range(q):  
        line = list(sys.stdin.readline().strip().split())  
  
        op = line[0]  
  
        if op == '1':  
            x, y = int(line[1]) - 1, int(line[2]) - 1  
            row[x], row[y] = row[y], row[x]  
  
        if op == '2':  
            x, y = int(line[1]) - 1, int(line[2]) - 1  
            outs.append(grid[row[x]][y])  
  
    print('\n'.join(map(str, outs)))  
  
if __name__ == "__main__":  
    main()
```
