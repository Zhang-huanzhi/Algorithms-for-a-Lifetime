### A44 - Change and Reverse

**时间限制**：1 秒 / **内存限制**：1024 MiB  
**分值**：1000 分

---

#### 问题描述
有一个长度为 $N$ 的数组 $A = [A_1, \dots, A_N]$，初始时对于所有的 $i$ 都有 $A_i = i$。你需要对该数组执行 $Q$ 次操作，第 $j$ 次操作由字符串 $\text{Query}_j$ 表示：

* **修改操作**：当 $\text{Query}_j =$ `1 x y` 时，将 $A_x$ 的值修改为 $y$。
* **反转操作**：当 $\text{Query}_j =$ `2` 时，将数组 $A$ 逆序（反转）。
* **获取操作**：当 $\text{Query}_j =$ `3 x` 时，输出 $A_x$ 的值。

请编写一个程序，正确回答所有的获取操作。

---

#### 约束条件
* $1 \le N \le 200000$
* $1 \le Q \le 200000$
* 在任意时刻，数组 $A$ 中的元素均为 $1$ 以上 $10^9$ 以下的整数。

---

#### 输入格式
输入按以下格式从标准输入给出：

```text
N Q
Query_1
⋮
Query_Q
```

---

#### 输出格式
请按顺序输出各个获取操作对应的答案。具体格式请参考输入输出样例。

---

#### 样例输入 1
```text
5 4
1 4 8
3 2
2
3 2
```

#### 样例输出 1
```text
2
8
```

数组 $A$ 的变化过程为 $[1, 2, 3, 4, 5] \to [1, 2, 3, 8, 5] \to [5, 8, 3, 2, 1]$。


# AC state
``` python
import sys  
from collections import deque  
  
def main():  
  
    n, q = map(int, sys.stdin.readline().strip().split())  
  
    arr = list(range(1, n + 1))  
  
    arr = deque(arr)  
    state = True  
    outs = []  
    for _ in range(q):  
        line = list(sys.stdin.readline().strip().split())  
  
        op = line[0]  
  
        if op == '1':  
            x, y = int(line[1]) - 1, int(line[2])  
  
            if state:  
                arr[x] = y  
            else:  
                arr[n - x - 1] = y  
  
        if op == '2':  
            state = not state  
  
        if op == '3':  
            x = int(line[1]) - 1  
  
            if state:  
                outs.append(arr[x])  
            else:  
                outs.append(arr[n - x - 1])  
    print('\n'.join(map(str, outs)))  
if __name__ == "__main__":  
    main()
```

# TLE 朴素
``` python
import sys

def main():

    n, q = map(int, sys.stdin.readline().strip().split())

    arr = list(range(1, n + 1))

    outs = []
    for _ in range(q):
        line = list(sys.stdin.readline().strip().split())

        op = line[0]

        if op == '1':
            x, y = int(line[1]) - 1, int(line[2])

            arr[x] = y

        if op == '2':
            arr.reverse()

        if op == '3':
            x = int(line[1]) - 1
            outs.append(arr[x])

    print('\n'.join(map(str, outs)))
if __name__ == "__main__":
    main()
```
