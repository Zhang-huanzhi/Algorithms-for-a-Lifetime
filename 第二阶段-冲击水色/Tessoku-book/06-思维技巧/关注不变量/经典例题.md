### A45 - Card Elimination（消除卡片）

**时间限制**：1 sec / **内存限制**：1024 MiB  
**分值**：1000 分

---

#### 题目描述
太郎有 $N$ 张卡片。  
第 $i$ 张（$1 \le i \le N$）卡片的颜色由字符 $A_i$ 表示，其中 `R` 代表红色，`B` 代表蓝色，`W` 代表白色。

他可以进行下图所示的 $6$ 种操作。例如，右下角的操作是“将 $1$ 张蓝色卡片和 $1$ 张红色卡片替换为 $1$ 张白色卡片”。进行 $N-1$ 次操作后，最终会剩下 $1$ 张卡片。请编写一个程序，判断最后剩下的卡片颜色是否有可能为 $C$。

#### 约束条件
- $2 \le N \le 200000$
- 字符 $C$ 为 `R`、`B`、`W` 中的某一个
- 字符 $A_i$ 为 `R`、`B`、`W` 中的某一个

#### 输入
输入按以下格式从标准输入给出：
```text
N C
A_1 A_2 ⋯ A_N
```
（注：$A_1 A_2 \cdots A_N$ 为一个长度为 $N$、不含空格的字符串）

#### 输出
如果能够使最后剩下的卡片颜色为 $C$，输出 `Yes`；否则输出 `No`。

---

#### 样例输入 1
```text
4 B
WBBR
```

#### 样例输出 1
```text
Yes
```

按照以下步骤进行操作，最后可以剩下蓝色的卡片：
1. 将 $1$ 张蓝色卡片和 $1$ 张红色卡片替换为 $1$ 张白色卡片  
   此时手头剩余的卡片变为 `WBW`
2. 将 $2$ 张白色卡片替换为 $1$ 张白色卡片  
   此时手头剩余的卡片变为 `WB`
3. 将 $1$ 张白色卡片和 $1$ 张蓝色卡片替换为 $1$ 张蓝色卡片  
   此时手头剩余的卡片变为 `B`

---

> **补充说明**（原题附图所包含的 $6$ 种操作）：
> - 白 + 白 $\rightarrow$ 白（`WW` $\rightarrow$ `W`）
> - 蓝 + 蓝 $\rightarrow$ 红（`BB` $\rightarrow$ `R`）
> - 红 + 红 $\rightarrow$ 蓝（`RR` $\rightarrow$ `B`）
> - 白 + 蓝 $\rightarrow$ 蓝（`WB` $\rightarrow$ `B`）
> - 白 + 红 $\rightarrow$ 红（`WR` $\rightarrow$ `R`）
> - 蓝 + 红 $\rightarrow$ 白（`BR` $\rightarrow$ `W`）


# AC Code
``` python
import sys  
  
def main():  
  
    n, c = sys.stdin.readline().strip().split()  
  
    arr = list(sys.stdin.readline().strip())  
  
    val = {'W': 0, 'B': 1, 'R': 2}  
    summ = 0  
    for char in arr:  
        if char == 'w':  
            summ += 0  
        elif char == 'B':  
            summ += 1  
        elif char == 'R':  
            summ += 2  
  
    if summ % 3 == val[c]:  
        print("Yes")  
    else:  
        print("No")  
  
if __name__ == "__main__":  
    main()
```
