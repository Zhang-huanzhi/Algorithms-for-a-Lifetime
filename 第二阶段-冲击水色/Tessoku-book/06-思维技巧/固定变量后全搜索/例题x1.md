**B42 - Two Faced Cards**  
时间限制: 1 sec / 内存限制: 1024 MiB

分值: 1000 分

### 题目描述
有 $N$ 张卡片，第 $i$ 张卡片的正面写有整数 $A_i$，背面写有整数 $B_i$。太郎君想要选出几张卡片，使得按以下方式定义的得分最大化：

$$[\text{得分}] = [\text{所选卡片正面数字之和的绝对值}] + [\text{所选卡片背面数字之和的绝对值}]$$

请问能得到的最大得分是多少？

### 限制条件
* $1 \le N \le 100000$
* $-10^9 \le A_i, B_i \le 10^9$ ($1 \le i \le N$)
* 输入中的所有值均为整数

### 输入
输入从标准输入按以下格式给出：

```text
N
A_1 B_1
⋮
A_N B_N
```

### 输出
请将答案作为整数输出。

### 输入样例 1
```text
5
2 8
4 -5
5 -3
-4 1
-2 -3
```

### 输出样例 1
```text
18
```
通过选择第 2 张、第 3 张和第 5 张卡片，得分为 $|4 + 5 - 2| + |-5 - 3 - 3| = 18$，这是可能达到的最大得分。

# AC Code
``` python
import sys  
  
def main():  
  
    n = int(sys.stdin.readline().strip())  
  
    arr = []  
    for _ in range(n):  
        a, b = map(int, sys.stdin.readline().strip().split())  
        arr.append((a, b))  
  
    signs = [(1, 1), (1, -1), (-1, 1), (-1, -1)]  
  
    ans = 0  
  
    for sa, sb in signs:  
        curr = 0  
        for a, b in arr:  
            gain = sa * a + sb * b  
            if gain > 0:  
                curr += gain  
  
        ans = max(curr, ans)  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```
