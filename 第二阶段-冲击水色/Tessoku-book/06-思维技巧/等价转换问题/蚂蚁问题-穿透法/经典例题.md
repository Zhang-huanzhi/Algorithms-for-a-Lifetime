### A43 - Travel 3
**运行时间限制：** 1 秒 / **内存限制：** 1024 MiB  
**分值：** 1000 分

#### 题目描述
在全长为 $L$ 米的 ALGO 隧道中，目前有 $N$ 个人。第 $i$ 个人初始位于距离西端 $A_i$ 米的位置，并正朝着方向 $B_i$ 步行（$B_i$ 为 `E` 时表示向东，$B_i$ 为 `W` 时表示向西）。

由于隧道很窄，当两个人到达同一位置（相遇）时，他们会各自调头反向移动。所有人步行的速度均为每秒 $1$ 米。请问最后一个人走出隧道是在多少秒之后？

#### 约束条件
- $1 \le N \le 200000$
- $1 \le A_1 < A_2 < \dots < A_N < L \le 10^9$
- $B_i$ 为 `E` 或 `W`
- $N$ 与 $A_i$ 均为整数

#### 输入格式
输入从标准输入按以下格式给出：
$$N \quad L$$
$$A_1 \quad B_1$$
$$\vdots$$
$$A_N \quad B_N$$

#### 输出格式
请以整数形式输出答案。

---

#### 样例输入 1
```plain
3 100
20 E
50 E
70 W
```

#### 样例输出 1
```plain
80
```

**样例说明 1：**  
第 2 个人将在 80 秒后走出隧道，是这 3 个人中最后一个离开隧道的。

# AC Code
``` python
import sys  
  
def main():  
  
    n, l = map(int, sys.stdin.readline().strip().split())  
  
    ans = 0  
    for _ in range(n):  
        a, b = sys.stdin.readline().strip().split()  
        a = int(a)  
  
        if b == 'E':  
            ans = max(ans, l - a)  
        else:  
            ans = max(ans, a)  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```
