**B43 - Quiz Contest**
时间限制: 1 sec / 内存限制: 1024 MiB

分值: 1000 分

### 题目描述
有 $N$ 名学生参加了问答竞赛。本次比赛共出了 $M$ 道题，在第 $i$ 道题中，除了第 $A_i$ 名学生以外的所有人都答对了。

请编写程序求出每名学生最终答对的题数。

### 约束条件
* $1 \le N, M \le 200000$
* $1 \le A_i \le N \ (1 \le i \le M)$

### 输入格式
输入从标准输入按以下格式给出：

$N \ M$
$A_1 \ A_2 \ \cdots \ A_M$

### 输出格式
请输出共 $N$ 行。
第 $k$ 行输出第 $k$ 名学生最终答对的题数。

### 样例输入 1
```text
4 6
1 4 1 4 2 1
```

### 样例输出 1
```text
3
5
6
4
```

# TLE 朴素模拟
``` python
import sys  
  
def main():  
  
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    brr = [0] * (n + 1)  
  
    for num in arr:  
  
        for idx in range(1, n + 1):  
  
            if idx == num:  
                continue  
  
            brr[idx] += 1  
  
    print("\n".join(map(str, brr[1:])))  
if __name__ == "__main__":  
    main()
```
# AC 正难则反
``` python
import sys  
  
def main():  
  
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    brr = [m] * n  
  
    for num in arr:  
        brr[num - 1] -= 1  
  
    print('\n'.join(map(str, brr)))  
  
if __name__ == "__main__":  
    main()
```
