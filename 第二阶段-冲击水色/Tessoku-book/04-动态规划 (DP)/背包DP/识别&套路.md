在实际刷题（如 LeetCode）或面试中，题目很少会直接写“这是一个背包问题”。它们通常会**伪装成数组划分、硬币找零、字符串拼接或数学运算**。

掌握以下**“识别信号”**与**“解题套路模版”**，可以帮你一眼看穿题目的本质并快速写出代码。

---

# 一、 如何识别背包问题？（翻译暗号）

识别背包问题的核心，是**在题目中寻找“容量”与“物品”的对应关系**。

### 1. 核心特征信号
当你看到以下描述时，80% 是背包问题：
*   **有限的限制**：给了一个固定的总和、固定的数组长度、固定的可用步数 $\to$ **这就是【背包容量 $W$】**。
*   **离散的候选集**：给了一组数字、一组硬币、一组字符串，且每个个体有自己的“代价” $\to$ **这就是【物品及物品重量 $w_i$】**。
*   **选择性**：每个元素可以“选或不选”，或者“选多少次”。
*   **求极值/方案数/可行性**：
    *   “最多能凑出多少价值？”（最值问题）
    *   “能不能正好凑出目标和？”（可行性问题）
    *   “凑成目标和有多少种组合方法？”（方案数问题）

### 2. 经典题型“黑话”翻译表

| 题目表象 | 背包本质翻译 | 背包类型 |
| :--- | :--- | :--- |
| **分割等和子集**：能否把数组分成和相等的两部分？ | 背包容量是 `sum/2`，每个元素只能用一次，问能否装满？ | 0-1 背包 (可行性) |
| **目标和**：给数组元素添加 `+` 或 `-` 使其等于 target | 转化为：选出一部分正数子集，和为 `(target+sum)/2`，有多少种选法？ | 0-1 背包 (求方案数) |
| **零钱兑换**：用最少枚硬币凑出金额 $K$（硬币无限） | 背包容量是 $K$，物品是硬币，价值是 1（消耗 1 枚），求最小总价值 | 完全背包 (求最小值) |
| **组合总和 IV**：用数组中的数凑出 target 的排列数 | 物品可以无限次使用，且讲究元素先后顺序 | 完全背包 (求排列数) |
| **一和零**：最多有 $m$ 个 0 和 $n$ 个 1，最多能拼出几个字符串？ | 字符串是物品，0 的数量和 1 的数量是**两个维度的背包容量** | 多维费用 0-1 背包 |

# 二、 背包问题的万能解题套路（四步框架）

遇到背包问题，严格按以下 4 步走，95% 的题目都能秒杀：

### 第一步：定类型（0-1 还是 完全？）
*   元素**只能用一次** $\to$ **0-1 背包**
*   元素**可以无限次重复使用** $\to$ **完全背包**

### 第二步：定状态转移方程（看问法）
背包问题通常只有 **三种问法**，方程公式是固定的：

1. **求最值问题（最大/最小）：**
   * 求最大：`dp[j] = max(dp[j], dp[j - weight[i]] + value[i])`
   * 求最小：`dp[j] = min(dp[j], dp[j - weight[i]] + 1)` （例如零钱兑换）
2. **求能否凑满（True / False 可行性）：**
   * `dp[j] = dp[j] || dp[j - weight[i]]`
3. **求方案数（方法总数）：**
   * `dp[j] = dp[j] + dp[j - weight[i]]`（累加所有可能）

---

### 第三步：定循环顺序（最关键的套路！）

这是决定代码死活的一步，背下这个**黄金法则**：

#### 规则 1：容量的遍历方向（正序 vs 倒序）
*   **0-1 背包**：容量必须 **倒序（从 $W$ 到 $weight[i]$）**。
    *   *原理*：防止同一个物品被计算多次。
*   **完全背包**：容量必须 **正序（从 $weight[i]$ 到 $W$）**。
    *   *原理*：允许利用当前物品累加更新。

#### 规则 2：遍历的内外层嵌套（针对求方案数问题）
在完全背包求方案数时，顺序决定了是**组合**还是**排列**：
*   **求组合数（不讲究顺序，[1,2] 和 [2,1] 算一种）**：
    *   **先遍历物品，再遍历背包容量**（外层 for 物品，内层 for 容量）。
*   **求排列数（讲究顺序，[1,2] 和 [2,1] 算两种）**：
    *   **先遍历背包容量，再遍历物品**（外层 for 容量，内层 for 物品）。

---

### 第四步：定初始化（Base Case）

*   **如果求最大价值**：`dp[0] = 0`，其余全部初始化为 `0` 或 $-\infty$。
*   **如果求最小硬币数**：`dp[0] = 0`，其余全部初始化为 $+\infty$（代码中可用一个极大值如 `amount + 1`）。
*   **如果求方案数**：`dp[0] = 1`，其余全部初始化为 `0`（含义是：凑出容量为 0 的方案有 1 种，就是什么都不装）。

# 三、 极简代码模板速记

### 1. 0-1 背包（最值/装满）模版
```python
# target: 背包容量, nums: 物品重量/价值
dp = [0] * (target + 1)

for num in nums:  # 遍历物品
    for j in range(target, num - 1, -1):  # 遍历容量【必须倒序】
        dp[j] = max(dp[j], dp[j - num] + num)
```

### 2. 完全背包（求组合数）模版
```python
dp = [0] * (target + 1)
dp[0] = 1  # 初始化

for num in nums:  # 【外层物品】：先定物品，避免顺序打乱产生排列
    for j in range(num, target + 1):  # 【内层容量正序】
        dp[j] += dp[j - num]
```

### 3. 完全背包（求排列数）模版
```python
dp = [0] * (target + 1)
dp[0] = 1

for j in range(1, target + 1):  # 【外层容量】：每个容量位置都把所有物品试一遍
    for num in nums:  # 【内层物品】
        if j >= num:
            dp[j] += dp[j - num]
```

# 记忆通关口诀

> 看到“子集目标和”，先找容量和物品。
> 物品只用一次是 0-1，容量必须倒着走；
> 物品无限次是完全，容量必须顺着走；
> 求最值用 `max/min`，求方案数用 `+=`；
> 组合问题先物后包，排列问题先包后物！
