**动态规划（Dynamic Programming，简称 DP）** 和 **背包问题（Knapsack Problem）** 是计算机科学和算法面试中最核心、最经典的内容。

下面用通俗易懂的语言，为你系统地梳理这两个概念。

---

# 第一部分：什么是动态规划（DP）？

### 1. 核心思想
动态规划的本质是：**大事化小，小事化了，且“不走回头路”（记录历史）**。
它将一个复杂的问题分解为若干个互相重叠的**子问题**，通过求解子问题的最优解，逐步推导出原问题的最优解。

> **一句话记忆：** “记住你算过的东西，避免重复劳动。”（例如：求斐波那契数列，把算过的 $F(n-1)$ 存起来，而不是每次都递归重新算）。

### 2. 动态规划的三个核心特征
如果一个问题能用 DP 解决，它通常具备以下特征：
1. **最优子结构**：大问题的最优解可以由子问题的最优解推导出来。
2. **重叠子问题**：在求解过程中，相同的子问题会被反复计算多次。
3. **无后效性**：一旦某个状态确定了，它就不会受之后决策的影响（“过去不依赖于未来”）。

### 3. 解 DP 题的标准“五步法”
1. **确定 dp 数组及下标含义**：比如 `dp[i]` 或 `dp[i][j]` 到底代表什么？
2. **推导状态转移方程**：这是最核心的一步，找到当前状态如何由之前的状态推导而来（数学递推式）。
3. **初始化边界条件**：起点是什么？比如 `dp[0] = 0`。
4. **确定遍历顺序**：从前往后还是从后往前？从小到大还是从大到小？
5. **举例推导验证**：手动填表，看结果对不对。

# 第二部分：什么是背包问题？

背包问题是动态规划中最具代表性的模型。

### 基本场景设定：
你有一个固定容量（承重）为 $W$ 的**背包**，面前有若干件**物品**。每件物品有自己的**重量（weight）**和**价值（value）**。
**目标**：在不超过背包容量的前提下，如何挑选物品，使得背包里的**总价值最大**？

根据物品的使用规则，背包问题衍生出几种最常见的类型：

---

### 1. 0-1 背包（最基础、最重要的母题）
*   **规则**：每种物品**只有一件**，你只能选择 **放（1）** 或 **不放（0）**。
*   **状态定义**：`dp[i][j]` 表示从前 $i$ 件物品中选，放入容量为 $j$ 的背包中所能获得的最大价值。
*   **状态转移方程**：
    对于第 $i$ 件物品，我们只有两个选择：
    *   **不放第 $i$ 件物品**：价值等于前 $i-1$ 件物品放进容量 $j$ 的价值 $\rightarrow$ `dp[i-1][j]`
    *   **放第 $i$ 件物品**（前提是背包能装下）：价值等于腾出空间后的前 $i-1$ 件物品价值 + 当前物品价值 $\rightarrow$ `dp[i-1][j - weight[i]] + value[i]`
    *   **综上**：
        $$dp[i][j] = \max(dp[i-1][j], dp[i-1][j - weight[i]] + value[i])$$

*   **空间优化（滚动数组，变为一维）**：
    由于每一行的状态只依赖于上一行，可以将空间压缩到一维：
    $$dp[j] = \max(dp[j], dp[j - weight[i]] + value[i])$$
    ⚠️ **特别注意**：一维 0-1 背包遍历容量 $j$ 时，**必须从大到小（倒序）遍历**！目的是防止同一件物品被重复放入多次。

---

### 2. 完全背包（Complete Knapsack）
*   **规则**：每种物品有**无限多件**，只要背包放得下，你可以拿任意件。
*   **状态转移方程**（一维优化后）：
    $$dp[j] = \max(dp[j], dp[j - weight[i]] + value[i])$$
*   **与 0-1 背包的唯一代码区别**：
    *   0-1 背包容量是**倒序**遍历（从 $W$ 到 $weight[i]$）。
    *   完全背包容量是**正序**遍历（从 $weight[i]$ 到 $W$），因为正序遍历正好允许利用当前物品累加多次。

---

### 3. 多重背包（Multiple Knapsack）
*   **规则**：第 $i$ 种物品有**固定数量 $k_i$ 件**。
*   **解法思路**：
    1.  **暴力展开**：把 $k_i$ 个相同的物品直接看作 $k_i$ 个不同的独立物品，转化为 0-1 背包问题。
    2.  **二进制拆分优化**：利用 $1, 2, 4, 8...$ 二进制组合可以拼出任何数的基本原理，将数量为 $K$ 的物品拆分成几个组合包，大幅减少物品数量后再跑 0-1 背包。

---

### 4. 其他常见衍生背包（了解即可）
*   **多维费用背包**：不仅限制重量，还限制体积。解法就是把 DP 维度再加一维 `dp[i][j][k]`。
*   **分组背包**：物品被分成若干组，每组里面**最多只能选一件**。
*   **求方案数（而不是求最大价值）**：比如“零钱兑换（凑出金额的组合数）”，状态转移方程由 $\max$ 变为累加求和：`dp[j] += dp[j - weight[i]]`。

---

# 总结与记忆口诀

| 背包类型 | 物品数量限制 | 容量遍历顺序（一维数组） | 核心应用场景举例 |
| :--- | :--- | :--- | :--- |
| **0-1 背包** | 每种物品只有 1 件 | **倒序**（从大到小） | 分割等和子集、目标和 |
| **完全背包** | 每种物品有无限件 | **正序**（从小到大） | 零钱兑换系列问题 |
| **多重背包** | 每种物品有有限 $k$ 件 | 拆分后走 0-1 背包逻辑 | 资源受限的物资分配 |

学习动态规划和背包问题的建议路线：
**彻底搞懂 0-1 背包（二维与一维推导） $\rightarrow$ 对比学习完全背包 $\rightarrow$ 刷 LeetCode 上的背包变形题（如 416. 分割等和子集、322. 零钱兑换、518. 零钱兑换 II）。**
