**是的，动态规划（DP）在刷题界不仅有套路，而且套路极其固定！**

很多人初学 DP 觉得难，是因为看到满屏的数学公式和各种奇怪的 `dp[i][j]`，以为每道题都要“灵光一闪”。但实际上，**90% 以上的 DP 题，状态定义（即 `dp` 括号里写什么）只有以下 5 大核心套路！**

只要你看懂题目的类型，闭着眼睛都能把 `dp` 的维度列出来：

---

### 🌟 DP 状态定义的 5 大经典“模板套路”

| DP 题型分类 | 典型特征 | 闭眼套用的 `dp` 定义 | 代表题型 |
| :--- | :--- | :--- | :--- |
| **① 背包 / 子集型**<br>*(就是本题)* | 给一堆物品，选一部分达到某种限制 | **`dp[i][j]`**：考虑**前 $i$ 个物品**，消耗了容量/达到了总和 **$j$** | 0-1 背包、子集和、零钱兑换 |
| **② 单序列型** | 在一个数组里找最长、最优的子序列 | **`dp[i]`**：以**第 $i$ 个元素结尾**的最优解 | 最长递增子序列 (LIS)、打家劫舍、最大子数组和 |
| **③ 双序列 / 字符串型** | 给出两个字符串或数组，求比较、匹配 | **`dp[i][j]`**：字符串 A 的**前 $i$ 个字符** 与 字符串 B 的**前 $j$ 个字符** 的关系 | 最长公共子序列 (LCS)、编辑距离、正则匹配 |
| **④ 区间 DP 型** | 题目涉及相邻合并，或者向两端扩展 | **`dp[i][j]`**：从下标 **$i$ 到 $j$ 这个闭区间 $[i, j]$** 的最优解 | 石子合并、最长回文子串、戳气球 |
| **⑤ 状压 DP 型** | 元素个数很少（$N \le 20$），选与不选 | **`dp[mask]`**：**$mask$（二进制数）** 表示当前选了哪些元素的集合 | 旅行商问题 (TSP)、全排列分配 |

---

### 那么，“死记”与“真正掌握套路”的区别在哪里？

#### ❌ 什么是“死记”？
* 看到题目就硬背代码：“这里写两个 `for` 循环，里面写一个 `dp[j-x]`，为什么倒序我不知道，反正背下来先写上。”
* **后果**：题目稍微一变（比如从“问能不能凑出 $S$”变成“问凑出 $S$ 最少要用几张卡片”），脑子立刻一片空白。

####  什么是“掌握套路”？（万能 4 步思考法）
当你遇到任何一道 DP 题时，只要按这 **4 步流水线** 走，答案自然就推出来了：

1. **第 1 步：套模板定状态（套路分类）**
   - 看到“从一堆卡片里挑数字” $\longrightarrow$ 命中 **背包/子集型模板**！
   - 状态立刻定下来：`dp[i][j]` = 考虑前 $i$ 张卡片，能否凑出和 $j$。
2. **第 2 步：关注“最后一步”做决策（状态转移）**
   - 对于第 $i$ 张卡片，我只有两种选择：
     - **不选**：那就是前 $i-1$ 张卡片凑出 $j$（`dp[i-1][j]`）
     - **选**：那就是前 $i-1$ 张卡片凑出 $j - x$（`dp[i-1][j-x]`）
   - 两者取个 `or`，公式就推出来了！
3. **第 3 步：定初值与边界（Base Case）**
   - 没卡片（$i=0$），和为 0 是必然可行的 $\longrightarrow$ `dp[0][0] = True`。
4. **第 4 步：空间优化（选做）**
   - 发现第 $i$ 行只看第 $i-1$ 行，直接砍掉第一维 $i$，改成一维倒序遍历！

---

### 总结
这就是为什么说 DP 有套路：
> **你不需要为每一道题发明一种新算法，你只需要识别出它是“5 大套路”中的哪一种，然后用标准的 4 步流水线把它解构掉。**
