在树和图论算法中，`order`（遍历序列）是一个非常核心且强大的技巧。

它的本质是：**利用一次遍历（BFS 或 DFS），把原本多分支、复杂的“二维树结构”，拉直（拍平）成一个“一维的线性列表”。**

通过这个一维列表，我们可以将复杂的“树上递归/动态规划”，转化成极其简单的**普通 `for` 循环**。

---

### 一、`order` 是怎么生成的？

以树的根节点为起点进行 **BFS（广度优先搜索）**，每次节点出队时，把它加入列表：

```python
q = deque([root])
order = []

while q:
    u = q.popleft()
    order.append(u)  # 记录出队顺序
    for v in adj[u]:
        if v != parent[u]:
            parent[v] = u
            q.append(v)
```

假设有一棵树如下（1 是根）：
```text
        1 (社长)
       / \
      2   3 (主管)
     / \   \
    4   5   6 (员工)
```
BFS 是一层一层向下访问的，因此生成的 `order` 列表就是：
$$\text{order} = [1, 2, 3, 4, 5, 6]$$

这个列表具有一个极其完美的性质：**任何一个节点的父节点，在列表里的位置一定排在它前面！**

---

### 二、`order` 的两大用法

把树拍平成列表后，树上的所有问题都可以用一个 `for` 循环搞定，主要分为**正序**和**逆序**两种：

#### 1. 正序遍历：自顶向下（从根传到叶）
> **顺序：** `for u in order:` $\to$ `[1, 2, 3, 4, 5, 6]`  
> **特点：** 当你处理到节点 $u$ 时，**它的父节点一定已经处理好了**。

**典型应用：**
* **计算每个节点的深度（到根节点的距离）**：
  ```python
  depth = [0] * (n + 1)
  for u in order:
      p = parent[u]
      if p > 0:
          depth[u] = depth[p] + 1
  ```
* **根节点向下传达指令/累加权值**（例如公司统一从上往下分发奖金倍率）。

---

#### 2. 逆序遍历：自底向上（从叶汇总到根）
> **顺序：** `for u in reversed(order):` $\to$ `[6, 5, 4, 3, 2, 1]`  
> **特点：** 当你处理到节点 $u$ 时，**它底下的所有子孙节点一定已经全部计算完毕了**。

**典型应用（树形 DP 的核心武器）：**
* **本题求职级 / 树的高度**：
  ```python
  rank = [0] * (n + 1)
  for u in reversed(order):
      p = parent[u]
      if p > 0:
          rank[p] = max(rank[p], rank[u] + 1)
  ```
* **求每个节点的子树大小（包含自己和所有下属的总人数）**：
  ```python
  sz = [1] * (n + 1)  # 每个人初始算自己 1 个人
  for u in reversed(order):
      p = parent[u]
      if p > 0:
          sz[p] += sz[u]  # 把自己的团队人数加到上级名下
  ```
* **汇总子树业绩总和 / 权值最大值**。

### 三、为什么它被称为“算法模板利器”？

在做算法题（特别是 Python 中）时，利用 `order` 有三大无法替代的优势：

| 传统写法（DFS 递归） | `order` 迭代写法（BFS 拍平） |
| :--- | :--- |
| **容易爆栈**：当树退化成一条链（$N = 10^5$），Python 会直接报 `RecursionError`。 | **绝不爆栈**：纯列表循环，内存和运行完全在堆上，安全可靠。 |
| **调试困难**：多层递归进进出出，断点调试时很容易绕晕。 | **极其直观**：就是一个一维列表，直接 `print(order)` 就能看到整棵树的拓扑层次。 |
| **递归开销大**：函数调用的出入栈会带来巨大的时间常数开销。 | **运行速度极快**：单层 `for` 循环是底层的 CPython 循环，速度通常比递归快数倍。 |

---

### 四、拓展：DFS 产生的 Order（DFS 序）
除了 BFS 产生的层序 `order`，在更高级的树上算法中，还可以用 DFS 记录顺序：
* **后序 DFS 序列**：记录离开节点的顺序，天然就是自底向上的顺序（相当于直接得到了 `reversed(order)`）。
* **欧拉序 / 进入离开时间戳（In-Out Order）**：记录进入和离开节点的时间点 `[in[u], out[u]]`。它有一个神奇性质——**以 $u$ 为根的整个子树，在序列中对应一个连续的区间**！这使得我们可以用**线段树/树状数组**直接对某棵子树进行快速区间修改和查询。

### 总结一句记忆口诀：
> **“BFS/DFS 拍平树，正序下传、逆序汇总。”**  
> 只要在树上遇到“父子依赖”的问题，记录一个 `order` 就能通杀大部分树形 DP 和遍历题目。
