### A65 - Road to Promotion（晋升之路）

**时间限制：** 1 秒 / **内存限制：** 1024 MiB  
**分值：** 1000 分

#### 题目描述
在 KYOPRO-MASTER 股份有限公司中一共有 $N$ 名员工，按照地位高低被依次编号为 $1$ 到 $N$。  
除了社长（员工 $1$）之外，每名员工都恰好有 $1$ 位直接上司，员工 $i$ 的直接上司是员工 $A_i$。  
请针对每位员工，输出其下属的总人数。  

这里规定：如果员工 $y$ 满足 $x \neq y$ 且沿着员工 $y$ 的直接上司一路向上追溯能够到达员工 $x$，则称员工 $y$ 是员工 $x$ 的下属。

#### 数据范围与制约
- $2 \le N \le 100000$
- $1 \le A_i \le i - 1$ ($2 \le i \le N$)
- 输入中的所有数值均为整数

#### 输入格式
输入从标准输入中按以下格式给出：

$$N$$
$$A_2 \quad A_3 \quad \dots \quad A_N$$

#### 输出格式
请按顺序输出员工 $1, 2, \dots, N$ 的下属人数，各数值之间用空格隔开。

---

#### 样例 1

**输入**
```text
7
1 1 3 2 4 4
```

**输出**
```text
6 1 3 2 0 0 0
```

#### 样例 2

**输入**
```text
15
1 2 1 1 1 6 2 6 9 10 6 12 13 12
```

**输出**
```text
14 2 0 0 0 8 0 0 2 1 0 3 1 0 0
```

# TLE 沿着链向上走
``` python
import sys
import math

def main():

    n = int(sys.stdin.readline().strip())

    arr = list(map(int, sys.stdin.readline().strip().split()))

    parent = [0] * (n + 1)
    for i in range(2, n + 1):
        parent[i] = arr[i - 2]

    ans = [0] * (n + 1)

    for i in range(2, n + 1):
        curr = parent[i]

        while curr >= 1:
            ans[curr] += 1
            curr = parent[curr]

    print(*(ans[1:]))

if __name__ == "__main__":
    main()
```

# TLE 沿着链向下
``` python
import sys
import math
from collections import deque

def main():

    n = int(sys.stdin.readline().strip())
    arr = list(map(int, sys.stdin.readline().strip().split()))

    graph = [ [] for _ in range(n + 1)]
    for i in range(n - 1):
        boss = arr[i]
        subordinate = i + 2
        graph[boss].append(subordinate)

    ans = [0] * (n + 1)

    for i in range(1, n + 1):
        q = deque([i])
        cnt = 0
        while q:
            curr = q.popleft()
            for child in graph[curr]:
                cnt += 1
                q.append(child)
        ans[i] = cnt

    print(*(ans[1:]))

if __name__ == "__main__":
    main()
```

# AC 倒序遍历 递归
``` python
import sys
import math
from collections import deque

def main():

    n = int(sys.stdin.readline().strip())
    arr = list(map(int, sys.stdin.readline().strip().split()))

    ans = [0] * (n + 1)

    for i in range(n, 1, -1):
        parent = arr[i - 2]
        ans[parent] += ans[i] + 1

    print(*(ans[1:]))

if __name__ == "__main__":
    main()
```
