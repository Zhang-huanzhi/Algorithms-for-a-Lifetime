### 三、 必备 Python 代码模板速记（考场直接套用）

你只需要在考前把下面这两个模板写熟即可：

#### 模板 1：万能树 DFS（向下求深度 + 向上求子树大小）
```python
import sys
# 必须写：防止深度退化为一条链时报错
sys.setrecursionlimit(300000)

def main():
    n = int(sys.stdin.readline())
    tree = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, sys.stdin.readline().split())
        tree[u].append(v)
        tree[v].append(u)

    depth = [0] * (n + 1)
    sub_size = [0] * (n + 1)

    def dfs(u, parent, d):
        depth[u] = d           # 1. 自顶向下：记录深度/路径状态
        sz = 1
        for v in tree[u]:
            if v != parent:    # 无向树避免往回走
                sz += dfs(v, u, d + 1)
        sub_size[u] = sz       # 2. 自底向上：收集子树汇总信息
        return sz

    dfs(1, -1, 0)
```

#### 模板 2：树 / 图的层序 BFS（求最短距离）
```python
from collections import deque
import sys

def bfs(start_node, n, tree):
    dist = [-1] * (n + 1)
    q = deque([start_node])
    dist[start_node] = 0

    while q:
        u = q.popleft()
        for v in tree[u]:
            if dist[v] == -1:       # 未访问过
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```
