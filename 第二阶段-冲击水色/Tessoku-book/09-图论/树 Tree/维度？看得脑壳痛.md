分析和选择“树的遍历”时，通常不需要死记硬背某一种具体写法，而是从以下 **5 个正交的核心维度** 来拆解和定义的：

---

### 维度一：按“搜索方向与路径”划分（搜索策略）
这是最本质的算法分类，决定了算法是优先往深处走，还是往宽处走。

| 类型 | 核心机制 | 数据结构 | 解决什么问题 |
| :--- | :--- | :--- | :--- |
| **深度优先遍历 (DFS)** | 选定一条路径走到底，遇到死胡同再回溯。 | **栈（Stack）**<br>（系统递归栈 / 显式栈） | 连通性、祖先与子树依赖、路径寻找、树形 DP。 |
| **广度优先遍历 (BFS)** | 像水波纹一样，以根为中心按“层”向外扩散。 | **队列（Queue）** | **无权树/图的最短路**、按层打印、树的宽度与分层统计。 |

---

### 维度二：按“节点的处理时机”划分（节点访问顺序）
DFS 访问一个节点 $u$ 时，有“刚进入”和“准备离开”等不同时间点。根据**何时对节点执行核心业务操作**，分为三种：

| 类型 | 访问顺序公式 | 核心思想 | 典型场景 |
| :--- | :--- | :--- | :--- |
| **前序遍历 (Pre-order)** | **根 $\to$ 左 $\to$ 右**<br>(父节点优先) | **刚踏入节点时就处理**。自顶向下派发信息。 | 传递深度/前缀和、树的序列化、输出树状目录。 |
| **中序遍历 (In-order)** | **左 $\to$ 根 $\to$ 右** | 处理完左子树，再处理自己，最后处理右子树。<br>*(注：仅适用于二叉树)* | **二叉搜索树（BST）** 排序输出、校验是否为有效 BST。 |
| **后序遍历 (Post-order)** | **左 $\to$ 右 $\to$ 根**<br>(子节点优先) | **处理完所有子树后，回溯时才处理自己**。自底向上汇总信息。 | **统计子树大小（本题 A65）**、求树高/直径、表达式树求值、删除整棵树。 |

---

### 维度三：按“信息与状态的流动方向”划分（工程与解题视角）
在写树上动态规划（树形 DP）或递归传参时，最重要的思维维度：

*   **自顶向下（Top-Down / 根到叶）**
    *   **表现形式**：把父节点的状态作为参数传入子节点的函数调用中（如 `dfs(child, depth + 1, path_sum + val)`）。
    *   **适用**：祖先信息往下继承、限制条件层层下发。
*   **自底向上（Bottom-Up / 叶到根）**
    *   **表现形式**：子节点通过 `return` 返回统计值，父节点把各个子节点的返回值加总或取 $\max/\min$。
    *   **适用**：子树规模汇总、树形 DP（只有先知道了子树的最优解，才能推导当前节点的最优解）。

---

### 维度四：按“代码实现与控制流”划分（编程实现手段）
同样是遍历逻辑，可以用不同的代码形态实现，各有优劣：

1. **递归实现（Recursive）**
   *   利用语言的调用栈，代码最简洁清晰。
   *   *局限*：在深度极深（如退化为链表，$N \ge 10^5$）时，容易导致栈溢出（Stack Overflow / RecursionError）。
2. **显式迭代栈实现（Iterative with Stack）**
   *   手动用列表 `stack` 模拟调用栈，杜绝爆栈风险。
3. **拓扑序/倒序循环（Iterative Topological Order）**
   *   针对特定题目（如节点满足 $A_i < i$ 或通过入度剥离叶子），直接通过单层 `for` 循环倒序/队列推进。
4. **线索化 / 莫里斯遍历（Morris Traversal）**
   *   临时利用叶子节点的空指针构建回溯线索，实现空间复杂度 $O(1)$ 的遍历。

---

### 维度五：按“树的结构特征”划分（适用模型）

*   **二叉树（Binary Tree）**：每个节点至多 2 个子节点（有前序、中序、后序之分）。
*   **多叉树 / 一般有根树（N-ary Tree / Rooted Tree）**：子节点数量不限，只有**前序、后序、层序**，没有天然的中序概念。
*   **无根树（Unrooted Tree）**：题目只给了 $N-1$ 条无向边，**没有指定根**。
    *   *遍历技巧*：可以任意指定 $1$ 号点为根，递归时携带 `parent` 参数（`if v != parent: dfs(v, u)`）来防止沿无向边走回头路。

### 维度串联速查表（遇到题目怎么套）

| 题目需求问什么？ | 思考维度链条（决策路径） |
| :--- | :--- |
| **“两点间最少走几步”** | 维度一(BFS) $\to$ 队列分层推进 |
| **“计算以每个点为根的子树节点数”** | 维度一(DFS) $\to$ 维度二(后序) $\to$ 维度三(自底向上) |
| **“求根节点到各节点的路径距离”** | 维度一(DFS) $\to$ 维度二(前序) $\to$ 维度三(自顶向下带参) |
| **“二叉搜索树中找第 K 小的值”** | 维度五(二叉树) $\to$ 维度二(中序遍历，天生递增) |
| **“题目给了一棵没有根的无向树”** | 维度五(无根树：选1号为根 + 记录 `parent` 破环) $\to$ 递归 DFS |
