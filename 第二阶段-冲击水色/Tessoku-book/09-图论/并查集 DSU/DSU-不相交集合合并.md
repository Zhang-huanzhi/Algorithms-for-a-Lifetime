**DSU** 是 **Disjoint Set Union**（不相交集合合并）的缩写，在中文语境中更广为人知的名字是——**并查集（Union-Find）**。

它是计算机科学与算法竞赛中最精妙、最高效的数据结构之一。如果用一句话概括它的作用：  
**它专门用于在常数级时间内，动态维护若干个“互不重叠的小圈子（集合）”，并支持合并与归属查询。**

---

### 一、 名字的由来

1. **Disjoint Set（不相交集合）**：
   * 集合与集合之间没有任何交集。比如集合 A 是 $\{1, 2, 3\}$，集合 B 是 $\{4, 5\}$，任何元素只能且必须属于其中一个集合。
2. **Union（合并）**：
   * 顾名思义，它的核心使命之一就是能快速把两个集合“融合成一个”。

在英文学术界和国外竞赛平台（如 Codeforces、AtCoder）中，通常叫它 **DSU**；在国内（LeetCode、洛谷、各大高校教材）中，更多称之为**并查集**。

---

### 二、 它解决什么核心问题？

它专门解决**动态连通性（Dynamic Connectivity）**问题：
* **不能做什么**：原生的 DSU **不支持拆分集合**（不支持把连好的边断开，只能合，不能分）。
* **擅长做什么**：如果整个过程只有“不断连线（加边）”和“询问两点是否相通”，DSU 是全场效率最高的最优解。

---

### 三、 三大核心操作

DSU 在内部把每个集合构建成一棵**树**，选树根作为这个集合的“代表元（Leader）”。

| 操作 | 英文名 | 逻辑含义 |
| :--- | :--- | :--- |
| **初始化** | `MakeSet(x)` | 每个人自成一派，自己的父节点是自己。 |
| **查询** | `Find(x)` | 顺着树枝向上找，找到 $x$ 所在树的最高树根（代表元）。 |
| **合并** | `Union(x, y)` | 找到 $x$ 的根和 $y$ 的根，把一棵树挂到另一棵树下面。 |

---

### 四、 为什么 DSU 如此神级？（极致的优化）

普通的树结构如果退化成一条链，查询耗时会高达 $O(N)$。DSU 凭借两项神级优化，把复杂度压到了极限：

1. **路径压缩（Path Compression）**：
   * 在调用 `Find(x)` 找到根节点后，递归或回溯时，顺便把路上走过的所有节点的父指针，**全部直接改成根节点**。整棵树瞬间被拍扁，高度变成 1~2 层。
2. **启发式合并（按大小 / 秩合并，Union by Size / Rank）**：
   * 当两棵树合并时，把**节点较少的小树**挂到**节点较多的大树**下面，防止树的深度无节制地增加。

#### 复杂度：反阿克曼函数 $O(\alpha(N))$
当同时开启上述两项优化后，单次操作的时间复杂度被数学证明为 **$O(\alpha(N))$**。  
对于现实世界中的任何天文数字，$\alpha(N) \le 4$。因此在工程和竞赛中，大家直接将它的单次耗时等同于 **$O(1)$（常数级）**。

---

### 五、 DSU 的四大经典应用场景

在面试和算法竞赛中，遇到以下问题基本上秒选 DSU：

1. **图的连通性判定**（本题 A66）：
   * 不断加边，随时查询两点是否连通。
2. **无向图判环（Cycle Detection）**：
   * 给定一条边 $(u, v)$，如果在连边前 `Find(u) == Find(v)`，说明它们已经连通了，**再加这条边必定成环**！
3. **Kruskal 最小生成树算法（MST）**：
   * 把图的所有边按权重升序排序，利用 DSU 依次贪心地加边，只要两端点不属于同一个集合就合并，直到连成一棵树。
4. **网格图连通块（如 LeetCode 200: 岛屿数量）**：
   * 二维网格中上下左右相邻的陆地，可以通过 `row * cols + col` 的坐标展平技巧，用 DSU 快速合并。

---

### 六、 进阶扩展（算法竞赛常客）

除了最基础的形态，DSU 还有几种著名的变体：

* **带权并查集（Weighted DSU）**：
  * 在维护集合连通性的同时，树边上附带权值，可以维护节点与根节点之间的“相对距离差 / 偏移量”（如食物链问题、推导相对坐标）。
* **种类并查集 / 扩展域并查集**：
  * 引入虚拟节点维护“对立关系”，实现“敌人的敌人是朋友”。
* **可撤销并查集（Rollback DSU）**：
  * 放弃路径压缩（只保留按大小合并，单次复杂度 $O(\log N)$），用一个栈记录每次合并修改了哪个指针，从而支持 `undo()` 撤销上一步合并操作。常用于离线分治（CDQ 分治）、线段树分治等高级图论场景。
