### B66 - Typhoon（台风）

**运行时间限制：** 2 秒 / **内存限制：** 1024 MiB  
**分值：** 1000 分

#### 问题陈述
ALGO 国有 $N$ 个车站和 $M$ 条铁路线。车站的编号为 $1$ 到 $N$，第 $i$ 条路线双向连接车站 $A_i$ 和车站 $B_i$。  
今天台风将在 ALGO 国登陆，部分铁路线可能会停运。针对这种情况，请按顺序处理以下 $2$ 种询问（Query）：

- **类型 1：** 第 $x$ 条路线停运。
- **类型 2：** 回答当前时刻能否从车站 $u$ 移动到车站 $v$。

若给定的询问总数为 $Q$，期望的时间复杂度为 $O((N + M + Q) \log N)$。

---

#### 制约条件
- $2 \le N \le 100000$
- $1 \le M \le 100000$
- $1 \le Q \le 100000$
- $1 \le A_i < B_i \le N \quad (1 \le i \le M)$
- $i \ne j \implies (A_i, B_i) \ne (A_j, B_j)$
- $\text{Query}_i \ (1 \le i \le Q)$ 均为以下两种格式之一：
  - `1 x`：$1 \le x \le M$。保证在该询问给出前，第 $x$ 条路线尚未停运。
  - `2 u v`：$1 \le u < v \le N$。
- 输入中的所有值均为整数。

---

#### 输入格式
输入通过标准输入按以下格式给出：

$$
\begin{aligned}
&N \quad M \\
&A_1 \quad B_1 \\
&A_2 \quad B_2 \\
&\vdots \\
&A_M \quad B_M \\
&Q \\
&\text{Query}_1 \\
&\text{Query}_2 \\
&\vdots \\
&\text{Query}_Q
\end{aligned}
$$

---

#### 输出格式
对于所有的**类型 2** 询问，按顺序依次输出答案：若能连通连达输出 `Yes`，否则输出 `No`，每个答案占一行。

---

### 样例说明

#### 样例 1
**输入**
```text
3 2
1 2
2 3
4
2 2 3
1 2
2 1 3
1 1
```

**输出**
```text
Yes
No
```

*解释：*
- 第 1 个询问（类型 2）：此时没有路线停运，车站 2 和车站 3 连通，输出 `Yes`。
- 第 2 个询问（类型 1）：第 2 条路线（连接 2 和 3）停运。
- 第 3 个询问（类型 2）：车站 1 与车站 3 不再连通，输出 `No`。
- 第 4 个询问（类型 1）：第 1 条路线停运。

# AC 离线+逆序+DSU
``` python
import sys  
  
from atcoder.dsu import DSU  
  
def main():  
  
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    graph = [(0, 0)]  
    for i in range(1, m + 1):  
        a, b = map(int, sys.stdin.readline().strip().split())  
  
        graph.append((a, b))  
  
    q = int(sys.stdin.readline().strip())  
  
    queries = []  
    deleted = [False] * (m + 1)  
  
    for _ in range(q):  
        line = list(sys.stdin.readline().strip().split())  
  
        op = line[0]  
        if op == '1':  
            x = int(line[1])  
  
            queries.append((1, x))  
            deleted[x] = True  
  
        if op == '2':  
            u, v = int(line[1]), int(line[2])  
  
            queries.append((2, u, v))  
  
    dsu = DSU(n + 1)  
  
    for i in range(1, m + 1):  
        if not deleted[i]:  
            u, v = graph[i]  
            dsu.merge(u, v)  
  
    outs = []  
    for query in reversed(queries):  
        if query[0] == 2:  
            _, u, v = query  
            if dsu.same(u, v):  
                outs.append("Yes")  
            else:  
                outs.append("No")  
        else:  
            _, x = query  
            u, v = graph[x]  
            dsu.merge(u, v)  
  
    outs.reverse()  
    print('\n'.join(outs))  
  
if __name__ == "__main__":  
    main()
```
