### A66 - Connect Query 

**时间限制**：1 秒 / **空间限制**：1024 MiB  
**分值**：1000 分

#### 题目描述
对于一个包含 $N$ 个顶点的图，请高效地处理以下 $2$ 种操作（查询）：

* **操作 1**：在顶点 $u$ 和顶点 $v$ 之间添加一条双向（无向）边。
* **操作 2**：回答顶点 $u$ 和顶点 $v$ 是否属于同一个连通分量。

初始状态下图没有任何边，给定的操作次数为 $Q$ 次。

#### 数据范围与约束
* $2 \le N \le 100000$
* $1 \le Q \le 100000$
* 每个 $\text{Query}_i$ ($1 \le i \le Q$) 的格式均为 $t_i \ u_i \ v_i$
* $t_i \in \{1, 2\}$ ($1 \le i \le Q$)
* $1 \le u_i < v_i \le N$ ($1 \le i \le Q$)
* 所有输入均为整数

#### 输入格式
输入通过标准输入按以下格式给出：

$$
N \quad Q \\
\text{Query}_1 \\
\text{Query}_2 \\
\vdots \\
\text{Query}_Q
$$

$\text{Query}_i$ 表示第 $i$ 次操作的信息。  
若为**操作 1**，格式为 `1 u v`；若为**操作 2**，格式为 `2 u v`。详情请参见样例输入。

#### 输出格式
按顺序输出所有**操作 2**的回答，每个回答占一行（属于同一连通分量输出 `Yes`，否则输出 `No`）。

---

#### 输入样例 1
```text
3 4
1 1 2
2 1 3
1 2 3
2 2 3
```

#### 输出样例 1
```text
No
Yes
```
* **说明**：
  * 第一次操作：在顶点 1 和顶点 2 之间连边。
  * 第二次操作：询问顶点 1 和 3 是否连通，此时不连通，输出 `No`。
  * 第三次操作：在顶点 2 和顶点 3 之间连边。
  * 第四次操作：询问顶点 2 和 3 是否连通，此时已连通，输出 `Yes`。

---

#### 输入样例 2
```text
12 12
2 9 11
1 1 7
1 1 4
2 3 6
1 3 5
2 3 5
1 10 12
1 4 8
1 8 11
2 10 12
1 5 9
2 6 8
```

#### 输出样例 2
```text
No
No
Yes
Yes
No
```

# TLE 朴素暴力DFS
``` python
import sys

def main():

    n, q = map(int, sys.stdin.readline().strip().split())

    graph = [ [] for _ in range(n + 1)]
    outs = []
    for _ in range(q):

        line = list(sys.stdin.readline().strip().split())

        op = line[0]

        if op == '1':
            u, v = int(line[1]), int(line[2])

            graph[u].append(v)
            graph[v].append(u)

        if op == '2':
            u, v = int(line[1]), int(line[2])

            st = []
            visited = [False] * (n + 1)
            st.append(u)

            while st:

                cur = st.pop()

                if cur == v:
                    outs.append("Yes")
                    break

                for nex in graph[cur]:
                    if not visited[nex]:
                        visited[nex] = True
                        st.append(nex)

            else:
                outs.append("No")

    print('\n'.join(outs))

if __name__ == "__main__":
    main()
```

# RE 手写DSU 函数写法 忘记解除递归限制
``` python
import sys

def main():

    n, q = map(int, sys.stdin.readline().strip().split())

    parent = list(range(n + 1))

    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])  # 路径压缩
        return parent[x]

    # 3. 合并
    def union(u, v):
        root_u = find(u)
        root_v = find(v)
        if root_u != root_v:
            parent[root_u] = root_v

    outs = []
    for _ in range(q):

        line = list(sys.stdin.readline().strip().split())
        op = line[0]

        if op == '1':
            u, v = int(line[1]), int(line[2])

            union(u, v)

        if op == '2':
            u, v = int(line[1]), int(line[2])

            if find(u) == find(v):
                outs.append("Yes")
            else:
                outs.append("No")

    print('\n'.join(outs))

if __name__ == "__main__":
    main()
```

# AC 手写DSU 类封装 
``` python
import sys

sys.setrecursionlimit(200000)

def main():

    n, q = map(int, sys.stdin.readline().strip().split())

    parent = list(range(n + 1))

    class DSU:
        def __init__(self, n):
            self.parent = list(range(n + 1))
            self.size = [1] * (n + 1)

        def find(self, x):
            root = x
            while root != self.parent[root]:
                root = self.parent[root]

            curr = x
            while curr != root:
                nex = self.parent[curr]
                self.parent[curr] = root
                curr = nex

            return root

        def union(self, u, v):
            root_u = self.find(u)
            root_v = self.find(v)

            if root_u == root_v:
                return False  # 已经在同一个集合中，无需合并

            if self.size[root_u] < self.size[root_v]:
                root_u, root_v = root_v, root_u

            self.parent[root_v] = root_u
            self.size[root_u] += self.size[root_v]
            return True

    outs = []
    dsu = DSU(n)
    for _ in range(q):

        line = list(sys.stdin.readline().strip().split())
        op = line[0]

        if op == '1':
            u, v = int(line[1]), int(line[2])

            dsu.union(u, v)

        if op == '2':
            u, v = int(line[1]), int(line[2])

            if dsu.find(u) == dsu.find(v):
                outs.append("Yes")
            else:
                outs.append("No")

    print('\n'.join(outs))

if __name__ == "__main__":
    main()
```
