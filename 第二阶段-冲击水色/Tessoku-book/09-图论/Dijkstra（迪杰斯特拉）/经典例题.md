### A64 - Shortest Path 2

**时间限制**：3 秒 / **内存限制**：1024 MiB  
**分值**：1000 分

#### 题目描述
请解决带权无向图上的单源最短路径问题。  
具体而言，给定一个满足以下条件的图，请计算从**顶点 $1$** 到各个顶点的最短路径长度：

- 图包含 $N$ 个顶点、$M$ 条边。
- 第 $i$ 条边连接顶点 $A_i$ 和顶点 $B_i$，边权（长度）为 $C_i$。

在后续说明中，我们将顶点 $1$ 到顶点 $k$ 的最短路径长度记为 $\text{dist}[k]$。

#### 约束条件
- $2 \le N \le 100000$
- $1 \le M \le \min(100000, N(N-1)/2)$
- $1 \le A_i < B_i \le N$ ($1 \le i \le M$)
- $1 \le C_i \le 10000$ ($1 \le i \le M$)
- 当 $i \ne j$ 时，$(A_i, B_i) \ne (A_j, B_j)$（即图中无重边）
- 所有输入数据均为整数

#### 输入格式
输入从标准输入按以下格式给出：

$$
\begin{matrix}
N & M \\
A_1 & B_1 & C_1 \\
A_2 & B_2 & C_2 \\
\vdots \\
A_M & B_M & C_M
\end{matrix}
$$

#### 输出格式
共输出 $N$ 行。  
第 $k$ 行输出 $\text{dist}[k]$ 的值。如果无法从顶点 $1$ 到达顶点 $k$，则输出 $-1$。

# AC Code
``` python
import heapq  
import sys  
import math  
from collections import deque  
  
  
def main():  
  
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    graph = [ [ ] for _ in range(n + 1)]  
    for _ in range(m):  
        a, b, c = map(int, sys.stdin.readline().strip().split())  
  
        graph[a].append((b, c))  
        graph[b].append((a, c))  
  
    dist = [math.inf] * (n + 1)  
  
    dist[1] = 0  
    pq = [(0, 1)]  
  
    while pq:  
  
        d, u = heapq.heappop(pq)  
  
        if d > dist[u]:  
            continue  
  
        for v, weight in graph[u]:  
            new_dist = d + weight  
  
            if new_dist < dist[v]:  
                dist[v] = new_dist  
                heapq.heappush(pq, (new_dist, v))  
  
    outs = []  
    for i in range(1, n + 1):  
        if dist[i] == math.inf:  
            outs.append(-1)  
        else:  
            outs.append(dist[i])  
  
    sys.stdout.write('\n'.join(map(str, outs)))  
  
  
if __name__ == "__main__":  
    main()
```
