### B62 - 打印路径 (Print a Path)

时间限制: 1 秒 / 内存限制: 1024 MiB

分值: 1000 分

#### 题目描述
给定一个由 $N$ 个顶点和 $M$ 条边组成的连通无向图。  
请输出一条从顶点 $1$ 到顶点 $N$ 的**简单路径**。

#### 限制条件
* $2 \le N \le 100000$
* $1 \le M \le 100000$
* $1 \le A_i < B_i \le N$ ($1 \le i \le M$)
* $i \neq j \implies (A_i, B_i) \neq (A_j, B_j)$（无重边）
* 给定的图是连通图
* 所有输入均为整数

#### 输入格式
输入通过标准输入按以下格式给出：

$$
N \quad M \\
A_1 \quad B_1 \\
A_2 \quad B_2 \\
\vdots \\
A_M \quad B_M
$$

#### 输出格式
请按以下格式在一行中输出答案：

$$
v_1 \quad v_2 \quad \dots \quad v_k
$$

$(v_1, v_2, \dots, v_k)$ 必须是给定图中从顶点 $1$ 到顶点 $N$ 的一条简单路径。形式化地说，$(v_1, v_2, \dots, v_k)$ 必须满足以下条件：

* $v_1 = 1, \; v_k = N$
* $i \neq j \implies v_i \neq v_j$（路径上无重复顶点）
* 图中存在连接 $(v_i, v_{i+1})$ 的边 ($1 \le i < k$)

若存在多条合法的简单路径，输出其中任意一条即可。

# 显式栈 + DFS
``` python 
import sys  
import math  
  
sys.setrecursionlimit(200000)  
  
def main():  
  
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    adj = [ [] for _ in range(n + 1)]  
    for _ in range(m):  
        a, b = map(int, sys.stdin.readline().strip().split())  
  
        adj[a].append(b)  
        adj[b].append(a)  
  
    parent = [-1] * (n + 1)  
  
    stack = [1]  
    parent[1] = 0  
  
    while stack:  
        curr = stack.pop()  
  
        if curr == n:  
            break  
  
        for nex in adj[curr]:  
            if parent[nex] == -1:  
                parent[nex] = curr  
                stack.append(nex)  
  
    path = []  
    curr = n  
    while curr != 1:  
        path.append(curr)  
        curr = parent[curr]  
    path.append(1)  
  
    path.reverse()  
    print(*path)  
  
  
if __name__ == "__main__":  
    main()
```

# 递归式 DFS
``` python
import sys
import math

sys.setrecursionlimit(200000)

def main():

    n, m = map(int, sys.stdin.readline().strip().split())

    adj = [ [] for _ in range(n + 1)]
    for _ in range(m):
        a, b = map(int, sys.stdin.readline().strip().split())

        adj[a].append(b)
        adj[b].append(a)

    visited = [False] * (n + 1)
    path = []

    def dfs(cur):

        visited[cur] = True
        path.append(cur)

        if cur == n:
            return True

        for nex in adj[cur]:
            if not visited[nex]:
                if dfs(nex):
                    return True

        path.pop()
        return False

    dfs(1)

    print(*path)


if __name__ == "__main__":
    main()
```

# Parent数组 DFS
``` python
import sys
import math

sys.setrecursionlimit(200000)

def main():

    n, m = map(int, sys.stdin.readline().strip().split())

    adj = [ [] for _ in range(n + 1)]
    for _ in range(m):
        a, b = map(int, sys.stdin.readline().strip().split())

        adj[a].append(b)
        adj[b].append(a)

    parent = [-1] * (n + 1)

    def dfs(u):
        if u == n:
            return True

        for v in adj[u]:
            if parent[v] == -1 and v != 1:
                parent[v] = u
                if dfs(v):
                    return True
        return False

    dfs(1)

    path = []
    curr = n
    while curr != 1:
        path.append(curr)
        curr = parent[curr]
    path.append(1)

    path.reverse()
    print(*path)


if __name__ == "__main__":
    main()
```
