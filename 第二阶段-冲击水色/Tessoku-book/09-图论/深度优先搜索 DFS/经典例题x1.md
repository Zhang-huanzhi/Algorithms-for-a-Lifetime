### A62 - 深度优先搜索（Depth First Search）

**运行时间限制**：1 秒 / **内存限制**：1024 MiB  
**分值**：1000 分

#### 题目描述
给定一个由 $N$ 个顶点和 $M$ 条边组成的无向图，顶点编号分别为 $1, 2, \dots, N$。  
第 $i$ 条边连接顶点 $A_i$ 和顶点 $B_i$。

请判断整张图是否连通，并按照以下要求输出结果：

- 如果整张图是连通的，输出 `The graph is connected.`
- 如果不是连通的，输出 `The graph is not connected.`

#### 数据范围与限制
- 输入的所有数值均为整数
- $1 \le N \le 10^5$
- $0 \le M \le \min\left(10^5, \dfrac{N(N-1)}{2}\right)$
- $1 \le A_i < B_i \le N$
- 图中不存在重边（多重边）和自环

#### 输入格式
输入通过标准输入按以下格式给出：

$$
N \quad M \\
A_1 \quad B_1 \\
A_2 \quad B_2 \\
\vdots \\
A_M \quad B_M
$$

#### 输出格式
请按照题目描述的要求输出相应内容。

---

#### 样例 1

**输入**
```text
3 2
1 3
2 3
```

**输出**
```text
The graph is connected.
```

**样例解释 1**  
给定的图是连通的。

---

#### 样例 2

**输入**
```text
6 6
1 4
2 3
3 4
5 6
1 2
2 4
```

**输出**
```text
The graph is not connected.
```

**样例解释 2**  
给定的图不是连通的（例如顶点 5 和 6 所在的连通块与其余部分不连通）。


# 系统栈 DFS
``` python
import sys
import math

sys.setrecursionlimit(200000)

def main():

    n, m = map(int, sys.stdin.readline().strip().split())

    adj = [ [] for _ in range(n + 1)]
    for _ in range(m):
        a, b = map(int, sys.stdin.readline().strip().split())

        adj[a].append(b)
        adj[b].append(a)

    visited = [False] * (n + 1)

    def dfs(u):
        visited[u] = True
        for v in adj[u]:
            if not visited[v]:
                dfs(v)

    dfs(1)

    if all(visited[1:]):
        print("The graph is connected.")
    else:
        print("The graph is not connected.")

if __name__ == "__main__":
    main()
```
