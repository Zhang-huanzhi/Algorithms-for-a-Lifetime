图论（Graph Theory）在所有算法门类中，是**数学符号标准化程度最高**的一门学科。

在国际算法竞赛中，图论的代码命名有一套高度公认的“学术兼工程惯例”。遵循这套命名规范，不仅能让你在写复杂图论时思维极度清晰，还能彻底杜绝“变量混淆”引发的恶性 Bug。

以下是针对图论各个细分场景的**命名黄金标准**：

---

### 一、图的基础骨架（点、边、表）

| 概念 | 推荐命名 | 避坑与说明 |
| :--- | :--- | :--- |
| **点数、边数** | `n, m` 或 `V, E` | 读入数据通常用 `n, m`；理论复杂度分析或全局常量用 `V, E`。 |
| **邻接表** | **`g`** 或 `graph` | 极其高频。在竞赛中写单字母 `g` 既简洁又不会产生歧义。 |
| **有向边端点** | **`u, v`** | **数学国际惯例**：表示一条由 $u$ 指向 $v$ 的边（$u \to v$）。$u$ 代表当前点/出发点，$v$ 代表目标点/邻居。 |
| **边权 / 代价** | **`w`** 或 `weight` / `cost` | 边的权重统一用 `w`（weight），建图时元组顺序固定为 **`(v, w)`**（即目标点在前，权重在后）。 |
| **边列表** | `edges` | 适用于 Kruskal、Bellman-Ford，元素格式固定为 `(u, v, w)`。 |
| **邻接矩阵** | `adj` 或 `matrix` | 仅在点数极小（$N \le 500$）且需要 $O(1)$ 查边时使用。 |

> **避坑警告**：
> 不要用 `from_node, to_node`（在某些语言中 `from` 是关键字）；也不要在同一份代码里一会儿用 `x, y` 一会儿用 `u, v`，**图论中代表顶点一律用 $u$ 和 $v$**。

---

### 二、度数与有向图（拓扑排序）

在有向图、DAG（有向无环图）以及基环树中，度数是核心状态：

| 概念 | 推荐命名 | 说明 |
| :--- | :--- | :--- |
| **入度** | **`in_deg`** 或 `indeg` | In-degree（指向当前点的边数）。拓扑排序的命脉。 |
| **出度** | **`out_deg`** 或 `outdeg` | Out-degree（从当前点指出的边数）。 |
| **无向图度数** | **`deg`** | 无向图中直接用 `deg[u]` 记录邻居个数。 |
| **拓扑序列** | **`topo`** 或 `order` | 存放拓扑排序结果的列表。 |

**标准拓扑排序代码片段**：
```python
# 命名极度自解释
in_deg = [0] * (n + 1)
# 建图时更新入度
for u, v in edges:
    g[u].append(v)
    in_deg[v] += 1

q = deque([u for u in range(1, n + 1) if in_deg[u] == 0])
topo = []
while q:
    u = q.popleft()
    topo.append(u)
    for v in g[u]:
        in_deg[v] -= 1
        if in_deg[v] == 0:
            q.append(v)
```

### 三、最短路家族（Dijkstra / SPFA / Floyd）

最短路算法的状态变量名非常固定：

| 概念 | 推荐命名 | 说明 |
| :--- | :--- | :--- |
| **源点、汇点** | **`s, t`** | Source（起点/源点）与 Target/Sink（终点/汇点）。 |
| **距离数组** | **`dist`** 或 `d` | 存储从起点到各点的当前已知最短距离。初始为 $\infty$。 |
| **确定标记** | **`done`** 或 `vis` | 仅在 Dijkstra 中使用，标记该点的最短路是否已经“出堆确定”，防止重复松弛。 |
| **前驱节点** | **`prev`** 或 `pre` | 用于**打印/还原最短路径**，`prev[v] = u` 表示 $v$ 是从 $u$ 走过来的。 |

**Dijkstra 堆中元素的命名约定**：
* 堆（Priority Queue）中元素一定要把**距离放第一位**：`(d, u)`，因为 Python 的堆默认按元组第一个元素比较。
```python
import heapq

# 堆中元素命名统一用 (d, u)
heap = [(0, s)]
dist[s] = 0

while heap:
    d, u = heapq.heappop(heap)

    if d > dist[u]:  # 剪枝懒惰删除，比 vis 数组更常用
        continue

    for v, w in g[u]:
        if dist[u] + w < dist[v]:
            dist[v] = dist[u] + w
            heapq.heappush(heap, (dist[v], v))
```

### 四、树论专属词汇库（Tree Algorithms）

树是无环连通图，它的专用属性更多：

| 概念 | 推荐命名 | 说明 |
| :--- | :--- | :--- |
| **根节点** | **`root`** | 树的根。无根树通常默认以 $1$ 号节点为根。 |
| **父节点** | **`p`** 或 `parent` / `fa` | `p` 最简短。DFS 遍历时常写 `dfs(u, p)` 防走回头路。 |
| **子节点** | **`v`** 或 `ch` (child) | `for v in g[u]: if v != p:` 属于遍历树的标准写法。 |
| **深度** | **`depth`** 或 `dep` | 根节点深度通常定义为 0 或 1。 |
| **子树大小** | **`sz`** 或 `sub_size` | 树形 DP 或树的重心必用变量。 |
| **重儿子** | **`heavy_son`** 或 `son` | 树链剖分（HLD）或 DSU on tree 用。 |
| **倍增祖先** | **`up[k][u]`** | LCA（最近公共祖先）倍增数组，表示 $u$ 向上跳 $2^k$ 步的祖先。 |

---

### 五、连通性与并查集（DSU / MST / SCC）

1. **并查集（Disjoint Set Union）**：
   * 集合代表（父亲）：**`parent`** 或 **`fa`**
   * 连通块大小 / 秩：**`size`** / **`rank`**
   * 方法名：**`find(x)`**（查找根）、**`union(x, y)`** 或 **`merge(x, y)`**（合并）、**`same(x, y)`**（判连通）。
2. **强连通分量（Tarjan / SCC）**：
   * 时间戳：**`dfn`**（或 `tin`）和 **`low`**（能追溯到的最小时间戳）。
   * SCC 编号：**`scc_id`** 或 `comp`。
   * 缩点后的新图：**`dag`** 或 `condensed_g`。

### 六、图论命名的“三项铁律”（防手滑）

1. **存邻居时，`v` 永远在前，`w` 永远在后**：
   * 邻接表统一：`g[u].append((v, w))`。
   * 遍历统一：`for v, w in g[u]:`。
   * *反例*：如果一会儿写 `(w, v)`，一会儿写 `(v, w)`，在复杂的图算法中 100% 会搞错顺序。
2. **堆（Heap）中，权值永远在前，顶点永远在后**：
   * 堆元素统一：`heapq.heappush(pq, (weight, u))`。
   * 因为 Python 优先队列按第一个字段排序，所以必须把代价作为第一项。
3. **永远用 `1-indexed` 处理图的顶点**：
   * 题目如果给 $1 \sim N$ 的节点编号，**数组直接开 `n + 1`**（如 `dist = [inf] * (n + 1)`）。
   * 强行把每个读入都 `-1` 转为 `0-indexed` 不仅浪费时间，而且在输出路径或做树形递归时极容易引发“差一错误（Off-by-one Error）”。
