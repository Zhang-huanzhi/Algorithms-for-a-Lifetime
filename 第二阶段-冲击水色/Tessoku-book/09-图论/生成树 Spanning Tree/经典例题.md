### B67 - Max MST (最大生成树)

**运行时间限制:** 1 秒 / **内存限制:** 1024 MiB  
**得分:** 1000 分

#### 题目描述
给定一个包含 $N$ 个顶点和 $M$ 条边的图。顶点的编号为 $1$ 到 $N$，第 $i$ 条边是连接顶点 $A_i$ 和 $B_i$ 的双向边，其长度（权重）为 $C_i$。

请计算该图的**最大生成树**中所有边的长度总和。

#### 约束条件
* $2 \le N \le 100000$
* $1 \le M \le 100000$
* $1 \le A_i < B_i \le N$
* 若 $i \neq j$，则 $(A_i, B_i) \neq (A_j, B_j)$（无重边）
* $1 \le C_i \le 10000$
* 给定的图是连通图
* 输入的所有数值均为整数

#### 输入格式
输入从标准输入中按以下格式给出：

$$
N \quad M
$$
$$
A_1 \quad B_1 \quad C_1
$$
$$
\vdots
$$
$$
A_M \quad B_M \quad C_M
$$

#### 输出格式
输出最大生成树中所有边的长度总和。

---

#### 样例 1

**输入：**
```text
7 9
1 2 12
1 3 10
2 6 160
2 7 15
3 4 1
3 5 4
4 5 3
4 6 120
6 7 14
```

**输出：**
```text
321
```


# AC Code
``` python
import math  
import sys  
  
from atcoder.dsu import DSU  
  
  
def main():  
  
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    edges = []  
    for _ in range(m):  
        u, v, w = map(int, sys.stdin.readline().strip().split())  
  
        edges.append((w, u, v))  
  
    edges.sort(key = lambda edge: edge[0], reverse=True)  
  
    dsu = DSU(n + 1)  
    mst_weight = 0  
    edges_count = 0  
  
    for w, u, v in edges:  
        # 如果两点未连通，说明加入该边不会成环  
        if not dsu.same(u, v):  
            dsu.merge(u, v)  
            mst_weight += w  
            edges_count += 1  
            if edges_count == n - 1:  
                break  
  
    print(mst_weight)  
  
if __name__ == "__main__":  
    main()
```
