写 BFS 觉得“怪怪的”，根源在于你**每次都在现场做微观决策**——“我是开一个 `visited` 还是用 `dist` ？”“步数是塞在队列里还是存在数组里？”“到底什么时候判断到没到终点？”。

当选择变多时，大脑就会产生内耗。

要消除这种“怪异感”，最有效的方法是**把所有的微观决策全给定死，形成一套铁打的固定套路（Golden Rules）**。以后无论写任何 BFS，都用这套模子往里套。

以下是写 BFS 最推荐固化的 **5 个习惯**：

---

### 习惯一：队列只存“坐标/节点”，绝不存“步数”

* **摇摆做法**：`q.append((r, c, step))`（容易和坐标混淆，还增加解包开销）。
* **固化习惯**：**队列只存位置 `q.append((r, c))`，步数全部由 `dist[r][c]` 统一管理。**

```python
# 永远只存位置
q = deque([(sr, sc)])
```
> **为什么？**  
> 因为一旦题目升级（比如要记录路径、多源 BFS、或者需要反复查询某点距离），把步数和坐标绑死在队列里就会非常被动；而 `dist` 数组本身就是最清晰的状态账本。

---

### 习惯二：距离与访问标记“二合一”，入队即标记（铁律）

* **摇摆做法**：又开 `visited = set()` 又开 `dist` 数组；或者在 `popleft()` 出队时才标记已访问。
* **固化习惯**：**一个 `dist` 搞定所有事，初始全部为 `-1`；只要 `append`，立即更新 `dist`！**

```python
# 1. 初始化全为 -1（-1 既代表未访问，也代表不可达）
dist = [[-1] * C for _ in range(R)]

# 2. 起点入队前先赋值
dist[sr][sc] = 0
q = deque([(sr, sc)])

# 3. 扩散时：先改 dist，再 append！
dist[nr][nc] = dist[r][c] + 1
q.append((nr, nc))
```
> **为什么？**  
> 如果出队时才标记，同一个格子会被周围 4 个格子重复压入队列 4 次，队列长度呈指数级暴涨，是导致 TLE/MLE 的最大元凶。“入队即标记”能保证**每个格子有且仅有一次进入队列**。

---

### 习惯三：坐标与方向写法死锁为 `(r, c)` 和 `dirs`

不要在 $x, y$ 还是 $y, x$ 上犹豫，永远使用以下固定的单词组合：

* 当前坐标：`r, c`（row, col）
* 方向增量：`dr, dc`（delta row, delta col）
* 下一步坐标：`nr, nc`（next row, next col）
* 四方向常量：固定写在开头

```python
# 永远这一套，连变量名都不要换
dirs = ((-1, 0), (1, 0), (0, -1), (0, 1))

for dr, dc in dirs:
    nr, nc = r + dr, c + dc
```

---

### 习惯四：终点检查统一在出队第一行判，或者干脆搜完全图

* **摇摆做法**：一会儿在入队前判断终点，一会儿在出队后判断，常常因为“起点正好等于终点”漏掉 corner case。
* **固化习惯**：
  * **日常竞赛推荐**：直接让 BFS 搜完（或者队列空），最后直接返回 `dist[gr][gc]`！
  * 如果数据特别大需要提前退出，**统一在出队的第一行判**：

```python
while q:
    r, c = q.popleft()

    # 统一在出队第一行做终点校验，最稳健，绝不漏起点就是终点的情况
    if r == gr and c == gc:
        return dist[r][c]

    for dr, dc in dirs:
        ...
```

---

### 习惯五：用“卫语句（Early Continue）”写判断，降低嵌套

* **摇摆做法**：写一个四五层深度的 `if`，括号套括号，极容易漏掉边界条件：
  ```python
  if 0 <= nr < R:
      if 0 <= nc < C:
          if grid[nr][nc] == '.':
              if dist[nr][nc] == -1:
                  ...
  ```
* **固化习惯**：**扁平化判断**。要么一行写完，要么用 `continue`：

```python
# 方式 A（最推荐，逻辑直观，从外到内短路求值）
if 0 <= nr < R and 0 <= nc < C and grid[nr][nc] == '.' and dist[nr][nc] == -1:
    dist[nr][nc] = dist[r][c] + 1
    q.append((nr, nc))

# 方式 B（当判断条件极其复杂时，用卫语句）
if not (0 <= nr < R and 0 <= nc < C):
    continue
if grid[nr][nc] == '#' or dist[nr][nc] != -1:
    continue
dist[nr][nc] = dist[r][c] + 1
q.append((nr, nc))
```

---

### 最终固化下来的“肌肉记忆”模版

把这套模版作为你以后写任何二维网格 BFS 的**唯一标准骨架**：

```python
from collections import deque


def bfs(grid, R, C, sr, sc, gr, gc):
    # 1. 常量与账本
    dirs = ((-1, 0), (1, 0), (0, -1), (0, 1))
    dist = [[-1] * C for _ in range(R)]

    # 2. 起点入队与标记
    dist[sr][sc] = 0
    q = deque([(sr, sc)])

    # 3. 核心循环
    while q:
        r, c = q.popleft()

        if r == gr and c == gc:
            return dist[r][c]

        for dr, dc in dirs:
            nr, nc = r + dr, c + dc

            # 边界 -> 障碍 -> 是否访问
            if (
                0 <= nr < R
                and 0 <= nc < C
                and grid[nr][nc] == '.'
                and dist[nr][nc] == -1
            ):
                dist[nr][nc] = dist[r][c] + 1  # 入队即标记
                q.append((nr, nc))

    return -1  # 无法到达
```

**心法总结**：  
无论题目怎么变，**`dist` 账本、`dirs` 遍历、`nr/nc` 命名、入队即标记** 这四根柱子绝不换。以后遇到 BFS，闭着眼睛把这 15 行敲出来，然后大脑只留给“题目的特殊限制怎么过滤”，你就再也不会觉得别扭了。
