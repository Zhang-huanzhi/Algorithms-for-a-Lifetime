### A60 - Stock Price
**运行时间限制：** 1 秒 / **内存限制：** 1024 MiB  
**得分：** 1000 分

#### 题目描述
KYOPRO-MASTER 股份有限公司自上市以来已经过去了 $N$ 天，第 $i$ 天的股票价格为 $A_i$ 元。太郎想要计算每一天的股票价格是“时隔多少天创下了新高”。在此，将第 $d$ 天的**起算日**定义如下：

* 满足 $i < d$ 且 $A_i > A_d$ 的**最大**的 $i$；
* 若不存在这样的 $i$，则称该天没有起算日。

请针对 $d = 1, 2, \dots, N$，分别计算出第 $d$ 天的起算日。

#### 约束条件
* 输入数据均为整数
* $1 \le N \le 200\,000$
* $1 \le A_i \le 10^9$
* $A_1, A_2, \dots, A_N$ 两两互不相同

#### 输入格式
输入通过标准输入按以下格式给出：

$$N$$
$$A_1 \quad A_2 \quad \dots \quad A_N$$

#### 输出格式
请按顺序输出 $d = 1, 2, \dots, N$ 时的起算日，各值之间以空格分隔。若某天不存在起算日，则输出 `-1`。

---

#### 样例输入 1
```text
6
6 2 5 3 1 4
```

#### 样例输出 1
```text
-1 1 1 3 4 3
```

**样例说明 1**  
例如，第 $6$ 天的起算日是第 $3$ 天。因为第 $5$ 天和第 $4$ 天的股价均小于等于 $A_6\ (= 4)$ 元，而第 $3$ 天的股价超过了 $A_6\ (= 4)$ 元。


# 暴力 TLE
``` python
import sys
import math

def main():

    n = int(sys.stdin.readline().strip())
    arr = [0] + list(map(int, sys.stdin.readline().strip().split()))

    ans = [-1] * (n + 1)

    for i in range(1, n + 1):
        for j in range(i - 1, 0, -1):
            if arr[j] > arr[i]:
                ans[i] = j
                break

    print(*ans[1:])

if __name__ == "__main__":
    main()
```

# 单调栈 AC
``` python
import sys  
import math  
  
def main():  
  
    n = int(sys.stdin.readline().strip())  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    ans = []  
    stack = []  
  
    for i in range(n):  
        day = i + 1  
        price = arr[i]  
  
        while stack and stack[-1][1] <= price:  
            stack.pop()  
  
        if stack:  
            ans.append(stack[-1][0])  
        else:  
            ans.append(-1)  
  
        stack.append((day, price))  
  
    print(*ans)  
  
if __name__ == "__main__":  
    main()
```
