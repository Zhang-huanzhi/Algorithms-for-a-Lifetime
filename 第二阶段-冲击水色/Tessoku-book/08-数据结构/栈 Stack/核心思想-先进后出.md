全面梳理一下**栈（Stack）**这一数据结构。用最通俗的语言、最实用的代码以及最贴合竞赛考点的方式来掌握它。

---

### 一、什么是栈（Stack）？

#### 1. 核心定义
栈是一种受限制的线性数据结构，其最核心的规则是：
> **LIFO（Last In, First Out，后进先出 / 先进后出）**

* **只能在同一端进行插入和删除**，这一端被称为**栈顶（Top）**。
* 另一端固定不动，被称为**栈底（Bottom）**。

#### 2. 生活中的形象比喻
* **叠放的盘子 / 书堆**：你只能把新盘子放在最上面；洗盘子时，也只能从最上面拿走刚放上去的盘子。
* **玩具手枪的弹匣**：最后压进弹匣的那颗子弹，开枪时最先被打出来。
* **吃薯片**：筒装薯片，最后装进筒里的那片，打开盖子最先吃到。

---

### 二、基本操作与时间复杂度

栈之所以极其高效，是因为它的所有核心操作都只发生在**栈顶**，因此时间复杂度全部是 **$O(1)$ 常数级**：

| 操作名称 | 英文 | 含义 | Python 中的写法 | 时间复杂度 |
| :--- | :--- | :--- | :--- | :--- |
| **压栈 / 入栈** | Push | 向栈顶放入一个新元素 | `stack.append(x)` | $O(1)$ |
| **弹栈 / 出栈** | Pop | 取出并删除栈顶的元素 | `x = stack.pop()` | $O(1)$ |
| **访问栈顶** | Top / Peek | 查看栈顶元素（但不删除） | `x = stack[-1]` | $O(1)$ |
| **判空** | IsEmpty | 检查栈里是否还有元素 | `if not stack:` | $O(1)$ |
| **获取大小** | Size | 查看栈内元素总数 | `len(stack)` | $O(1)$ |

### 三、Python 极简模板

在竞赛中，**千万不要手写 `class Stack`**，直接用 Python 自带的列表（`list`）充当栈：

```python
# 1. 创建一个空栈
stack = []

# 2. 压栈 (Push)
stack.append(10)
stack.append(20)
stack.append(30)
# 此时栈内状态：[10, 20, 30] (30 在栈顶)

# 3. 查看栈顶 (Top)
top_val = stack[-1]  # 结果是 30，但 30 依然在栈里

# 4. 弹栈 (Pop)
popped_val = stack.pop()  # 取出 30，此时栈内剩余 [10, 20]

# 5. 判空 (IsEmpty)
if stack:
    print("栈不为空")
else:
    print("栈已经空了")
```

### 四、为什么需要栈？（竞赛四大经典场景）

栈不仅仅是一个容器，它天生自带一种**“把当前事情暂存起来，先去处理最新突发事件，处理完再回头接着做”**的哲学。

在 ABC 比赛中，遇到以下 4 类题型，请**条件反射**地想到栈：

#### 场景 1：括号与语法匹配（刚刚做过的 B51）
* **特征**：配对、闭合、就近消除。
* **套路**：遇到左半边（`(`、`[`、`{`）就压栈；遇到右半边（`)`、`]`、`}`）就弹栈配对。

#### 场景 2：相邻元素消除（“消消乐”模型）
* **典型例题**：给一个字符串 `abbaca`，每次消除两个相邻且相同的字符，直到不能消除为止。
* **套路**：遍历字符串，如果当前字符和 `stack[-1]` 相同，直接 `stack.pop()`（消除）；否则 `stack.append(char)`。最后栈里剩下的就是答案。

#### 场景 3：撤销与回滚（Undo / Ctrl+Z）
* **典型例题**：打字机模拟题。输入字符时打印；输入 `B` 时撤销上一个字符；或者输入一段状态后回滚。
* **套路**：栈天然记录了“历史操作”。出栈就是回到上一个状态。

#### 场景 4：表达式求值与嵌套解析
* **典型例题**：带括号的四则运算，如 `3 * (2 + 4)`。
* **套路**：计算机没法一眼看懂括号的优先级，但通过“操作数栈”和“运算符栈”，可以一层一层剥开最深层的括号优先计算。

### 五、两个最容易爆 WA/RE 的避坑指南

1. **空栈弹出（IndexError）**
   * **雷区**：在栈为空的时候调用了 `stack.pop()` 或者 `stack[-1]`，程序直接崩溃报 `IndexError: pop from empty list`。
   * **铁则**：任何时候 `pop()` 或访问 `[-1]` 之前，**一定要确认栈非空**：
	    ``` python
	    if stack:  # 必须先确认栈非空！
		    val = stack.pop()
    
	    ```
1. **输出顺序颠倒**
   * **雷区**：如果把一堆东西压进栈，最后按出栈顺序打印，得到的顺序是**倒序**的。
   * **铁则**：如果题目要求按原来的顺序输出，最后输出前可以用 `stack.reverse()` 或者直接打印 `stack`。
