**“对于每一个位置，求它左边/右边第一个比它大/小的位置。”**

---

为你选了一道**单调栈领域最经典、最高频的母题**。

这道题是各大算法面试和 AtCoder/LeetCode 中单调栈的“第一题”——**每日温度（气温回暖问题）**。它能帮你彻底掌握**“为什么单调栈必须存下标”**。

### 题目：每日温度（Daily Temperatures）

#### 题目描述
给定一个整数数组 $T$ 代表连续几天的日最高气温。  
请你计算：对于每一天，**至少要等多少天**才能迎来一个**更温暖（严格更高）**的气温？  
如果之后都不会有更高气温，则记为 $0$。

#### 输入格式
第一行输入一个整数 $N$，表示天数。  
第二行输入 $N$ 个以空格隔开的整数 $T_1, T_2, \dots, T_N$，表示每天的气温。

#### 输出格式
输出一行 $N$ 个整数，以空格隔开，表示每一天需要等待的天数。

#### 数据范围
* $1 \le N \le 10^5$
* $30 \le T_i \le 100$
* **时间限制：** 2.0 秒（意味着 $O(N^2)$ 的暴力循环会直接超时，必须用 $O(N)$ 的解法！）

---

#### 样例 1

**输入**
```text
8
73 74 75 71 69 72 76 73
```

**输出**
```text
1 1 4 2 1 1 0 0
```

**解释：**
* 第 0 天是 73℃，第二天（第 1 天）是 74℃ 比它高，只需等 **1** 天。
* 第 1 天是 74℃，第二天（第 2 天）是 75℃ 比它高，只需等 **1** 天。
* 第 2 天是 75℃，要等到第 6 天的 76℃ 才会更高，所以要等 $6 - 2 =$ **4** 天。
* 第 3 天是 71℃，第 5 天的 72℃ 比它高，等 $5 - 3 =$ **2** 天。
* 第 4 天是 69℃，第 5 天的 72℃ 比它高，等 $5 - 4 =$ **1** 天。
* 第 5 天是 72℃，第 6 天的 76℃ 比它高，等 $6 - 5 =$ **1** 天。
* 第 6 天（76℃）和第 7 天（73℃）之后都没有更高的气温了，输出 **0**。

---

### 思考小提示

1. 既然要找“**右边第一个比当前气温高**”的那一天，应该用单调递减栈还是单调递增栈？
2. 题目问的是“**要等几天**”（即下标的差值 $i - \text{prev\_i}$），所以在栈里存**气温**还是存**下标**？



# AC Code
``` python
import sys  
import math  
  
def main():  
  
    t = int(sys.stdin.readline().strip())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    # 单调栈  
    ans = [0] * t  
    stack = []  
  
    for i in range(t):  
  
        while stack and arr[i] > arr[stack[-1]]:  
            top_idx = stack.pop()  
            ans[top_idx] = i - top_idx  
  
        stack.append(i)  
  
    print(*ans)  
  
  
  
if __name__ == "__main__":  
    main()
```
