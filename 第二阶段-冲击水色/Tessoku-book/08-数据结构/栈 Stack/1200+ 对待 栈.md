在 AtCoder 冲击 1200+（水色）的体系中，如果说**队列（Queue）是“向外扩散”的骨架（BFS/最短路）**，那么**栈（Stack）就是“回溯、抵消与区间极值”的瑞士军刀**。

单纯的 `stack.append()` 和 `stack.pop()` 只是语法，但在 1000~1400 分段的题目中，栈的考察频率和**解题灵巧度**甚至往往高于队列。

看待栈，建议你从以下 **4 个核心业务场景** 去把握：

---

### 1. “成对抵消”与“祖玛/消消乐”模型（ABC C/D 题极高频）
只要题面中出现：**“如果相邻两个满足某种条件就消除/合并”**，或者**“撤销上一步操作”**，你的第一反应必须是**栈**。

*   **思维本质**：消除当前元素后，它左边的元素会和它右边的元素产生“新的相邻关系”。栈的 `top` 恰好就是“左边紧邻的有效元素”，能以 $O(1)$ 捕获这种连锁反应。
*   **常见题型**：
    *   括号匹配 / 语法闭合
    *   消除连续相同的字符/球（如连凑满 $K$ 个就爆炸）
    *   光标移动、回退键模拟（Undo/Redo）

> **典型真题练习**：
> *   [ABC 240 D - Strange Balls](https://atcoder.jp/contests/abc240/tasks/abc240_d)（用栈存 `[数值, 连续出现次数]` 的经典好题，绿题）
> *   [ABC 328 D - Take ABC](https://atcoder.jp/contests/abc328/tasks/abc328_d)（经典栈消除字符串模式，茶/绿）
> *   [ABC 268 D - Unique Nicknames](https://atcoder.jp/contests/abc268/tasks/abc268_d) / 回溯法模拟

---

### 2. 单调栈（Monotonic Stack）（ABC D/E 题的分水岭）
这是冲 1200+ **必须完全吃透的技巧**。
单调栈指：在入栈时，不断弹出破坏单调性的元素，保证栈内元素始终**单调递增**或**单调递减**。

*   **解决的核心问题**：
    在 $O(N)$ 时间内，求出**每一个元素左边（或右边）第一个比它大（或小）的元素位置**。
*   **延伸的高频考点**：
    1.  **直方图最大矩形**（柱状图面积）：以当前元素为高，能向左右扩展的最远边界是多少。
    2.  **“贡献法”求子区间最值之和**：计算每个元素作为 $\min$ 或 $\max$ 的子区间有多少个。

> **典型真题练习**：
> *   [ABC 189 C - Mandarin Orange](https://atcoder.jp/contests/abc189/tasks/abc189_c)（可以用 $O(N^2)$ 暴力，但单调栈 $O(N)$ 是标准解，茶/绿题）
> *   [ABC 311 E - Defect-free Squares](https://atcoder.jp/contests/abc311/tasks/abc311_e)（或者二维最大全 1 矩阵类问题）
> *   [ABC 157 E - Simple String Queries](https://atcoder.jp/contests/abc157/tasks/abc157_e)（区间统计对比）

---

### 3. 递归与 DFS：Python 选手的“系统栈陷阱”
递归调用在计算机底层就是**系统函数调用栈（Call Stack）**。
作为 Python 选手，在 1200+ 的图论/树形 DP 题目中，必须对栈有底层敬畏：

1.  **爆栈危机**：Python 默认的最大递归深度仅为 1000。
    *   在树深可达 $10^5$ 的题目中，只要写递归 DFS，必须在代码最顶部加上：
        ```python
        import sys
        sys.setrecursionlimit(10**6)
        ```
2.  **手写栈模拟 DFS（防 TLE/MLE）**：
    *   PyPy 在递归过深时容易消耗大量内存甚至 TLE。遇到极深的树，学会用 `stack = [root]` 显示地手写栈来完成后序遍历/拓扑顺序，是高段位 Python 选手的保底技能。

---

### 4. 历史回退（Rollback）思想（水色进阶）
在 1200~1400 分段，经常会出现“可撤销”的需求，例如：
*   **可撤销并查集（Rollback Union-Find）**：不支持路径压缩，而是将每次 `union` 操作修改的节点和原值压入一个历史记录栈。需要回滚时，从栈顶弹出操作进行逆向赋值。
*   用于处理离线动态图连通性、分治树等。

---

### 学习建议与总结

对于冲刺 1200+，对待“栈”的训练清单：

1.  **不要花时间在基础栈操作上**：像 `A51 - Stack`（单纯压栈出栈）这种题看一眼即可，直接跳过。
2.  **专项训练“栈模拟与消除”**：把 **ABC 240 D** 和 **ABC 328 D** 写掉，养成“相邻消除找栈”的肌肉记忆。
3.  **彻底吃透“单调栈”模板**：找一道经典的“求数组中每个数右侧第一个比它大的数”，用 Python 把单调栈模板背下来，理解为什么它弹出的总次数是 $O(N)$ 的。
