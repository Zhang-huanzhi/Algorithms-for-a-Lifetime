以下是 AtCoder 官方库中 **`FenwickTree`** 的完整使用说明和速查手册：

---

### 1. 导入与简介
在 Python（`ac-library-python`）中导入：
```python
from atcoder.fenwicktree import FenwickTree
```
- **核心功能**：专门用于高效处理 **“单点加法更新”** 与 **“区间加法求和”**。
- **时间复杂度**：
  - 初始化：$O(N)$
  - 单点加法 `add`：$O(\log N)$
  - 区间求和 `sum`：$O(\log N)$
- **空间复杂度**：$O(N)$

---

### 2. 核心规则（非常重要！）
AtCoder 库对树状数组进行了二次封装，所有接口遵循以下两条规范：
1. **0-indexed（从 0 开始计数）**：下标范围为 $0 \le p < n$。若题目是 1-based，调用接口前必须减 1。
2. **左闭右开区间 $[l, r)$**：求和范围包含左端点 $l$，但**不包含**右端点 $r$。

---

### 3. API 详解

#### (1) 初始化：`FenwickTree(n)`
- **说明**：创建一个长度为 $n$ 的树状数组，初始时所有元素的值均为 $0$。
- **约束**：$n \ge 0$
- **示例**：
  ```python
  ft = FenwickTree(5)  # 相当于维护了一个初始为 [0, 0, 0, 0, 0] 的序列
  ```

#### (2) 单点累加：`ft.add(p, x)`
- **说明**：将下标为 $p$ 的元素**加上** $x$（执行的是 `a[p] += x` 操作，**不是替换/赋值**）。
- **参数**：
  - `p`：要修改的下标，必须满足 $0 \le p < n$。
  - `x`：要累加的增量（整数）。
- **示例**：
  ```python
  ft.add(2, 10)  # a[2] += 10
  ```

#### (3) 区间求和：`ft.sum(l, r)`
- **说明**：计算并返回左闭右开区间 $[l, r)$ 内所有元素的和，即：
  $$a[l] + a[l+1] + \dots + a[r-1]$$
- **参数**：
  - 必须满足 $0 \le l \le r \le n$。
  - 特殊情况：当 $l == r$ 时，区间为空，返回 `0`。
- **示例**：
  ```python
  total = ft.sum(1, 4)  # 计算 a[1] + a[2] + a[3] 的和
  ```

---

### 4. 常见场景用法技巧

#### 场景 A：如果题目要求的是“单点修改/覆盖”，而不是累加？
树状数组本身只支持增量 `add`，如果要把下标 `p` 的值直接**修改替换为 $x$**，需要配合一个普通的数组 `arr` 维护原值，通过算差值（`diff`）来完成：
```python
arr = [0] * n  # 记录当前每个位置的实际值

# 将下标 p 的值设置为 x
diff = x - arr[p]
arr[p] = x
ft.add(p, diff)
```

#### 场景 B：题目给的区间是 1-based，并且是闭区间 $[L, R]$？
假设题目要求计算 $A_L + A_{L+1} + \dots + A_R$（1-based 闭区间）：
- 0-based 下，起始点变成了 $L - 1$。
- 0-based 下，由于右端点是开区间，要包含到原第 $R$ 个元素，开区间右界应设为 $R$。
- **转换公式**：
  ```python
  ans = ft.sum(L - 1, R)
  ```

#### 场景 C：求单点元素的值？
查询第 $p$ 个元素的值（0-based）：
```python
val = ft.sum(p, p + 1)  # 等价于求区间 [p, p+1) 的和
```

### 5. 快速测试小例子

```python
from atcoder.fenwicktree import FenwickTree

# 1. 初始化一个长度为 5 的序列 (a[0] ~ a[4] 均为 0)
ft = FenwickTree(5)

# 2. 修改元素
ft.add(1, 5)   # a[1] += 5  -> 序列变为: [0, 5, 0, 0, 0]
ft.add(3, 8)   # a[3] += 8  -> 序列变为: [0, 5, 0, 8, 0]
ft.add(1, 3)   # a[1] += 3  -> 序列变为: [0, 8, 0, 8, 0]

# 3. 区间查询
print(ft.sum(0, 5))  # 全局和 [0, 5) -> 8 + 8 = 16
print(ft.sum(1, 4))  # a[1] + a[2] + a[3] -> 8 + 0 + 8 = 16
print(ft.sum(2, 4))  # a[2] + a[3] -> 0 + 8 = 8
print(ft.sum(1, 2))  # 单点查询 a[1] -> 8
```
