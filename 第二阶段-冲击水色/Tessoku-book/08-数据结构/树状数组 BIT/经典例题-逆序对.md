### B59 - 逆序对数量（Number of Inversions）

**时间限制**：4 秒 / **内存限制**：1024 MiB  
**分值**：1000 分

#### 题目描述
给定一个长度为 $N$ 的数列 $A = (A_1, A_2, \dots, A_N)$。  
请计算满足 $1 \le i < j \le N$ 且 $A_i > A_j$ 的整数对 $(i, j)$ 的数量（即数列的逆序对数量）。

#### 数据范围
* 输入的所有数值均为整数
* $1 \le N \le 150000$
* $A$ 是 $(1, 2, \dots, N)$ 的一个排列

#### 输入格式
输入从标准输入按以下格式给出：

$$N$$  
$$A_1 \quad A_2 \quad \dots \quad A_N$$

#### 输出格式
输出满足条件的整数对 $(i, j)$ 的数量。

---

#### 样例输入 1
```text
4
2 4 1 3
```

#### 样例输出 1
```text
3
```
**样例 1 解释**：  
满足条件的整数对共有 $3$ 个：$(i, j) = (1, 3), (2, 3), (2, 4)$。

---

#### 样例输入 2
```text
7
3 6 4 5 7 1 2
```

#### 样例输出 2
```text
12
```

# AC BIT 
``` python
import sys  
import math  
  
from atcoder.fenwicktree import FenwickTree  
  
def main():  
  
    n = int(sys.stdin.readline().strip())  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    bit = FenwickTree(n)  
  
    ans = 0  
    for num in arr:  
  
        idx = num - 1  
  
        ans += bit.sum(idx + 1, n)  
  
        bit.add(idx, 1)  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
```
