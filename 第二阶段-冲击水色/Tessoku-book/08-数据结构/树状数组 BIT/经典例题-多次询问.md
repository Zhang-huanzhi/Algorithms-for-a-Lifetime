### A59 - RSQ (Range Sum Queries)

时间限制：3 秒 / 内存限制：1024 MiB  
分值：1000 分

#### 题目描述
给定一个长度为 $N$ 的数列 $A = (A_1, A_2, \dots, A_N)$，初始时所有元素的值均为 $0$。请处理以下 $2$ 种操作（查询）：

- **操作 1**：将 $A_{pos}$ 的值更新为 $x$。
- **操作 2**：计算并输出 $A_l, A_{l+1}, \dots, A_{r-1}$ 的总和。

总共需要处理的操作数量为 $Q$ 个。

#### 数据范围
- 输入的所有数值均为整数
- $1 \le N \le 100000$
- $1 \le Q \le 100000$
- $1 \le pos \le N$
- $0 \le x \le 1000$
- $1 \le l < r \le N + 1$

#### 输入格式
输入通过标准输入按以下格式给出：

$$
N \quad Q \\
\text{Query}_1 \\
\text{Query}_2 \\
\vdots \\
\text{Query}_Q
$$

在第 $i$ 个操作 $\text{Query}_i$ 中，首先给出操作的种类 $c_i$（值为 $1$ 或 $2$）。  
若 $c_i = 1$，则额外给出 $pos, x$；  
若 $c_i = 2$，则额外给出 $l, r$。

即每个操作为以下两种格式之一：
```text
1 pos x
```
```text
2 l r
```

#### 输出格式
对于每个操作 2，按顺序输出对应的答案，每个答案占一行。

---

#### 输入样例 1
```text
8 4
1 3 16
1 6 24
2 4 8
2 1 7
```

#### 输出样例 1
```text
24
40
```

**样例解释 1**  
- 初始时，$A = (0, 0, 0, 0, 0, 0, 0, 0)$。
- 第 1 个操作将 $A_3$ 的值更新为 $16$。数列变为 $A = (0, 0, 16, 0, 0, 0, 0, 0)$。
- 第 2 个操作将 $A_6$ 的值更新为 $24$。数列变为 $A = (0, 0, 16, 0, 0, 24, 0, 0)$。
- 第 3 个操作计算 $(A_4, A_5, A_6, A_7) = (0, 0, 24, 0)$ 的总和，输出 $24$。
- 第 4 个操作计算 $(A_1, A_2, A_3, A_4, A_5, A_6) = (0, 0, 16, 0, 24, 0)$ 的总和，输出 $40$。
