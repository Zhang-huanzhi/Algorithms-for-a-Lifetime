

| 对比维度           | 传统双指针法                                                          | 字符串哈希（Rolling Hash）                                        |
| :------------- | :-------------------------------------------------------------- | :--------------------------------------------------------- |
| **单次查询时间**     | $O(L)$（$L$ 为子串长度，最坏 $O(N)$）                                     | **$O(1)$**                                                 |
| **预处理时间**      | $O(1)$（无需预处理）                                                   | $O(N)$                                                     |
| **$Q$ 次查询总时间** | $O(Q \times N) \approx 10^{10}$ 操作 $\rightarrow$ **严重超时 (TLE)** | **$O(N + Q) \approx 2 \times 10^5$ 操作 $\rightarrow$ 轻松通过** |
| **空间复杂度**      | $O(1)$                                                          | $O(N)$（需存储前缀/后缀哈希值及幂次）                                     |
| **实现难度**       | 极简单，直观易懂                                                        | 稍高，需注意模数选取与哈希公式                                            |
| **正确率风险**      | 绝对准确（无碰撞风险）                                                     | 存在理论哈希冲突可能（选大质数如 $2^{61}-1$ 可基本消除）                         |

---

### 简要总结

* **什么时候用双指针法**：  
  适用于**单次或极少量判断**（$Q$ 很小，如 $Q = 1$），此时无需额外空间与预处理，直接比较最快、最安全。

* **什么时候用字符串哈希**：  
  适用于**多次高频区间查询**（$Q$ 很大，如 $Q \ge 10^4$）。核心思想是**“空间换时间 + 前缀和思想”**，用一次 $O(N)$ 的预处理换取每次询问 $O(1)$ 极速响应，从而将原本超时的 $O(Q \times N)$ 优化至 $O(N + Q)$。
