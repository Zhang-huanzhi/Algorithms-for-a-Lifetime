用一句话概括 **0-1 BFS**：**它是边权只有 $0$ 和 $1$ 时的“零成本” Dijkstra 算法。**

它的核心价值在于：既拥有 Dijkstra 算最短路的正确性，又没有堆排序的 $\log$ 开销，能在 **$O(V + E)$ 的线性时间**内跑完。

---

### 一、 核心原理：维护队列的“两段单调性”

所有最短路算法（BFS、Dijkstra）能得出正确结果的前提只有一个：**从小到大，优先处理当前代价最小的节点。**

#### 1. 普通 BFS 为什么成立？
普通 BFS 边权全为 $1$。如果当前出队的点距离为 $d$，走一步变成 $d+1$，全部塞到队尾。
此时队列里永远只有**两段**数字，且**单调递增**：
$$[\ \underbrace{d, d, \dots, d}_{\text{当前正在处理}}, \quad \underbrace{d+1, d+1, \dots, d+1}_{\text{下一轮要处理}}\ ]$$

#### 2. 0-1 BFS 的做法
当边权只有 $0$ 和 $1$ 时，如果当前出队的点距离是 $d$：
- **走权重为 0 的边**：得到的新距离是 $d + 0 = \mathbf{d}$。
- **走权重为 1 的边**：得到的新距离是 $d + 1 = \mathbf{d+1}$。

为了**死守队列“从小到大”的单调性**：
- **距离为 $d$ 的点**：和当前批次同级，甚至比排在后面的 $d+1$ 更小，必须**插到队首（`appendleft`）**，优先处理！
- **距离为 $d+1$ 的点**：属于下一轮批次，正常**放到队尾（`append`）**。

整个过程队列依然被死死维持在两段：
$$\text{队首 } [\ \overbrace{d, d, \dots, d}^{\text{0 权边插到这里}}, \quad \overbrace{d+1, d+1, \dots, d+1}^{\text{1 权边插到这里}}\ ] \text{ 队尾}$$

---

### 二、 为什么它能保证最优？

因为队列永远保持单调递增，所以：
1. **第一次出队的瞬间，该点的最短路就已经被完全确定了**。
2. 每个点最多只会被正确更新并出队处理常数次，绝对不会发生“后面算出更优解导致前面全盘推翻重算”的死循环。

---

### 三、 算法精髓（3 句话牢记）

1. **走免费的边（0）**：直接插队到最前面（`appendleft`）。
2. **走收费的边（1）**：老实排队到最后面（`append`）。
3. **出来的永远是当前代价最小的点**，完美避开堆排序（Heap），用一个双端队列（`deque`）零成本实现了贪心！
