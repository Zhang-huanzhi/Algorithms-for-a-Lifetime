### D - 迷宫中的魔法使 (Wizard in Maze)

**时间限制**：2 秒 / **内存限制**：1024 MiB  
**分值**：400 分  

#### 题目描述
有一个包含 $H$ 行 $W$ 列、共 $H \times W$ 个格子的迷宫。

从上往下数第 $i$ 行、从左往右数第 $j$ 列的格子记为 $(i, j)$。
若 $S_{i, j}$ 为 `#`，表示该格子是墙壁；若为 `.`，表示该格子是道路。

一名魔法使最初位于格子 $(C_h, C_w)$。魔法使可以通过以下 $2$ 种方式进行移动：

- **移动方式 A（步行）**：移动到与当前所在格子**上下左右**相邻的道路格子。
- **移动方式 B（瞬移魔法）**：移动到以当前格子为中心、$5 \times 5$ 范围内的任意道路格子（即行坐标差的绝对值 $\le 2$ 且列坐标差的绝对值 $\le 2$ 的道路格子）。

无论采用哪种移动方式，都**不能**移动到迷宫外面。

魔法使想要到达格子 $(D_h, D_w)$，请问**最少**需要使用多少次瞬移魔法？

#### 输入格式
输入按以下格式从标准输入给出：

$$
\begin{aligned}
&H \quad W \\
&C_h \quad C_w \\
&D_h \quad D_w \\
&S_{1,1} S_{1,2} \dots S_{1,W} \\
&\vdots \\
&S_{H,1} S_{H,2} \dots S_{H,W}
\end{aligned}
$$

#### 输出格式
输出到达目标格子所需使用瞬移魔法的**最小次数**。  
如果无法到达 $(D_h, D_w)$，则输出 `-1`。

#### 数据范围与约束
- $1 \le H, W \le 10^3$
- $1 \le C_h, D_h \le H$
- $1 \le C_w, D_w \le W$
- $S_{i, j}$ 是 `#` 或 `.`
- 起点 $S_{C_h, C_w}$ 与终点 $S_{D_h, D_w}$ 均为 `.`
- $(C_h, C_w) \neq (D_h, D_w)$

---

### 输入样例 1
```text
4 4
1 1
4 4
..#.
..#.
.#..
.#..
```

### 输出样例 1
```text
1
```
**样例说明 1**：  
例如可以先步行移动到 $(2, 2)$，再从 $(2, 2)$ 使用瞬移魔法到达 $(4, 4)$，这样仅需使用 $1$ 次瞬移魔法。（注意：步行不能斜向移动）


起点四周全被墙壁包围（$5 \times 5$ 范围内无其他通路），根本无法从当前位置离开，故输出 `-1`。

# AC Code
``` python
import sys  
import math  
from collections import deque  
  
  
def main():  
  
    h, w = map(int, sys.stdin.readline().strip().split())  
  
    sx, sy = map(int, sys.stdin.readline().strip().split())  
    tx, ty = map(int, sys.stdin.readline().strip().split())  
    sx, sy = sx - 1, sy - 1  
    tx, ty = tx - 1, ty - 1  
  
    arr = [ sys.stdin.readline().strip() for _ in range(h)]  
  
    q = deque()  
    dist = [ [math.inf] * w for _ in range(h)]  
    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]  
  
    q.append((sx, sy))  
    dist[sx][sy] = 0  
  
    ans = -1  
    while q:  
  
        x, y = q.popleft()  
        d = dist[x][y]  
  
        if x == tx and y == ty:  
            ans = d  
            break  
  
        for dx, dy in directions:  
            nx, ny = x + dx, y + dy  
            if 0 <= nx < h and 0 <= ny < w and arr[nx][ny] == '.':  
                if dist[nx][ny] > d:  
                    dist[nx][ny] = d  
                    q.appendleft((nx, ny))  
  
        for dx in range(-2, 3):  
            for dy in range(-2, 3):  
                nx, ny = x + dx, y + dy  
                if 0 <= nx < h and 0 <= ny < w and arr[nx][ny] == '.':  
                    if dist[nx][ny] > d + 1:  
                        dist[nx][ny] = d + 1  
                        q.append((nx, ny))  
  
    print(ans)  
if __name__ == "__main__":  
    main()
```
