要理解非递归线段树的底层原理，可以拆解为三个核心问题：

1. **核心思想：为什么线段树能把 $O(N)$ 降到 $O(\log N)$？**
2. **存储结构：为什么一个一维数组就能表示整棵二叉树？**
3. **算法本质：为什么查询函数里的那几行 `while` 循环能准确拼出目标区间？**

---

### 一、核心思想：分治与“拼图”

假设你要计算数组中某个长度为 $1000$ 的区间的最大值。
* **暴力做法**：把这 1000 个数一个一个比较，比较 999 次。
* **线段树的做法**：像**拼积木**一样。线段树预先帮你算好并存下了长度为 $1, 2, 4, 8, 16, \dots$ 的各个小块的最大值。当你要查 1000 个数时，线段树不需要看 1000 个元素，而是挑出少数几个已经算好的“大块”（比如一个长为 512 的块 + 一个长为 256 的块 + 一个长为 128 的块……）。

因为任何一个区间，最多只需要拼接 **$2 \times \log_2 N$** 个已经算好的预制块，所以查询时间直接从 $O(N)$ 降到了 $O(\log N)$。

---

### 二、内存结构：二叉树的数组映射原理

代码中有一行精妙的设置：
```python
size = 1
while size <= n + 1:
    size <<= 1
tree = [0] * (2 * size)
```
这里利用了完全二叉树的经典数学性质。如果根节点编号为 $1$：

```text
               1 (区间 0~8)
           /              \
       2 (0~4)          3 (4~8)
       /     \          /     \
    4 (0~2) 5 (2~4)   6 (4~6) 7 (6~8)
    /  \    /  \      /  \    /  \
   8    9  10  11    12  13  14  15   <-- 叶子节点（原始数据存放处）
 [0]  [1]  [2]  [3]  [4]  [5]  [6]  [7]
```

你会发现以下数学规律：
1. **父子关系极其整齐**：
   * 任意节点 $x$ 的**左孩子**一定是 $2x$（偶数）。
   * 任意节点 $x$ 的**右孩子**一定是 $2x + 1$（奇数）。
   * 任意节点 $x$ 的**父节点**一定是 $x // 2$（向下取整）。
2. **叶子节点位置固定**：
   * 所有原始数据都被放在第 $\log_2(size)$ 层。
   * 原始数组的第 $i$ 个数，直接落在 `tree[size + i]` 上。

这就解释了 **单点修改（Update）** 的原理：
修改了叶子节点 `pos + size` 后，只要一路找父节点 `pos //= 2`，重新取两个孩子的最大值 `tree[pos] = max(tree[2*pos], tree[2*pos+1])`，沿着树干往上爬到根节点即可。沿途只经过了树高（$\log_2 N$）个节点。

### 三、查询原理：最巧妙的自底向上双指针

最令人拍案叫绝的是查询函数的原理：
```python
def query(l, r):
    res = 0
    l += size
    r += size
    while l < r:
        if l & 1:           # 如果 l 是奇数（右孩子）
            res = max(res, tree[l])
            l += 1
        if r & 1:           # 如果 r 是奇数（右孩子）
            r -= 1
            res = max(res, tree[r])
        l //= 2
        r //= 2
    return res
```
这里查询的是**左闭右开区间** $[l, r)$。这两个指针从最底层的叶子节点开始，**一边向上爬，一边像拉拉链一样向中间靠拢**。

#### 为什么是 `if l & 1` 和 `if r & 1`？

观察上面的二叉树：**偶数节点是左孩子，奇数节点是右孩子**。

1. **对于左边界 `l`：**
   * **如果 `l` 是偶数（左孩子）**：
     * 说明它和它的右兄弟都在查询区间内部。我们**不需要**在这里急着把 `tree[l]` 算进答案，因为下一轮循环爬到它们的父节点 `l // 2` 时，父节点就已经代表了这两个孩子的合并结果！所以直接上升一层即可。
   * **如果 `l` 是奇数（右孩子，即 `l & 1 == 1`）**：
     * 这意味着它的左兄弟（属于别的区间）**不在**我们的查询范围内。
     * 因此，它的父节点包含了区间外的数据，**我们不能使用它的父节点**！
     * 这时唯一的办法是：**把这个节点单独结算进答案**（`res = max(res, tree[l])`），然后把指针往右挪一位（`l += 1`），让它变成偶数，以便后续顺利上升到上一层。

2. **对于右边界 `r`（注意 $r$ 是开区间的右端点，代表不包含 $r$）：**
   * **如果 `r` 是奇数（右孩子，即 `r & 1 == 1`）**：
     * 说明我们的区间刚好包含了它的左兄弟（$r - 1$，偶数节点），但不包含 $r$。
     * 因为不包含 $r$，同样无法使用它们的父节点。
     * 所以必须单独把左兄弟结算（`r -= 1; res = max(res, tree[r])`）。
   * **如果 `r` 是偶数（左孩子）**：
     * 说明左兄弟和右兄弟都不在区间内，直接安心上升一层（`r //= 2`）。

3. **终止条件：**
   当 `l` 和 `r` 相遇（`l == r`）甚至交错时，说明整个区间的所有子区间已经被完全覆盖并结算完毕，循环结束。

---

### 实例演示

假设数组大小 $size = 8$，我们要查询区间 $[2, 7)$（即下标 $2, 3, 4, 5, 6$ 的最大值）：
1. 初始：$l = 2 + 8 = 10$（偶数），$r = 7 + 8 = 15$（奇数）。
2. **第一轮（叶子层）**：
   * $l = 10$（偶数，左孩子）：不单独结算。
   * $r = 15$（奇数，右孩子）：将左兄弟 $14$ 结算进答案（$r=14$，计入节点 $14$）。
   * 上升一层：$l = 10 // 2 = 5$，$r = 14 // 2 = 7$。
3. **第二轮（长度为 2 的块）**：
   * $l = 5$（奇数，右孩子）：将节点 $5$ 结算进答案，然后 $l = 5 + 1 = 6$。（注意：节点 $5$ 已经代表了原始下标 $2, 3$ 的合并最大值！）
   * $r = 7$（奇数，右孩子）：将节点 $6$ 结算进答案，然后 $r = 6$。（节点 $6$ 代表了原始下标 $4, 5$ 的合并最大值！）
   * 上升一层：$l = 6 // 2 = 3$，$r = 6 // 2 = 3$。
4. **结束**：$l == r == 3$，退出循环。

**最终收集的节点是：**
* 节点 $14$（代表下标 $6$）
* 节点 $5$（代表下标 $2, 3$）
* 节点 $6$（代表下标 $4, 5$）

正好拼成了 $[2, 7)$，一共只用了 **3 次操作**！这就是非递归线段树能够在对数时间内正确算出答案的全部奥秘。
