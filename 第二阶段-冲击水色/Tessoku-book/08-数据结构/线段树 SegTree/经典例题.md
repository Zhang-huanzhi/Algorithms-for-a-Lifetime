### A58 - RMQ (Range Maximum Queries)

**时间限制：** 3 秒 / **内存限制：** 1024 MiB  
**分值：** 1000 分  

#### 题目描述
给定一个长度为 $N$ 的数列 $A = (A_1, A_2, \dots, A_N)$，初始时所有元素的值均为 $0$。请处理以下 $2$ 种操作（查询）：

* **操作 1：** 将 $A_{pos}$ 的值更新为 $x$。
* **操作 2：** 求 $A_l, A_{l+1}, \dots, A_{r-1}$ 中的最大值并输出。

保证给定的操作总数为 $Q$ 个。

#### 数据范围与约束
* 所有输入均为整数
* $1 \le N \le 100000$
* $1 \le Q \le 100000$
* $1 \le pos \le N$
* $0 \le x \le 10^9$
* $1 \le l < r \le N+1$

#### 输入格式
输入从标准输入按以下格式给出：

$$
N \quad Q \\
\text{Query}_1 \\
\text{Query}_2 \\
\vdots \\
\text{Query}_Q
$$

第 $i$ 个操作 $\text{Query}_i$ 首先给出操作类型 $c_i$（$1$ 或 $2$）。  
若 $c_i = 1$，则紧接着给出 $pos, x$；  
若 $c_i = 2$，则紧接着给出 $l, r$。

即每个操作为以下两种格式之一：
```text
1 pos x
2 l r
```

#### 输出格式
对于所有的操作 2，按顺序输出对应的答案，每个答案占一行。

---

#### 输入样例 1
```text
8 4
1 3 16
2 4 7
1 5 13
2 4 7
```

#### 输出样例 1
```text
0
13
```

**样例解释：**
初始时，$A = (0, 0, 0, 0, 0, 0, 0, 0)$。
* 第 1 个操作将 $A_3$ 的值更新为 $16$。数列变为 $A = (0, 0, 16, 0, 0, 0, 0, 0)$。
* 第 2 个操作查询 $(A_4, A_5, A_6) = (0, 0, 0)$ 的最大值，输出 $0$。
* 第 3 个操作将 $A_5$ 的值更新为 $13$。数列变为 $A = (0, 0, 16, 0, 13, 0, 0, 0)$。
* 第 4 个操作查询 $(A_4, A_5, A_6) = (0, 13, 0)$ 的最大值，输出 $13$。

# AC Atcoder内置数据结构
``` python
import sys  
import math  
from atcoder.segtree import SegTree  
  
def main():  
  
    n, q = map(int, sys.stdin.readline().strip().split())  
  
    seg = SegTree(max, 0, n + 1)  
  
    outs = []  
    for _ in range(q):  
  
        line = list(sys.stdin.readline().strip().split())  
  
        op = line[0]  
  
        if op == '1':  
            pos, x = int(line[1]), int(line[2])  
            seg.set(pos, x)  
  
        if op == '2':  
            l, r = int(line[1]), int(line[2])  
            outs.append(seg.prod(l, r))  
  
    print("\n".join(map(str, outs)))  
if __name__ == "__main__":  
    main()```

# AC Code 手写非迭代线段树
``` python
import sys
import math

def main():

    n, q = map(int, sys.stdin.readline().strip().split())

    size = 1
    while size <= n + 1:
        size <<= 1

    tree = [0] * (2 * size)

    def update(pos, x):
        pos += size
        tree[pos] = x
        pos //= 2

        while pos > 0:
            tree[pos] = max(tree[2 * pos], tree[2 * pos + 1])
            pos //= 2

    def query(l, r):
        res = 0
        l += size
        r += size
        while l < r:
            if l & 1:
                res = max(res, tree[l])
                l += 1

            if r & 1:
                r -= 1
                res = max(res, tree[r])

            l //= 2
            r //= 2

        return res

    outs = []
    for _ in range(q):

        line = list(sys.stdin.readline().strip().split())

        op = line[0]

        if op == '1':
            pos, x = int(line[1]), int(line[2])

            update(pos, x)

        if op == '2':
            l, r = int(line[1]), int(line[2])
            outs.append(query(l, r))

    print("\n".join(map(str, outs)))
if __name__ == "__main__":
    main()
```


# TLE 暴力代码
``` python
import sys
import math

def main():

    n, q = map(int, sys.stdin.readline().strip().split())

    arr = [0] * (n + 1)

    outs = []
    for _ in range(q):

        line = list(sys.stdin.readline().strip().split())

        op = line[0]

        if op == '1':
            pos, x = int(line[1]), int(line[2])

            arr[pos] = x

        if op == '2':
            l, r = int(line[1]), int(line[2])

            ans = max(arr[l : r])
            outs.append(ans)

    print("\n".join(map(str, outs)))
if __name__ == "__main__":
    main()
```
