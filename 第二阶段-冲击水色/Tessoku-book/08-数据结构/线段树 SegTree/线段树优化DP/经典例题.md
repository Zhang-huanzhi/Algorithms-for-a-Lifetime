### B58 - Jumping
**运行时间限制：** 2.5 秒 / **内存限制：** 1024 MiB  
**分值：** 1000 分

#### 题目描述
有 $N$ 个跳台排成一横排，从左到右依次编号为 $1$ 到 $N$。跳台 $1$ 为起点，跳台 $N$ 为终点。跳台 $i$ 位于距离起点 $X_i$ 米的位置。

你每次只能向右跳跃，且单次跳跃的距离必须在 $L$ 米以上、$R$ 米以下（包含 $L$ 和 $R$）。请问从起点到达终点最少需要跳跃多少次？

保证在给定的输入数据中，一定能够从起点到达终点。

#### 数据范围与限制
* 输入均为整数
* $2 \le N \le 100000$
* $1 \le L \le R \le 10^9$
* $0 = X_1 < X_2 < \dots < X_N \le 10^9$
* 保证一定可以从起点到达终点

#### 输入格式
输入从标准输入中按以下格式给出：

$$
\begin{matrix}
N & L & R \\
X_1 & X_2 & \dots & X_N
\end{matrix}
$$

#### 输出格式
输出到达终点所需的最少跳跃次数。

---

#### 输入样例 1
```text
5 20 40
0 20 30 60 70
```

#### 输出样例 1
```text
2
```

**样例说明 1**  
最优策略是：先跳跃 $30$ 米到达跳台 $3$，再跳跃 $40$ 米到达跳台 $5$，总共跳跃 $2$ 次。

# 线段树优化DP AC Code
``` python
import sys  
import math  
from bisect import bisect_left, bisect_right  
  
from atcoder.segtree import SegTree  
  
  
def main():  
  
    n, l, r = map(int, sys.stdin.readline().strip().split())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    st = SegTree(min, math.inf, n)  
    st.set(0, 0)  
  
    dp = [math.inf] * (n + 1)  
    dp[0] = 0  
  
    for i in range(1, n):  
  
        left_idx = bisect_left(arr, arr[i] - r)  
        right_idx = bisect_right(arr, arr[i] - l)  
  
        if left_idx < right_idx:  
  
            min_dp = st.prod(left_idx, right_idx)  
  
            if min_dp != math.inf:  
                dp_i = min_dp + 1  
                st.set(i, dp_i)  
  
    print(st.get(n - 1))  
  
if __name__ == "__main__":  
    main()
```

# 纯DP TLE

``` python
import sys
import math

from atcoder.segtree import SegTree


def main():

    n, l, r = map(int, sys.stdin.readline().strip().split())

    arr = list(map(int, sys.stdin.readline().strip().split()))

    dp = [math.inf] * (n + 1)
    dp[0] = 0

    for i in range(1, n):
        for j in range(i):
            if arr[i] - r <= arr[j] <= arr[i] - l:
                dp[i] = min(dp[i], dp[j] + 1)

    print(dp[n - 1])

if __name__ == "__main__":
    main()
```
