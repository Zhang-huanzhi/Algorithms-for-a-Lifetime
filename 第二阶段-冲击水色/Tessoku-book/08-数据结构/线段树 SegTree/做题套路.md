在线段树的题目中，无论题目包装得多花哨，解题套路都可以总结为一套标准的**“三步思考法”**与**“三大经典模型”**。

只要你顺着这个思路走，1200~1400 分段绝大多数线段树题目都能被拆解。

---

### 第一步：识别信号（什么时候该用线段树？）

做题时只要同时出现以下 **3 个特征**，脑子里要秒出“线段树”：

1. **“动态更新”与“区间统计”交替进行**：
   * 如果**只有查询，没有修改**：优先用**前缀和**（求和）或 **ST 表**（静态 RMQ），复杂度 $O(1)$，不需要线段树。
   * 如果**频繁修改又频繁查区间**：必须上线段树（或树状数组）。
2. **数据范围在 $10^5 \sim 2 \times 10^5$**：
   * 显然提示你每次操作必须是 $O(\log N)$。
3. **统计的信息满足“结合律”**：
   * 大区间的信息可以由两个子区间直接“拼”出来（比如：最大值、最小值、和、乘积、GCD、异或）。
   * *反例：区间众数就不满足结合律，不能直接用普通线段树。*

---

### 第二步：核心三要素设计（如何套用模板/库？）

无论用手写的非递归线段树，还是用 `from atcoder.segtree import SegTree`，你只需要在草稿纸上确定 **3 个要素**：

| 要素 | 含义 | 设计原则 | 常见踩坑点 |
| :--- | :--- | :--- | :--- |
| **叶子节点存什么** | 树的底层下标代表什么 | 通常是数组下标，有时是**数值（值域）** | 如果数值到 $10^9$，需先**离散化** |
| **`op(a, b)`** | 左右子树怎么合并 | 代表题目要查询的聚合操作 | 必须满足结合律 |
| **`e`（单位元）** | 空区间的默认值 | 必须满足：对任意 $x$，`op(x, e) == x` | **求最大值设为 $-\infty$，求最小值设为 $+\infty$**（设成 0 会错！） |

#### 快速查表：常见操作的三要素
* **区间和**：`op = lambda a, b: a + b`, `e = 0`
* **区间最大值**：`op = max`, `e = -10**18`
* **区间最小值**：`op = min`, `e = 10**18`
* **区间 GCD**：`op = math.gcd`, `e = 0`（因为 $\gcd(x, 0) = x$）

### 第三步：掌握 1200+ 级别的三大高频模型

在 AtCoder 的 1200~1400 难度中，线段树通常以以下三种形态出现：

#### 模型 1：裸操作包装题（直接模拟）
* **题面形式**：题目包装了一套游戏规则、排队规则或交易规则，本质上就是让你单点改某个位置，然后问某段区间的极值或和。
* **套路**：剥离题目背景，直接建立数组，套 `SegTree`。刚才做的 A58 就是最纯粹的这类题。

#### 模型 2：线段树优化 DP（★最重要的高频考点）
如果在推导动态规划时，发现状态转移方程长这样：
$$dp[i] = \max_{j \in [L_i, R_i]} (dp[j]) + \text{cost}$$
* **暴力做法**：为了求 $dp[i]$，需要往前遍历所有的 $j$，双重循环导致时间复杂度为 $O(N^2)$，会 TLE。
* **套路破解**：
  1. 开一棵线段树，线段树的第 $j$ 个叶子节点存的是 **$dp[j]$ 的值**。
  2. 求 $dp[i]$ 时，直接在线段树上查询区间 $[L_i, R_i]$ 的最大值，耗时 $O(\log N)$。
  3. 算出来 $dp[i]$ 后，立马执行 `seg.set(i, dp[i])` 插回线段树。
  4. 总时间复杂度瞬间降为 **$O(N \log N)$**！
* *经典代表题*：最长上升子序列（LIS）的带权变体、带跳跃距离限制的爬楼梯/跳跃游戏。

#### 模型 3：权值线段树 + 离散化（求逆序对 / 计数）
很多时候，线段树维护的**不是原数组的下标，而是数值本身的大小**！
* **叶子节点 `tree[x]` 的含义**：数值为 $x$ 的元素在当前出现了多少次。
* **应用场景（比如求逆序对）**：
  * 从左到右遍历数组 $A$。
  * 当遇到 $A[i]$ 时，查询线段树中区间 $[A[i] + 1, \infty)$ 的和，这代表**在它左边、且比它大的数有几个**。
  * 查完后，把 $A[i]$ 插入线段树：`seg.set(A[i], seg.get(A[i]) + 1)`。
* **套路细节**：如果数值 $A[i]$ 很大（比如 $10^9$），数组开不下，先进行**离散化**：
  ```python
  # 离散化标准套路
  vals = sorted(set(A))
  rank = {val: i for i, val in enumerate(vals)}
  # 之后用 rank[A[i]] 作为线段树的下标（范围缩至 0 ~ N-1）
  ```

### 做题检查清单（Checklist）

遇到像线段树的题时，在动笔前自问这 4 个问题：
1. **区间是闭区间还是开区间？**
   * AtCoder 的 `SegTree.prod(l, r)` 默认是 **左闭右开 $[l, r)$**，传入右边界时记得检查是否需要 $+1$。
2. **单位元 `e` 是否会干扰答案？**
   * 求最大值时，如果数组里可能有负数，`e` 千万不能设成 `0`，必须设成 `-10**18`。
3. **是否其实用树状数组（BIT）就够了？**
   * 如果只涉及“单点加、区间求和”，优先用 AtCoder 的 `FenwickTree`，常数比线段树更小，甚至不会有任何超时风险。
4. **能否离线处理？**
   * 有些题目可以把所有询问存下来，按照某个端点排个序再依次处理（离线查询），往往能把难题降维成基础的权值线段树。
