在算法题中，考察“倍增”（Binary Lifting）通常有非常明显的**信号特征**和**固定的代码套路**。

只要你掌握了它的**“识别信号”**和**“4步通用骨架”**，这类题基本都是送分题。

---

### 一、 题眼识别：什么时候该想到倍增？

看到题目满足以下 **3 个组合特征** 时，直接往倍增上想：

1. **步数极巨大**：天数/步数 $Y$ 或 $K$ 达到 $10^9$ 甚至 $10^{18}$（普通循环必死）。
2. **转移方向唯一（确定性）**：
   - 处于状态 $A$ 时，下一步**唯一确定**会走到状态 $B$（如本题）。
   - 或者在树上，每个节点往上的父节点是唯一确定的。
3. **大量的查询（$Q \ge 10^5$）**：
   - 如果只有 1 个询问，且 $K$ 极大，可以找环（基环树找环）；
   - **但如果有上万次甚至几十万次询问，且每个询问的步数都不同**，99% 是倍增！

### 二、 通用做题“4步走”骨架

无论是哪种倍增题，代码结构几乎完全一致：

#### 第 1 步：确定上限 $K$（即几次方）
看题目中跳跃的最大范围 $M$：
* 如果范围是点数 $N \le 10^5$（树上深度）：$\log_2(10^5) \approx 17$，取 $K = 18$ 或 $20$。
* 如果步数是 $Y \le 10^9$：$\log_2(10^9) \approx 29.9$，取 $K = 30$。
* 如果步数是 $Y \le 10^{18}$：$\log_2(10^{18}) \approx 59.8$，取 $K = 62$。

#### 第 2 步：初始化 Base Case（跳 1 步）
设置走 $2^0 = 1$ 步的初始信息：
```python
dp[0][i] = arr[i]  # 走 1 步去哪
# 如果带权值（比如跳跃收集金币）：
# weight[0][i] = val[i]
```

#### 第 3 步：固定外层循环，两段拼凑（预处理）
**核心公式死记硬背**：外层循环 $k$，内层循环所有点 $i$：
```python
for k in range(1, K):
    for i in range(1, n + 1):
        dp[k][i] = dp[k - 1][dp[k - 1][i]]
        # 若带权，顺便把前半段和后半段的贡献合并：
        # weight[k][i] = weight[k - 1][i] + weight[k - 1][dp[k - 1][i]]
```

#### 第 4 步：处理查询（两种跳法）
查询通常只有两种套路：
1. **已知具体要跳 $Y$ 步** $\to$ **按二进制位跳**（从小到大或从大到小均可）：
   ```python
   for k in range(K):
       if (y >> k) & 1:
           x = dp[k][x]
   ```
2. **未知步数，要找满足条件的最远点（比如 LCA、找临界点）** $\to$ **从大到小试探跳**：
   ```python
   for k in range(K - 1, -1, -1):
       if 还能跳(dp[k][x]):
           x = dp[k][x]
   ```

### 三、 算法竞赛中最核心的 3 大题型套路

#### 题型 1：功能图快速跳跃（就是本题类型）
* **特征**：每个点有唯一的出边，问跳 $Y$ 步到哪。
* **进阶变种（带权跳跃）**：
  > “每经过一个洞能吃 $W_i$ 个金币，问走 $Y$ 步一共能吃多少金币？”
  
  **应对套路**：多开一个 `sum_dp[k][i]` 记录走 $2^k$ 步累计的权值。
  ```python
  # 预处理：前半段的钱 + 后半段的钱
  sum_dp[k][i] = sum_dp[k - 1][i] + sum_dp[k - 1][dp[k - 1][i]]
  
  # 查询时：只要跳了，就把这段的钱累加
  if (y >> k) & 1:
      total_gold += sum_dp[k][x]
      x = dp[k][x]
  ```

#### 题型 2：树上倍增求 LCA（最近公共祖先）
* **特征**：给一棵树，多次询问点 $u$ 和点 $v$ 的最近公共祖先是哪个，或者两点间路径的最大权值。
* **套路套路**：
  1. `up[k][u]` 表示节点 $u$ 向上跳 $2^k$ 层的祖先。
  2. 先让深的节点用倍增跳到和浅的节点**同一深度**。
  3. 如果此时两点重合，说明浅的那个本身就是 LCA。
  4. 如果不重合，让两个点**同时从大到小试探往上跳**：
     只要 `up[k][u] != up[k][v]`，说明还没到 LCA（在 LCA 下方），就一起往上跳。跳完后，它们的直接父节点 `up[0][u]` 就是 LCA！

#### 题型 3：倍增替代二分（倍增试探法）
* **特征**：原本可以用“二分答案”做的题，但每次 `check()` 函数代价比较大，或者在树上想找一个满足条件的最浅祖先。
* **套路**：
  不需要每次二分从头跑，直接利用倍增表从高位向低位试探：
  ```python
  curr = start
  for k in range(K - 1, -1, -1):
      next_node = dp[k][curr]
      if check(next_node):  # 如果跳了之后仍然满足条件
          curr = next_node  # 就真正跳过去
  ```
  这样一步到位，时间复杂度直接省掉一个 $\log$。

### 四、 做题避坑指南（极易挂的点）

1. **外循环和内循环的顺序绝不能写反**：
   必须外层枚举 $k$（幂次），内层枚举点 $i$。因为第 $k$ 层的计算必须基于整个第 $k-1$ 层完全填满。
2. **越界与哨兵节点（0 号节点）**：
   在树上跳跃时，如果跳出根节点了，通常让它停在 `0` 节点，并且保证 `dp[k][0] = 0`，防止数组越界或者指针死循环。
3. **位运算优先级**：
   Python 里 `(y >> k) & 1` 的括号千万别省，`&` 的优先级比比较运算符低。
