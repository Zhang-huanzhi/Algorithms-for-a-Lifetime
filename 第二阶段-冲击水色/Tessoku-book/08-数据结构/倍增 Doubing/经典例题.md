### A57 - Doubling (倍增)

**运行时间限制:** 2 秒 / **内存限制:** 1024 MiB  
**分值:** 1000 分

#### 题目描述
在一个有 $N$ 个洞的沙坑里住着一只蚂蚁。已知这只蚂蚁的移动非常有规律：如果它某天处于洞 $i$（$1 \le i \le N$），那么第二天就会移动到洞 $A_i$。

请据此回答以下 $Q$ 个询问：

第 $j$ 个询问：若当前位于洞 $X_j$，那么 $Y_j$ 天后它会在哪个洞中？

#### 约束条件
* 输入的所有值均为整数
* $1 \le N \le 100000$
* $1 \le Q \le 100000$
* $1 \le A_i \le N$
* $1 \le X_j \le N$
* $1 \le Y_j \le 10^9$

#### 输入格式
输入从标准输入按以下格式给出：

$$
N \quad Q \\
A_1 \quad A_2 \quad \dots \quad A_N \\
X_1 \quad Y_1 \\
X_2 \quad Y_2 \\
\vdots \\
X_Q \quad Y_Q
$$

#### 输出格式
输出共 $Q$ 行。  
第 $j$ 行输出第 $j$ 个询问的答案。

---

#### 样例 1

**输入**
```text
7 4
2 4 1 7 6 5 3
1 1
1 5
2 13
5 999999999
```

**输出**
```text
2
1
3
6
```

**样例解释 1**  
当蚂蚁当前在洞 $1$ 时：
* $1$ 天后在洞 $A_1 = 2$
* $2$ 天后在洞 $A_2 = 4$
* $3$ 天后在洞 $A_4 = 7$
* $4$ 天后在洞 $A_7 = 3$
* $5$ 天后在洞 $A_3 = 1$

因此，第 $1$ 个和第 $2$ 个询问的答案分别为 $2$ 和 $1$。


# AC Code
``` python
import sys  
import math  
  
def main():  
  
    n, q = map(int, sys.stdin.readline().strip().split())  
    arr = [0] + list(map(int, sys.stdin.readline().strip().split()))  
  
    K = 30  
    dp = [[0] * (n + 1) for _ in range(K)]  
  
    for i in range(1, n + 1):  
        dp[0][i] = arr[i]  
  
    for k in range(1, K):  
        for i in range(1, n + 1):  
            dp[k][i] = dp[k - 1][dp[k - 1][i]]  
              
    outs = []  
    for _ in range(q):  
        x, y = map(int, sys.stdin.readline().strip().split())  
  
        for k in range(K):  
  
            if (y >> k) % 2:  
                x = dp[k][x]  
  
        outs.append(x)  
  
    print('\n'.join(map(str, outs)))  
  
if __name__ == "__main__":  
    main()
```
