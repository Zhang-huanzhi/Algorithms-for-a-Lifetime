# 经典01背包代码 RE MLE
``` python
import itertools  
import sys  
import math  
from collections import deque  
  
  
def main():  
  
    n, w = map(int, sys.stdin.readline().strip().split())  
  
    arr = []  
  
    for _ in range(n):  
        a, b = map(int, sys.stdin.readline().strip().split())  
        arr.append((a, b))  
  
    dp = [0] * (w + 1)  
  
    for a, b in arr:  
  
        for j in range(w, b - 1, -1):  
            dp[j] = max(dp[j], dp[j - b] + a)  
  
    print(dp[w])  
  
if __name__ == "__main__":  
    main()
```


### 为什么在这一题中不能这样写？（踩坑分析）

这就是为什么题目被称为 **“反套路”** 的原因：

1. **内存超限（MLE / MemoryError）**：
   - 题目中 $W \le 10^9$。
   - 如果开一个大小为 $W + 1$ 的数组 `dp = [0] * (W + 1)`，仅这一个数组就需要约 $10^9 \times 8 \text{ Bytes} \approx \mathbf{8\ GB}$ 的内存。
   - 即使题目给了 1024 MiB（1GB）的大内存，也远远装不下，在 Python 中运行第一步就会直接抛出 `MemoryError`。

2. **时间超限（TLE）**：
   - 这种背包的外层循环是 $N$，内层循环是 $W$。
   - 总运算次数为 $O(N \cdot W) \approx 20 \times 10^9 = 2 \times 10^{10}$ 次操作。
   - 计算机 1 秒通常跑约 $10^8$ 次运算，这需要跑几百秒，远远超过 2 秒的时限。

---

### 补充：另一种常见的“按价值 DP”能用吗？

在背包问题中，有时当体积 $W$ 很大时，如果**总价值总和 $\sum A_i$ 很小**，我们可以把 DP 状态反转：
- 设 `dp[v]` 为“获得美味度 $v$ 所需的**最小体积**”。
- 复杂度为 $O(N \sum A_i)$。

但看本题的数据范围：$A_i \le 10^9$，总美味度也能达到 $20 \times 10^9$，所以“按价值 DP”同样开不下数组。

**结论**：
当看到 **$W$ 很大、价值很大**，但 **$N$ 极小（$N \le 20$）** 时，出题人给你的信号就是：**立刻扔掉 DP 思维，直接用子集枚举（暴力全排列 / DFS）！**
