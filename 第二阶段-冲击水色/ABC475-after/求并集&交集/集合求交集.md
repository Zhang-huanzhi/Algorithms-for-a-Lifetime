### 经典题目：共同空闲时间（区间列表的交集）

#### 题目描述
小明和小红各自列出了一天中自己的**空闲时间段**。每个人的时间段都已经按先后顺序排好了，并且各自的时间段之间不会互相重叠。

* **小明的空闲时间** $A = [[0, 2], [5, 10], [13, 23], [24, 25]]$
* **小红的空闲时间** $B = [[1, 5], [8, 12], [15, 24], [25, 26]]$

现在他们想约出来一起学习，请找出他们**两个人同时都有空的时间段**（即求这组区间的**交集**）。

#### 期望输出
```plain
[[1, 2], [5, 5], [8, 10], [15, 23], [24, 24], [25, 25]]
```
*(注：像 `[5, 5]` 这种单个时间点也是合法的交集，说明在 5 点整两人都刚好有空)*

---

### 第一步：抛开代码，先看任意两个时间段怎么求“重合部分”

假设小明在 $[0, 2]$（0点到2点）有空，小红在 $[1, 5]$（1点到5点）有空。

我们用一根时间轴画出来：
```text
小明:  0 ========= 2
小红:       1 ================== 5
重合:       1 ===== 2
```

他们共同有空的时间显然是 **$[1, 2]$**。

请仔细观察这个 $[1, 2]$ 是怎么来的：
1. **共同有空的开始时间**：
   小明 0 点就有空，但小红要等到 1 点才开始有空。两人要“同时”有空，必须等大家都准备好，所以**开始时间取更晚的那个**：
   $$\text{开始} = \max(0, 1) = 1$$
2. **共同有空的结束时间**：
   小明 2 点就要走了，小红虽然能呆到 5 点，但小明一走就不能一起学了，所以**结束时间取更早离开的那个**：
   $$\text{结束} = \min(2, 5) = 2$$

> **这就是为什么求交集叫“左取大，右取小”！**  
> 因为开始要等人齐（取大），结束看谁先撤（取小）。

#### 如果两个人根本碰不上呢？
比如小明 $[0, 2]$，小红 $[3, 5]$：
* 按公式算：开始时间取 $\max(0, 3) = 3$，结束时间取 $\min(2, 5) = 2$。
* 结果出现了：开始时间是 3，结束时间是 2。**3 点开始、2 点结束，这显然不可能！**（即 $\text{开始} > \text{结束}$）。
* 这就说明他们**完全没有重合**。

---

### 第二步：两串时间表，指针该怎么移动？

现在小明和小红各自手里有一长串时间段。我们用两个指针 $i$ 和 $j$，分别从小明和小红的第一个时间段开始看：

1. **第一回合**：
   * 小明看着自己的 $A[0] = [0, 2]$，小红看着自己的 $B[0] = [1, 5]$；
   * 算交集：$[\max(0, 1), \min(2, 5)] = [1, 2]$，记录下来！
   * **关键问题：接下来谁看下一段？是 $i$ 往后挪，还是 $j$ 往后挪？**
     * 小明的时间在 **2 点** 就彻底结束了；
     * 小红的时间要持续到 **5 点**；
     * **小明的这一段已经彻底过去（2 点结束了），他绝不可能再和小红未来的任何时间有交集了！**
     * 所以，**谁先结束，谁就翻篇（指针 $+1$）**！
     * 这里小明先结束（$2 < 5$），所以小明的指针 $i$ 移到下一段 $A[1]$。

2. **第二回合**：
   * 小明看自己的 $A[1] = [5, 10]$，小红依然是刚才那段 $B[0] = [1, 5]$（因为她能持续到 5 点，刚才还没耗尽）；
   * 算交集：$[\max(5, 1), \min(10, 5)] = [5, 5]$，记录下来！
   * 这次小红先结束（$5 \le 10$），所以**小红翻篇（$j$ 移到下一段 $B[1]$）**，小明留在原地等待。

以此类推，就像两个人拿尺子比对，**谁的右端点短，谁就下班翻页**，直到某一个人看完了全部时间表。

---

### 第三步：完整的 Python 代码

对照上面的逻辑，代码其实就是直接翻译我们的思考过程：

```python
def intervalIntersection(A, B):
    i = 0  # 小明的指针
    j = 0  # 小红的指针
    ans = []
    
    # 只要两个人都还有没看完的时间段
    while i < len(A) and j < len(B):
        # 1. 求共同有空的交集：人到齐才开始(max)，有人走就结束(min)
        start = max(A[i][0], B[j][0])
        end = min(A[i][1], B[j][1])
        
        # 2. 如果开始时间 <= 结束时间，说明真的碰上面了
        if start <= end:
            ans.append([start, end])
            
        # 3. 谁先结束，谁翻篇！
        if A[i][1] < B[j][1]:
            i += 1  # A[i] 已经结束了，去看小明的下一段
        else:
            j += 1  # B[j] 已经结束了，去看小红的下一段
            
    return ans


# 测试数据
A = [[0, 2], [5, 10], [13, 23], [24, 25]]
B = [[1, 5], [8, 12], [15, 24], [25, 26]]

print(intervalIntersection(A, B))
# 输出: [[1, 2], [5, 5], [8, 10], [15, 23], [24, 24], [25, 25]]
```

---

### 一句话总结

1. **两段交集**：`[max(起点), min(终点)]`（人齐才开始，有人走就散）。
2. **指针推进**：比一下谁的终点更小，**先结束的那个走人**。
