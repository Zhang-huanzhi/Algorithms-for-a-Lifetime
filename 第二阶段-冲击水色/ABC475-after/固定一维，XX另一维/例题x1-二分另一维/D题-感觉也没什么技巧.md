### D - Automat

时间限制: 2 秒 / 内存限制: 1024 MiB  
分值: 425 分

#### 题目描述
在 AtCoder 王国中，流通着两种面额的纸币：$1$ 美元纸币和 $K$ 美元纸币。

在 AtCoder 王国的 J 公司全自动食堂里，售卖甜点和饮料两种商品。

食堂里有一台售卖 $N$ 种甜点的甜点自动售货机，和一台售卖 $M$ 种饮料的饮料自动售货机。甜点的编号为 $1$ 到 $N$，饮料的编号为 $1$ 到 $M$。

甜点 $i$ 的售价为 $A_i$ 美元，饮料 $j$ 的售价为 $B_j$ 美元。

两台机器的支付与找零规则如下：
- **甜点自动售货机**：既接受 $1$ 美元纸币，也接受 $K$ 美元纸币。
- **饮料自动售货机**：**只接受** $K$ 美元纸币（不接受 $1$ 美元纸币）。
- **找零规则**：两台售货机找零时，**都只找回 $1$ 美元纸币**。
- 同一种商品**最多只能购买一次**。

高桥君带着 $X$ 张 $1$ 美元纸币和 $Y$ 张 $K$ 美元纸币来到了食堂。

请计算高桥君用手头的纸币最多能够购买多少件商品（甜点和饮料的总数量）。

#### 限制条件
- $1 \le N \le 2 \times 10^5$
- $1 \le M \le 2 \times 10^5$
- $2 \le K \le 10^9$
- $0 \le X \le 10^{15}$
- $0 \le Y \le 10^9$
- $1 \le A_i \le 10^9 \ (1 \le i \le N)$
- $1 \le B_j \le 10^9 \ (1 \le j \le M)$
- 所有输入均为整数

---

#### 输入格式
输入从标准输入按以下格式给出：

$$N\quad M\quad K$$
$$X\quad Y$$
$$A_1\quad A_2\quad \dots\quad A_N$$
$$B_1\quad B_2\quad \dots\quad B_M$$

#### 输出格式
输出一个整数，表示最多可以购买的商品数量。

4. 投入 22 张 1 美元纸币购买甜点 1，找零 0 美元。

无法购买超过 4 件商品，因此答案为 4。

# AC Code 二分&前缀和
``` python
import sys
from bisect import bisect_left, bisect_right


def main():

    n, m, k = map(int, sys.stdin.readline().strip().split())

    x, y = map(int, sys.stdin.readline().strip().split())

    arr = list(map(int, sys.stdin.readline().strip().split()))
    brr = list(map(int, sys.stdin.readline().strip().split()))

    # 这个数据范围，看上去不可能是动归了
    # 既然是最大熟数量，肯定是买小的呗。肯定需要优先考虑饮料，但全用y来买饮料，感觉这种贪心肯定不能成立

    arr.sort()
    brr.sort()
    crr = []
    cx, cy = x, y
    for i in range(m):

        if cy * k > brr[i]:

            if brr[i] % k != 0:
                cy -= brr[i] // k + 1
                cx += (brr[i] // k + 1) * k - brr[i]
            else:
                cy -= brr[i] // k
        else:
            break

        crr.append((cx, cy))

    pre = [0] * (n + 1)
    for i in range(n):
        pre[i + 1] = pre[i] + arr[i]
    
    # 默认全买饮料
    ans = bisect_right(pre, x + y * k) - 1
    for i in range(len(crr)):

        cx, cy = crr[i]

        if i > 0 and crr[i] == crr[i - 1]:
            break

        num  = cx + (cy * k)

        # 看看num可以买多少个a
        cnt = bisect_right(pre, num) - 1

        ans = max(ans, cnt + i + 1)

    print(ans)

if __name__ == "__main__":
    main()
```
