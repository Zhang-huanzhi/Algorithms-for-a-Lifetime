**“固定一维，二分另一维”**（Fix one dimension, binary search the other）是算法竞赛和高频面试题中**极其经典且威力巨大**的一种解题范式（Paradigm）。

它的本质是：**利用“单调性”，将 $O(N \times M)$ 的二维暴力枚举，降维优化到 $O(N \log M)$。**

---

### 一、 核心思想：从“平面地毯式搜索”到“精准雷达定位”

假设一个问题有两个互相影响的决定变量 $(x, y)$，我们需要找满足条件的最优组合：

1. **暴力搜索（$O(N \times M)$）**：
   - 先循环枚举 $x$（$N$ 种可能）；
   - 在里面再循环枚举 $y$（$M$ 种可能）。
   - **痛点**：当 $N, M \approx 2 \times 10^5$ 时，总运算量是 $4 \times 10^{10}$，必定超时（TLE）。

2. **固定一维，二分另一维（$O(N \log M)$）**：
   - **“固定一维”**：我们外层依然枚举 $x$。此时 $x$ 的值确定了，相当于把一个**二维动态问题**变成了一个**一维静态问题**。
   - **“二分另一维”**：由于 $y$ 具有某种**单调性**（例如选的越多花费越多），我们**不需要**一个个去试 $y$，而是直接通过**二分查找**在 $O(\log M)$ 的时间内精准定位到最合适的 $y$。
   - **效果**：运算量瞬间从 $4 \times 10^{10}$ 骤降到 $2 \times 10^5 \times 18 \approx 3.6 \times 10^6$ 次操作，耗时不到 0.05 秒！

---

### 二、 结合本题看：这个技巧是如何落地的？

在这道题中，我们的目标是最大化商品数 $m + n$：
- 变量 1（$m$）：买了前 $m$ 个饮料；
- 变量 2（$n$）：买了前 $n$ 个甜点。

#### 步骤演示：
1. **固定一维（$m$）**：
   - 我们用一个 `for` 循环遍历买饮料的数量 $m = 0, 1, 2, \dots, M$。
   - 一旦 $m$ 固定了，买饮料花掉的钱就确定了，**剩下可以用来买甜点的钱 $\text{rem}$ 就变成了一个固定常数**。

2. **二分另一维（$n$）**：
   - 现在问题变成：“手头有 $\text{rem}$ 元，最便宜的甜点单价依次为 $A_1, A_2, \dots, A_N$，最多能买前几个？”
   - 甜点前缀和数组 `pre` 是**严格单调递增**的（买 $1$ 个花的钱 $<$ 买 $2$ 个 $<$ 买 $3$ 个……）。
   - 这就满足了二分的前提！我们直接用 `bisect_right(pre, rem) - 1`，在 $O(\log N)$ 时间内就能算出最大的 $n$。

```python
# 代码体现：
for m in range(M + 1):  # 1. 固定一维：固定饮料买 m 个
    rem = total_money - cost_B[m]  # 算出剩下的钱

    # 2. 二分另一维：在甜点前缀和上二分查找最多买 n 个
    n = bisect_right(pre_A, rem) - 1

    ans = max(ans, m + n)  # 更新全局最优解
```

### 三、 这个技巧的使用条件（什么时候能用？）

当你遇到一道最优化或计数问题，且具备以下 **3 个特征** 时，立刻要想到这个技巧：

1. **有两个独立的决策变量** $(i, j)$ 或 $(m, n)$。
2. **当确定其中一个变量后，另一个变量的合法性/代价具有「单调性」**：
   - 比如：选的物品越多，总价值越大/总花费越大；
   - 比如：右端点往右移，区间和必然变大。
3. **可以通过「前缀和」或类似工具在 $O(1)$ 或 $O(\log N)$ 内验证状态**。

### 四、 常见应用场景（举一反三）

| 场景类型 | 问题描述 | 如何“固定一维，二分另一维” |
| :--- | :--- | :--- |
| **两类物品搭配**（本题） | 选 $m$ 个 A 类物品和 $n$ 个 B 类物品，求满足预算的最大数量。 | **固定** A 类物品数量 $m$，**二分** B 类物品前缀和找最大 $n$。 |
| **两数之和/差变形** | 给定数组，求满足 $A[j] - A[i] \le K$ 的最长区间 $[i, j]$。 | **固定**左端点 $i$，在有序数组中**二分**寻找最远合法的右端点 $j$。 |
| **三数之和（3Sum）** | 在数组中寻找 $A[i] + A[j] + A[k] = 0$。 | **固定**前两维 $i, j$，在剩下的有序数组中**二分**寻找 $-(A[i]+A[j])$（或固定一维双指针）。 |
| **子矩阵最大和** | 在二维矩阵中找面积最大且和不超过 $K$ 的子矩阵。 | **固定**子矩阵的上下边界（转为一维），**二分**左右边界。 |

### 五、 进阶补充：二分与双指针的关系

值得一提的是，**“双指针（尺取法）”往往是“二分另一维”的极致优化版**：
- 如果当你把一维 $m$ 逐渐增大时，通过二分找到的最优解 $n$ **也单调递减（不会反复横跳）**；
- 那么你甚至不需要每次都从头二分（$O(\log N)$），直接让 $n$ 指针从上一次的位置往左退即可；
- 这样复杂度会进一步从 $O(M \log N)$ 优化到极致的线性 $O(M + N)$。
