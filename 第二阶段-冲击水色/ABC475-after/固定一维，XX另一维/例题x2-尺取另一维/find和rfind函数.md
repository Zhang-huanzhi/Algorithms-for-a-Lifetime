这两个都是 Python 打算法竞赛（如 AtCoder、Codeforces）时非常高频、好用的“省代码 + 防 Bug”技巧，简要总结如下：

---

### 1. `s = ' ' + sys.stdin.readline().strip()`

这句话其实包含**两个技巧**：

#### ① 为什么用？
1. **`sys.stdin.readline().strip()`（快读 + 去换行）**
   - `sys.stdin.readline()` 比 `input()` 快很多，读入大量数据时能防止超时（TLE）。
   - 但它会把行末的 `\n`（换行符）一起读进来，所以必须用 `.strip()` 去掉首尾空白和换行符。
2. **`' ' + ...`（哨兵位 / 转为 1-based 下标）**
   - **对齐题目公式**：算法题的下标通常从 $1$ 开始（$S_1 \dots S_N$），前面拼一个空格占住 `0` 号位，就能直接用 `s[1]` 到 `s[N]`，省去无数 `+1`、`-1` 的脑力转换。
   - **防止 Python 负数下标隐蔽 Bug**：在 Python 里，如果下标不小心减成了 `-1`，不会报错，而是会偷偷取到**最后一个字符**！加个空格占位后，即使访问 `s[1-1]` 也是安全的 `' '`（哨兵），不会绕回末尾。

#### ② 怎么用？
- **字符串**：`s = ' ' + sys.stdin.readline().strip()`（选一个题目绝对不会出现的字符，如空格 `' '` 或 `'#'`）。
- **数组/列表**：`a = [0] + list(map(int, sys.stdin.readline().split()))`。
- **注意**：如果题目输入的字符串本身允许包含**前导/尾随空格**，不能用 `.strip()`，要改用 `.rstrip('\r\n')`（只去换行不去空格）。

---

### 2. `s.find()` 和 `s.rfind()`

#### ① 为什么用？
1. **写法极简**：一行代替 `for` 循环遍历找“首次/末次出现位置”。
2. **速度极快**：Python 的字符串内置方法底层是 C 语言实现的，在 $3 \times 10^5$ 长度的字符串里找字符，比你自己写 Python `for` 循环快得多。
3. **配合 `' ' + s` 刚刚好**：因为索引 `0` 是空格，所以找到的直接就是 **1-based 下标**。
4. **比 `index()` 安全**：找不到时返回 `-1`，不会直接报错（`index()` 找不到会抛 `ValueError` 导致程序崩溃 RE）。

#### ② 怎么用？
- `s.find(sub)`：从左往右找，返回 `sub` **第一次**出现的下标；找不到返回 `-1`。
- `s.rfind(sub)`：从右往左找（`r` = reverse/right），返回 `sub` **最后一次**出现的下标；找不到返回 `-1`。
- **进阶用法**：还可以指定搜索区间 `s.find(sub, start, end)`（在 `[start, end)` 范围内找）。
- **避坑点**：
  - 使用前必须确认目标一定存在（比如先 `if 'A' not in s:` 特判），否则返回值 `-1` 混进 `min()` 或下标计算里会得出错误结果。
  - 这两个方法只属于**字符串（`str`）**，**列表（`list`）没有** `.find()` 方法！
