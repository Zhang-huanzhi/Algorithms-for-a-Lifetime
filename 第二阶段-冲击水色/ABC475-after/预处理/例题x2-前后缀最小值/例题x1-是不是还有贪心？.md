### D - Back and Forth Distance

运行时间限制: 2 秒 / 内存限制: 1024 MiB  
分值: 400 分

#### 题目描述

有 $N$ 个格子排成一条直线，从左到右依次编号为 $1, 2, \dots, N$。

当你位于格子 $i$ 时，可以进行以下任意一种移动：

- 选择一个满足 $1 \le j < i$ 的整数 $j$，移动到格子 $j$。该移动的代价为 $L_i$。
- 选择一个满足 $i < j \le N$ 的整数 $j$，移动到格子 $j$。该移动的代价为 $R_i$。

现给出 $Q$ 次询问，请对每次询问作答。每次询问的格式如下：

- 给出整数 $s, t$。求从格子 $s$ 开始，经过若干次移动到达格子 $t$ 所需的最小总代价。

#### 数据范围

- $2 \le N \le 3 \times 10^5$
- $1 \le Q \le 3 \times 10^5$
- $1 \le L_i \le 10^9 \quad (2 \le i \le N)$
- $1 \le R_i \le 10^9 \quad (1 \le i \le N - 1)$
- 对于每次询问，$1 \le s, t \le N$
- 对于每次询问，$s \ne t$
- 输入的所有数值均为整数

#### 输入格式

输入通过标准输入给出，格式如下：

> $N$ $Q$  
> $L_2$ $L_3$ $\dots$ $L_N$  
> $R_1$ $R_2$ $\dots$ $R_{N-1}$  
> $\text{query}_1$  
> $\text{query}_2$  
> $\vdots$  
> $\text{query}_Q$  

其中，$\text{query}_i$ 表示第 $i$ 次询问，格式如下：

> $s$ $t$

#### 输出格式

输出共 $Q$ 行。  
第 $i$ 行输出第 $i$ 次询问的答案。

---

#### 样例 1

**输入**
```text
5 7
5 6 2 9
3 1 3 8
1 2
2 1
2 4
3 2
3 5
4 3
5 2
```

**输出**
```text
3
3
1
5
3
2
9
```

**样例解释**

关于第 1、2 个询问：
- 在第 1 个询问中，直接从格子 $1$ 移动到格子 $2$，总代价为 $R_1 = 3$，这是可能达到的最小总代价。
- 在第 2 个询问中，先从格子 $2$ 移动到格子 $4$，再从格子 $4$ 移动到格子 $1$，总代价为 $R_2 + L_4 = 1 + 2 = 3$，这是可能达到的最小总代价。

# AC Code
``` python
import sys  
import math  
  
def main():  
  
    n, q = map(int, sys.stdin.readline().strip().split())  
  
    lrr = [math.inf, math.inf] + list(map(int, sys.stdin.readline().strip().split()))  
    rrr = [math.inf] + list(map(int, sys.stdin.readline().strip().split())) + [math.inf]  
  
    arr = [math.inf] * (n +  1)  
    for i in range(1, n + 1):  
        arr[i] = min(arr[i - 1], rrr[i])  
  
    brr = [math.inf] * (n + 2)  
    for i in range(n, 0, -1):  
        brr[i] = min(brr[i + 1], lrr[i])  
  
    outs = []  
    for _ in range(q):  
        s, t = map(int, sys.stdin.readline().strip().split())  
  
        if s < t:  
            outs.append(min(rrr[s], lrr[s] + arr[s - 1]))  
  
        else:  
            outs.append(min(lrr[s], rrr[s] + brr[s + 1]))  
  
    sys.stdout.write('\n'.join((map(str, outs))))  
  
if __name__ == "__main__":  
    main()
```
