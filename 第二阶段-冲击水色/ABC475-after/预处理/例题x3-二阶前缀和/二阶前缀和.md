### 什么是二阶前缀和？

简单来说：**“前缀和的前缀和”** 就是二阶前缀和。

如果说：
- **普通前缀和（一阶）** 是为了在 $O(1)$ 时间内求出 **原数组一段区间的元素和**；
- 那么 **二阶前缀和** 就是为了在 $O(1)$ 时间内求出 **“前缀和数组”的一段区间的和**，或者求某种**带有“线性递增权重”的求和式**。

---

### 一、数学推导与展开

设原数组为 $A = [A_1, A_2, A_3, \dots, A_n]$（下标从 1 开始）。

#### 1. 一阶前缀和 $S$
$$S_k = \sum_{i=1}^k A_i = A_1 + A_2 + \dots + A_k$$

#### 2. 二阶前缀和 $SS$（对 $S$ 再求一次前缀和）
$$SS_m = \sum_{k=1}^m S_k = S_1 + S_2 + S_3 + \dots + S_m$$

我们把每个 $S_k$ 展开看一下：
$$\begin{aligned}
S_1 &= A_1 \\
S_2 &= A_1 + A_2 \\
S_3 &= A_1 + A_2 + A_3 \\
&\dots \\
S_m &= A_1 + A_2 + A_3 + \dots + A_m
\end{aligned}$$

把它们全部竖着加起来，统计每一个 $A_i$ 到底被加了多少次：
- $A_1$ 出现了 $m$ 次
- $A_2$ 出现了 $m - 1$ 次
- $A_3$ 出现了 $m - 2$ 次
- ……
- $A_m$ 出现了 $1$ 次

于是得到二阶前缀和的**展开通项公式**：
$$SS_m = \sum_{i=1}^m (m - i + 1) \cdot A_i$$

> **直观理解**：二阶前缀和就是对原数组 $A$ 的前 $m$ 项做**加权求和**，权重从 $m$ 一路递减到 $1$。

---

### 二、二阶前缀和的代码实现

二阶前缀和的计算非常直观，只需要做两次单层循环即可，时间复杂度 $O(N)$：

```python
# 原数组 A (大小为 n)
A = [1, 10, 100, 1000]
n = len(A)

# 1. 计算一阶前缀和 pre1
pre1 = [0] * (n + 1)
for i in range(n):
    pre1[i + 1] = pre1[i] + A[i]
# pre1 = [0, 1, 11, 111, 1111]

# 2. 计算二阶前缀和 pre2 (对 pre1 做前缀和)
pre2 = [0] * (n + 1)
for i in range(1, n + 1):
    pre2[i] = pre2[i - 1] + pre1[i]
# pre2 = [0, 1, 12, 123, 1234]
```

### 三、二阶前缀和常见的 3 大应用场景

#### 场景 1：金字塔/三角形结构的拼接求和（即本题模型）
当一个序列是由原序列的各个前缀依次拼接而成时：
$$B = \underbrace{(A_1)}_{\text{第 1 块}}, \underbrace{(A_1, A_2)}_{\text{第 2 块}}, \underbrace{(A_1, A_2, A_3)}_{\text{第 3 块}}, \dots$$
- 第 $1$ 块的和就是 $S_1$；
- 第 $2$ 块的和就是 $S_2$；
- 第 $m$ 块的和就是 $S_m$；
- **前 $m$ 个整块的所有元素之和**，自然就是：
  $$S_1 + S_2 + \dots + S_m = SS_m$$
这就是为什么本题能够直接用 `pre2[m]` 拿到前 $m$ 块的总和。

#### 场景 2：计算形如 $\sum (i \cdot A_i)$ 的带权区间和
在很多题目中会遇到带有下标权重的求和，比如：
$$\sum_{i=1}^m i \cdot A_i$$
利用二阶前缀和的展开式：
$$SS_m = \sum_{i=1}^m (m - i + 1) \cdot A_i = (m + 1)\sum_{i=1}^m A_i - \sum_{i=1}^m i \cdot A_i = (m+1)S_m - \sum_{i=1}^m i \cdot A_i$$
移项后可以得到：
$$\sum_{i=1}^m i \cdot A_i = (m + 1)S_m - SS_m$$
**结论**：求带系数 $i$ 的加权和，可以通过一阶和二阶前缀和在 $O(1)$ 时间内快速算出。

#### 场景 3：二阶差分数组的原数组还原
- 如果有一类区间修改操作是：给区间 $[L, R]$ 加上一个**等差数列**（例如依次加上 $1, 2, 3, \dots$）；
- 这种操作在一阶差分下还是复杂的，但在**二阶差分**下只需要修改 $O(1)$ 个离散点；
- 最后从二阶差分还原到最终数组时，就需要连续做**两次前缀和**（即二阶前缀和）。

###  类比微积分，建立直觉

| 离散（算法竞赛）       | 连续（高等数学/物理）                   | 形象与直观理解        |
| :------------- | :---------------------------- | :------------- |
| **原数组 $A$**    | 加速度 $a(t)$                    | 每一个离散位置的基础数值   |
| **一阶前缀和 $S$**  | 速度 $v(t) = \int a(t)\,dt$     | 累计求和了一次（一次积分）  |
| **二阶前缀和 $SS$** | 位移 $s(t) = \iint a(t)\,dt^2$  | 累计求和了两次（二次积分）  |
| **一阶差分**       | 速度对时间求导 $\frac{dv}{dt}$       | 相邻两项做一次差（一次微分） |
| **二阶差分**       | 位移对时间求二阶导 $\frac{d^2s}{dt^2}$ | 连续做两次差（二次微分）   |


当问题出现**“累加之和”**、**“三角形/梯形面积累加”**、**“等差数列加权”** 时，几乎都可以联想到**二阶前缀和**。
