### C - Second Choice Election

**运行时间限制：** 2 秒 / **内存限制：** 1024 MiB  
**分值：** 300 分

#### 题目描述

AtCoder 村即将举行投票选举新村长。  
共有 $N$ 位候选人，分别编号为候选人 $1$，候选人 $2$，$\dots$，候选人 $N$。

共有 $M$ 位选民，其中第 $i$ 位选民（$1 \le i \le M$）的第一志愿是候选人 $A_i$，第二志愿是候选人 $B_i$。

当恰好有一名候选人退出选举时，每位选民将按以下规则进行投票：
- 若自己的第一志愿候选人**没有退选**，则投票给第一志愿候选人。
- 若自己的第一志愿候选人**退选了**，则投票给第二志愿候选人。

在未退选的候选人中，得票数最多的候选人当选。若得票数最多的候选人有多位，则**编号最小**的候选人当选。

请对 $k = 1, 2, \dots, N$ 的每一个情况，求出仅有候选人 $k$ 退选时当选的候选人编号。

---

#### 数据范围与限制

- $2 \le N \le 2 \times 10^5$
- $1 \le M \le 2 \times 10^5$
- $1 \le A_i, B_i \le N$
- $A_i \neq B_i$
- 所有输入均为整数。

---

#### 输入格式

输入由标准输入以如下格式给出：

$$
\begin{matrix}
N & M \\
A_1 & B_1 \\
A_2 & B_2 \\
\vdots & \vdots \\
A_M & B_M
\end{matrix}
$$

---

#### 输出格式

输出共 $N$ 行。  
第 $i$ 行输出仅有候选人 $i$ 退选时最终当选的候选人编号。

---

#### 样例 1

**输入**
```text
5 6
1 3
1 3
2 1
2 1
3 4
4 2
```

**输出**
```text
3
1
1
2
1
```

**样例说明**

当仅有候选人 $1$ 退选时，各选民的投票情况如下：
- 选民 $1$ 的第一志愿候选人退选了，因此投票给第二志愿候选人 $3$。
- 选民 $2$ 的第一志愿候选人退选了，因此投票给第二志愿候选人 $3$。
- 选民 $3$ 的第一志愿候选人没有退选，因此投票给第一志愿候选人 $2$。
- 选民 $4$ 的第一志愿候选人没有退选，因此投票给第一志愿候选人 $2$。
- 选民 $5$ 的第一志愿候选人没有退选，因此投票给第一志愿候选人 $3$。
- 选民 $6$ 的第一志愿候选人没有退选，因此投票给第一志愿候选人 $4$。

因此最终得票数为：候选人 $2$ 得 $2$ 票，候选人 $3$ 得 $3$ 票，候选人 $4$ 得 $1$ 票。此时得票最多的候选人 $3$ 当选。

当其他候选人退选时的当选情况分别如下：
- 仅候选人 $2$ 退选时，候选人 $1$ 得 $4$ 票，候选人 $3$ 得 $1$ 票，候选人 $4$ 得 $1$ 票，得票最多的候选人 $1$ 当选。
- 仅候选人 $3$ 退选时，候选人 $1$ 得 $2$ 票，候选人 $2$ 得 $2$ 票，候选人 $4$ 得 $2$ 票，得票最多的候选人中编号最小的候选人 $1$ 当选。
- 仅候选人 $4$ 退选时，候选人 $1$ 得 $2$ 票，候选人 $2$ 得 $3$ 票，候选人 $3$ 得 $1$ 票，得票最多的候选人 $2$ 当选。
- 仅候选人 $5$ 退选时，候选人 $1$ 得 $2$ 票，候选人 $2$ 得 $2$ 票，候选人 $3$ 得 $1$ 票，候选人 $4$ 得 $1$ 票，得票最多的候选人中编号最小的候选人 $1$ 当选。

因此按顺序逐行输出 `3, 1, 1, 2, 1`。


# AC Code
``` python
import sys  
  
def main():  
  
    n, m = map(int, sys.stdin.readline().strip().split())  
  
    arr = []  
    brr = [ [] for _ in range(n + 1)]  
    crr = [0] * (n + 1)  
    for _ in range(m):  
        a, b = map(int, sys.stdin.readline().strip().split())  
  
        arr.append((a, b))  
        brr[a].append(b)  
        crr[a] += 1  
  
    order = sorted(range(1, n + 1), key= lambda x:(-crr[x], x))  
    top1 = order[0]  
    top2 = order[1]  
  
    outs = []  
    for k in range(1, n + 1):  
  
        for b in brr[k]:  
            crr[b] += 1  
  
        candidates = set(brr[k])  
        if top1 != k:  
            candidates.add(top1)  
        if top2 != k:  
            candidates.add(top2)  
  
        winner = max(candidates, key=lambda x: (crr[x], -x))  
        outs.append(winner)  
  
        for b in brr[k]:  
            crr[b] -= 1  
  
    print("\n".join(map(str, outs)))  
if __name__ == "__main__":  
    main()
```
