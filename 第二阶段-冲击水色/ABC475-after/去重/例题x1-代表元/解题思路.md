为了让你从头到尾彻底理顺这道题，我们模拟一次**“拿到题目后从零开始的完整思考过程”**，并用样例 1 把所有情况全部列出来验证。

---

### 第一步：读懂操作，把动作画面化

题目的操作分两步：选一个位置 $r$（原题记为 $i$），把它抽出来，插到它自己或前面的某个位置 $l$（原题记为 $j$，$1 \le l \le r$）。

我们可以把它分成两种截然不同的结果：
1. **不动（$l = r$）**：抽出来再放回原位，序列和原来一模一样（$B = A$）。
2. **往左插（$l < r$）**：把 $A_r$ 放到第 $l$ 位，原本 $[l, r-1]$ 里的所有数全体向右平移一格：
   ```text
   原序列 A:  ...  [ A_l   A_{l+1}  ...  A_{r-1}  A_r ]  ...
   新序列 B:  ...  [ A_r   A_l      ...  A_{r-2}  A_{r-1} ]  ...
   ```

---

### 第二步：面对“计数去重”的难点

总共有多少种选 $(l, r)$ 的方案？大概有 $\frac{N^2}{2}$ 种。
由于 $N \le 2 \times 10^5$：
1. 我们不可能暴力模拟出所有序列放进集合（`set`）去重，必须用数学方法直接统计数量。
2. 直接算 $\frac{N(N-1)}{2} + 1$ 是错的，因为**不同的 $(l, r)$ 可能会变出完全相同的序列**（比如样例 2 `1 1 1 1 1`，无论怎么移都只有 1 种结果）。

**核心问题就变成了：怎么数，才能让每一种可能得到的新序列，恰好只被算到 1 次？**

---

### 第三步：破局关键——只看“真正发生变化的边界”

把任意一个合法结果序列 $B$ 拿来和原序列 $A$ 逐位对比：

* **情况 1：$B = A$（没有变化）**
  只要选择 $l = r$ 就能得到，所以原序列 $A$ 永远是可达的，固定占 **$1$ 种**。

* **情况 2：$B \ne A$（至少有一处不同）**
  既然 $B$ 和 $A$ 不一样，那我们一定能从左到右找到：
  * $A$ 和 $B$ 不同的**最左边的位置**，记为 $m$；
  * $A$ 和 $B$ 不同的**最右边的位置**，记为 $M$。（显然 $m < M$，因为只移动一张牌不可能只改 1 个位置）

现在问一个关键问题：**如果某次操作 $(l, r)$ 变出了 $B$，那么 $(l, r)$ 和 $[m, M]$ 是什么关系？**

1. 因为 $[l, r]$ 外面的元素根本没动过，所以发生变化的位置一定都在 $[l, r]$ 里面，即 **$l \le m < M \le r$**。
2. 如果 $l < m$（或者 $M < r$），说明你操作的区间**扯得太宽了**，把根本没发生改变的边界也包进去了：
   * **左边扯宽了（$l < m$）**：这意味着第 $l$ 位其实没变（$B_l = A_l$），而 $B_l$ 是由 $A_r$ 移过来的，说明 **$A_r = A_l$**。甚至如果 $l+1 < m$，第 $l+1$ 位也没变，说明 $A_{l+1} = B_{l+1} = A_l = A_r$……一路推过去，$A_l, A_{l+1}, \dots, A_{m-1}$ 全都等于 $A_r$！
     $\rightarrow$ 也就是说，你把 $A_r$ 插到这一串相同的数前面，和直接插到 $m$ 位置，得到的序列**完全相同**！
   * **右边扯宽了（$M < r$）**：这意味着第 $r$ 位其实没变（$B_r = A_r$），而 $B_r$ 是被 $A_{r-1}$ 挤过去顶替的，说明 **$A_{r-1} = A_r$**。一路推回去，$A_M, A_{M+1}, \dots, A_r$ 全都相等！
     $\rightarrow$ 也就是说，你拿第 $r$ 个数往左移，和拿第 $M$ 个数往左移，得到的序列**完全相同**！

**由此得出一个极其漂亮的结论：**
> **每一个发生改变的新序列 $B$，都一定能——且只能唯一地——由对其“实际变化区间 $[m, M]$”的操作得到！**

我们不需要去数那些“扯宽了”的多余操作，只需要数**“左右两端点都真正发生了改变”**的操作 $(l, r)$（即恰好 $l = m$ 且 $r = M$ 的操作）：
* 左端点改变 $\iff B_l \ne A_l \iff$ **$A_r \ne A_l$**
* 右端点改变 $\iff B_r \ne A_r \iff$ **$A_{r-1} \ne A_r$**

因为任何两个不同的 $(l, r)$ 对应着不同的“变化边界 $[m, M]$”，所以它们变出来的新序列 $B$ **绝对不会重复**，也**绝对不会遗漏**！

### 第四步：用样例 1 把所有情况亲手“走”一遍

来看样例 1：`N = 6`，`A = [1, 4, 1, 4, 2, 1]`。
我们按照上述两条条件：**$A_r \ne A_{r-1}$** 且 **$A_l \ne A_r$**，把每个 $r$ 能配对的 $l$ 全部列出来：

* **情况 1：不动（$B = A$）**
  * `(1, 4, 1, 4, 2, 1)` $\longrightarrow$ **1 个**

* **情况 2：枚举 $r$ 从 2 到 6**
  * **$r = 2$**（$A_2 = 4 \ne A_1 = 1$，右端合法）：
    * $l = 1$ ($A_1=1 \ne 4$) $\rightarrow$ `(4, 1, 1, 4, 2, 1)`
    * **贡献 1 个**
  * **$r = 3$**（$A_3 = 1 \ne A_2 = 4$，右端合法）：
    * ~~$l = 1$ ($A_1=1 = 1$)~~：跳过！因为把第 3 位的 `1` 插到第 1 位或第 2 位，都会得到 `(1, 1, 4, 4, 2, 1)`，由 $l=2$ 统一代表。
    * $l = 2$ ($A_2=4 \ne 1$) $\rightarrow$ `(1, 1, 4, 4, 2, 1)`
    * **贡献 1 个**
  * **$r = 4$**（$A_4 = 4 \ne A_3 = 1$，右端合法）：
    * $l = 1$ ($A_1=1 \ne 4$) $\rightarrow$ `(4, 1, 4, 1, 2, 1)`
    * ~~$l = 2$ ($A_2=4 = 4$)~~：跳过！与 $l=3$ 结果相同，由 $l=3$ 代表。
    * $l = 3$ ($A_3=1 \ne 4$) $\rightarrow$ `(1, 4, 4, 1, 2, 1)`
    * **贡献 2 个**
  * **$r = 5$**（$A_5 = 2 \ne A_4 = 4$，右端合法）：
    * $l = 1, 2, 3, 4$ 全都不等于 $2$：
      * $l=1 \rightarrow$ `(2, 1, 4, 1, 4, 1)`
      * $l=2 \rightarrow$ `(1, 2, 4, 1, 4, 1)`
      * $l=3 \rightarrow$ `(1, 4, 2, 1, 4, 1)`
      * $l=4 \rightarrow$ `(1, 4, 1, 2, 4, 1)`
    * **贡献 4 个**
  * **$r = 6$**（$A_6 = 1 \ne A_5 = 2$，右端合法）：
    * ~~$l = 1$ ($A_1=1 = 1$)~~：跳过！与 $l=2$ 相同。
    * $l = 2$ ($A_2=4 \ne 1$) $\rightarrow$ `(1, 1, 4, 1, 4, 2)`
    * ~~$l = 3$ ($A_3=1 = 1$)~~：跳过！与 $l=4$ 相同。
    * $l = 4$ ($A_4=4 \ne 1$) $\rightarrow$ `(1, 4, 1, 1, 4, 2)`
    * $l = 5$ ($A_5=2 \ne 1$) $\rightarrow$ `(1, 4, 1, 4, 1, 2)`
    * **贡献 3 个**

总数：$1 + 1 + 1 + 2 + 4 + 3 = 12$ 个，跟题目样例输出列的 12 个序列**一模一样，一个不多，一个不少**！

### 第五步：将思路优化为 $O(N)$ 算法

现在我们不需要真的构造出这些序列，只需要数出每个 $r$ 贡献了几个 $l$：

1. 答案初始值 `ans = 1`（代表原序列 $A$）。
2. 用一个数组 `cnt[x]` 记录**在当前位置 $r$ 之前**，数字 `x` 一共出现了多少次。
3. 从左到右遍历 $r$（1-based 下标从 $2$ 到 $N$）：
   * 如果 $A_r \ne A_{r-1}$：
     在 $r$ 左边总共有 $r - 1$ 个位置，减去其中值等于 $A_r$ 的位置个数 `cnt[A[r]]`，剩下的就是所有满足 $A_l \ne A_r$ 的合法 $l$ 的数量：
     $$\text{ans} \mathrel{+}= (r - 1) - \text{cnt}[A_r]$$
   * 如果 $A_r == A_{r-1}$：不累加任何贡献（贡献为 0）。
   * 最后执行 `cnt[A[r]] += 1`，继续看下一个 $r$。

---

### 第六步：边界检查与复杂度

* **特殊情况 $N = 1$**：循环不执行，直接输出 `1`，正确。
* **全部元素相等**（如样例 2）：每次都有 $A_r == A_{r-1}$，不累加任何新序列，输出 `1`，正确。
* **时间复杂度**：遍历一遍数组，每次查询和更新 `cnt` 都是 $O(1)$，总复杂度 **$O(N)$**。
* **空间复杂度**：需要大小为 $N+1$ 的计数数组，总复杂度 **$O(N)$**。
* **数值范围**：答案最大可达 $\frac{N(N-1)}{2} + 1 \approx 2 \times 10^{10}$，如果用 C++/Java 需要开 64 位整数（`long long` / `long`），Python 则无需担心溢出。
