**D - Move One Card Left**

**执行时间限制**：2 sec / **内存限制**：1024 MiB

**分值**：400 分

### 问题描述

给定一个由正整数组成的长度为 $N$ 的序列 $A = (A_1, A_2, \dots, A_N)$。

对序列 $A$ **恰好进行 $1$ 次**如下操作：

从 $A$ 中选择一个元素取出，并将其插入到剩余序列中原本所在的位置或更靠前的位置。更严格地说，按顺序执行以下 $2$ 个步骤：
1. 选择一个满足 $1 \le i \le N$ 的整数 $i$，令长度为 $N-1$ 的序列 $X = (X_1, X_2, \dots, X_{N-1})$ 为 $(A_1, A_2, \dots, A_{i-1}, A_{i+1}, A_{i+2}, \dots, A_N)$，并令整数 $Y$ 为 $A_i$。
2. 选择一个满足 $1 \le j \le i$ 的整数 $j$，将长度为 $N$ 的序列 $(X_1, X_2, \dots, X_{j-1}, Y, X_j, X_{j+1}, \dots, X_{N-1})$ 作为新的 $A$。

请注意，在插入元素时，有时可以插入到序列的最左端或最右端。

请计算作为操作结果能得到多少种不同的序列。

即使操作中选择的 $(i, j)$ 不同，只要得到的序列相等，就只计为同一种。

---

### 约束条件
- $1 \le N \le 2 \times 10^5$
- $1 \le A_i \le N \ (1 \le i \le N)$
- 所有输入均为整数

---

### 输入
输入按以下格式从标准输入给出：
```text
N
A_1 A_2 ... A_N
```

### 输出
输出答案。

---

### 样例输入 1
```text
6
1 4 1 4 2 1
```

### 样例输出 1
```text
12
```
例如，选择 $i=6, j=4$ 进行操作，可以得到 $(1,4,1,1,4,2)$。

除此之外，还可以得到以下 $11$ 种序列：
- $(1,1,4,1,4,2)$
- $(1,1,4,4,2,1)$
- $(1,2,4,1,4,1)$
- $(1,4,1,2,4,1)$
- $(1,4,1,4,1,2)$
- $(1,4,1,4,2,1)$
- $(1,4,2,1,4,1)$
- $(1,4,4,1,2,1)$
- $(2,1,4,1,4,1)$
- $(4,1,1,4,2,1)$
- $(4,1,4,1,2,1)$

因此，请输出 `12`。

---

import sys  
from collections import Counter  
  
  
def main():  
  
    n = int(sys.stdin.readline().strip())  
  
    arr = list(map(int, sys.stdin.readline().strip().split()))  
  
    # 怎么插入都不会重复吧？原地踏步？what?  
    cnt = [0] * (n + 1)  
    cnt[arr[0]] += 1  
    ans = 1  
  
    for i in range(1, n):  
        if arr[i] != arr[i - 1]:  
            ans += i - cnt[arr[i]]  
        cnt[arr[i]] += 1  
  
    print(ans)  
  
if __name__ == "__main__":  
    main()
