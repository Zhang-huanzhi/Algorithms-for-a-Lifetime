**双射（Bijection）**，通俗来说就是**“完全的一对一绑定”**（One-to-One Correspondence）。

在数学和计算机中，如果集合 $A$ 和集合 $B$ 之间存在双射关系，意味着：
1. **$A$ 中的每一个元素，都唯一对应 $B$ 中的一个元素。**
2. **$B$ 中的每一个元素，也唯一对应 $A$ 中的一个元素。**
3. **不能有“多对一”，也不能有“一对多”，更不能有落单/冲突。**

---

### 生活中的直观例子

* **是不是双射？**
  * **例子 1（是双射）：** 每个公民对应一张**唯一的身份证号**；每个身份证号也只属于**唯一的公民**。这就是双射（一对一）。
  * **例子 2（不是双射）：** 一个老师带多个学生（多对一）；或者同一个人有多个手机号（一对多）。

### 在这道题中的具体体现

题目中给出的条件是：
> $S_i = S_j \iff T_i = T_j$ （充要条件，即等价）

这个等价符号拆解开来，就是要求**字母和数字之间建立双射**：

1. **从左推到右（$S_i = S_j \implies T_i = T_j$）：同一个字母必须对应同一个数字**
   * 如果 $S$ 中第 1 位和第 3 位都是 `'c'`，那么素数 $T$ 的第 1 位和第 3 位也**必须是同一个数字**（比如都是 `1`）。
2. **从右推到左（$T_i = T_j \implies S_i = S_j$）：不同的字母绝对不能对应相同的数字**
   * 如果第 1 位是 `'m'`，第 3 位是 `'t'`，那么它们在素数里**绝不能都是数字 `8`**。

#### 结合样例 1 来看反例：
* 目标单词：$S = \text{"motor"}$
* 错误输出：$T = 81817$
  * 检查位置：第 1 位是 `'m'` 对应 `8`，第 3 位是 `'t'` 对应 `8`。
  * 出现问题：两个**不同的字母**（`m` 和 `t`）都对应了**同一个数字** `8`，这就**破坏了双射关系**，因此该输出是错误的。
* 正确输出：$T = 10607$
  * 映射关系：`m` $\leftrightarrow$ 1, `o` $\leftrightarrow$ 0, `t` $\leftrightarrow$ 6, `r` $\leftrightarrow$ 7
  * 每个字母唯一对应一个数字，每个数字也唯一对应一个字母，这就是完美的**双射**。

### 代码中如何验证“双射”？

在代码中，通常需要**开两个映射数组/哈希表**来进行双向绑定检查：

```cpp
// c2d: 记录 字母 -> 数字 的映射
// d2c: 记录 数字 -> 字母 的映射
int c2d[26], d2c[10];
memset(c2d, -1, sizeof(c2d));
memset(d2c, -1, sizeof(d2c));

bool is_bijection = true;
for (int i = 0; i < n; i++) {
    int u = S[i] - 'a'; // 字母
    int v = T[i] - '0'; // 数字

    // 检查字母 -> 数字是否冲突（一对多）
    if (c2d[u] != -1 && c2d[u] != v) is_bijection = false;
    // 检查数字 -> 字母是否冲突（多对一）
    if (d2c[v] != -1 && d2c[v] != u) is_bijection = false;

    // 建立双向绑定
    c2d[u] = v;
    d2c[v] = u;
}
```
