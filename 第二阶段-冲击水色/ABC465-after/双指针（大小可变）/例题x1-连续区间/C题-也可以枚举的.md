### C - Walk the Line

**时间限制**：2 秒 / **内存限制**：1024 MiB  
**分值**：300 分

#### 题目描述

有 $N$ 座城镇排成一条直线。城镇从 $1$ 到 $N$ 进行编号。对于每个满足 $1 \le i \le N-1$ 的整数 $i$，城镇 $i$ 与城镇 $i+1$ 之间都有一条长度为 $A_i$ 的道路相连。

你最初位于城镇 $S$。你可以沿着道路在相邻的两座城镇之间重复移动。

在你移动的总距离不超过 $L$ 的前提下，求你在整个移动过程中**最多能访问多少个不同的城镇**。  
注意：初始所在的城镇 $S$ 也算作已访问的城镇，且同一座城镇重复访问多次只计算一次。

#### 制约条件

* $2 \le N \le 8000$
* $1 \le S \le N$
* $0 \le L \le 10^{18}$
* $1 \le A_i \le 10^9$
* 输入的所有数值均为整数。

#### 输入格式

输入从标准输入给出，格式如下：

```
N S L
A_1 A_2 ... A_{N-1}
```

#### 输出格式

输出一个整数，表示最多能访问的城镇数量。

---

#### 样例 1

**输入**
```
6 3 10
5 2 4 1 6
```

**输出**
```
4
```

**样例说明 1**  
你最初在城镇 $3$。如果按照城镇 $3 \to 2 \to 3 \to 4 \to 5$ 的顺序移动，移动总距离为 $2+2+4+1=9 \le 10$。在这个过程中访问了城镇 $2, 3, 4, 5$，共 $4$ 座城镇。  
无法在总移动距离不超过 $10$ 的情况下访问 $5$ 座或更多城镇，因此答案为 $4$。
